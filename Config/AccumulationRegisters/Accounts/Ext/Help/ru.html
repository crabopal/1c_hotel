Регистр накопления "Взаиморасчеты"

Назначение

Регистр используется для ведения баланса по лицевому счету клиента

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Валюта лицевого счета. Ссылается на справочник «Валюты».
  • Лицевой счет. Ссылается на документ «Фолио».
  • Секция оплаты. Ссылается на справочник «Секции оплаты». 

Ресурсы

  • Сумма. Тип значения: «Число».
  • Сумма преавторизации. Тип значения: «Число».

Реквизиты

  • Клиент (гость). Ссылается на справочник «Клиенты (гости)».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Ресурс. Ссылается на справочник «Ресурсы».
  • Цена. Тип значения: «Число».
  • Количество. Тип значения: «Число». 
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники». 
  • Услуга. Ссылается на справочник «Услуги».
  • Ставка НДС %. Ссылается на справочник «Ставки НДС».
  • Сумма НДС. Тип значения: «Число».
  • Способ оплаты. Ссылается на справочник «Способы оплаты». 
  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение», «Состав квоты», «Фолио».
  • Это доход от продажи номеров. Тип значения: «Булево».
  • Входит в цену. Тип значения: «Булево».
  • Это доход от продажи ресурсов. Тип значения: «Булево».
  • Это преавторизация. Тип значения: «Булево».
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях».
  • Начисление. Ссылается на документ «Начисление».

Дополнительная информация

Документы, порождающие движения: «Начисление», «Перемещение депозита», «Платеж», «Преавторизация», «Возврат», «Акт», «Сторно».
