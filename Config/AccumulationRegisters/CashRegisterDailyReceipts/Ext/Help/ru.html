Регистр накопления "Выручка по кассовым сменам"

Назначение

Основной кассовый регистр, содержит данные необходимые для формирования кассовых X и Z отчетов.

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Фирма. Ссылается на справочник «Фирмы».
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины».
  • Валюта. Ссылается на справочник «Валюты».
  • Секция оплаты. Ссылается на справочник «Секции оплаты».
  • Способ оплаты. Ссылается на справочник «Способы оплаты».
  • Контрагент. Ссылается на справочник «Контрагенты».
  • Договор. Ссылается на справочник «Договоры».
  • Группа гостей. Ссылается на справочник «Группы гостей».

Ресурсы

  • Выручка. Тип значения: «Число».
  • Сумма НДС. Тип значения: «Число».
  • Сумма оплат. Тип значения: «Число».
  • Сумма НДС оплат. Тип значения: «Число».
  • Сумма возвратов. Тип значения: «Число». 
  • Сумма НДС возвратов. Тип значения: «Число».

Реквизиты

  • Плательщик. Ссылается на справочники «Клиенты (гости)», «Контрагенты».
  • Лицевой счет. Ссылается на документ «Фолио». 

Дополнительная информация

Документы, порождающие движения: «Платеж от контрагента», «Платеж», «Возврат».
