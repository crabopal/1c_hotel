Регистр накопления "Реализация за текущий отчетный период"

Назначение

Содержит текущие, не "закрытые" актами, итоги реализации услуг. Основной регистр, по которому отбирает остатки документ "Закрытие периода"

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Фирма. Ссылается на справочник «Фирмы».
  • Контрагент в фолио. Ссылается на справочник «Контрагенты».
  • Договор в фолио. Ссылается на справочник «Договоры».
  • Группа гостей. Ссылается на справочник «Группы гостей». 
  • Валюта фолио. Ссылается на справочник «Валюты».
  • Лицевой счет. Ссылается на документ «Фолио».
  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение», «Состав квоты». 
  • Начисление. Ссылается на документ «Начисление».

Ресурсы

  • Выручка. Тип значения: «Число».
  • Сумма НДС. Тип значения: «Число».
  • Количество. Тип значения: «Число».

Дополнительная информация

Документы, порождающие движения: «Начисление», «Акт», «Сторно».
