Регистр накопления "Взаиморасчеты с контрагентами"

Назначение

Используется для ведения баланса взаиморасчетов с контрагентами.

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Фирма. Ссылается на справочник «Фирмы».
  • Контрагент в бухгалтерии. Ссылается на справочник «Контрагенты».
  • Договор в бухгалтерии. Ссылается на справочник «Договоры».
  • Валюта взаиморасчетов с контрагентом. Ссылается на справочник «Валюты».
  • Группа гостей. Ссылается на справочник «Группы гостей».
  • Гостиница. Ссылается на справочник «Гостиницы». 

Ресурсы

  • Сумма. Тип значения: «Число». 

Реквизиты

  • Лицевой счет. Ссылается на документ «Фолио».
  • Клиент (гость). Ссылается на справочник «Клиенты (гости)».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Ресурс. Ссылается на справочник «Ресурсы».
  • Количество человек. Тип значения: «Число».
  • Учетная дата. Тип значения: «Дата».
  • Цена. Тип значения: «Число».
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». 
  • Услуга. Ссылается на справочник «Услуги».
  • Сумма НДС. Тип значения: «Число».
  • Количество. Тип значения: «Число».

Дополнительная информация

Документы, порождающие движения: «Распределение аванса», «Платеж от контрагента», «Платеж», «Возврат», «Акт».
