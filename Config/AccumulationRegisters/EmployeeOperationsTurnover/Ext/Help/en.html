Регистр накопления "Обороты по выполненным персоналом работам"

Назначение

Регистр используется для накопления статистики по работам сотрудников и построения аналитических отчетов, которые позволят показывать среднюю длительность выполнения работ (по сотрудникам, типам номеров и т.д.), среднюю убираемую площадь; среднее время простоя сотрудников, расходы номенклатуры (чистящих средств, белья и т.д.) и т.д.

Относится к подсистеме: «Управление службой номеров».

Измерения

  • Сотрудник. Ссылается на справочник «Сотрудники».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Работа. Ссылается на справочник «Работы».
  • Номенклатура. Ссылается на справочник «Номенклатура».
  • Единица измерения. Тип значения: «Строка».

Ресурсы

  • Счетчик работ. Тип значения: «Число».
  • Продолжительность работы в минутах. Тип значения: «Число».
  • Площадь номера. Тип значения: «Число».
  • Количество человек. Тип значения: «Число».
  • Количество номенклатуры в штуках, граммах или миллилитрах. Тип значения: «Число».

Реквизиты

  • Время начала работы. Тип значения: «Дата».
  • Время окончания работы. Тип значения: «Дата».
  • Код начала работы для телефонной АТС. Тип значения: «Число».
  • Код окончания работы для телефонной АТС. Тип значения: «Число».
  • На каждого человека (гостя). Тип значения: «Булево».
  • На единицу площади номера. Тип значения: «Булево».
  • Примечания. Тип значения: «Строка». 
  • Автор. Ссылается на справочник «Сотрудники».
