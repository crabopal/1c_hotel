Регистр накопления "Депозиты"

Назначение

Оборотный регистр по платежам по лицевым счетам. используется для формирования закладки "Платежи" при просмотре транзакций по лицевому счету

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Валюта лицевого счета. Ссылается на справочник «Валюты».
  • Лицевой счет. Ссылается на документ «Фолио».
  • Платеж. Ссылается на документ «Платеж».

Ресурсы

  • Сумма. Тип значения: «Число».
  • Сумма преавторизации. Тип значения: «Число».

Реквизиты

  • Плательщик. Ссылается на справочники «Клиенты (гости)», «Контрагенты».
  • Секция оплаты. Ссылается на справочник «Секции оплаты».
  • Способ оплаты. Ссылается на справочник «Способы оплаты».
  • Валюта платежа. Ссылается на справочник «Валюты».
  • Сумма платежа. Тип значения: «Число».
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины».
  • Примечания. Тип значения: «Строка».
  • Это преавторизация. Тип значения: «Булево».
  • Автор. Ссылается на справочник «Сотрудники».

Дополнительная информация

Документы, порождающие движения: «Перемещение депозита», «Платеж», «Преавторизация», «Возврат».
