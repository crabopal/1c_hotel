Регистр накопления "Маркированные товары"

Назначение

Аналитический регистр для сбора оборотов по маркированным товарам.

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Код маркировки. Тип значения: «Строка в Base64».

Ресурсы

  • Сумма. Тип значения: «Число». 
  • Сумма НДС. Тип значения: «Число». 
  • Количество. Тип значения: «Число». Количество услуги

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Фирма. Ссылается на справочник «Фирмы». 
  • Ставка НДС %. Ссылается на справочник «Ставки НДС».  
  • Услуга. Ссылается на справочник «Услуги».

Дополнительная информация

Документы, порождающие движения: «Платеж», «Возврат», «Начисление», «Сторно».
