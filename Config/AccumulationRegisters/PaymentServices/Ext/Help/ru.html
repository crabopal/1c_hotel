Регистр накопления "Распределение платежей по услугам"

Назначение

Регистр позволяет документу "Закрытие периода" выполнять автоматическое распределение платежей по оказанным услугам. Используется для формирования отчета по оплаченным за период услугам. Так же может использоваться процедурой загрузки платежей в бухгалтерию для определения договора, на который проводить суммы платежей.

Относится к подсистеме: «Управление взаиморасчетами».

Измерения

  • Лицевой счет. Ссылается на документ «Фолио».
  • Услуга. Ссылается на справочник «Услуги».
  • Платеж. Ссылается на документы «Акт», «Возврат», «Перемещение депозита», «Платеж».

Ресурсы

  • Сумма. Тип значения: «Число».

Дополнительная информация

Документы, порождающие движения: «Начисление», «Закрытие периода», «Перемещение депозита», «Платеж», «Возврат», «Акт», «Сторно».
