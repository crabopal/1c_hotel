Регистр накопления "Телефонные разговоры"

Назначение

Оборотный регистр хранит данные о телефонных разговорах из номеров и используется в отчетах по телефонным разговорам.

Относится к подсистеме: «Стойка администратора».

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип телефонного разговора. Ссылается на перечисление «Типы телефонных звонков».
  • Регион телефонного разговора. Тип значения: «Строка».
  • Номер телефона. Ссылается на справочник «Телефонные номера».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Услуга телефонного разговора. Ссылается на справочник «Услуги».
  • Валюта. Ссылается на справочник «Валюты». 
  • Фирма. Ссылается на справочник «Фирмы».

Ресурсы

  • Сумма в валюте документа. Тип значения: «Число».
  • Сумма услуги сбора за разговор в валюте документа. Тип значения: «Число». 
  • Количество. Тип значения: «Число». 

Реквизиты

  • Дата и время разговора. Тип значения: «Дата».
  • Номер телефона куда был звонок. Тип значения: «Строка».
  • Примечания. Тип значения: «Строка». 
  • Цена. Тип значения: «Число».
  • НДС входит в цену телефонного разговора. Тип значения: «Булево». 
  • Единица измерения. Тип значения: «Строка». 
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». 
  • Сумма НДС в валюте документа. Тип значения: «Число». 
  • Лицевой счет. Ссылается на документ «Фолио».
  • Начисление. Ссылается на документ «Начисление».
  • Услуга сбора за разговор. Ссылается на справочник «Услуги». 
  • Ставка НДС % услуги сбора за разговор. Ссылается на справочник «Ставки НДС».
  • Сумма НДС услуги сбора за разговор в валюте документа. Тип значения: «Число».
  • Начисление - сбор. Ссылается на документ «Начисление».
  • Дата курса обмена. Тип значения: «Дата». Краткое описание.
  • Курс обмена валюты документа по отношению к базовой валюте. Тип значения: «Число».
  • Автор. Ссылается на справочник «Сотрудники». Краткое описание.
