Регистр накопления "Данные отчетов по динамике продаж (Pickup/Pace reports)"

Назначение

Оборотный регистр содержит данные по прогнозу продаж номеров по брони в разрезе учетных показателей продаж гостиницы и даты и времени продажи. Этот учетный регистр используется для формирования Pickup и Pace отчетов по динамике продаж номеров.

Относится к подсистеме: «Фронт-офис».

Измерения

  • Период. Тип значения: «Дата и время». Дата и время первоначального бронирования или внесения изменений или отмены брони. 
  • Учетная дата. Тип значения: «Дата».
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице». 
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга».
  • Автор операции. Ссылается на справочник «Сотрудники».
  • Контрагент. Ссылается на справочник «Контрагенты».
  • Агент. Ссылается на справочник «Контрагенты».
  • Группа гостей. Ссылается на справочник «Группы гостей».
  • Тариф. Ссылается на справочник «Тарифы».
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Отчетная валюта. Ссылается на справочник «Валюты».
  • Фирма. Ссылается на справочник «Фирмы».
  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Это отмена. Булево. Выставляется в Истина для записей об отмене бронирования.

Ресурсы

  • Доходы от продажи номеров. Тип значения: «Число».
  • Доходы от продажи номеров без НДС. Тип значения: «Число».
  • Продано номеров. Тип значения: «Число».
  • Продано мест. Тип значения: «Число».
  • Продано дополнительных мест. Тип значения: «Число».
  • Человеко-дни. Тип значения: «Число».

Дополнительная информация

Документы, порождающие движения: «Бронь», «Размещение».
