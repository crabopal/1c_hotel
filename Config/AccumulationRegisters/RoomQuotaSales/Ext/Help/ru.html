Регистр накопления "Продажи квот номеров"

Назначение

Используется для ведения план-фактного анализа продаж номеров в квотах

Относится к подсистеме: «Продажи квот номеров».

Измерения

  • Квота номеров. Ссылается на справочник «Квоты номеров».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Номер. Ссылается на справочник «Номерной фонд».

Ресурсы

  • Номеров в квоте. Тип значения: «Число».
  • Мест в квоте. Тип значения: «Число».
  • Забронировано номеров. Тип значения: «Число».
  • Забронировано мест. Тип значения: «Число».
  • Гарантированная бронь номеров. Тип значения: «Число».
  • Гарантированная бронь мест. Тип значения: «Число».
  • Использовано номеров. Тип значения: «Число».
  • Использовано мест. Тип значения: «Число». 
  • Остается номеров. Тип значения: «Число».
  • Остается мест. Тип значения: «Число».
  • Счетчик документов ввода в квоту. Тип значения: «Число». 

Реквизиты

  • Дата и время начала периода изменения квоты. Тип значения: «Дата».
  • Продолжительность в днях. Тип значения: «Число».
  • Дата и время окончания периода изменения квоты. Тип значения: «Дата».
  • Группа гостей. Ссылается на справочник «Группы гостей».
  • Гость. Ссылается на справочник «Клиенты (гости)».
  • Тип клиента. Ссылается на справочник «Типы клиентов». 
  • Тариф. Ссылается на справочник «Тарифы».
  • Тип тарифа. Ссылается на справочник «Типы тарифов».
  • Комиссия агента. Тип значения: «Число».
  • Вид комиссии агента. Ссылается на перечисление «Виды комиссий агентам». 
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».
  • Это ввод квоты. Тип значения: «Булево».
  • Это бронирование. Тип значения: «Булево».
  • Это размещение. Тип значения: «Булево».
