Регистр накопления "Прогноз продаж"

Назначение

Оборотный регистр содержит данные по прогнозу продаж услуг по брони номеров и брони ресурсов в разрезе учетных показателей продаж гостиницы. Этот учетный регистр используется для хранения данных, которые используются для формирования прогнозных значений продаж в некоторых аналитических отчетах по продажам.

Относится к подсистеме: «Управление взаиморасчетами».

Реквизиты

  • Это сторно. Тип значения: «Булево».
  • Сумма по тарифу проживания. Тип значения: «Число». Стоимость услуги по выбранному тарифу без скидок
  • Разница между начисленной суммой и суммой по тарифу проживания. Тип значения: «Число».
  • Количество мест в номере. Тип значения: «Число». Технический реквизит, который хранит общее кол-во основных мест в номере на момент поселения гостя.
  • Количество гостей в номере. Тип значения: «Число». Технический реквизит, который хранит максимально возможное кол-во гостей в номере на момент поселения гостя.
  • Количество человек. Тип значения: «Число». Сколько гостей проживает в номере по этому размещению (если в программе регистрируются все гости, то 1, в некоторых случаях может быть 2 и более, если остальные гости в программе не регистрируются).
  • Количество номеров. Тип значения: «Число». Число проданных номеров. Определяется видом размещения. Обычно 1, если вид размещения "номер" или 0.5, если вид размещения "место", 0, если вид размещения "совместно" или "доп. место"
  • Количество мест. Тип значения: «Число». Технический реквизит. Число проданных основных мест.
  • Количество дополнительных мест. Тип значения: «Число». Число проданных дополнительных мест.
  • Тип тарифа. Ссылается на справочник «Типы тарифов».
  • Примечание. Тип значения: «Строка». Примечание к услуге.
