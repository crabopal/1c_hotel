Справочник "Сокращения"

Назначение

Справочник «Сокращения» содержит список общеупотребимых сокращений, используемых в адресах. Справочник используется при вводе адресов через выбор из адресного классификатора.

Справочник заполняется автоматически в момент загрузки адресного классификатора.

Относится к подсистеме: «Классификатор адресов».

Параметры

Длина кода: 4; Тип кода: «Число».

Длина наименования: 52.

Не иерархический.

Реквизиты

  • Сокращение. Тип значения: «Строка». Содержит представление сокращения.
  • Тип сокращения. Ссылается на перечисление «Типы сокращений». Может быть Город, Район, Область, Улица. Используется только при загрузке классификатора. 

Способ вызова

  • Вызывается из главного меню системного администратора "Настройки/КЛАДР/Сокращения ".
