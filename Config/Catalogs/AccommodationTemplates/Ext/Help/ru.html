Справочник "Шаблоны размещения гостей"

Назначение

Справочник шаблонов строк брони/размещений в составе группы гостей по видам размещений. Используется для быстрого добавления в состав группы нескольких строк по разным видам размещений на основании данных в выбранной строке состава группы.

Относится к подсистеме: «Управление Номерным Фондом».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 150.

Не иерархический.

Реквизиты

  • Примечания. Тип значения: «Строка». Описание мероприятия.
  • Таблица видов размещений. Тип значения: Элемент справочника «Виды размещения». В шаблоне должна быть как минимум одна строка.

Способ вызова

Вызывается:

  • Из меню "Номерной фонд/Справочники/Настройки" системного администратора программы
