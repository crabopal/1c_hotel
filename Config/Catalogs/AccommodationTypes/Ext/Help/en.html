Справочник "Виды размещения"

Назначение

В этом справочнике описываются возможные виды размещения гостей в номерах гостиницы. 
Вид размещения участвует в формировании цены за проживание.

Существует 2 наиболее распространенные схемы определения видов размещения в гостиницах.

1 вариант: стоимость проживания одного человека в двухместном номере не отличается от стоимости проживания двух человек в этом же двухместном номере. Тогда используют следующие 4 вида: Номер, Место, Доп. место и Совместно. При этом стоимость места равна половине стоимости номера; стоимость доп. места задается отдельно, а стоимость Совместно равна нулю, и используется для регистрации гостей проживающих совместно с тем гостем, который оплачивает номер.

2 вариант: стоимость проживания одного человека в двухместном номере и двух человек отличается. В этом случае используется 6 видов размещения: Номер 1 (Single), Номер 2 (Double), Место (Bed, стоимость вычисляется по формуле "Номер 2"/2), Доп. место (Additional bed), Совместно (Together), Подселение (Additional guest, стоимость вычисляется по формуле "Номер 2" – "Номер 1"), где Номер 1 и Номер 2 – это стоимость на человека в одноместном и в двухместном номере соответственно; «Совместно» используется для регистрации гостей проживающих совместно; «Подселение» позволяет быстро оформить гостя на 1-2 дня и взять доплату за разницу стоимости между одноместным размещением и двухместным - используется в случае, когда в номере проживает один гость и к нему на 1-2 дня нужно подселить второго гостя. При подселении проживание второго гостя по умолчанию оплачивается самим вторым гостем.

Реквизиты

  • Код. Тип значения: «Строка» 5 символов. Подбирается для быстрого выбора в документах или для краткого отображения в отчетах. (Например: Н1, Н2, М, С, П, ДП) 
  • Наименование. Основное представление значения. 
  • Переводы наименования на различные языки. Содержит перевод наименования для печати.
    Перевод задается в виде строк на разных языках, разделенных символом ";" (точка с запятой).
    Строка на одном языке состоит из кода языка, указанного в метаданных, символа "=" (равно) и, собственно, строки текста на данном языке в одинарных кавычках.
    Например: RU='Номер 1'; EN='Single'
    Если перевод указан, то в печатных формах будет использоваться именно он, если перевод не задан, то будет использовано наименование. 
  • Тип. Тип размещения выбирается из перечисления "Типы размещений"
    Тип размещения «Номер» означает, что гость по данному виду размещения занимает весь номер.
    Тип размещения «Место» - означает что гость занимает только 1 или несколько мест в номере. Количество мест указывается в реквизите "Количество мест"
    Количество занимаемых мест определяется параметром «Количество мест». Стоимость по виду размещения «Место» обычно равна половине стоимости номера. Данный вид размещения используется когда гостям, проживающим в одном номере нужно разделить счета так, чтобы каждый оплачивал только за себя.
    Тип размещения «Совместно» - не занимает мест в номере и может использоваться только вместе с видом размещения «Номер». В случае когда в номере проживают 2 гостя, и вам необходимо оформить счет на одного из них, вы этого гостя оформляете на вид размещения «Номер», а второго гостя на вид размещения «Совместно». Т.е. этот вид размещения нужен для того, чтобы просто зарегистрировать гостя в номере.
    Тип размещения «Доп. место» - также используется только вместе с другими видами размещения (Место или Номер). Данный вид размещения может быть определен в тарифе и задана стоимость за дополнительное место. Кроме того, во всех отчетах, где рассчитывается количество занятых доп.мест, учитываются гости только с этим типом вида размещения. 
  • Количество номеров. Тип значения: «Число». Указывает количество занятых номеров по данному виду размещения. Заполняется только у вида размещения с типом "Номер", и обычно равно 1.  
  • Количество мест. Тип значения: «Число». Указывает количество мест, занимаемых гостем по данному виду размещения. Указывается у видов размещения с типом "Место".  
  • Количество дополнительных мест. Тип значения: «Число». Указывает количество дополнительных мест у вида размещения с типом "доп. места". У остальных видов размещения должно быть = 0. 
  • Количество человек. Тип значения: «Число». Указывается количество человек оформляемых по данному виду размещения. Данное количество подставляется в документах "Размещение" и "Резервирование" и может быть изменено в документе. 
  • Количество человек для перерасчетов в брони. Тип значения: «Число». 
  • Линк на картинку вида размещения на сайте гостиницы. Содержит относительный путь к картинке для данного вида размещения. Используется в модуле он-лайн бронирования. Путь должен быть задан относительно размещения модуля на сайте. 
  • Линк на страницу с описанием вида размещения на сайте гостиницы. Содержит относительный путь к странице с описанием вида размещения. Используется в модуле он-лайн бронирования. Путь должен быть задан относительно размещения модуля на сайте. 
  • Начислять на основной лицевой счет номера. Если флажок выключен (стандартное значение), то каждому гостю будет открыт персональный лицевой счет, и все начисления будут производится на этот, отдельный счет. Если флажок включен, то начисления по этому виду размещения будут автоматически переноситься на гостя с видом размещения "Номер". Обычно включается для видов размещения "Совместно" или "Доп. место".  
  • Порядок сортировки. Тип значения: «Число». Используется в отчетах для сортировки. Также в этом порядке выводятся строки в форме "Что свободно". В этом порядке отображается выпадающий список при выборе в документах.  
  • Примечания. Тип значения: «Строка». Содержит произвольный комментарий, который отображается только на форме списка.

Способ вызова
