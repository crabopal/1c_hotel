Справочник "Возрастные группы"

Назначение

Справочник определяет названия диапазонов возраста клиентов. Элементы справочника используются при построении аналитических отчетов для анализа клиентов гостиницы по возрастам. "Возрастная группа" хранится в карточке клиента и заполняется автоматически при сохранении карточки клиента по его возрасту.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Неиерархический.

Реквизиты

  • Возраст от. Определяет начальный возраст от которого клиент будет попадать в возрастную группу.
  • Возраст до. Определяет конечный возраст до которого (включительно) клиент будет попадать в возрастную группу.
  • Примечания. Произвольный комментарий к возрастной группе. 

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Возрастные группы"
