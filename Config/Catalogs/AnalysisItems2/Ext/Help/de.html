Справочник "Параметры учета 2"

Назначение

Справочник "Параметры учета 2" содержит список элементов первого вида, которые используются в плане счетов бухгалтерского учета для ведения аналитического учета. Используется в плане счетов.

Относится к подсистеме: «Настройки/Бухгалтерия».

Параметры

Длина кода: 10, тип кода: Строка.

Длина наименования: 150.

Не иерархический.
