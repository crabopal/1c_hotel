Справочник "Районы"

Назначение

Справочник "Районы" - это адресный классификатор, который содержит список районов региона.
Справочник может редактироваться конечным пользователем, однако для его заполнения и обновления следует использовать обработку "Импорт классификаторов".

Относится к подсистеме: «Классификатор адресов».

Параметры

Длина кода: 12, тип кода: Строка.

Длина наименования: 52.

Не иерархический.

Реквизиты

  • Сокращение. Ссылается на справочник «Сокращения». Содержит сокращение обозначения района.
  • Почтовый индекс. Тип значения: «Строка». Содержит почтовый индекс района.
  • Регион. Ссылается на справочник «Регионы».  Содержит ссылку на регион, к которому относится данный район.
  • Страна. Ссылается на справочник «Страны». Содержит ссылку на страну, к которой относится район.
  • Код внешнего классификатора. Тип значения: «Строка». Содержит код из КЛАДР.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.

Способ вызова

Вызывается из меню "Настройки/Адреса/Районы"
