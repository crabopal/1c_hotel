Справочник "Номенклатура"

Назначение

Справочник "Номенклатура" содержит перечень расходных материалов, которые используются при выполнении работ.
Также, в справочнике можно указать единицы измерения для каждой используемой номенклатуры и добавить необходимые примечания.

Пример заполнения справочника:
Чистящее средство (гр.) (порошок)

Относится к подсистеме: «Управление службой номеров».

Используется в документе «Регистрация работ персонала».

Для каждого вида работ можно указать нормативы расхода номенклатуры, которые будут использоваться при автоматическом заполнении документа.

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Тип значения: «Число». Используется для сортировки в отчетах.
  • Единица измерения. Тип значения: «Строка». Обозначение единицы измерения. Используется только в отчетах.
  • Примечания. Тип значения: «Строка». Краткое описание номенклатуры. Используется только для отображения в списке.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.

Способ вызова

Вызывается из меню "Служба номеров/Справочники/Номенклатура"
