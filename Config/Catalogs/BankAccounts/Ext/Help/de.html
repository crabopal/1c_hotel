Справочник "Банковские счета"

Назначение

Используется для хранения информации о банковских счетах фирм и контрагентов.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 10, тип кода: Строка.

Длина наименования: 25.

Не иерархический.

Владельцы справочника: «Фирмы», «Контрагенты».

Реквизиты

  • Валюта счета. Ссылается на справочник «Валюты». Используется для отбора банковского счета, при выставлении счета на оплату. В документе "Счет-требование" можно выбрать только тот банковский счет, валюта которого совпадает с валютой документа.
  • Прямые расчеты. Флажок "Прямые расчеты" следует установить, если банк является самостоятельным банком и рассчитывается с другими банками напрямую. Если же расчетный счет открыт в филиале головного банка или в конкретном случае расчеты ведутся через другой банк, с которым банк поддерживает корреспондентские отношения, флажок "Прямые расчеты" устанавливать не следует.
  • Получатель. Тип значения: «Строка». Содержит строку для печати в поле "Получатель" в счете-требовании на оплату. Если не заполнено, то будет использовано наименование фирмы.

Следующие реквизиты счета используются в печатных формах документов "Счет-требование" и "Счет-фактура".

  • Номер счета. Тип значения: «Строка».
  • Название банка. Тип значения: «Строка».
  • Город банка. Тип значения: «Строка».
  • Корреспондентский номер счета банка. Тип значения: «Строка».
  • БИК банка. Тип значения: «Строка».
  • ИНН банка. Тип значения: «Строка».

При непрямых расчетов используются реквизиты:

  • БИК банка корреспондента. Тип значения: «Строка».
  • Название банка корреспондента. Тип значения: «Строка».
  • Город банка корреспондента. Тип значения: «Строка».
  • Корреспондентский номер счета банка корреспондента. Тип значения: «Строка».
  • SWIFT код банка корреспондента. Тип значения: «Строка».
  • ИНН банка корреспондента. Тип значения: «Строка».

Для валютных счетов используются реквизиты:

  • SWIFT код банка. Тип значения: «Строка».

    Формы

    • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
    • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

    Способ вызова

    Вызывается из меню "Взаиморасчеты/Справочники/Банковские счета", а также из формы элемента справочника "Фирмы" и "Контрагенты", закладка "Банковские счета".
