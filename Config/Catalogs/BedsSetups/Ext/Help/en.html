Справочник "Конфигурации кроватей"

Назначение

Содержит список используемых конфигураций кроватей: "Сдвинуты", "Раздвинуты", "Две сдвинуты, две раздвинуты", ... Конфигурация может быть указана у номера и используется в бронировании номеров для указания, что должно быть сделано в номере перед заездом гостя. Форма поиска свободных номеров позволяет фильтровать номера по нужной конфигурации.

Относится к подсистеме: «Настройка/Номера».

Параметры

Длина кода: 25 - указывайте здесь краткое название конфигурации, которое будет отображаться в брони, форме поиска свободных номеров, в списке номеров. Тип кода: Строка.

Длина наименования: 150 - указывайте здесь детальное описание конфигурации

Переводы наименования: Строка, которая может содержать переводы названия конфигурации кроватей для вывода в печатных формах.

Не иерархический справочник.

Способ вызова

Вызывается из меню "Настройки/Номерной фонд/Конфигурации кроватей"
