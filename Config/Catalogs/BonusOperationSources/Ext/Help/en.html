Справочник "Источники операций с бонусами"

Назначение

Справочник содержит список типовых причин выполнения операций с бонусами или с суммами на подарочных картах. Используется в документах "Операции с бонусами" и "Платежи бонусами".

Используется для ускорения ввода в систему типовых операций с бонусами т.к. позволяет в параметрах источника указать сумму списываемых или начисляемых бонусов, которая при выборе будет подставлена в документ.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка, авто-нумерация

Длина наименования: 150.

Неиерархический.

Реквизиты

  • Сумма. Тип значения: «Число». Сумма бонусов по умолчанию.
  • На каждый день. Тип значения: «Булево». Если галочка включена, то сумма бонусов при подстановке в операцию с бонусами умножается на число дней проживания гостя.
  • Гостиница. Используется при ведении мульти-гостиничного учета. Для выбора в операции с бонусами доступны только те источники, у которых гостиница совпадает с текущей или не указана.
