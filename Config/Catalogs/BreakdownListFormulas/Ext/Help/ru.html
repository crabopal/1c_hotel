Справочник "Формулы списка детализации"

Назначение

Список содержит формулы для вычисления цены и количества услуги, которая детализирует начисление. Пример: в услугу "Полупансион" начисляемую по тарифу проживания может входить стоимость питания. В этом случае можно создать формулу детализации с указанием, что стоимость питания вычисляется как 20% от стоимости полупансиона. Формула позволяет вычислить стоимость детализирующей услуги и переопределить ее количество. Переопределить количество может быть необходимо на основании числа проживающих в номере гостей.

Формула списка детализации может быть указана в карточке услуги. В этом случае, при выборе этой услуги в настройках списка детализации, программа будет использовать параметры из справочника.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 100.

Неиерархический.

Реквизиты

  • Ставка НДС. Если указана, позволяет задать ставку НДС детализирующей услуги отличную от ставки услуги начисления.
  • Цена. Число. Используется если у детализирующей услуги нужно указать фиксированную стоимость.
  • Валюта цены. Валюта фиксированной или вычисленной по формуле цены детализирующей услуги.
  • Формула вычисления цены. Строка. Можно указывать произвольное выражение на встроенном языке 1С. Результат вычислений должен быть присвоен переменной [ItemPrice]
    Поддерживается следующий список переменных:
    • [Amount] - сумма основной услуги (сумма начисления). Она корректируется после обработки каждого элемента
    • [DiscountAmount] - сумма скидки. Она корректируется после обработки каждого элемента
    • [CommissionAmount] - сумма комиссии. Она корректируется после обработки каждого элемента
    • [Цена] - цена основной услуги
    • [Количество] - количество основной услуги
    • [VATRate] - ставка НДС основной услуги в виде числа
    • [VATAmount] - сумма НДС основной услуги. Она корректируется после обработки каждого элемента
    • [ItemVATRate] - ставка НДС текущего элемента в виде числа
    • [AccountingDate] - учетная дата основной услуги
    • [NumberOfPersons] - кол-во человек в брони
    • [NumberOfAdults] - кол-во взрослых в брони
    • [NumberOfTeenagers] - кол-во подростков в брони
    • [NumberOfChildren] - кол-во детей в брони
    • [NumberOfInfants] - кол-во младенцев в брони
  • Количество. Число. Используется если у детализирующей услуги нужно указать фиксированное количество отличное от количества начисляемой услуги.
  • Формула вычисления количества. Строка. Можно указывать если количество детализирующей услуги нужно переопределить например исходя из числа гостей в номере. Правила и переменные те же, что и для формулы цены, но результат вычислений должен быть присвоен переменной [ItemQuantity]
  • Сдвиг даты услуги. Число. Позволяет сдвинуть дату детализирующей услуги на указанное число дней от даты начисляемой услуги. Используйте, например, 1 для завтраков.
