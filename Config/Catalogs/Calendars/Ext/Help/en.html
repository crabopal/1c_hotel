Справочник "Календари"

Назначение

Календарь - это свойство тарифа. В календаре определяется какая дата к какому типу дня относится. 
Календарей у одной гостиницы может быть несколько. Календаря будет два, если, например, для базового тарифа вы используете сезонное или любое другое изменение цен, а для тарифов организаций, которые присылают к вам гостей, вы хотите, чтобы цены по дням не изменялись, т.к. организации и так работают по тарифам со скидками. 
Цены по тарифу могут меняться в зависимости от сезона, дня недели, праздников. Изменение цен может быть привязано к дням проведения в вашем городе выставок или других мероприятий. Следовательно, кроме типа клиента, на цену оказывает влияние тип дня, в который проживает гость. Срок проживания гостя может состоять из периодов, которые относятся к разным типам дней и стоимость номера в сутки также должна меняться в зависимости от типа дня. 

Реквизиты

  • Код. Тип значения: «Строка» 5 символов. используется для быстрого отбора и краткого представления в отчетах. Назначается вручную. 
  • Наименование. Содержит краткое наименование. Является основным представлением элемента. 
  • Порядок сортировки. Тип значения: «Число». Используется для сортировки в отчетах. 
  • Примечания. Тип значения: «Строка». Краткое описание календаря, отражается только в списке.

Закладка "Дни календаря"

  • В колонке "Период" указывается дата. Даты должны быть указаны все, без пропусков. Если дата в календаре отсутствует, то на эту дату не будет выполнено начислений. 
  • В колонке "Тип дня" указывается тип дня, соответствующий дате из колонки "Период". Тип дня задает цену. 
  • Колонка "Расписание дня" используется для бронирования ресурсов. В данной колонке можно указать в какие часы ресурс доступен для бронирования. Если расписание не указано, то считается что ресурс работает круглосуточно. 

Отображает записи из регистра сведений "Дни календаря".

Для заполнения календаря используйте кнопку "Заполнить" на закладке "Дни календаря". 
Выберите пункт "Мастер заполнения", чтобы запустить специальный мастер, который поможет сформировать календарь. 
Либо выберите пункт "Скопировать из другого календаря", чтобы скопировать записи из другого календаря. 

Закладка "Типы дней календаря по продолжительности проживания"

Отображает записи из регистра сведений "Типы дней календаря по продолжительности проживания". Этот регистр позволяет для тарифа задать шкалу выбора типа дня по продолжительности проживания гостя. 
Пример: для тарифа "Базовый" можно указать, что при продолжительности проживания от 4-х дней программа для расчета состава услуг должна использовать цены из типа дня "4 - 7 дней проживания". При продолжительности проживания от 7-ми дней должна использовать цены из типа дня "7 - 12 дней проживания". При продолжительности проживания от 12-ти дней должна использовать цены из типа дня "от 12 дней проживания". 
При расчете услуг для каждого дня проживания гостя программа получает цены как по типам дней из основного календаря тарифа, так и по этому вспомогательному регистру. Для начисления услуг используется тот тип дня, цены в котором меньше. 
Данный регистр позволяет задать цены в зависимости от продолжительности проживания, в случае, когда эта цена не выражается в виде скидки от базовой цены, а просто назначается. 
В случае, если в гостинице по продолжительности проживания предоставляют скидку, то нужно настраивать накопительные скидки. 

  • В колонке "Количество дней проживания" указывается порог применения цены. 
  • В колонке "Тип дня" указывается тип дня для расчета цены. 

Способ вызова

  • Вызывается из меню "Взаиморасчеты/Справочники/Настройки/Календари"
