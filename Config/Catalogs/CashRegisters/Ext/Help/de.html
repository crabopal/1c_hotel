Справочник "Контрольно-Кассовые Машины"

Назначение

Список используемых контрольно-кассовых машин. 
 
Можно регистрировать как автономные ККМ, так и подключенные в режиме фискального регистратора. Если указан режим "фискальный регистратор" (ФР), то необходимо указать тип ККМ и выбрать драйвер ККМ. Установочная программа драйвера входит в комплект поставки ККМ. 

На закладке ФР можно определить, будут ли в чеке печататься суммы по секциям или будет выводиться только итоговая сумма.

Программа позволяет проводить суммы по кассе разными типами оплаты. Таблица наименований типов оплаты для печати на чеке настраивается в параметрах настройки ККМ (меню Сервис/Параметры, на закладке "Общий драйвер ККМ" или "Настройка таблиц"). Связь между способом оплаты в программе и типом оплаты по кассе устанавливается на форме способа оплаты параметром "Тип оплаты по ККМ". Если этот параметр не заполнен или установлен в "Наличные", то суммы проведенные этим способом оплаты по кассе изменяют сумму наличности в кассе. Если установлено значение "Тип оплаты 2, 3 или 4", то суммы проведенные этим способом оплаты по кассе НЕ изменяют сумму наличности в кассе.

Все типы драйверов позволяют печатать в конце чека итоговые суммы НДС и НП. Если включить флажок "Печатать в чеках сумму НДС", то, если сумма НДС по документу не нулевая, будет распечатана строка "В т.ч. НДС: ХХХ.ХХ". 

Включите флажок "Z-Отчет по ФР снимается отдельно" для того, чтобы при проведении документов закрытия кассовых смен Z-Отчет с ККМ автоматически не снимался. Этот флажок должен быть включен, если для снятия Z-Отчета с ККМ вы используете специализированную программу.

Относится к подсистеме: «Управление взаиморасчетами».

Владельцы справочника: «Фирмы».

Реквизиты

  • Код. Строка, 5 символов. Используется для быстрого отбора в документах и для краткого представления в отчетах. 
  • Наименование. Краткое наименование ККМ. Основное представление элемента. 
  • Порядок сортировки. Используется для сортировки в отчетах. Также в этом порядке происходит выбор из выпадающего списка фирм в документах "Платеж". 
  • Фирма. Владелец справочника, обязательный реквизит. Любая ККМ должна быть привязана к одной какой-либо фирме.  
  • Гостиница. Ссылка на элемент справочника "Гостиницы". Указывает к какой гостинице относится данная ККМ. Поле можно не заполнять, если по этой кассе проводятся платежи по разным гостиницам, например в центральном офисе продаж сети гостиниц или если в программе не используется репликация данных средствами УРИБ.  
  • Заводской номер ККМ. Используется в печатных формах документов на возврат (форма КМ-3). 
  • Регистрационный номер ККМ. Используется в печатных формах документов на возврат (форма КМ-3). 
  • Тип X-Отчета по умолчанию. Указывает печатную форму отчета кассира используемую по-умолчанию. 
  • Тип Z-Отчета по умолчанию. Указывает печатную форму отчета кассира используемую по-умолчанию при закрытии смены. 
  • Префикс документов закрытия смен. Строка, 4 символа. Позволяет задать свою нумерацию документов закрытия смены для каждой ККМ. Если префиксы не заданы, то нумерация единая для всех ККМ. 
  • Номер терминала. Тип значения: "Число". Используется при подключении к программе терминалов процессинга кредитных карт в случаях, когда в процессинговый центр банка нужно передавать разный номер терминала в зависимости от текущего ККМ. 
  • По кассе разрешен возврат наличных непосредственно из денежного ящика. Тип значения: «Булево». 
  • Примечания. Краткий комментарий. 
  • Подключается к программе. Если флажок включен, то при проведении платежей будет пробиваться кассовый чек. Параметры подключения и режим работы ККМ настраивается на закладке "Параметры подключения". 

Закладка "Параметры подключения"

  • Закладка доступна если включен флажок "Подключается к программе" и содержит настройки работы драйвера торгового оборудования. 

    • Печатать на чеке сумму НДС. Если включен, то при печати чека будет вычисляться сумма НДС и печататься строка вида "в т.ч. НДС " и сумма НДС. Если ККМ настроена так, что фискальный регистратор сам печатает сумму НДС, то флажок нужно выключить. 
    • Печатать на чеке строку "НДС включён в сумму". Если флажок включен, то печатается строка "НДС включен в сумму". 
    • Печатать на чеке наименование кассовых секций. Если флажок включен, то на чеке будет печататься наименование кассовой секции так как оно задано в таблице секций в памяти ККМ. 
    • Не печатать Z-Отчет автоматически при закрытии смены. Если флажок включен, то при проведении документа "Закрытие смены" не будет дана команда на ФР на снятие z-отчета. В этом случае z-отчет на ККМ нужно будет снять вручную. (Рекомендуемое значение: Включен) 
    • Не обнулять сумму наличных при снятии Z-отчета. Если флажок выключен, то сумма наличности в ККМ не будет обнулена при закрытии смены. Флажок выключают, когда сдачу наличности оформляют документом "Инкассация". 
    • Не открывать автоматически новую кассовую смену после Z-Отчета. Используется на некоторых моделях ККМ. Если флажок включен (рекомендуемое значение), то смена будет открыта при первом пробитом чеке ККМ. Если флажок выключен, то смена будет открыта сразу после снятия z-отчета. 
    • Драйвер ККМ. Указывает какой драйвер будет использован для работы с ККМ. Драйвер обычно поставляется поставщиком ККМ. Для ККМ "Прим" используется платная версия "Атол:Драйвер ККМ". 
    • Использовать логическое устройство. Если флажок включен, то параметры ККМ будут сохранены в реестре в качестве логического устройства ККМ. Используется драйверами "Атол" и "Штрих-М". Полезно при подключении к одному компьютеру нескольких ККМ на разных портах, например при многофирменном учете. 
    • Номер логического устройства. Тип значения: «Число». Указывает на номер логического устройства драйвера. Используется, когда включен флажок "Использовать логическое устройство". 
    • Протокол драйвера. Тип значения: «Строка». Используется драйвером "Атол". 
    • Пароль доступа к ККМ. Тип значения: «Строка». Содержит пароль доступа ККМ. Для разных моделей ККМ разные пароли доступа. Пароль по-умолчанию для многих ККМ "0000" или " ". 
    • Модель ККМ. Тип значения: «Строка». Используется драйвером "Атол". Возможные значения указаны в документации к драйверу. 
    • Максимальная ширина чека в символах. Тип значения: «Число». По данному значению будет отформатирован чек при печати. Если значение не указано, то будет использоваться значение по-умолчанию = 24. 
    • Адрес кассового сервера. Тип значения: «Строка». Имя компьютера или IP адрес компьютера к которому подключена ККМ. 
    • Порт. Тип значения: «Строка». Указывается имя порта подключения. Например "COM1". 
    • Скорость обмена. Указывается скорость обмена числом. Например 9600. 
    • Максимальное время ожидания ответа от ККМ в миллисекундах. Тип значения: «Число». Содержит таймаут для работы ККМ. 
    • Печатать слип операции по кредитной карте в открытом кассовом чеке. Используется для ККМ не поддерживающих печать нефискального документа. В этом случает слип операции по кредитной карте печатаются в открытом кассовом чеке, и сразу пробивается чек. 
    • Записывать лог файл. Флажок передается драйверу. Настройки логов производятся в драйвере ККМ. 
    • Печатать на чеке шапку счета. Если флажок включен, то при печати чека будет выводится заголовок, содержащий номер комнаты, имя клиента, номер фолио и имя кассира. 
    • Интернет адрес для верификации чека. Тип значения: "Строка". Содержит интернет адрес ОФД, по которому можно проверить пробитый чек. В адресе могут быть указаны 5 подстановочных переменных: %FiscalStorageFactoryNumber% - заводской номер фискального накопителя (ФН); %ChequeFiscalNumber% - фискальный признак чека (ФП);  %ChequeSequenceNumber% - порядковый номер чека (ФД); %CashDayChequeNumber% - порядковый номер чека в смене; %ChequeAmount% - сумма чека. 
      • Примеры заполнения реквизита:  
        • https://lk.platformaofd.ru/web/noauth/cheque?fn=%FiscalStorageFactoryNumber%&fp=%ChequeFiscalNumber% - для Платформа ОФД 
        • https://receipt.taxcom.ru/v01/show?fp=%ChequeFiscalNumber%&s=%ChequeAmount%&sf=False&sfn=False - для Такском ОФД
        • https://cash.kontur.ru/?fnSerialNumber=%FiscalStorageFactoryNumber%&fiscalDocumentNumber=%ChequeSequenceNumber%&fiscalSignature=%ChequeFiscalNumber% - для Контур ОФД
