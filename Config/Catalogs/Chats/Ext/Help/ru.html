Справочник "Телеграмм чаты"

Назначение

Справочник телеграмм чатов служит для хранения информации по чатам которые взаимодействуют с чат ботом.

Параметры

Длина кода: 10, тип кода: Строка.

Длина наименования: 50.

Реквизиты

  • Бот. Тип значения: «Ссылка "Чат боты"». Ссылка на чат бота с которым работает текущий чат.
  • Чат ID. Тип значения: «Строка». Уникальный номер чата полученный из api телеграмма. 
  • Личный чат. Тип значения: «Булево». Если чат личный то проверки на код сотрудника не будет.
  • Активен. Тип значения: «Булево». Ссылка на чат бота с которым работает текущий чат.
