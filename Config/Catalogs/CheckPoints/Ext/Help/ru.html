Справочник "КПП"

Назначение

Справочник используется для хранения списка Контрольно Пропускных Пунктов для целей миграционного учета.

Если в наборе прав пользователя выключить право "097 - Есть права добавлять любые КПП в справочник и использовать их в записях в журнале регистрации иностранцев. Иначе есть права только выбирать зарегистрированные ранее КПП из справочника", то пользователь сможет в документе выбрать только те значения которые указаны в справочнике.
Если же право включено, тогда наименование КПП вводится в документе строкой. Те наименования, которые не использовались ранее, автоматически добавляются в справочник.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 10, тип кода: Строка.

Длина наименования: 50.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/КПП"
