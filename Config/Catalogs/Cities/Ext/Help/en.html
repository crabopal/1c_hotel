Справочник "Населенные пункты"

Назначение

Справочник "Города" содержит список городов и других населенных пунктов. Справочник может редактироваться конечным пользователем.
Однако, для его заполнения и обновления следует использовать обработку "Импорт классификаторов".

Относится к подсистеме: «Классификатор адресов».

Параметры

Длина кода: 12, тип кода: Строка.

Длина наименования: 52.

Не иерархический.

Реквизиты

  • Сокращение. Ссылается на справочник «Сокращения». Содержит сокращение обозначения населенного пункта.
  • Почтовый индекс. Тип значения: «Строка». Содержит почтовый индекс города, населенного пункта.
  • Регион. Ссылается на справочник «Регионы».  Содержит ссылку на регион, к которому относится данный город (населенный пункт).
  • Страна. Ссылается на справочник «Страны». Содержит ссылку на страну, к которой относится город.
  • Код внешнего классификатора. Тип значения: «Строка». Содержит код из КЛАДР.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.

Способ вызова

Вызывается из меню "Настройки/Адреса/Населенные пункты"
