Справочник "Типы информации по клиентам"

Назначение

Справочник содержит структуру хранения доп. информации по клиентам. Справочник иерархический. Группы в справочнике объединяют однотипные виды информации, например в группу "Медицина" можно добавить виды информации "Аллергия" и "Диагноз".

В карточке клиента в форме доп. информации показывается дерево типов информации, где по каждому элементу можно вводить примечания и описания принятых отелем мер/действий. По каждому типу информации программа хранит историю изменения этих примечаний. История хранится в регистре сведений "История доп. информации по клиентам".

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 6, тип кода: Число. Автонумерация

Длина наименования: 150.

Иерархический.
