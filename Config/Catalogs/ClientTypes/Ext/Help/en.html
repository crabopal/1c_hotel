Справочник "Типы клиентов"

Назначение

Справочник определяет типы клиентов: гость; сторонний посетитель; сотрудник; VIP гость; смежник и т.д.

Цены за проживание и другие услуги по тарифу, например питание, которые начисляются гостю при его размещении в гостинице, в первую очередь определяются типом клиента. Каждая категория цен соответствует элементу справочника "Типы клиентов". Внутри приказа об изменении цен, спецификации формул для связанных тарифов или пакета услуг для разных типов клиентов у услуг могут указываться различные цены. По умолчанию цены указываются для пустого типа клиента. Если в брони указан тип клиента, но для этого типа клиента в тарифе нет явно указанных цен, то программа возьмет цены для пустого типа клиента. Это правило не распространяется на пакеты услуг. В пакетах цены для различных типов клиентов необходимо обязательно указывать.

В справочнике типов клиентов можно создавать папки. Разрешен только 1 уровень вложенности, т.е. папку в папке программа создать не позволит. В тарифах и пакетах различные цены можно указывать только для типов клиентов (элементов и папок) из верхнего уровня иерархии. Таким образом в программе нельзя указать различные цены для типов клиентов из одной папки. У всех таких элементов будут одинаковые цены.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Используется для сортировки в отчетах.
  • Бесплатный клиент. Флажок необходимо включить, если цена, по данному типу клиента = 0. Используется для накопления статистики по гостям с нулевой ценой проживания. 
  • Требовать подтверждения типа при каждом поселении. Тип значения: «Булево». Означает, что если данному типу гостя предоставляется скидка, то необходимо подтвердить ее.
  • Шаблон строки подтверждения. Тип значения: «Строка». Это сообщение с запросом ввести подтверждение того, что данный гость имеет право пользоваться скидкой. В качестве подтверждения обычно указывается номер какого-либо документа (инвалидной книжки, табельный номер и т.д.) 
  • Тип скидки. Ссылается на справочник «Типы скидок». Тип скидки для данного типа гостя.
  • Отключить автоматические скидки. Тип значения: «Булево». Включённый флажок означает, что для такого типа гостей автоматические (накопительные) скидки не будут действовать.
  • Отключить все скидки. Тип значения: «Булево». Включённый флажок означает, что для такого типа гостей не будут действовать любые скидки
  • Начисление бонусов запрещено. Тип значения: «Булево». Включённый флажок означает, что для такого типа гостей не будут накапливаться бонусы в программе лояльности
  • Очищать ФИО гостей после выселения. Тип значения: «Булево». Включенный флажок означает, что при выселении гостей программа будет очищать у гостя все идентификационные данные: ФИО, серию и номер паспорта, телефоны и т.д. При этом также очищаются соответствующие поля в истории изменений карточки гостя и в истории изменений связанных с этим гостем документов. В качестве фамилии гостя программа установит его код.
  • Секция оплаты. Ссылается на справочник «Секции оплаты». Позволяет проводить платежи по ККМ по разным кассовым секциям (отделам).
  • Цвет в карте загрузки НФ. Позволяет выбрать цвет. В карте загрузки гостиницы, в журнале брони, в "шахматке", все гости данного типа будут отмечены выбранным цветом.
  • Примечания. Произвольный комментарий к типу клиента. 

Способ вызова
