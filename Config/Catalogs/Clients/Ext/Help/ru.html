Справочник "Клиенты (гости)"

Назначение

Справочник хранит данные гостей, которые проживают, проживали или когда-либо пользовались услугами гостиницы,
а так же заявителей, сторонних посетителей.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 12, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Реквизиты

Закладка "Данные клиента"

  • Фамилия. Тип значения: «Строка».
  • Имя. Тип значения: «Строка».
  • Отчество. Тип значения: «Строка».
  • Полное имя. Заполняется автоматически при сохранении. Содержит Фамилию Имя и Отчество. Используется для отображения в журнале брони и размещений, а также может использоваться в отчетах.
  • Пол. Ссылается на перечисление «Пол».  Мужской или женский.
  • Гражданство. Ссылается на справочник «Страны».
  • Телефон. Строка с телефоном гостя.
  • Факс. Факс гостя, может использоваться для отправки подтверждений.
  • E-mail. Адрес почты гостя. Может использоваться для отправки подтверждения бронирования.
  • Дата рождения.
  • Место рождения. Строка. Заполняется в форме ввода адреса по адресному классификатору.
  • Адрес проживания. Строка. Заполняется в форме ввода адреса по адресному классификатору.
  • Вид документа удостоверяющего личность. Ссылается на справочник «Виды документов удостоверяющих личность».
  • Серия документа удостоверяющего личность.
  • Номер документа удостоверяющего личность. 
  • Дата выдачи документа удостоверяющего личность. 
  • Документ удостоверяющий личность действителен до. 
  • Кем выдан документ удостоверяющий личность. 
  • Язык. Ссылается на справочник «Языки». Язык печати счета или подтверждения для гостя. Автоматически назначается по стране гражданства гостя.
  • Полис медицинского страхования. Тип значения: «Строка». Используется при печати форм путевок, анкет, полисов, и других внешних печатных форм.

Закладка «Правила начисления»

Содержит правила начисления, которые переносятся при бронировании или размещения данного гостя.
Чаще всего используется для постоянных клиентов. Если в данной таблице указать "мастер-счет", то при поселении гостя все услуги от заезда к заезду будут скапливаться на данном "мастер-счете".

  • N (Номер строки). Определяет приоритет применения правила начисления. Для любой услуги сначала проверяется первое правило, если услуга удовлетворяет правилу, то выбирается этот счет, если нет, то проверяется следующее правило, со следующим номером строки.
  • Способ разделения оплаты. Ссылается на перечисление «Типы правил начисления». Определяет какие услуги будут начислены на выбранный счет.
  • Значение правила начисления. Ссылается на справочники «Наборы услуг», «Услуги». Используется, если в поле "Значение правила начисления" было выбрано "Услуги, включенные в набор услуг" или "Выбранная услуга". Указывается соответственно набор услуг или услуга. Можно выбирать группу услуг. Если выбрана услуга или набор услуг, то на указанный счет будут начисляться только те услуги, которые указаны в наборе или соответствуют выбранной услуге.
  • Начислять на лицевой счет. Ссылается на документ «Фолио». Указывает на какой лицевой счет начислять услуги. Если у счета включен флажок "мастер-счет", то начисления будут произведены именно на этот счет, и, при выселении, этот счет не будет закрыт.
    Если же в счете флажок "мастер-счет" выключен, то данный счет используется как шаблон. Т.е. при каждом заезде будет создаваться новый счет с такими же параметрами как в выбранном лицевом счете.
  • Действует с даты. Тип значения: «Дата». Указывает период действия правила. Если учетная дата начисления услуги, раньше этой даты, то услуга не будет начислена на выбранный счет.
  • Действует по дату. Тип значения: «Дата». Указывает период действия правила. Если учетная дата начисления услуги, больше этой даты, то услуга не будет начислена на выбранный счет.

Кнопка "По умолчанию" создает правила, в соответствии с шаблоном, заданном в справочнике "Гостиницы", на закладке "Правила начисления для клиентов".
Кнопка "Уменьшить приоритет" опускает строку вниз и устанавливает больший номер строки. Тем самым уменьшается приоритет правила.
Кнопка "Увеличить приоритет" поднимает строку вверх и устанавливает меньший номер строки. Тем самым увеличивается приоритет правила.

    Закладка "Параметры"

    • Тип клиента. Ссылается на справочник «Типы клиентов».  Содержит тип клиента. Используется для назначения специальных цен для гостя или для аналитических отчетов.
    • Строка подтверждения для типа клиента. Тип значения: «Строка». Содержит информацию относящуюся к типу клиента, или объясняющую причину назначения данного типа клиента.
    • Тип скидки. Ссылается на справочник «Типы скидок». Содержит тип скидки присвоенный гостю. При выборе гостя в документах "Бронь" и "Размещение" данный тип скидки автоматически подставляется в документ и применяется к начисленным услугам.
    • Строка подтверждения скидки. Тип значения: «Строка». Может содержать информацию относящуюся к скидке или описывающую причину предоставления этой скидки.
    • В "белом" списке. Если галочка включена, то в форме поиска гостей данный гость будет выделен зеленой рамкой и надписью "в белом списке".
    • В "черном" списке. Если галочка включена, то в форме поиска гостей данный гость будет выделен красной рамкой и надписью "в черном списке!".
    • Не селить. Если галочка включена, то программа не проведет документ "Размещение" с данным гостем.
    • Код во внешней системе. Тип значения: «Строка». Заполняется если данные были загружены из внешней системы, например из системы он-лайн бронирования.
    • Автор. Ссылается на справочник «Сотрудники». Заполняется автоматически тем пользователем, который создал данный элемент в системе.
    • Дата регистрации в программе. Тип значения: «Дата». Дата и время создания элемента в системе.

    Закладка "Примечания"

    • Титул. Тип значения: «Строка». Содержит титул гостя. Используется при печати анкеты гостя или информационных писем для гостя.
    • Обращение. Тип значения: «Строка». Содержит обращение к гостю. Пример: Mr, Ms, Dr. Используется при печати анкеты гостя или информационных писем для гостя.
    • Дети. Тип значения: «Строка». Используется для печати формы регистрации по месту пребывания.
    • Родители. Тип значения: «Строка».
    • Строка организации для печати лицевых счетов. Тип значения: «Строка». Данная строка заполняется автоматически, если в печатной форме счета в поле организации было введено значение. Полезно для командировочных гостей, которым требуется чтобы в гостиничном счете была указана организация и ее адрес. Если заполнено, то данное значение печатается в счете гостя в поле "Организация". Обычно заполняется у гостей из германии редактированием поля Организация непосредственно на печатной форме лицевого-счета. 
    • Воинское звание. Ссылается на справочник «Воинские звания».
    • Место работы. Тип значения: «Строка». Используется для печати форм путевок.
    • Инвалидность. Тип значения: «Строка».  Используется при печати путевок на лечение.
    • Примечания. Содержит произвольную информацию по гостю. Показывается в форме списка при поиске гостя.
    • Копировать примечания в бронь/размещения. Если галочка включена, то примечание гостя будет скопировано в бронь или размещение гостя, чтобы данное примечание было видно в журнале брони или проживающих.

    Закладка "Фото"

    • Фото. Тип значения: «Хранилище значения». Содержит фотографию гостя. Показывается в форме поиска гостей.

    По кнопке "Загрузить" можно загрузить фото клиента из файла.
    По кнопке "Сохранить" можно сохранить фото клиента в файл на диск.
    Кнопка "Очистить" удаляет фото клиента из базы.

    Закладка "Кредитные карты"

    Содержит список кредитных карт, зарегистрированных за этим клиентом. Карты можно выбирать и использовать в документах оплаты по лицевым счетам, где указан данный клиент. Права доступа к кредитным картам регулируются флажком "050 - Есть права на сохранение кредитных карт в базе данных" и "060 - Есть права на просмотр и изменение данных кредитных карт" в наборе прав пользователя.

    Закладка "Статистика"

    • Направление маркетинга. Ссылается на справочник «Направления маркетинга». Если заполнено, то при выборе гостя, данное значение будет автоматически подставлено в "Бронь" или "Размещение".
    • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице». Если заполнено, то при выборе гостя, данное значение будет автоматически подставлено в "Бронь" или "Размещение".

    На закладке представлены статистические данные гостя.

    Формы

    • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
    • Список. Основная форма списка. Используется для отображения списка элементов.
    • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
    • Поиск. Основная форма выбора. Используется для отображения списка выбора элементов.
    • Форма выбора группы. Основная форма выбора группы. Используется для выбора групп.

      Способ вызова

      Вызывается из меню В главном меню кнопка "Еще", затем кнопка "Клиенты".
