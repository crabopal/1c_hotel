Справочник "Страны"

Назначение

Справочник «Страны» содержит перечень стран мира, в соответствии с Общероссийским Классификатором Стран Мира ОКСМ, введенном в действие Постановлением Госстандарта от 14.12.2001 № 529.
При первоначальной настройке базы справочник загружается из макета по кнопке "Загрузить".

Относится к подсистеме: «Классификатор адресов».

Реквизиты

  • Код. Тип кода: Число, 3. Код страны по классификатору.
  • Переводы наименования на различные языки. Используется при печати счета на разных языках.
  • Код ISO. 2х символьный код ISO по классификатору.
  • Код ISO (3 символа). 3х символьный код ISO по классификатору. Используется при выгрузке данных о гостях в УФМС.
  • Необходима виза для въезда. Флажок означает что у гостя из этой страны должна быть виза.
  • Язык. Язык печати документов по-умолчанию.

Способ вызова

Вызывается из меню "Настройки/Адреса/Страны"
