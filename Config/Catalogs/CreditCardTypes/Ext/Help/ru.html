Справочник "Типы кредитных карт"

Назначение

Справочник содержит информацию о типах кредитных карт: VISA, MasterCard, AmericanExpress и т.д. Используется в отчетах для анализа и сверки расчетов с банком, обслуживающим карты.

Относится к подсистеме: «Управление взаиморасчетами».

Реквизиты

  • Код. Тип значения: «Строка», 5. Используется для быстрого выбора и краткого обозначения типа карты. Например VS, MC, AX 
  • Наименование. Содержит имя карты, должно совпадать с именем типа карты, возвращаемым драйвером. Тогда тип карты будет заполнятся автоматически при проведении платежа. 
  • Порядок сортировки. Тип значения: «Число». Используется для сортировки в отчетах. 
  • Примечания. Произвольный комментарий. 

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Настройки/Типы кредитных карт"
