Справочник "Кредитные карты"

Назначение

Справочник кредитных карт, по которым выполнялись транзакции.

При заселении гостя регистрируется и его кредитная карта, которой присваивается код в программе. Данные из справочника могут использоваться для проведения оплаты с помощью голосовой авторизации или с помощью банковских терминалов, если они подключены к программе.

Доступ к справочнику ограничивается флажком "050 - Есть права на сохранение кредитных карт в базе данных" и "060 - Есть права на просмотр и изменение данных кредитных карт" в наборе прав пользователя.

Относится к подсистеме: «Управление взаиморасчетами».

Реквизиты

  • Владелец карты. Ссылается на справочники «Клиенты (гости)», «Контрагенты». Карта может принадлежать гостю или контрагенту.
  • Тип карты. Ссылается на справочник «Типы кредитных карт». Содержит тип карты - "VISA", "MasterCard" и т.д. Используется в отчетах по картам для последующей сверки взаиморасчетов с банком.
  • Номер карты. Содержит полный номер карты, может быть использован для голосовой авторизации. Может содержать маскированный номер карты, если данные по карте были переданы в программу из банковского терминала.
  • Имя на карте. Указывается латинскими буквами так как указано на карте.
  • Срок действия. Месяц и год действия карты.
  • CSС (CVV, CVC) Код. Данный код используется при авторизации платежа, некоторые банки не смогут провести оплату без указания данного кода.
  • Карта выдана. Банк или организация выдавшая карту.
  • Примечания. Произвольный комментарий к карте.
  • Автор. Имя пользователя программы зарегистрировавшего карту.
  • Дата регистрации в программе. Дата и время внесения информации о карте в программу.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Кредитные карты"
