Справочник "Параметры системы процессинга кредитных карт"

Назначение

Справочник параметров систем процессинга кредитных карт. Используется при подключении банковских терминалов к программе.

Если терминал подключен, то при проведении платежа по способу оплаты "Кредитная карта" будет вызван соответствующий драйвер, который проведет платеж и вернет в программу результат.  

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Тип системы процессинга кредитных карт. Указывается тип драйвера для работы с "Кредитными картами". 
  • Количество символов в строке слипа. Используется для форматирования слипа по ширине для печати на кассовой ленте ККМ (фискального регистратора).  
  • Номер терминала. Передается в драйвер. 
  • Номер используемого логического устройства. Используется "Атол:Драйвер платежных систем". 
  • Сохранять данные кредитных карт в базе данных. Если галочка включена, то данные карты (номер карты, срок действия и проч.) будут сохранены в справочнике. 
  • Печатать слип операции по кредитной карте на принтере терминала. Нужно включить в случае, если банковский терминал оборудован собственным принтером слип-чеков и вам удобно его использовать. Если галочка выключена, то слип-чек печатается на принтере фискального регистратора.
  • Печатать слип операции по кредитной карте на принтере ККМ внутри открытого кассового чека. Нужно включить в случае, если фискальный регистратор (ККМ) не позволяет печатать на кассовой ленте не фискальные документы. В этом случае слип-чек будет впечатываться в конец открытого кассового чека и только потом чек будет закрываться. 
  • Используется многодорожечный считыватель карт. Флажок включен, если считыватель на рабочем месте считывает несколько дорожек. Если же считыватель настроен только на одну вторую дорожку, то флажок должен быть выключен. 
  • Параметры подключения к системе процессинга кредитных карт. Текст с параметрами подключения. Передается в виде XML файла драйверу работы с банковскими терминалами. 

Способ вызова

Вызывается из меню "Настройки/Параметры системы процессинга кредитных карт"
