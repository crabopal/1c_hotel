Справочник "Валюты"

Назначение

Список всех используемых в гостинице валют.

Курс валюты обязательно должен быть указан для каждой гостиницы. Для базовой валюты необходимо установить курс = 1.

Относится к подсистеме: «Управление взаиморасчетами».

Реквизиты

  • Код. Тип значения: «Число», 3. Код должен совпадать с кодом валюты в бухгалтерии, для выгрузки реализации. Код также должен совпадать с кодом валюты на ресурсе rbc.ru для автоматической загрузки курсов валют.
  • Переводы наименования на различные языки. Содержит перевод наименования для печати.
    Перевод задается в виде строк на разных языках, разделенных символом ";" (точка с запятой).
    Строка на одном языке состоит из кода языка, указанного в метаданных, символа "=" (равно) и, собственно, строки текста на данном языке в одинарных кавычках.
    Например: RU='руб.'; EN='RUB'
    Если перевод указан, то в печатных формах будет использоваться именно он, если перевод не задан, то будет использовано наименование.
  • Символ представления валюты. Символ для краткого представления валюты. Используется на формах документов и в списках.
  • Порядок сортировки. Используется для сортировки в отчетах.
  • Помещать символ перед суммой. Влияет на форматирование суммы с указанием валюты. Если флажок включен то символ валюты будет указан перед суммой.
    Пример: "$100.00"
  • Примечания. Произвольный комментарий.

Табличная часть «Параметры сумм прописью»

  • Язык. Ссылается на справочник «Языки». Указывается язык печати.
  • Параметры формирования сумм прописью. Строка для формирования суммы прописью.
    Пример для USD: EN = dollar, dollars, cent, cents, 2 ;RU=доллар, доллара, долларов, м, цент, цента, центов,м, 2
    Пример для Руб: EN = ruble, rubles, copeck, copecks, 2 ;RU=рубль, рубля, рублей, м, копейка, копейки, копеек, ж, 2

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Классификаторы/Валюты"
