Справочник "Типы контрагентов"

Назначение

Справочник позволяет группировать контрагентов по произвольным условиям, например по маркетинговым группам. Используется в отчетах для аналитики. 

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Используется в отчетах для сортировки.
  • Тип тарифа. Ссылается на справочник «Типы тарифов».
  • Формировать акты только в конце отчетного периода. Тип: Булево. Если галочка включена, то акты по контрагентам с данным типом при проведении документов закрытия периода будут формироваться только в последний день месяца.
  • Примечания. Произвольный комментарий.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Типы контрагентов"
