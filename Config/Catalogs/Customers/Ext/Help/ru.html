Справочник "Контрагенты"

Назначение

Контрагенты гостиницы - это общее понятие, куда включаются турфирмы, организации, оплачивающие проживание гостей, частные лица и т.п. Справочник "Контрагенты" сделан многоуровневым так, что в нем можно группировать контрагентов по типам, т.е. по различным условиям для удобства поиска.

Относится к подсистеме: «Управление взаиморасчетами».

Объекты, вводимые на основании: «Распределение аванса», «Платеж от контрагента», «Счет-требование», «Акт».

Закладка "Данные контрагента"

  • Код. Строка, 10. Код назначается автоматически с учетом префикса, заданного в гостинице. 
  • Наименование. Краткое наименование контрагента. Является основным представлением. Используется для поиска в списке и быстрого выбора в документах по первым буквам. 
  • Полное наименование. Используется для печати документов. 
  • Юридический адрес. Строка с адресом печатается в документах. 
  • Почтовый адрес. 
  • Телефон. 
  • Факс. 
  • E-mail. 
  • Валюта взаиморасчетов с контрагентом. Ссылается на справочник «Валюты». В этой валюте показывается оперативный баланс контрагента в форме брони. Если контрагенту необходимо производить начисления в выбранной валюте (отличной от основной), и акты также необходимо выставлять в этой валюте, то в правилах начисления необходимо указать валюту лицевого счета. Если правила начисления не задать, то при бронировании будут применены стандартные правила начисления с основной валютой, и все начисления будут пересчитаны в основную валюту.  
  • ИНН. Печатается в документах Счет, Акт и Счет-фактура. 
  • КПП. Печатается в документах Счет, Акт и Счет-фактура. 
  • Головная организация. Ссылается на справочник «Контрагенты». Используется для печати Счет-фактуры. 
  • Язык. Определяет язык печати документов. 
  • Тип контрагента. Ссылается на справочник «Типы контрагентов». Используется в отчетах для аналитики. 
  • Тип скидки. Указывает какую скидку необходимо применить при выборе контрагента. 
  • Основание предоставления скидки. Строка с комментарием к типу скидки о причинах предоставления этой скидки. 
  • В "белом" списке. Тип значения: «Булево». 
  • В "черном" списке. Тип значения: «Булево». 
  • Планируемый способ оплаты. Способ оплаты по-умолчанию для брони ресурсов. 
  • Агент. Указывает какой агент получает комиссию при продаже услуг выбранному контрагенту. 
  • Комиссия агента. Процент комиссии агента. 
  • Вид комиссии агента. Указывает способ расчета комиссии агента. "Процент".  
  • Набор услуг, по которому начисляется комиссия агентам. Указывает по каким услугам будет рассчитана комиссия. Например, по тарифу начисляются услуги проживания и питания, а комиссию платят только за проживание.  
  • Грузополучатель. Строка, используется для оформления счет-фактуры. 
  • Примечания. Комментарий к контрагенту. 
  • Копировать примечания в бронь/размещения. Если флажок включен, то при выборе контрагента в документах "Бронь" или "Размещение" примечания контрагента будут продублированы в документе для отображения в журналах. 
  • Код во внешней системе. Используется при выгрузке в бухгалтерию. Для синхронизации справочников контрагентов в этом поле указывается код контрагента в базе бухгалтерии. Код заполняется автоматически обработкой загрузки при первом проставлении соответствия. 
  • Цвет в карте загрузки НФ. Выбранным цветом будут отмечены гости в графической карте номерного фонда, шахматке, журнале брони. 
  • Менеджер. Сотрудник, ответственный за работу с контрагентом. Автоматически заполняется при создании контрагента, но может быть изменен в процессе работы. Реквизит можно использовать для отборов и группировки в отчетах чтобы оценить эффективность работы менеджеров. 
  • Дата и время регистрации в системе. Дата и время создания элемента в справочнике. Заполняется автоматически. Не редактируется. 

    Закладка "Правила начисления"

    Содержит правила начисления, которые переносятся при бронировании или размещения по данному контрагенту. 
    Если необходимо указать, что при выборе контрагента бронь будет оплачена по безналичному расчету контрагентом, то нужно нажать кнопку "По-умолчанию", которая создаст правило, по которому услуги по тарифу будут начисляться на фолио контрагента.

    • N (Номер строки). Определяет приоритет применения правила начисления. Для любой услуги сначала проверяется первое правило, если услуга удовлетворяет правилу, то выбирается этот счет, если нет, то проверяется следующее правило, со следующим номером строки. 
    • Способ разделения оплаты. Ссылается на перечисление «Типы правил начисления». Определяет какие услуги будут начислены на выбранный счет. 
    • Значение правила начисления. Ссылается на справочники «Наборы услуг», «Услуги». Используется, если в поле "Значение правила начисления" было выбрано "Услуги, включенные в набор услуг" или "Выбранная услуга". Указывается соответственно набор услуг или услуга. Можно выбирать группу услуг. Если выбрана услуга или набор услуг, то на указанный счет будут начисляться только те услуги, которые указаны в наборе или соответствуют выбранной услуге. 
    • Начислять на лицевой счет. Ссылается на документ «Фолио». Указывает на какой лицевой счет начислять услуги. Если у счета включен флажок "мастер-счет", то начисления будут произведены именно на этот счет, и, при выселении, этот счет не будет закрыт. 
      Если же в счете флажок "мастер-счет" выключен, то данный счет используется как шаблон. Т.е. при каждом заезде будет создаваться новый счет с такими же параметрами как и в выбранном счете. 
    • Действует с даты. Тип значения: «Дата». Указывает период действия правила. Если учетная дата начисления услуги раньше этой даты, то услуга не будет начислена на выбранный счет. 
    • Действует по дату. Тип значения: «Дата». Указывает период действия правила. Если учетная дата начисления услуги больше этой даты, то услуга не будет начислена на выбранный счет.

    Кнопка "По умолчанию" создает правила, в соответствии с шаблоном, заданном в справочнике "Гостиницы", на закладке "Правила начисления для контрагентов". 
    Кнопка "Уменьшить приоритет" опускает строку вниз и устанавливает больший номер строки. Тем самым уменьшается приоритет правила. 
    Кнопка "Увеличить приоритет" поднимает строку вверх и устанавливает меньший номер строки. Тем самым увеличивается приоритет правила.

      Закладка "Контактные лица"

      Содержит список контрактных лиц контрагента.

      • Руководитель. Имя руководителя. Может использоваться для печати договоров при подключении внешних печатных форм. 
      • Главный бухгалтер. Имя бухгалтера для печатных форм. 
      • Контактное лицо. Можно указать, если это необходимо, имена, номера телефонов или какую-нибудь другую информацию, для людей, которые являются представителями контрагента. Новые контактные лица контрагента автоматически добавляются в список контактных лиц, который можно просмотреть и отредактировать на закладке "Контактные лица". 

      Закладка "Тарифы"

      В таблице тарифов перечисляются те тарифы, которые можно использовать с данным контрагентом. Остальные тарифы будут недоступны для выбора. Если таблица тарифов пустая, то ограничений на выбор тарифа нет.

      • Тариф по умолчанию. Тариф, который будет подставлен автоматически при бронировании или размещении при выборе данного контрагента. 
      • Набор услуг начисляемый по тарифу. Значение будет автоматически подставлено в "Бронь" или "Размещение" при выборе договора. Соответственно по документу будут начислены только те услуги, которые включены в выбранный Набор услуг. 
      • Условия начисления штрафов. Ссылается на справочник «Условия начисления штрафов за незаезд и позднюю аннуляцию», в котором определяются формулы расчета штрафов за незаезд и позднюю аннуляцию. По этим формулам сумма штрафа автоматически вычисляется и начисляется на лицевые счета брони при установке у брони статуса "Незаезд" (обработкой "Снятие просроченной брони" или вручную) или при установке у брони статуса "Поздняя аннуляция". 

      Закладка "Договоры"

      Содержит список договоров контрагентов.

      • Договор по умолчанию. Указывает какой договор будет автоматически подставлен в документ при выборе данного контрагента. 

      Закладка "Банковские счета"

      Содержит список банковских счетов контрагентов. Реквизиты счета контрагента используются для печати счетов-фактур.

      • Основной банковский счет контрагента. Автоматически подставляется в счет на оплату. 

      Закладка "Кредитные карты"

      Содержит список кредитных карт контрагента.

      Закладка "Статистика"

      • Тип клиента. Выбранное значение будет подставляться автоматически в документы при выборе контрагента. 
      • Строка подтверждения для типа клиента. Комментарий к выбранному типу клиента и причине назначения данного типа клиента. 
      • Примечания для типа клиента. Комментарий к выбранному типу клиента. Может содержать указания для менеджеров и сотрудников по работе с данным клиентом. 
      • Направление маркетинга. Выбранное значение будет подставляться автоматически в документы при выборе контрагента. 
      • Источник информации о гостинице. Выбранное значение будет подставляться автоматически в документы при выборе контрагента.

      В таблице статистики отражаются данные по гостям контрагента.

      Способ вызова

      Вызывается из меню "Взаиморасчеты/Справочники/Контрагенты", либо в главном меню кнопка "Еще", далее кнопка "Контрагенты".
