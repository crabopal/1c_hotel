Справочник "Обработки"

Назначение

Справочник пользовательских настроек обработок. Используется для создания списка часто используемых обработок с заранее определенными параметрами. Часть параметров обработок можно вычислять при запуске по формулам, которые указываются в настройках. Форма ввода формул открывается по кнопке "Динамические параметры" на форме элемента настройки обработки. Можно создавать настройки как для типовых обработок реализованных в конфигурации, так и для любых внешних обработок.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 6, тип кода: Число.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Внешняя обработка. Если флажок включен, то используется внешняя обработка. 
  • Обработка. Указывается наименование обработки из конфигурации так как она задана в метаданных, либо указывается ссылка на внешнюю обработку, загруженную в справочник «Внешние обработки».
  • Статические параметры обработки. Содержит параметры обработки указываемые на форме самой обработки. Для редактирования настроек необходимо открыть форму обработки, установить параметры, и нажать на кнопку "Сохранить параметры".
  • Динамические параметры обработки. Содержит алгоритм заполнения параметров по умолчанию при открытии формы обработки.
  • Набор прав. Если реквизит заполнен, то обработка будет доступна пользователю с выбранным набором прав. Если необходимо предоставить доступ к обработке пользователям с разными наборами прав, то необходимо заполнить таблицу "Наборы прав" ниже.
  • Ключ регламентного задания. Строка с уникальным идентификатором обработки, обычно совпадает с именем обработки. По этому ключу фоновое задание "Выполнить обработку" находит необходимую обработку и запускает ее. Фоновые задания не могут исполнять внешние обработки, т.е. в фоновые задания можно включить только обработки, включенные в конфигурацию. 
  • Порядок сортировки. Числовое значение, может использоваться для сортировки списка обработок в форме выбора.
  • Примечания. Произвольный комментарий к обработке. 

Табличная часть «Наборы прав»

Содержит перечень наборов прав пользователей, которым разрешен доступ к данной обработке. Если не указан ни один набор прав, то доступ к обработке будет только у тех пользователей, у которых в наборе прав включен флажок "048 - Есть права на выполнение любых процедур. Иначе есть права только на процедуры из набора прав". 

Способ вызова

Вызывается из меню "Обработки"
