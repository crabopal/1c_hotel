Справочник "Номенклатурные группы"

Назначение

Справочник «Номенклатурные группы» содержит список номенклатурных групп по которым в бухгалтерском учете ведется учет доходов. Номенклатурные группы указываются у услуг. Коды бэк-офиса номенклатурных групп входят в состав данных выгружаемых в программы бухгалтерского учета.

Относится к подсистеме: «Настройки/Бухгалтерия».

Параметры

Длина кода: 5, тип кода: Строка

Длина наименования: 100

Не иерархический. 

Реквизиты

Код бэк-офиса: 50, тип кода: Строка. Участвует, как код номенклатурной группы, при выгрузке в бухгалтерию. Если не указан, то для выгрузки используется обычный код номенклатурной группы.
