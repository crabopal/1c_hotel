Справочник "Отделы"

Назначение

Справочник содержит организационную структуру отделов гостиницы. Используется в сообщениях. Можно, например отправить сообщение на отдел, тогда это сообщение будет доступно только пользователям из этого отдела.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Число, используется для сортировки в отчетах.
  • Гостиница. Ссылается на справочник «Гостиницы». Определяет гостиницу, которой принадлежит отдел. 
  • Примечания. Произвольный комментарий.

Способ вызова

Вызывается из меню "Настройки/Отделы"
