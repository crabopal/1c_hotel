Справочник "Типы скидок"

Назначение

Использование типов скидок позволяет хранить историю изменения процента скидки и изменять этот процент централизованно. В карточке типа скидки можно указать наименование и выбрать накопительная это будет скидка или нет.

В типе скидки можно задать набор услуг. В этом случае скидка будет применяться только к услугам из указанного набора. Если набор услуг оставить пустым, то скидка будет применяться ко всем услугам. Если процентное значение указано со знаком минус, то цена автоматически будет увеличена на указанное процентное значение (наценка).

Относится к подсистеме "Скидки".

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Используется для сортировки в отчетах.
  • Действует с даты. Задает начало действия скидки.
  • Действует по и включая дату. Окончание действия скидки.
  • Требовать ввод строки подтверждения. Тип значения: «Булево». Если необходимо контролировать предоставленные скидки, то можно настроить выполнение проверки. И при выборе данного типа скидки программа потребует ввести подтверждение.
  • Шаблон строки подтверждения. Строка с шаблоном подтверждения показывается при выборе типа скидки. 
  • Группа услуг, на которую действует скидка/наценка. Ссылается на справочник «Наборы услуг». Возможно задать набор услуг. В этом случае скидка будет применяться только к услугам из указанного набора. Если набор услуг оставить пустым, то скидка будет применяться на все услуги.
  • Округлять цену. Если включен флажок то будет произведено округление цены после применения скидки.
  • Разрядность округления цены (...; -2 до 100; -1 до 10; 0 до 1; 1 до 0.1; 2 до 0.01; ...). Задает до скольких знаков округлять цену.
  • Разрешены различные проценты скидок для разных наборов услуг. Тип значения: «Булево». Означает, что для одного типа скидки можно ввести насколько наборов услуг и дать им различные проценты.
  • Суммовая скидка. Тип значения: «Булево». Если включена, то в документах указывается не процент скидки, а сумма, которая равномерно "размазывается" по услугам начисляемым автоматически по тарифу проживания или по настройкам цен ресурсов. Указывать процент скидки у таких типов скидок нельзя.
  • Тип скидки назначается вручную в документах и не может быть автоматически изменен или отменен. Тип значения: «Булево». Ставится в тех случаях, если вы хотите, чтобы независимо от производимых изменений в брони/размещении и пересчетах, скидка оставалась неизменной.
  • Персональная скидка (не применяется ко всей группе гостей). Тип значения: «Булево». Если флажок включен – означает, что скидка будет применима только для данного гостя, в карточке которого идет выбор скидки. Если нет, то при выборе скидки для одного гостя из группы, она будет распространяться на всех проживающих из группы.
  • Накопительная скидка. Если включено, то включается механизм накопительных скидок. 
  • Тип накопительной скидки должен быть выбран в документах явно. Накопительная скидка применяется автоматически для всех гостей. Но если включить данную галочку, то накопительная скидка будет применена только для тех гостей, у которых явно выбран данный тип скидки. Таким образом можно указать, что программа скидок распространяется не на всех, а только на выбранных гостей. 
  • За каждый заезд. Если включено, то будут учитываться накопления только по текущему размещению гостя и не будут учитываться предыдущие заезды.
  • Применять ко всему периоду проживания. Если выключено, то скидка будет применена только к последующим дням проживания после достижения порога скидки. Например: при цене 1000 руб. за ночь в гостинице определена скидка 5%, если накоплено более 5000 руб. В этом случае первые 5 ночей будут стоить по 1000 руб., а 6-я и далее ночи будут на 5% дешевле. Если же данный флажок включить, то 5% скидка будет применена на весь срок проживания, т.е. включая первые 5 ночей. 
  • Накопительная скидка применяется только к "открытым" тарифам. Скидка будет применена только к тем тарифам у которых включен флажок "Открытый тариф".
  • Тип накопительной скидки. Определяет по какому параметру происходит накопление - ночи, заезды, сумма услуг.
  • Внешний алгоритм. Ссылается на справочник «Внешние обработки». Может содержать произвольный алгоритм расчета.
  • Измерение накопительной скидки. Определяет в разрезе чего происходит накопление - по гостям, контрагентам, дисконтным картам. 
  • Период накопления в днях. Задает срок проверки накопления скидки. Если не указан, то берется вся история базы.
  • Дата начала периода накопления. Определяет начальную дату, с которой накапливается скидка. 
  • Отключить автоматические скидки. Означает, что данная сидка является приоритетной, и, при ее выборе, накопительные скидки рассчитываться и применяться не будут.
  • Каждый N день бесплатно. Означает, что основные услуги из тарифа в брони и размещении будут начисляться по нулевой цене каждый указанный в этом поле день из периода проживания. Обычно используется в типах скидок без указания процента скидки.
  • Коэффициент расчета бонусов. Коэффициент, используемый для расчета суммы бонусов по накопленной базе. Пример: если накапливаются заезды, то коэффициент показывает сколько бонусов будет начислено за каждый заезд; если накапливаются человекодни, то коэффициент показывает сколько бонусов будет начислено за каждый прожитый гостем день; если накапливается сумма оказанных услуг, то коэффициент показывает, сколько бонусов будет начислено за каждую единицу отчетной валюты.
  • Множитель пересчета суммы оплаты бонусами в кол-во списываемых бонусов. Множитель используемый при списании накопленных бонусов в счет оказанных услуг. Коэффициент показывает сколько бонусов будет списано за каждую единицу валюты платежа с учетом курса пересчета из таблицы курсов валют. Если коэффициент не указан, то он принимается равным 1. Кол-во списываемых бонусов получается по формуле = [сумма оплаты бонусами в валюте платежа]*[курс пересчета бонусов валюты платежа в базовую валюту гостиницы из таблицы курсов на дату курса платежа]*[данный множитель]. Пример: если множитель равен 10, то за каждые 10 бонусов в счет оплаты услуг пойдет 1 единица базовой валюты.
  • Примечания. Комментарий к скидке.
