Справочник "Наборы прав доступа в системах электронных замков"

Назначение

Каждый элемент справочника содержит набор авторизационных параметров, которые открывают/закрывают доступ гостей к каким-либо помещениям с установленными электронными замками. На форме выдачи электронных карт-ключей сотрудник гостиницы, если у него есть права, может указать один из доступных ему наборов. Ключ будет выдан в соответствии с указанными в наборе правами доступа. Список доступных сотруднику наборов авторизационных параметров указывается в наборе прав сотрудника. Поля в справочнике необходимо заполнять в соответствии с установленной в гостинице системой электронных замков. Для систем компании Norweq используются поля "Тип карты" и "Группа пользователей". Для систем компаний Onity, Salto, Inhova, Ciza заполняются поля "Разрешенные гостям права доступа" и "Запрещенные гостям права доступа". Правила ввода значений параметров правил доступа описаны в документации к соответствующим системам электронных замков.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип карты ключа. Должен соответствовать значению CardType в системе VISION .
  • Группа пользователей. Должен соответствовать UserGroup в системе VISION.
  • Разрешенные гостям права доступа. Строка передается в систему электронных замков в качестве параметра доступа. Должен соответствовать настройкам системы электронных замков. 
  • Запрещенные гостям права доступа. Передается в систему электронных замков при кодировании карты. Определяет зоны запрещенные к доступу по карте. Должен соответствовать настройкам в системе электронных замков.
  • Примечания. Комментарий к записи. 

Способ вызова

Вызывается из меню "Настройки/Наборы прав доступа в системах электронных замков"
