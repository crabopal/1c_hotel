Справочник "Параметры системы электронных замков"

Назначение

Справочник параметров системы управления электронными замками. Определяет тип системы и параметры подключения к системе. Данные параметры привязываются к рабочему месту в справочнике "Рабочие места". На каждом рабочем месте могут быть свои настройки для подключения к разным энкодерам карт.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип системы электронных замков. Определяет тип поддерживаемой системы электронных замков.
  • Тип подключения. Указывается как происходит подключение - по TCP/IP, RS232 или USB.
  • Имя сервера. Используется при подключении по TCP/IP. Указывается либо имя либо IP адрес сервера где запущена служба PMS интерфейса замковой системы. 
  • Папка обмена. Используется для систем с интерфейсом через обмен файлами.
  • Порт. Имя порта подключения при соединении по RS232. Например COM1 
  • Скорость обмена. Указывается при подключении по RS232. Число определяющее скорость. Например: 9600 
  • Четность. Параметр работы COM порта.
  • Биты данных. Параметр работы COM порта.
  • Стоп биты. Параметр работы COM порта.
  • Идентификатор рабочей станции (XX). Передается в систему электронных замков. Определяет с какой станции идет команда. Должен соответствовать значению заданному в системе электронных замков 
  • Номер энкодера. Номер энкодера, на котором должна быть изготовлена карта. Все энкодеры нумеруются в настройках системы электронных замков. 
  • Тип карты ключа. Соответствует CardType в системе электронных замков VingCard. Для системы Orbita определяет тип замка, например MAGNETIC_LOCK. 
  • Группа пользователей. Для системы VingCard соответствует параметру UserGroup.
  • Разрешенные гостям права доступа. Права доступа по-умолчанию передаваемые в систему электронных замков.
  • Запрещенные гостям права доступа. Запрещенные права доступа передаваемые в систему электронных замков.
  • Разрешен выбор параметров авторизации при выдаче ключей. Тип значения: «Булево». Если "истина",то пользователь на форме выдачи карт-ключей может выбрать нужный набор дополнительных дверей, которые должен открывать ключ.
  • Код лицензии. Код лицензии для кодирования карт. Для системы VingCard VISION должен быть PMS Code (используется только при подключении по TCP/IP).
  • Транслитерировать имена гостей (Иванов -> Ivanov). Некоторые системы электронных замков неверно отражают буквы русского алфавита. В этом случае необходимо включать транслитерацию.
  • Делать карты только из списка лицевых счетов. Включают когда карта от номера служит расчетной картой гостя, на которую внесен депозит. В таком случае карта-ключ привязывается к лицевому счету, баланс по счету будет балансом карты. Энкодер системы замков должен поддерживать запись на 2-ю дорожку.
  • При отправке команд на сервер электронных замков использовать коды номеров в системе, а не наименования номеров.Если включен, то в систему электронных замков будет отправляться код номера комнаты указанный в реквизите "Код в системе электронных замков" в номерном фонде. Если выключен, то будет использоваться наименование номера.
  • Количество минут, вычитаемое из времени заезда гостя. При кодировании карты время заезда будет уменьшено на указанное число минут. Используется для систем в которых замки не переводят зимнее/летнее время автоматически.
  • Записывать первую дорожку. Если включен, то энкодер системы должен поддерживать запись на 1-ю дорожку. На эту дорожку записывается строка состоящая из идентификатора карты, номера лицевого счета, номера комнаты, полного имени клиента, даты заезда и даты выезда. Все поля строки отделены друг от друга символом "^". В зависимости от типа системы электронных замков ограничена максимальная длина данных на первой дорожке. Для, например, системы Norweq Vision эта длина данных записываемых на 1-ю дорожку ограничена 76 символами.
  • Записывать вторую дорожку. Если включен, то энкодер системы должен поддерживать запись на 2-ю дорожку. На эту дорожку будет записан идентификатор персональной карты гостя. В этом случае карта-ключ привязывается к счету гостя и может выступать как карта оплаты в баре или ресторане гостиницы.
  • Максимальное кол-во символов на 1-ой дорожке.

Способ вызова

Вызывается из меню "Настройки/Параметры систем электронных замков"
