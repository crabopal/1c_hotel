Справочник "Настройки сотрудников"

Назначение

Справочник настроек сотрудников (пользователей). Выбранные пользователем параметры вступят в силу только после перезапуска программы.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 10, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Пароль ККМ. Тип значения: «Строка». Если сотрудник будет пробивать чеки на ККМ в режиме фискального регистратора, то для того, чтобы программа не запрашивала пароль каждый раз при пробивании чека, его можно ввести в поле «Пароль ККМ». 
  • Имя пользователя в охранной системе. Передается в интерфейс с охранной системой. 
  • Пароль пользователя в охранной системе. Передается в интерфейс с охранной системой. 
  • Имя пользователя в системе электронных замков. Передается в систему электронный замков как подпись автора ключа. 
  • Пароль пользователя в системе электронных замков. Передается в интерфейс с системой электронных замков. Используется для систем, запрашивающих такой пароль. 
  • Стиль оформления программы. Указывает стиль оформления форм. Влияет на цветовую гамму форм. 
  • Спрашивать подтверждение выбора способа оплаты. Если в гостинице возможен расчет по кредитным картам, то рекомендуется включать пользователям-кассирам флажок «Спрашивать подтверждение выбора способа оплаты». 
  • Спрашивать подтверждение завершения работы с программой. Также рекомендуется всем пользователям включать опцию «Спрашивать подтверждение завершения работы с программой». Это позволит сократить число ошибочных выходов из программы, когда пользователи попадают мышкой не в «крестик» закрытия нужного окна, а в кнопку закрытия приложения. 
  • Спрашивать число строк для копирования в таблице состава группы гостей в брони и размещениях. Если флажок включен, то программа будет запрашивать количество строк при копировании. Если выключен, то будет молча добавляться одна строка. Используется в документах "Бронь" и "Размещение" на закладке "Состав группы". 
  • По умолчанию открывать проведенную бронь только на чтение. Рекомендуется включить пользователям, которые обычно не исправляют бронь (ресепшн), для того чтобы не путали бронь с документом Размещение и не забывали нажимать кнопку "Поселить" при оформлении гостя. 
  • При вводе паспортных данных клиента копировать адрес места рождения в адрес прописки. Часто эти адреса совпадают. Такая опция сокращает время оформления гостя на потоке. 
  • Не показывать сообщения о недостатке свободных номеров. Если флажок включен, то при проведении бронирования или размещения пользователю не будет показываться сообщение о недостатке мест. Документы будут проведены если мест хватает и не будут проведены если мест недостаточно и у пользователя нет прав игнорировать нехватку мест. 
  • При вводе данных нового клиента копировать адреса из карточки главного в группе. Удобно включать этот флажок при оформлении больших групп гостей, приехавших из одного города. Данный флажок можно включить в день заезда такой группы, и, после окончания оформления группы, выключить его. 
  • Использовать 24:00 для отображения полночи в календаре брони ресурсов. Используется при отображении календаря занятости ресурсов. Если флажок выключен, то для отображения полночи используется 00:00 

Способ вызова

Вызывается из главного меню по кнопке "Еще", на дополнительной панели №3 кнопка "Настройки сотрудника"
