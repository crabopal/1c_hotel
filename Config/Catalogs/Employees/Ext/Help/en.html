Справочник "Сотрудники"

Назначение

Содержит список сотрудников гостиниц и их учетные данные. Если сотрудник работает с программой, то его запись в справочнике создается автоматически при первом запуске программы под этим сотрудником. Если сотрудник не работает с программой, например это горничная, то его можно добавить в справочник вручную. В случае ручного добавления сотрудника в справочник в качестве кода рекомендуется использовать инициалы, например, для сотрудника Иванов Петр Викторович код сотрудника будет ИПВ. В качестве наименования сотрудника рекомендуется указывать фамилию и инициалы, например Иванов П.В. Не рекомендуется указывать полное имя человека, т.к. потом длинное имя будет неудобно читать в колонках автора документов, автора сообщений и т.д. Если сотрудник работает с программой, то, после первого запуска программы от имени этого сотрудника, необходимо установить привязку сотрудника к гостинице и назначить сотруднику его набор прав.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 36, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Переводы имени сотрудника на различные языки. Тип значения: «Строка». Используется в печатных формах на иностранных языках для перевода имени менеджера выставившего счет или принявшего бронь. 
  • Пол. Ссылается на перечисление «Пол». 
  • Гостиница. Ссылается на справочник «Гостиницы». В большинстве случаев должно быть заполнено гостиницей в которой работает сотрудник. 
  • Отдел. Ссылается на справочник «Отделы». Указывается, что сотрудник работает в отделе. 
  • Секция номеров. Ссылается на справочник «Секции номерного фонда». Устанавливает привязку сотрудника к определенной секции номерного фонда 
  • Номер. Ссылается на справочник «Номерной фонд». Обычно это папка номеров. Устанавливает привязку сотрудника к этажу или корпусу гостиницы. Используется обычно у горничных и супервайзеров. 
  • Должность. Тип значения: «Строка». 
  • Учетный номер. Тип значения: «Строка». Табельный номер в системе управления персоналом. 
  • Код доступа в АТС. Тип значения: «Число». Персональный код который сотрудник набирает на телефоне при регистрации работ в номерах. 
  • Набор прав. Ссылается на справочник «Наборы прав». Набор прав сотрудника. Определяет уровень допуска сотрудника к различным бизнес-операциям. 
  • Настройки пользователя. Ссылается на справочник «Настройки сотрудников».
  • Рабочее место. Ссылается на справочник «Рабочие места». Указывается в случаях, когда программа эксплуатируется в терминальном режиме. В таких случаях реальное рабочее место (компьютер где исполняется программа) -- это терминальный сервер, но сотрудникам нужны разные настройки по доступу к оборудованию, ККМ и т.д. В этом случае в справочнике рабочих мест создаются записи соответствующие виртуальным рабочим местам с нужными настройками и сотрудники "привязывается" к таким виртуальным рабочим местам. 
  • Фамилия. Тип значения: «Строка». Фамилия сотрудника полностью 
  • Имя. Тип значения: «Строка». Имя сотрудника полностью 
  • Отчество. Тип значения: «Строка». Отчество сотрудника полностью 
  • Гражданство. Ссылается на справочник «Страны». Страна гражданства сотрудника 
  • Телефоны. Тип значения: «Строка». Домашние/служебные телефоны сотрудника 
  • E-mail. Тип значения: «Строка». E-mail сотрудника

Обязательное поле в случаях, когда сотрудник отправляет подтверждения брони или счета-требования по E-mail непосредственно из программы

  • Список E-mail адресов для ответов. Тип значения: «Строка». E-Mail, который программа подставит в качестве адреса для отправки ответов в электронных письмах с подтверждениями брони и счетами-требованиями. Если не указано, то в качестве обратного адреса в электронном письме отправленном из программы указывается E-Mail сотрудника.  
  • Bcc (скрытая копия) E-Mail. Тип значения: «Строка». Куда скрыто пересылать письма отправляемые из программы 
  • Дата рождения. Тип значения: «Дата». 
  • Место рождения. Тип значения: «Строка». Может заполняться по адресному классификатору 
  • Адрес проживания. Тип значения: «Строка». Может заполняться по адресному классификатору 
  • ИНН. Тип значения: «Строка». 
  • Вид документа удостоверяющего личность. Ссылается на справочник «Виды документов удостоверяющих личность»
  • Серия документа удостоверяющего личность. Тип значения: «Строка». 
  • Номер документа удостоверяющего личность. Тип значения: «Строка». 
  • Дата выдачи документа удостоверяющего личность. Тип значения: «Дата». 
  • Документ удостоверяющий личность действителен до. Тип значения: «Дата». 
  • Кем выдан документ удостоверяющий личность. Тип значения: «Строка». 
  • Воинское звание. Ссылается на справочник «Воинские звания»
  • В запасе. Тип значения: «Булево». 
  • Примечания. Тип значения: «Строка». 
  • Порядок сортировки. Тип значения: «Число». Используется для сортировки сотрудников в отчетах в порядке отличном от сортировки по фамилии. 
  • Адрес SMTP сервера электронной почты. Тип значения: «Строка». Заполняется IP адресом или именем почтового сервера через который программа будет отправлять электронные письма с подтверждением брони или счетами-требованиями 
  • Порт SMTP сервера электронной почты. Тип значения: «Число». 
  • Тип аутентификации используемый SMTP сервером. Ссылается на перечисление «Типы идентификации пользователей SMTP сервером». 
  • Имя пользователя SMTP сервера интернет почты. Тип значения: «Строка». Логин на сервер электронной почты 
  • Пароль пользователя SMTP сервера интернет почты. Тип значения: «Строка». Пароль на сервер электронной почты 
  • Обязательно подключаться сначала к POP3 серверу перед подключением к SMTP серверу. Тип значения: «Булево». 
  • Адрес POP3 сервера электронной почты. Тип значения: «Строка». Используется для получения почты с почтового ящика непосредственно в программе. 
  • Порт POP3 сервера электронной почты. Тип значения: «Число». 
  • Тип аутентификации используемый POP3 сервером. Ссылается на перечисление «Типы идентификации пользователей POP3 сервером». 
  • Имя пользователя сервера интернет почты. Тип значения: «Строка». 
  • Пароль пользователя сервера интернет почты. Тип значения: «Строка». 
  • Время ожидания соединения с сервером электронной почты. Тип значения: «Число». 
  • Подпись. Тип значения: «Хранилище значения». Факсимиле подписи сотрудника. Используется в печатной форме счета-требования при печати с включенным в счете флажком "Печатать с печатью фирмы" 
  • Последние открытые объекты. Тип значения: «Хранилище значения». Используется для хранения списка последних 50 объектов (документов/элементов справочников), которые открывал/создавал этот сотрудник.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов. 
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы. 
  • Форма элемента. Основная форма объекта. Используется для заполнения реквизитов сотрудника. 

Способ вызова

Вызывается из меню "Настройки/Сотрудники"
