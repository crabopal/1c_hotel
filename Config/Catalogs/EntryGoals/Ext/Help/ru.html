Справочник "Цели въезда"

Назначение

Справочник содержит перечень целей въезда иностранных граждан на территорию РФ. Цель въезда может быть выбрана при заполнении уведомления о регистрации иностранного гражданина в группе полей с данными визы. Используется для предоставления сведений об иностранных гражданах в службу УФМС.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 6, тип кода: Строка.

Длина наименования: 50.

Не иерархический.

Реквизиты

  • Тип визы. Указывается с каким типом визы можно использовать данную цель въезда.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Цели въезда"
