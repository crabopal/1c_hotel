Справочник "Мероприятия"

Назначение

Справочник мероприятий (выставок, экспозиций, встреч), которые проходят рядом с гостиницей. Если мероприятие заведено в справочнике, то это мероприятие показывается на форме графической карты загрузки номерного фонда, в отчете "Загрузка гостиницы по дням" и в отчете "Планируемые группы". Мероприятия выводятся в шапке форм для справки, чтобы при анализе загрузки гостиницы легче было привязываться к событиям.

Относится к подсистеме: «Управление Номерным Фондом».

Параметры

Длина кода: 12, тип кода: Строка. Включена автонумерация.

Длина наименования: 150.

Не иерархический.

Реквизиты

  • Дата с. Тип значения: «Дата». Дата начала мероприятия. Обязательное поле для заполнения.
  • Дата по. Тип значения: «Дата». Дата окончания мероприятия. Обязательное поле для заполнения.
  • Цвет. Тип значения: «Хранилище значений». Цвет мероприятия в отчетах и графической карте номеров. Если не выбран, то используется серый цвет RGB(240, 240, 240)
  • Примечания. Тип значения: «Строка». Описание мероприятия.
  • Гостиница. Тип значения: Элемент справочника «Гостиницы». Может быть не заполнен. В этом случае мероприятие доступно при работе с данными любой гостиницы.

Способ вызова

Вызывается:

  • Из меню "Номерной фонд/Справочники/Мероприятия" системного администратора программы
  • Из главного меню менеджера по продажам на 2-ой дополнительной закладке по кнопке "Мероприятия"
  • Из отчета "Загрузка гостиницы по дням" при двойном щелчке левой кнопкой мыши в любой дате на строке мероприятий. Строка показывается только, если в период отчета попадает хотя-бы одно не помеченное на удаление мероприятие. Также, из панели инструментов отчета по кнопке "Мероприятия"
  • Из отчета "Планируемые группы" при двойном щелчке левой кнопкой мыши в любой дате на строке мероприятий. Строка показывается только, если в период отчета попадает хотя-бы одно не помеченное на удаление мероприятие. Также, из панели инструментов отчета по кнопке "Мероприятия"
  • Выделением периода в строке мероприятий в графической карте номерного фонда. Строка показывается только, если в период загрузки данных карты попадает хотя-бы одно не помеченное на удаление мероприятие. Также, из панели инструментов формы по кнопке "Мероприятия"
  • Из формы "Свободные номера по квотам" при двойном щелчке левой кнопкой мыши в любой дате на строке мероприятий. Строка показывается только, если в период формы попадает хотя-бы одно не помеченное на удаление мероприятие. Также, из панели инструментов формы по кнопке "Мероприятия"
