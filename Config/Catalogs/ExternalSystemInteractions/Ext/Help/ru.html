Справочник "Взаимодействия с внешними системами"

Назначение

Справочник используется для управления активностью и настройками интерфейсов к внешним системам. Позволяет включать/выключать взаимодействия, задавать период активности подключений, хранить параметры взаимодействий.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 36, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Период активности взаимодействия. Указывается дата начала и дата окончания периода действия.
  • Кол-во дней действия взаимодействия. Указывается кол-во дней от текущей рабочей даты в течении которых будет активно взаимодействие. Используется для указания "скользящего" периода взаимодействия, например, для указания периода выгрузки остатков свободных номеров во внешнюю систему.
  • Действует. Тип: Булево. Используется для быстрого отключения/активации взаимодействия. 
  • Параметры. Данные конфигурационного XML файла взаимодействия. Изменить параметры можно по кнопке "Настроить параметры" в карточке взаимодействия 
  • Ссылка базы данных. (Infobase URL). Если заполнена, то ссылка на объекты базы данных будет дополнена значением этой переменной. Используется при интеграции с CRM или PBX. По клику на ссылку автоматически открывается база 1С-Отель в которой уже открыта форма объекта. Ссылка должна начинаться c e1c://

Возможно указывать либо период действия либо кол-во дней действия. Это взаимоисключающие реквизиты.

Способ вызова

Вызывается из меню "Настройки/Взаимодействия с внешними системами"
