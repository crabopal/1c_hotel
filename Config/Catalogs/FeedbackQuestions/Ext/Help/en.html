Справочник "Вопросы для отзывов"

Назначение

Справочник "Вопросы для отзывов" используется для создания списка вопросов и определения вариантов ответов на вопрос для опросных листов обратной связи (документы "Отзывы клиентов"), которые либо печатаются и выкладываются в номера гостей, либо отправляются по почте гостю после выезда.

Относится к подсистеме: «Настройки/Отзывы».

Параметры

Длина кода: 12, тип кода: Строка. Автонумерация

Длина наименования: 100.

Иерархический.

Реквизиты

  • Текст вопроса. Строка 1000 символов. Содержит текст вопроса.
  • Тип ответа. Перечисление. Содержит возможные варианты типов ответа.
  • Диапазон числового ответа с. Число. Если тип ответа "Число", то можно указать диапазон вариантов ответа от и до.
  • Диапазон числового ответа по. Число.

Способ вызова

Вызывается из меню "Настройки/Отзывы/Вопросы для отзывов"
