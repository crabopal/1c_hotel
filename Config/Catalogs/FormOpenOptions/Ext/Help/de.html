Справочник "Настройка внешнего вида форм"

Назначение

Справочник используется для изменения внешнего вида форм объектов программы согласно пожеланиям пользователей. Настройки реализованные в справочнике позволяют управлять видимостью, доступностью и заголовками элементов форм. 

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 9, тип кода: Строка.

Длина наименования: 150.

Иерархический. Группы справочника создаются автоматически при заполнении структурой объектов метаданных программы.

Реквизиты

  • Форма. Название формы, настройки полей которой будут изменяться

Табличная часть Элементы формы

  • Имя элемента. Имя элемента формы для которого изменяются параметры.
  • Видимость. Признак видимости элемента. 
  • Доступность. Признак доступности элемента. 
  • Требовать заполнения. Признак обязательности заполнения элемента на форме. 
  • Заголовок. Текст заголовка элемента формы. 

Способ вызова

Вызывается из меню "Настройки/Администрирование"
