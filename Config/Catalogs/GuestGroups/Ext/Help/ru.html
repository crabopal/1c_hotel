Справочник "Группы гостей"

Назначение

Группы (заезды). Группа является понятием, которое объединяет гостей из одного заезда. Группы идентифицируются уникальными номерами. У каждой группы может быть указано краткое описание, по которому возможен поиск данных наравне с номером группы.

Номер группы является номером подтверждения брони.

Группа является одним из 3-х основных учетных параметров вместе с контрагентом и договором. В разрезе контрагентов, договоров и групп программа ведет управленческий баланс взаиморасчетов. В большинстве форм списков программы возможен отбор данных по группам. Справочник наполняется автоматически при бронировании и поселении, большинство реквизитов справочника также заполняются автоматически. Ситуации, когда элементы этого справочника нужно создавать вручную очень редки.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 12, тип кода: Число. Номер группы (номер подтверждения брони)

Длина наименования: 50. Краткое описание группы

Иерархический.

Владельцы справочника: «Гостиницы».

Объекты, вводимые на основании: «Счет-требование», «Отгрузка путевок», «Акт».

Реквизиты

  • Контрагент. Ссылается на справочник «Контрагенты». Контрагент, от которого заезжают гости в группе
  • У группы разрешен только один контрагент/договор/агент. Тип значения: «Булево». Важный параметр. По умолчанию флажок включен и программа автоматически следит за тем, что у всех гостей из группы будет один и тот же плательщик, способ оплаты услуг и правила разделения услуг между контрагентом и самим гостем. Если у какого-либо гостя в группе меняется способ оплаты с наличного расчета на безналичный, то программа автоматически изменит способ оплаты у всех гостей, которые входят в эту группу. Если флажок выключен, то у каждого гостя в группе можно указать индивидуальные параметры оплаты. У гостей могут быть указаны различные контрагенты и договоры, различные способы оплаты и правила разделения услуг между контрагентом и гостем. 
  • Клиент. Ссылается на справочник «Клиенты (гости)». Главный клиент в группе. Руководитель группы. По умолчанию заполняется программой автоматически тем гостем, которому оказано услуг на максимальную сумму. Если реквизит установлен вручную, то он фиксируется и далее автоматически не меняется.
  • Клиент установлен вручную. Тип значения: «Булево». Истина, если руководитель группы выбран вручную
  • Дата заезда. Тип значения: «Дата». Краткое описание. Самая ранняя дата заезда гостей из группы
  • Продолжительность в днях или часах. Тип значения: «Число». Продолжительность проживания группы в гостинице.  Высчитывается автоматически при указании дат заезда и выезда. При размещении по почасовым тарифам рассчитывается в часах. Во всех остальных случаях рассчитывается в днях.
  • Дата выезда. Тип значения: «Дата». Самая поздняя дата выезда гостей из группы.
  • Заезд гостей. Тип значения: «Число».  Количество гостей заезжающих по группе
  • Цвет в карте загрузки НФ. Тип значения: «Хранилище значения». Цвет отображения гостей из этой группы в графической карте номерного фонда, шахматке, журнале брони.
  • На проверке. Тип значения: «Булево». Если флажок включен, то группа стоит на проверке, т.е. по группе не формируются акты об оказании услуг даже если последний гость из группы уже выехал.
  • Примечания. Тип значения: «Строка». Подробное описание группы
  • Контрольная дата. Тип значения: «Дата». Дата, при наступлении которой необходимо получить от клиента подтверждение заезда, уточнить условия бронирования, состав и число заезжающих гостей
  • Код во внешней системе. Тип значения: «Строка». Код группы во внешней системе бронирования, например в GDS
  • Менеджер. Ссылается на справочник «Сотрудники». Менеджер гостиницы ответственный за работу с гостями из этой группы. Заполняется автоматически при создании группы текущим сотрудником. Может быть изменен вручную
  • Дата и время регистрации в системе. Тип значения: «Дата». Дата и время создания группы в системе
  • Таблица правил начисления. Позволяет задать правила начисления, которые будут использоваться перед правилами, указываемыми в брони и размещениях. Позволяет создавать, например, единственный лицевой счет, на который будут выполняться начисления услуг контрагента.  

Формы

  • Форма элемента. Основная форма объекта. Используется для просмотра статистики по группе, навигации к связанной с группой информацией (журнал брони, проживающие гости, счета-требования, акты и проч.) и редактирования реквизитов группы.
  • Форма группы. Основная форма группы (папки с группами гостей). Используется для заполнения обязательных реквизитов папки групп. Папки групп гостей используются для ведения независимой нумерации групп в разных диапазонах номеров в распределенных базах данных. В случаях, когда бронирование возможно как в удаленном офисе продаж так и непосредственно в гостинице, номера групп создаваемые в разных местах не должны пересекаться. В параметрах гостиницы узла плана обмена можно указать, какая папка будет использоваться для ведения списка групп этого узла. Далее в папке вручную создается одна группа и в ней вручную устанавливается первый номер группы из выделенного для этого узла диапазона номеров групп.
  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма выбора папки группы. Основная форма выбора папки групп гостей. Используется для выбора папок групп.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Группы гостей"

Дополнительная информация

Программа позволяет быстро выполнять групповые операции (над всеми гостями группы): начисление доп. услуг, заезд, выселение, перевод гостей с наличного расчета на безналичный и наоборот и т.д.
