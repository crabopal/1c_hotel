Aktivieren Sie das Kontrollkästchen "Namen der Gäste löschen", wenn Sie neue Gäste auf der Buchungskarte angeben möchten. Wenn Sie eine Buchung kopieren, um eine neue Aufenthaltsdauer für Gäste aus der kopierten Buchung zu erstellen, müssen Sie dieses Kontrollkästchen deaktivieren. Aktivieren Sie das Kontrollkästchen "Dieselben persönlichen Konten und Abrechnungsregeln verwenden", wenn Sie möchten, dass die Dienste aus der neuen Buchung den persönlichen Konten der kopierten Buchung gutgeschrieben werden.
