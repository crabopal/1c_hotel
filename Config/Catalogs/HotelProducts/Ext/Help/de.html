Справочник "Путевки и курсовки"

Назначение

Справочник выданных клиентам путевок и курсовок.

Папки (группы) справочника считаются типами путевок/курсовок.

Путевки/курсовки не нужно добавлять в справочник заранее!

Достаточно создать папки определяющие типы путевок/курсовок, например, "Семейная", "Мать и дитя", "Детская", "Курсовка на питание" и проч. Определить для каждого типа путевки параметры по умолчанию, т.е заполнить реквизиты "Вид расчета продолжительности проживания", "Расчетный час", "Услуга", "Секция оплаты". Последние 2 реквизита не обязательные. В брони или размещении в поле "Путевка/курсовка" нужно руками ввести номер бланка путевки, который собираетесь выдать и нажать Enter. Номер вводится вместе с префиксом. Префикс можно указывать как в начале, так и в конце номера. Программа предложит вам выбрать тип путевки, социальный показатель (если справочник заполнен) и автоматически создаст путевку в выбранной папке с параметрами, которые она возьмет из настроек типа путевки и формы оформляемого документа.

Справочник является основным измерением оборотного регистра продаж путевок и курсовок.

Относится к подсистеме: «Продажи путевок и курсовок».

Параметры

Длина кода: 20, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Объекты, вводимые на основании: «Размещение», «Бронь».

Реквизиты

  • Не действует. Тип значения: «Булево». Позволяет временно сделать заезд не доступным. Не используется для путевок/курсовок.
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Квота номеров. Ссылается на справочник «Квоты номеров».
  • Тип номера. Ссылается на справочник «Типы номеров». Тип номера связанный с заездом или путевкой. Обязательно для заполнения.
  • Дата заезда. Тип значения: «Дата». Дата заезда, как указана в бланке путевки или дата начала периода проживания по заезду
  • Продолжительность в днях или часах. Тип значения: «Число».
  • Дата выезда. Тип значения: «Дата». Краткое описание. Дата выезда, как указана в бланке путевки или дата окончания периода проживания по заезду
  • Фиксировать период проживания. Тип значения: «Булево». Если включен заставляет программу рассчитывать услуги за проживание не по периоду реального заезда, а по периоду указанному в путевке.
  • Фиксировать планируемый период проживания. Тип значения: «Булево». Если включен, то период проживания в карточке путевки фиксируется и не изменяется при изменении периода проживания в брони/размещении. При включенном флажке "Фиксировать планируемый период проживания", в отличие от флажка "Фиксировать период проживания", программа рассчитывает услуги за проживание по периоду реального заезда, а не по периоду указанному в путевке.
  • Фиксировать стоимость путевки. Тип значения: «Булево». Если включен заставляет программу игнорировать цену проживания из тарифа и вычислять ее как частное от деления стоимости путевки на число дней проживания гостя.
  • Стоимость путевки. Тип значения: «Число». Полная стоимость путевки.
  • Валюта. Ссылается на справочник «Валюты». Валюта стоимости путевки.
  • Дата оплаты. Тип значения: «Дата». Заполняется вручную после оплаты путевки. Не обязательное поле. Может использоваться в отчетах по проданным путевкам/курсовкам.
  • Вид расчета продолжительности проживания. Ссылается на перечисление «Виды расчета продолжительности проживания». Указывает алгоритм вычисления даты выезда путевки по введенным дате заезда и продолжительности проживания.
  • Расчетный час. Тип значения: «Дата».
  • Услуга. Ссылается на справочник «Услуги». Заполняется только у типов путевок. Определяет услугу проживания по путевкам выбранного типа. Поле не обязательно для заполнения.
  • Секция оплаты. Ссылается на справочник «Секции оплаты». Заполняется только у типов путевок. Определяет платежную секцию, по которой будет проходить оплата путевок выбранного типа. Поле не обязательно для заполнения.
  • Примечания. Тип значения: «Строка». Подробное описание путевки.
  • Код во внешней системе. Код путевки во вешней системе, например в системе GDS
  • Социальный показатель. Ссылается на справочник «Социальные показатели». Используется как один из разделителей учета в отчетах по продажам путевок

Формы

  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма списка. Основная форма списка. Используется для отображения списка путевок.
  • Форма выбора. Основная форма выбора. Используется для отображения списка выбора элементов.
  • Форма выбора группы. Основная форма выбора группы. Используется для выбора групп.

Способ вызова

Вызывается из меню "Номерной фонд/Продажи путевок и курсовок/Путевки и курсовки" или из главного меню по кнопке "Еще...", закладка "2", кнопка "Путевки и курсовки".

Дополнительная информация

У путевок может фиксироваться стоимость и/или период проживания. Если у элемента справочника включен флажок "Фиксировать стоимость путевки" или флажок "Фиксировать период проживания" и эта путевка выбрана в брони или размещении, то основные услуги по тарифу рассчитываются программой по периоду и/или по стоимости путевки, а не по периоду проживания гостя или тарифу. Другими словами, если в размещении выбрана путевка "П100201 - 10-ти дневный заезд", а гость опоздал или выехал раньше чем должен был, то стоимость его проживания не изменится и будет соответствовать полной стоимости путевки.

Если включен флажок "Фиксировать стоимость путевки", то стоимость путевки будет равномерно распределена между днями периода реального проживания гостя.

Если включен флажок "Фиксировать период проживания", то услуги будут начисляться по тарифу, но по дням из периода проживания путевки, а не реального периода проживания гостя.

Флажки "Фиксировать стоимость путевки" и "Фиксировать период проживания" можно включать одновременно.
