Справочник "Типы карт идентификации клиентов"

Назначение

Используется для связки типов выдаваемых гостям и посетителям отеля идентификационных карт (карт используемых для организации безналичной системы оплат услуг на территории отеля) с условиями проживания гостя.

Тип карт можно указывать у тарифа или у пакета услуг. При выдаче карт гостям программа проконтролирует, что условия проживания гостя (тариф или пакет) соответствуют приложенной к считывателю карте. В этом режиме работы карты, перед выдачей клиентам, необходимо предварительно регистрировать в справочнике "Карты идентификации клиентов".

 

Относится к подсистеме: «Управление взаиморасчетами».

 

Для редактирования справочника у пользователя в наборе прав в режиме 1С:Предприятия должна быть включена галочка "092 - Есть права управлять номерным фондом"

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Используется в отчетах для сортировки данных по типам карт. 
  • Название цвета. Используется для именования цвета карт в случаях когда каждому типу карт соответствует свой цвет карты 
  • Цвет карты. Определяет цвет карт данного типа.
  • Тип (описание) фолио доп услуг. Если указано, то карту данного типа можно будет прикрепить только к фолио, у которых тип (описание) фолио начинается также, как указанная здесь строка.
  • Разрешенные внешние системы. При начислении услуг из внешних систем (СПА, Ресторан, ...) можно ограничить список систем, которые могут закрывать услуги на счет гостя по картам данного типа. В поле перечисляются коды этих систем через запятую, например: "СПА, TraktirFO".
  • Не использовать правила начисления. При начислении услуг из внешних систем (СПА, Ресторан, ...) обычно программа определяет фолио, на которое будет начислена услуга, по правилам начисления гостя, которому выдана карта. Если включена галочка "Не использовать правила начисления", то программа будет начислять такие услуги из внешних систем на фолио карты игнорируя правила начисления гостя.
  • Индивидуальная. При регистрации фактического оказания услуг (например на входе в зал питания по системе шведского стола) программа обычно позволяет одной картой зарегистрировать услуги всей семьи (всех гостей) из одного номера. Если включена галочка "Индивидуальная", то программа регистрирует услуги только гостя чья карта.
  • Регистрировать фактическое оказание услуг без контроля наличия начислений. Обычно программа при регистрации услуги проверяет, что услуга была ранее начислена на лицевой счет гостя (завтрак был начислен по тарифу или вручную на фолио). Если необходимо регистрировать оказание услуг без такой проверки, то включите эту галочку.
  • Разрешенный набор услуг. Если указан, то регистрация фактического оказания услуг, которые не входят в набор будет требовать ручного подтверждения от пользователя. Если не указан, то ручное подтверждение фактической регистрации услуги будет выполняться всегда. Под ручным подтверждением понимается отображение пользователю названия услуги и кому она была оказана. Для подтверждения пользователь должен выбрать эту услугу на экране. 
  • Примечания. Произвольный комментарий с пояснением к типу карт. 

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Типы карт идентификации клиентов"
