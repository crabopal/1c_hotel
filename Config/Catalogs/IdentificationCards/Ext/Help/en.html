Справочник "Карты идентификации клиентов"

Назначение

Справочник хранит список обслуживаемых электронных (магнитных) карт идентификации клиентов (гостей). По каждой карте хранится ссылка на лицевой счет, клиента, параметры проживания этого клиента.

Новые карты могут регистрироваться вручную или автоматически в процессе выдачи электронных карт-ключей. Новые карты идентификации клиентов регистрируются автоматически при выдаче карт-ключей если в настройках подключения системы электронных замков включен флажок "Записывать на вторую дорожку".

Вручную карту можно привязать к лицевому счету или к "Размещению" с помощью кнопки "Карты" в списке лицевых счетов.

Баланс по карте - это баланс по лицевому счету, к которому карта привязана, либо сумма балансов по документу-основанию, в случае, когда он указан.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 12, тип кода: Строка.

Длина наименования: 150.

Не иерархический.

Реквизиты

  • Дата регистрации. Содержит дату и время создания карты в справочнике.
  • Автор. Ссылка на справочник "Сотрудники". Содержит имя сотрудника, который выдал карту.
  • Заблокирована. Тип значения: «Булево». Если Истина, то при попытке прокатать карту пользователь получит отказ и сообщение указанное в причине блокировки
  • Выселен. Тип значения: «Булево». Истина, если гость уже выехал
  • Идентификатор. Тип значения: «Строка». Идентификатор карты, т.е. строка записанная на второй дорожке без префиксов и суффиксов
  • UID Карты. Тип значения: «Строка». Содержит уникальный идентификатор бесконтактной карты (заводской номер карты). Заполняется автоматически в случае, когда бесконтактная карта кодируется с помощью системы электронных замков, и данная система возвращает UID после успешной операции кодирования. Используя данный UID можно отследить сколько разных карт выдано гостю с помощью отчета "Аудит выданных карт идентификации клиентов"
  • Лицевой счет. Ссылается на документ «Фолио». Указывает лицевой счет, привязанный к карте. Баланс по этому лицевому счету и есть баланс по карте, в случае, если не заполнен документ-основание.
  • Документ основание. Ссылается на документ "Размещение", "Бронь", "Бронь ресурса" или "Состав квоты". Указывает документ, к которому привязана карта. В этом случае баланс по карте равен сумме балансов по всем лицевым счетам, указанных в правилах начисления документа-основания, в которых плательщиком является гость. Лицевой счет, на который необходимо начислять услуги по этой карте определяется в момент начисления, автоматически, в соответствии с правилами начислений. Если документ-основание заполнен, то реквизит "Лицевой счет" игнорируется. 
  • Группа гостей. Ссылается на справочник «Группы гостей». Заполняется по данным документа "Лицевой счет" или "Размещение".
  • Клиент. Ссылается на справочник «Клиенты (гости)». Владелец карты.
  • Номер. Ссылается на справочник «Номерной фонд». Указывается номер, в котором проживает гость.
  • Дата и время с. Тип значения: «Дата». Справочная информация, содержит дату и время заезда гостя, для того чтобы передать по запросу во внешнюю систему Фронт-офиса ресторана. Заполняется автоматически по данным лицевого счета или размещения.
  • Дата и время по. Справочная информация, содержит дату и время выезда гостя. Передается во Фронт-офис ресторан по запросу по карте. 
  • Гостиница. Ссылается на справочник «Гостиницы». Указывает гостинцу в которой зарегистрирована карта.
  • Причина блокировки. Содержит описание причины блокировки. Также это описание передается в систему Фронт-офиса ресторана при запросе гостя по карте.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Карты идентификации клиентов"
