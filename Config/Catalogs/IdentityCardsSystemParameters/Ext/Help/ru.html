Справочник "Параметры системы карт идентификации клиентов"

Назначение

Справочник параметров подключения считывателей магнитных карт идентификации клиентов и дисконтных картР> 

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Тип считывателя карт. Ссылается на перечисление «Типы считывателей карт». Если выбрано значение RS232, то программа обрабатывает события чтения карты и в момент чтения курсор ввода может располагаться в любом поле форм. Если выбран тип "В разрыв клавиатуры", то при чтении карты курсор ввода должен быть в поле "Карта идентификации клиента" или "Дисконтная карта"
  • Номер логического устройства. Тип значения: «Число». Указывает номер логического устройства драйвера, которое будет использоваться для работы с оборудованием. Если номер не указан, то он принимается равным 1. 
  • Порт. Тип значения: «Строка». Указывается в формате COMX, где X -- это номер порта. Если используется считыватель подключенный в разрез клавиатуры, но с драйвером компании Атол с поддержкой событий чтения, то в типе считывателя карт нужно выбирать RS232, а в поле порт указать COM99
  • Скорость обмена. Тип значения: «Число». 9600 по умолчанию
  • Четность. Ссылается на перечисление «Виды четности». Нет по умолчанию
  • Биты данных. Ссылается на перечисление «Биты данных». 8 по умолчанию
  • Стоп биты. Ссылается на перечисление «Стоп биты». 1 по умолчанию
  • Префикс. Тип значения: «Строка».
  • Суффикс. Тип значения: «Строка».

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Настройки/Параметры системы карт идентификации клиентов"

Дополнительная информация

Поля Префикс и Суффикс обязательны для ввода в случае подключения по RS232. Если указанные префикс и суффикс не совпадают с записанными на второй дорожке, то события чтения карты не возникают. Префикс и суффикс можно указывать через их десятичные кода в формате #XX, где XX -- десятичный код символа
