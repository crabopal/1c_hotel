Справочник "Параметры подключения сканеров изображений"

Назначение

Справочник параметров подключения сканеров изображений

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Тип драйвера сканера изображений. Тип значения: «Перечисление.Драйверы сканирования и распознавания изображений». Указывает какой драйвер из списка поддерживаемых программой будет использоваться для сканирования изображений и их распознавания. Поле обязательно для заполнения
  • Имя Twain сканера. Тип значения: «Строка», длина 250. Указывается название сканера, который будет использоваться для сканирования. Если не указано, то будет использоваться сканер по умолчанию
  • Директория установки компоненты сканирования. Тип значения: «Стока», длина 1000. Для драйвера от компании Cognitive здесь указывается путь к директории установки компоненты сканирования CoScApi.dll. Если не указано, то по умолчанию предполагается "c:\Program Files\Cognitive\ScanifyAPI\Scanify\Bin32\". Указывается только для драйвера «Cognitive»
  • Файл параметров контекста сканирования. Тип значения: «Стока», длина 250. Для драйвера от компании Cognitive здесь указывается имя файла с параметрами контекста сканирования. Если не указано, то по умолчанию предполагается "scapi.ini". Указывается только для драйвера «Cognitive»
  • Размер бумаги. Тип значения: «Перечисление.Размеры бумаги». Если не указано, то используется настройка сканера по умолчанию. Указывается только для драйвера «1C Scan»
  • Поворот. Тип значения: «Число (3, 0)». Указывается количество градусов для поворота отсканированной картинки перед ее сохранением в программе. Указывается только для драйвера «1C Scan»
  • Глубина цвета. Тип значения: «Перечисление.Глубина цвета». Если не указано, то принимается равным 24 бита. Указывается только для драйвера «1C Scan»

    Табличная часть «Конфигурации сканирования»

    • Конфигурация сканирования. Ссылается на справочник «Конфигурации сканирования». 

    Если табличная часть не заполнена, то система предполагает, что сканируются паспорт или права гостя. Если предполагается сканирование и других документов удостоверяющих личность (например: миграционной карты, визы, страниц заграничного паспорта и т.д.), то для каждого вида документа на рабочем месте должна быть настроена соответствующая конфигурация сканирования. В табличной части перечисляются все конфигурации, которое могут быть использованы при работе портье. Перед началом сканирования программа будет предлагать пользователю выбрать одну из перечисленных здесь конфигураций.

    Формы

    • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
    • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
    • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

    Способ вызова

    Вызывается из меню "Настройки/Параметры подключения сканеров изображений"
