Справочник "Настройки подключения к Интернет"

Назначение

Содержит настройки подключения к прокси серверам гостиницы. Параметры подключения к прокси серверу указываются в настройках рабочего места и используются при установке интернет соединений с этого рабочего места, например, для отправки СМС сообщений, получения курсов валют и т.д. 

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 100.

Не иерархический.

Реквизиты

  • Пользователь. Строка. Имя пользователя прокси сервера.
  • Пароль. Строка. Пароль пользователя прокси сервера.
  • Не использовать прокси для локальных адресов. Булево. Установите в Истина если прокси сервер не должен использоваться при обращении к адресам локальной сети гостиницы.

Табличная часть «Протоколы»

  • Протокол. Строка. Название протокола, например: "http", "ftp", ...
  • Имя прокси сервера. Имя прокси сервера, который обрабатывает запросы по указанному протоколу.
  • Порт. Число. Номер порта по которому выполнять обращения к прокси серверу.

Способ вызова

Вызывается из меню "Настройки/Настройки подключения к Интернет"
