Справочник "Направления маркетинга"

Назначение

Справочник хранит перечень кодов маркетинга, которыми аналитическая служба гостиницы производит сегментацию клиентской базы. В справочник обычно вносят сегменты рынка. Примеры: корпоративные клиенты, туристы, спортсмены, командировочные и т.д. Р>

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Тип значения: «Число».
  • Требовать подтверждения при каждом поселении. Тип значения: «Булево».
  • Шаблон строки подтверждения. Тип значения: «Строка».
  • Тип тарифа. Ссылается на справочник «Типы тарифов».
  • Тип скидки. Ссылается на справочник «Типы скидок».
  • Отключить автоматические скидки. Тип значения: «Булево».
  • Примечания. Тип значения: «Строка».

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Направления маркетинга"

Дополнительная информация

Не нужно путать справочник направлений маркетинга с справочником типов клиентов. В типах клиентов указываются те значения, которые влияют на стоимость проживания. Если сегмент клиентов на стоимость проживания не влияет, то это направление маркетинга, иначе -- тип клиента
