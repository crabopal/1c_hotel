Справочник "Статусы задач"

Назначение

Справочник статусов задач используется для ведения списка состояний задач.
 
Примеры статусов задач:
 1. Новая- задача создана
 2. В работе - задача в работе
 3. Закрыта - задача закрыта
 
У каждого статуса необходимо установить признак закрыта эта задача или нет. Если реквизит "Закрыта" установлен, то задача считается не действующей. Если реквизит "Закрыта" не установлен, то задача считается действующей.

У статуса задач можно указать цвет задачи в журнале и списках.

Относится к подсистеме: «Управление задачами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Тип значения: «Число».
  • Закрыта. Тип значения: «Булево».
  • Цвет задачи. Тип значения: «Хранилище значения».
  • Примечания. Тип значения: «Строка».

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Задачи/Статусы задач"

Дополнительная информация

У статуса можно указать цвет задачи в журнале и списках
