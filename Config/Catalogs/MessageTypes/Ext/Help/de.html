Справочник "Виды задач/действий/сообщений"

Назначение

Содержит список видов задач/действий/сообщений.
Для видов задач это могут быть виды неисправностей: Сантехника, Электрика, Плотник и т.д.
Для видов действий это могут быть: Звонок, Встреча, E-Mail и т.д.

Относится к подсистеме: «Управление задачами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Отдел. Ссылается на справочник "Отделы". Если указан, то при выборе типа в задачи в качестве получателя сообщения будет установлен этот отдел.
  • Примечания. Строковый комментарий к типу задачи.
  • Порядок сортировки. Используется в отчетах для сортировки.
  • Статус по умолчанию. Позволяет при выборе вида новой задачи сразу установить ее начальный статус

Способ вызова

Вызывается из меню "Задачи/Виды задач/действий/сообщений"
