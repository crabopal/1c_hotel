Справочник "Воинские звания"

Назначение

Справочник содержит воинские звания в соответствии с Общероссийским классификатором информации о населении (ОКИН). Может быть использован при поселении по военному билету.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Воинские звания"
