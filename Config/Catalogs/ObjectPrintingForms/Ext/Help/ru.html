Справочник "Печатные формы объектов"

Назначение

Справочник содержит настройки списка печатных форм различных объектов программы: документов или справочников.Р>

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Тип объекта. Ссылается на справочники «Ресурсы», «Номерной фонд», «Клиенты», «Контрагенты», «Договоры», Ссылается на документы «Счет-требование», «Размещение», «Приказ об изменении цен тарифа», «Запись в журнал регистрации иностранных граждан», «Бронь ресурса», «Бронь», «Акт», «Фолио».
  • Язык. Ссылается на справочник «Языки».
  • Отчет. Ссылается на справочник «Отчеты».
  • Внешняя обработка. Ссылается на справочник «Внешние обработки».
  • Внешний макет. Тип значения: «Хранилище значения».
  • Имя файла внешнего макета. Тип значения: «Строка».
  • Дата и время загрузки файла внешнего макета. Тип значения: «Дата».
  • Дата и время последнего изменения файла внешнего макета. Тип значения: «Дата».
  • Параметр. Тип значения: «Строка».
  • Текст на форме. Тип значения: «Строка».
  • Автоматическая печать формы при первой записи объекта. Тип значения: «Булево».
  • Пример печатной формы. Тип значения: «Хранилище значения». 
  • Примечания. Тип значения: «Строка».
  • Это форма по умолчанию. Тип значения: «Булево».
  • Действует. Тип значения: «Булево».

Формы

  • Форма списка. Основная форма списка. Используется для отображения списка элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Choice form. Основная форма выбора. Используется для отображения списка выбора элементов.
  • Форма выбора группы. Основная форма выбора группы. Используется для выбора групп.

Способ вызова

Вызывается из меню "Настройки/Печатные формы объектов"
