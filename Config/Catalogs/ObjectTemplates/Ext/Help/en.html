Справочник "Шаблоны операций"

В программе предусмотрена возможность создавать шаблоны типовых операций бронирования, поселения, добавления новых лицевых счетов. Шаблон позволяет определить значения по умолчанию для реквизитов создаваемых документов.Р>

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Объекты, вводимые на основании: «Размещение», «Фолио», «Бронь», «Бронь ресурса».

Реквизиты

  • Тип объекта. Ссылается на документы «Размещение», «Фолио», «Бронь», «Бронь ресурса».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Это операция по умолчанию. Тип значения: «Булево». Если установить флажок, то фокус ввода при открытии меню выбора шаблона будет стоять на этом элементе.
  • Действует. Тип значения: «Булево».
  • Примечания. Тип значения: «Строка».
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Вид размещения. Ссылается на справочник «Виды размещения».
  • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице».
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга».
  • Строка подтверждения для направления маркетинга. Тип значения: «Строка».
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Строка подтверждения для типа клиента. Тип значения: «Строка».
  • Квота номеров. Ссылается на справочник «Квоты номеров».
  • Тариф. Ссылается на справочник «Тарифы».
  • Тип тарифа. Ссылается на справочник «Типы тарифов».
  • Набор услуг начисляемый по тарифу. Ссылается на справочник «Наборы услуг».
  • Тип скидки. Ссылается на справочник «Типы скидок».
  • Основание предоставления скидки. Тип значения: «Строка».
  • Скидка %. Тип значения: «Число».
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг».
  • Статус брони. Ссылается на справочник «Статусы брони». Обязательный к заполнению реквизит.
  • Начислять услуги. Тип значения: «Булево».
  • Текст подтверждения/отказа в бронировании. Тип значения: «Строка».
  • Рейтинг. Тип значения: «Число».
  • Статус размещения. Ссылается на справочник «Статусы размещения гостей в номерах».
  • Начислить разовый сбор. Тип значения: «Булево».
  • Планируемый способ оплаты. Ссылается на справочник «Способы оплаты». Данный реквизит обычно заполняется автоматически из настроек гостиницы. Если автоматического заполнения реквизита не произошло, то его необходимо заполнить вручную!
  • Отчетная валюта. Ссылается на справочник «Валюты». Данный реквизит обычно заполняется автоматически из настроек гостиницы. Если автоматического заполнения реквизита не произошло, то его необходимо заполнить вручную!
  • Фирма. Ссылается на справочник «Фирмы». Данный реквизит обычно заполняется автоматически из настроек гостиницы. Если автоматического заполнения реквизита не произошло, то его необходимо заполнить вручную!
  • Валюта лицевого счета. Ссылается на справочник «Валюты».
  • Описание лицевого счета. Тип значения: «Строка».
  • Контрагент. Ссылается на справочник «Контрагенты».
  • Договор. Ссылается на справочник «Договоры».
  • Секция оплаты. Ссылается на справочник «Секции оплаты».
  • Способ оплаты. Ссылается на справочник «Способы оплаты».
  • Статус брони ресурса. Ссылается на справочник «Статусы брони ресурсов».
  • Мастер счет. Тип значения: «Булево».
  • Лицевой счет закрыт. Тип значения: «Булево».
  • Группа гостей. Ссылается на справочник «Группы гостей». 
  • Номер. Ссылается на справочник «Номерной фонд».
  • Дата и время с. Тип значения: «Дата».
  • Дата и время по. Тип значения: «Дата».
  • Глубина кредита. Тип значения: «Число».
  • Не изменять фирму автоматически из брони/размещения. Тип значения: «Булево».
  • Тип ресурса. Ссылается на справочник «Типы ресурсов».
  • Ресурс. Ссылается на справочник «Ресурсы».

Формы

  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Список. Основная форма списка. Используется для отображения списка элементов.
  • Форма выбора. Основная форма выбора. Используется для отображения списка выбора элементов.
  • Форма выбора группы. Основная форма выбора группы. Используется для выбора групп.

Способ вызова

Вызывается из меню "Настройки/Шаблоны операций"

Дополнительная информация

В шаблоне должны быть заполнены все реквизиты, которые присутствуют в целевом документе. Если, например, в документе размещения есть реквизит "Фирма" и в шаблоне фирма не заполнена, то и в размещении созданном по шаблону фирма заполнена не будет!
