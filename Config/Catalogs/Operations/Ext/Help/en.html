Справочник "Работы"

Назначение

Программа позволяет вести учет работ, выполняемых персоналом гостиницы в номерах и вспомогательных помещениях. Для учета работ во вспомогательных помещениях, таких как: кабинеты сотрудников, коридоры, лестничные клетки и т.д. Эти помещения должны быть заведены в справочниках типов номеров и справочнике номерного фонда как виртуальные номера. Справочник работ позволяет зарегистрировать в программе различные типы уборок и других действий, которые выполняют горничные и прочие сотрудники службы эксплуатации номерного фонда. По каждой работе можно задавать нормы выполнения в разрезе типов помещений (виртуальных типов номеров) или самих помещений (виртуальных номеров). Нормы задаются на время выполнения работы в минутах и на площадь в кв. метрах. Также по каждой работе можно вести нормативы расхода различной номенклатуры: чистящих порошков, жидкостей и т.д.

Относится к подсистеме: «Управление службой номеров».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Тип значения: «Число».
  • Код начала работы для телефонной АТС. Тип значения: «Число».
  • Код окончания работы для телефонной АТС. Тип значения: «Число».
  • Примечания. Тип значения: «Строка».
  • Уборка по выезду. Тип значения: «Булево».
  • Текущая уборка. Тип значения: «Булево».
  • Уборка в свободном номере. Тип значения: «Булево».
  • Уборка после ремонта. Тип значения: «Булево».
  • Выполнять для каждого гостя. Тип значения: «Булево».
  • Используется фактическая регистрация работ этого вида. Тип значения: «Булево». Если флажок выключен, то при проведении документов «План работ» программа по числу запланированных работ для каждой горничной позволит распечатать отчет по количеству работ горничной за период. Если флажок включен, то предполагается, что в гостинице используются механизмы регистрации фактически выполненных горничными работ этого вида. Это может быть либо ручной ввод итогов выполненных работ в соответствующей форме, либо регистрация работ через АТС.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма выбора группы. Основная форма выбора группы. Используется для выбора групп.

Способ вызова
