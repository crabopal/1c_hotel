Справочник "Способы оплаты"

Назначение

Справочник используется для ведения списка способов оплаты допустимых при оформлении платежей.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Не иерархический.

Реквизиты

  • Переводы наименования на различные языки. Тип значения: «Строка». 
  • Проводить по ККМ. Тип значения: «Булево». Если включен, то платеж привязывается в программе к ККМ и попадает в X и Z-отчеты по кассе. 
  • Печатать чек по ККМ. Тип значения: «Булево». Если включен и платеж привязан к ККМ подключенной к программе в режиме фискального регистратора, то при проведении нового или не проведенного платежа будет пробит кассовый чек 
  • Оплата наличными. Тип значения: «Булево». Включите, если способ оплаты является оплатой наличными 
  • Оплата кредитной картой. Тип значения: «Булево». Включите, если способ оплаты является оплатой кредитной картой 
  • Требовать ввода кода авторизации платежа. Тип значения: «Булево». Если включен, то платеж кредитной картой не будет проводится пока не заполнен код авторизации платежа 
  • Требовать ввода референс кода платежа. Тип значения: «Булево». Если включен, то платеж кредитной картой не будет проводится пока не заполнен референс номер платежа (RRN) 
  • Оплата контрагентом. Тип значения: «Булево». Включите, если способ оплаты используется для проведения в программе платежей от контрагентов (организаций), а не от физических лиц 
  • Оплата бонусами. Тип значения: «Булево». Включите, если способ оплаты используется для погашения задолженности в программе за счет накопленных бонусных баллов 
  • Только для возвратов. Тип значения: «Булево». Включите, если способ оплаты должен быть доступен для выбора только в возвратах 
  • Платежи проводятся по внешнему (не подключенному к программе) банковскому терминалу. Тип значения: «Булево». Если включен, то при проведении платежа с таким способом оплаты на рабочем месте подключенном к банковскому терминалу, отправка команды на терминал выполняться не будет 
  • Оплата через интернет эквайринг. Тип значения: «Булево». Если включен, то при проведении платежа с таким способом оплаты в чек будут передан тег 1125 (Признак расчета Интернет) и 1187 (Место расчетов). В тег 1187 (Место расчетов) передается значение поля "Место расчетов" из настроек ККТ или значение поля "Сайт" из карточки отеля. 
  • Тип закрытия чека по ККМ. Тип значения: «Число». Используется для установки соответствия между способом оплаты в программе и типом оплаты в фискальном регистраторе. Для всех поддерживаемых типов драйвером является числом от 0 до 9. Смысл чисел различается в разных драйверах. 
  • Порядок сортировки. Тип значения: «Число». 
  • Тип карты. Ссылается на справочник «Типы кредитных карт». 
  • Примечания. Тип значения: «Строка». 
  • Шаблон сообщения и тип рассылки. Ссылка на справочник "Шаблоны текста сообщений". Если заполнен, то, во первых, включает режим автоматической отправки СМС или E-Mail сообщения в момент проведения платежа или возврата с этим статусом и, во вторых, определяет текст этого сообщения. В тексте шаблона могут использоваться подстановочные выражения указанные в справке по справочнику шаблонов. Тип рассылки определяет транспорт доставки сообщения: СМС или E-Mail 

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов. 
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов. 

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Настройки/Способы оплаты"
