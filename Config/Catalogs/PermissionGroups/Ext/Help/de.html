Справочник "Наборы прав"

Назначение

Справочник содержит список наборов прав сотрудников. Набор прав определяет, какие действия разрешены сотруднику. Каждому сотруднику необходимо задать один из определенных в системе наборов прав.

При установке программы справочник уже содержит настроенные наборы прав соответствующие ролям, определенным в конфигурации. Редактировать справочник рекомендуется только опытным пользователям.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Табличная часть «Доступные тарифы»

  • Тариф. Ссылается на справочник «Тарифы». Содержит список доступных сотруднику для выбора тарифов

Табличная часть «Авторизации замковых систем»

  • Набор правил доступа системы электронных замков. Ссылается на справочник «Наборы прав доступа в системах электронных замков». 

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Настройки/Наборы прав"
