Справочник "Телефонные номера"

Назначение

Содержит телефонную книгу гостиницы. Каждый телефон может быть привязан к номеру комнаты.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 10, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Владельцы справочника: «Гостиницы».

Реквизиты

  • Номер телефона. Тип значения: «Строка».
  • Транк. Тип значения: «Строка».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Порядок сортировки. Тип значения: «Число».
  • Множитель. Тип значения: «Число».
  • Междугородние/международные звонки заблокированы. Тип значения: «Булево».
  • Для абонента есть сообщение. Тип значения: «Булево».
  • Услуга телефонного разговора. Ссылается на справочник «Услуги».
  • Услуга сбора за разговор. Ссылается на справочник «Услуги».
  • Примечания. Тип значения: «Строка».

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Телефонные номера"
