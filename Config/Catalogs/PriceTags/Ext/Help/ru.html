Справочник "Признаки цены"

Назначение

Признаки цены - это дополнительный параметр ценообразования. В справочнике задаются названия "Ярлыков", к которым с одной стороны можно прикрепить приказы об изменения цен, а с другой использовать их в таблицах диапазонов значений параметров участвующих в ценообразовании. Например гостиница может задать диапазоны длительности проживания гостя и к каждому диапазону прикрепить ярлыки: "Проживание 0 - 10 дней", "Проживание 10 - 20 дней", ... и, соответственно, в приказах определить цены. Другой вариант. Гостиница может задать диапазоны значений процента загрузки, при котором применяется та или иная цена: "Загрузка 0% - 30%", "Загрузка 30% - 60%" и т.д.

Реквизиты

  • Код. Тип значения: «Строка» 5 символов. используется для быстрого отбора и краткого представления ярлыка в отчетах. Назначается вручную.
  • Наименование. Содержит краткое наименование. Является основным представлением элемента.
  • Порядок сортировки. Тип значения: «Число». Используется для сортировки в отчетах.
  • Примечания. Тип значения: «Строка». Описание признака, отражается только в списке.
  • Гостиница. Тип значения: Ссылка на справочник «Гостиницы». Не обязательный для заполнения реквизит. Если указан, позволяет создавать для разных гостиниц разные наборы признаков.

Для заполнения диапазонов значений связанных с признакам цены используйте документ «Приказ об изменении диапазонов признаков цены».

Способ вызова

  • Вызывается из меню "Взаиморасчеты/Справочники/Настройки/Признаки цены" или из справочника "Тарифы" по кнопке "Перейти/Признаки цены".
