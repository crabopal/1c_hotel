Справочник "Правила вычисления количества услуг"

Назначение

Справочник алгоритмов вычисления количества услуг начисляемых по тарифу проживания.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Период услуги в часах. Тип значения: «Число». Обычно 24 (сутки). Для почасовых видов расчета может быть 1. Для алгоритма «Помесячно» должен быть 24.
  • Используется расчетный час. Тип значения: «Булево». Установка данного флажка имеет смысл только при указании значения расчётного часа.
  • Расчетный час. Тип значения: «Время». Расчётный час оказания услуги
  • Тип вида расчета количества. Ссылается на перечисление «Виды расчета количества проживания». По сути, определяет базовый алгоритм, который программа будет использовать для вычисления количества услуги. Остальные параметры только модифицируют выбранный алгоритм в части расчета стоимости раннего заезда, позднего выезда и т.д.
  • Внешний алгоритм. Ссылается на справочник «Внешние обработки». Программа позволяет запрограммировать произвольный алгоритм расчета количества услуги по периоду проживания гостя и подключить этот алгоритм в правилах расчета количества. Детальное описание порядка подключения внешнего алгоритма расчета высылается разработчиком после запроса от пользователя программы в случаях, когда необходимого результата действительно невозможно добиться штатными средствами.
  • Время бесплатного осмотра номера в часах. Тип значения: «Число». Если указано и гость находился в номере меньше указанного числа часов, то стоимость за пребывание в номере не будет начислена.
  • Время бесплатного проживания в номере до переселения гостя в другой номер. Тип значения: «Число». Если оно указано, и гость пребывал в номере меньше указанного времени, то стоимость равна 0
  • Время бесплатной задержки в номере в часах. Тип значения: «Число».
  • Время почасовой задержки в номере в часах. Тип значения: «Число». Количество часов до которого программа будет начислять почасовую задержку
  • Время задержки на четверть суток в номере в часах. Тип значения: «Число». Количество часов до которого программа будет начислять задержку в четверть суток
  • Время задержки на пол суток в номере в часах. Тип значения: «Число». Количество часов до которого программа будет начислять задержку в пол суток
  • Правило округления задержки выезда. Ссылается на перечисление «Правила округления количества». Как округлять задержку с учетом минут выезда: до целого часа, до полного часа или по правилам округления. 
  • Время бесплатного раннего поселения в часах. Тип значения: «Число».
  • Время почасового раннего поселения в часах. Тип значения: «Число».
  • Время раннего заезда на четверть суток в часах. Тип значения: «Число».
  • Время пол суточного раннего поселения в часах. Тип значения: «Число».
  • Правило округления длительности раннего заезда . Ссылается на перечисление «Правила округления количества».
  • Время почасового поселения в часах при заезде на срок меньше суток. Тип значения: «Число».
  • Время четверть суточного поселения в часах при заезде на срок меньше суток. Тип значения: «Число».
  • Время пол суточного поселения в часах при заезде на срок меньше суток. Тип значения: «Число». .
  • Правило округления длительности проживания на срок меньше суток. Ссылается на перечисление «Правила округления количества».
  • Для первых суток рассчитывать задержку от времени выезда. Тип значения: «Булево».
  • Первые сутки проживания строго от расчетного часа. Тип значения: «Булево».
  • Первые сутки проживания строго до расчетного часа. Тип значения: «Булево».
  • Переселение из номера в номер учитывать по расчетному часу. Тип значения: «Булево». Используется только для алгоритма «Проживание». Если выключен и гость переселяется в другой номер временем поз-же расчетного часа, то за проживание в старом номере ему будет дополнительно начислена задержка выезда. Если флажок включен, программа рассчитывает количество так, как будто гость переселялся расчетным часом.
  • Только для иностранцев. Тип значения: «Булево». Если включен и гость гражданин базовой страны (России), услуга начисляться не будет.
  • Только для граждан. Тип значения: «Булево». Если включен, и гость не является гражданином базовой страны (России), услуга начисляться не будет.
  • Не начислять в брони. Тип значения: «Булево». Если включен, то при расчете состава услуг брони услуга с данным правилом расчета количества начисляться не будет.
  • Начислять питание на первый день при сроке проживания меньше суток. Тип значения: «Булево».
  • Примечания. Тип значения: «Строка».

Формы

  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Настройки/Правила вычисления количества"
