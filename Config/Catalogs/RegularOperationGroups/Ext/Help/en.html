Справочник "Наборы регламентных работ"

Назначение

Используется для определения списка регламентных работ в номерах, которые выполняют горничные или другие сотрудники. Используется в настройках документа "План работ" и в настройках отчета "Задание на уборку".Р> Примеры регламентных работ: замена белья, замена полотенец, генеральная уборка номера и т.д.

Относится к подсистеме: «Управление службой номеров».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Примечания. Тип значения: «Строка».

Табличная часть «Регламентные работы»

  • Регламентная работа. Ссылается на справочник «Работы». Вид работы в номере
  • Периодичность выполнения регламентных работ в днях. Тип значения: «Число». Как часто выполняется работа. Например замена белья раз в 3 дня
  • Выполнять в день заезда. Тип значения: «Булево».
  • Выполнять в день выезда. Тип значения: «Булево».
  • Выполнять для занятых номеров. Тип значения: «Булево».
  • Выполнять для свободных номеров. Тип значения: «Булево».
  • Не выполнять по выходным. Тип значения: «Булево».
  • Выполнять для каждого гостя. Тип значения: «Булево».

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Служба номеров/Справочники/Наборы регламентных работ"
