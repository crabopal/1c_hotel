Справочник "Отчеты"

Назначение

Содержит меню отчетов. Меню отчетов может содержать как отчеты встроенные в программу, так и любые внешние отчеты. Пользователи могут добавлять в меню свои отчеты копируя существующие и изменяя их настройки.

У каждого отчета можно перечислить наборы прав пользователей, которые будут иметь доступ к этим отчетам.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 6, тип кода: Число.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Внешний отчет. Тип значения: «Булево». Включен, если используется внешний отчет загруженный в справочник "Внешние обработки"
  • Отчет. Тип значения: «Строка» - если используется встроенный в программу отчет, является именем отчета в метаданных конфигурации; Ссылается на справочник «Внешние обработки» - если это внешний отчет.
  • Статические параметры отчета. Тип значения: «Хранилище значения». Содержит сохраненные значения реквизитов отчета и настройки построителя отчета.
  • Динамические параметры отчета. Тип значения: «Строка». Содержит выражение на встроенном языке 1С:Предприятие, которое инициализирует некоторые реквизиты отчета. Вызывается после загрузки статических параметров и позволяет устанавливать, например, период отчета исходя из его смысла.
  • Это пакет отчетов. Тип значения: «Булево». Включено, если отчет, после формирования, автоматически запускает другие отчеты, указанные в таблице пакета, и выводит их в туже печатную форму
  • Набор прав. Ссылается на справочник «Наборы прав». Набор прав, пользователям которого разрешено использовать отчет
  • Ключ регламентного задания. Тип значения: «Строка». Ключ, по которому отчет вызывается из менеджера фоновых заданий
  • Порядок сортировки. Тип значения: «Число». Возможный порядок отображения отчета в меню отчетов. По умолчанию отчеты отображаются в меню в порядке кодов отчетов.
  • Текст заголовка отчета (если пустой, то используется наименование отчета). Тип значения: «Строка». Позволяет задать разные наименования отчета в меню и на печатной форме. Например в меню отчет может называться "Планируемый заезд на завтра", а в печатной форме просто "Планируемый заезд"
  • Внешний макет. Тип значения: «Хранилище значения». Позволяет переопределить макет отчета из конфигурации, который содержит форматы/заголовки полей отчета
  • Имя файла внешнего макета. Тип значения: «Строка». Имя файла из которого был загружен внешний макет
  • Дата и время загрузки файла внешнего макета. Тип значения: «Дата».
  • Дата и время последнего изменения файла внешнего макета. Тип значения: «Дата».
  • Примечания. Тип значения: «Строка». Детальное описание отчета. Отображается в меню.

Табличная часть «Пакет»

  • Действует. Тип значения: «Булево».
  • Отчет. Ссылается на справочник «Отчеты». Отчет, который будет выведен после печати основного отчета
  • Не использовать параметры родительского отчета. Тип значения: «Булево».
  • Не выводить в отчет заголовок отчета. Тип значения: «Булево».
  • Не выводить в отчет заголовок таблицы отчета. Тип значения: «Булево».
  • Не выводить в отчет детальные строки. Тип значения: «Булево».
  • Не выводить в отчет подвал таблицы отчета. Тип значения: «Булево».
  • Не выводить в отчет общие итоги. Тип значения: «Булево».
  • Не выводить в отчет подвал отчета. Тип значения: «Булево».
  • Вставить разделитель страниц перед формированием этого отчета. Тип значения: «Булево».

Табличная часть «Наборы прав»

  • Набор прав. Ссылается на справочник «Наборы прав».

Формы

  • Форма списка. Основная форма списка. Используется для отображения списка элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Choice form. Основная форма выбора. Используется для отображения списка выбора элементов.
  • Форма выбора группы. Основная форма выбора группы. Используется для выбора групп.

Способ вызова

Вызывается из меню "Отчеты" или по кнопке "Отчеты" в главном меню программы
