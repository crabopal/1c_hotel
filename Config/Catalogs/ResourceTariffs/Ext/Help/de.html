Справочник "Тарифы ресурсов"

Назначение

Справочник позволяет указывать цены ресурсов в разрезе тарифов. 

Относится к подсистеме: «Управление мероприятиями».

Параметры

Длина кода: 25, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Используется в отчетах для сортировки.
  • Гостиница. Ссылается на справочник «Гостиницы». Может быть пустым, что позволяет использовать этот тариф во всех гостиницах сети.
  • Примечания. Произвольный комментарий.

Способ вызова

Вызывается из меню "Мероприятия/Тарифы ресурсов"
