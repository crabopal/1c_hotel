Справочник "Типы ресурсов"

Назначение

Справочник содержит типы ресурсов: сауны, конференц. залы, и т.д. Используется для отбора в календаре ресурсов. Является обязательным реквизитом ресурса.

Относится к подсистеме: «Ресурсы».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Гостиница. Указывает «Гостиницу», к которой относится данный тип ресурсов.  
  • Переводы наименования на различные языки. Содержит перевод наименования для печати. 
    Перевод задается в виде строки на разных языках, разделенных символом ";" (точка с запятой). 
    Строка на одном языке состоит из кода языка, указанного в метаданных, символа "=" (равно) и, собственно, строки текста на данном языке в одинарных кавычках. 
    Например: RU='Конференц-зал"'; EN='Conference hall'  
  • Фирма. Ссылается на справочник «Фирмы». Задает фирму, которая будет подставлена в документ при выборе данного типа ресурса. Используется, когда продажи ресурса оформляются по отдельной фирме. Если не заполнен то будет использована фирма "по-умолчанию" из параметров гостиницы. 
  • Лицевой счет - шаблон. Ссылается на документ «Фолио». Задает шаблон лицевого счета для начисления. При бронировании ресурса будет создан отдельный лицевой счет, параметры которого будут заполнены по указанному шаблону. 
  • Примечания. Строковый комментарий. 
  • Порядок сортировки. Используется в отчетах для сортировки. 

Способ вызова

Вызывается из меню "Ресурсы/Справочники/Типы ресурсов"
