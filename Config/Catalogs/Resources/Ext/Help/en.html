Справочник "Ресурсы"

Назначение

Справочник содержит ресурсы доступные для бронирования по часам: сауны, конференц. залы, кабинеты и т.д.Р>

Относится к подсистеме: «Ресурсы».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Владельцы справочника: «Типы ресурсов».

Реквизиты

  • Переводы наименования на различные языки. Содержит перевод наименования для печати.
    Перевод задается в виде строки на разных языках, разделенных символом ";" (точка с запятой).
    Строка на одном языке состоит из кода языка, указанного в метаданных, символа "=" (равно) и, собственно, строки текста на данном языке в одинарных кавычках.
    Например: RU='Переговорная"'; EN='Meeting room' .
  • Круглосуточная работа. Если флажок включен, то на форме "Календарь ресурсов" все часы, с 00:00 до 24:00 будут отмечены как рабочие.
  • Пакет услуг. Ссылается на справочник «Пакеты услуг». Определяет пакет услуг, начисляемых автоматически при бронировании ресурса. 
  • Календарь работы ресурса. Ссылается на справочник «Календари». используется для правильного определения цены. Стоимость ресурса может зависеть от дня недели или от сезона, и такую смену цены мы можем показать с помощью календаря.
  • Гостиница. Ссылается на справочник «Гостиницы». Указывает к какой гостинице относится ресурс.
  • Фирма. Ссылается на справочник «Фирмы». Необязательный параметр. Если оставить его пустым, то услуги будут начислены от имени основного юридического лица, указанного в параметрах гостиницы. Данный реквизит предназначен для случаев, когда продажа ресурса должна быть оформлена отдельным юридическим лицом.
  • Базовая цена за час в отчетной валюте. Этот параметр используется программой для вычисления желаемой выручки от продаж ресурса за период и, далее, для вычисления процента продаж ресурса как отношения реальной выручки от продаж к желаемой. 
  • Максимальное кол-во человек. Это информационное поле, которое рекомендуется заполнить. Это количество отражается в календаре ресурсов и является подсказкой для менеджера.
  • Лицевой счет - шаблон. Ссылается на документ «Фолио». Задает шаблон лицевого счета для начисления. При бронировании ресурса будет создан отдельный лицевой счет, параметры которого будут заполнены по указанному шаблону.
  • Примечания. Произвольный комментарий к ресурсу, описание.
  • Порядок сортировки. Задает порядок, в котором ресурсы отображаются на форме календаря загрузки ресурсов. 

Табличная часть «Пакеты услуг»

При бронировании ресурса автоматически будут начислены все услуги из перечисленных в таблице пакетов.

Способ вызова

Вызывается из меню "Ресурсы/Справочники/Ресурсы"
