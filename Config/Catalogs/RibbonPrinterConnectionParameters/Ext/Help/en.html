Справочник "Параметры подключения ленточных принтеров"

Назначение

Справочник параметров подключения ленточных принтеров. Такие принтеры могут использоваться для печати из программы талонов на питание и проч. В настоящий момент для работы с такими принтерами поддерживается только "Атол:Драйвер принтеров чеков".

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Модель принтера. Номер модели принтера, см. документацию к драйверу. 
  • Использовать логическое устройство. Тип значения: «Булево». Если включено, то используются параметры подключения указанные в настройках логического устройства с указанным номером. Если выключено, то используются параметры подключения указанные на этой форме. Параметры подключения логического устройства хранятся в реестре Windows
  • Номер логического устройства. Тип значения: «Число». Номер используемого логического устройства
  • Порт. Тип значения: «Строка». Указывается числом, возможные варианты см. в документации к драйверу. Числа в диапазоне от 1 до 32 соответствуют подключению к COM портам с соответствующими номерами 
  • Скорость обмена. Тип значения: «Число». 9600 по умолчанию
  • IP адрес принтера. Тип значения: «Строка». Содержит IP-адрес устройства, который был настроен на принтере. Используется если в поле "Порт" указано число 99.

  • IP порт принтера. Тип значения: «Число». Используется если в поле "Порт" указано число 99 

  • Контроль потока. Тип значения: «Булево». Свойство выбирает режим контроля потока при обмене данными с принтером. Если включено, то драйвер проверяет значение сигнала CTS, с помощью которого принтер сигнализирует возможность приема данных от ПК. При использовании контроля потока необходимо наличие в кабеле, соединяющем ПК с принтером, провода, передающего сигнал RTS от принтера на контакт №8 (CTS) разъёма ПК
  • Эксклюзивный доступ. Тип значения: «Булево». Свойство устанавливает признак монопольного доступа к устройству сервера оборудования. Если к устройству сервера оборудования подключен один клиент (приложение) с включенной галочкой, то другие клиенты (приложения) не смогут подключиться к этому устройству. С установленным флажком  можно подключаться к устройству сервера, когда у устройства сервера нет клиентов.
  • Имя компьютера. Тип значения: «Строка». Свойство задает имя ПК в сети, к порту которого подключено устройство. Если свойство пустое, то используется имя ПК по умолчанию, указанное в конфигураторе DCOM для данного драйвера. Если работа с устройством ведется через порт удаленной машины, то должен быть настроен DCOM (подробнее см. «АТОЛ: Драйверы торгового оборудования», раздел «Настройка DCOM»). Если DCOM на ПК не установлен, то свойство должно быть пустым и работа будет вестись через порт ПК, на котором запущено клиентское приложение.
  • Тип штрихкода. Тип значения: «Перечисление Типы штрихкодов». Поле заполняется типом штрихкодов, которые поддерживаются принтером в случаях, если необходимо на талонах питания печатать идентификационный штрихкод. По этому штрихкоду в ресторане можно регистрировать фактически оказанные услуги.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Настройки/Параметры подключения ленточных принтеров"
