Справочник "Виды блокировки номеров"

Назначение

Виды блокировок номеров используются при временном снятии номеров с продажи. Обычно это различные виды ремонтов или аренды. Пользователь должен указать код вида блокировки (обычно заглавными буквами, например ЭЛ для ремонта по электрике или СН для ремонта по сантехнике) и наименование.

Блокировка устанавливается у номера на определенный период с помощью документа "Установить блокировку", который вводится в карточке номера на закладе "Блокировки".

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Объекты, вводимые на основании: «Установить блокировку».

Реквизиты

  • Порядок сортировки. Используется в отчетах для сортировки. 
  • Это ремонт. Данный флажок ставится в случае если номер заблокирован по причине ремонта. Используется при планировании работ горничных. На день окончания ремонта будет запланирована работа по уборке номера.
  • Добавлять к числу проданных номеров при расчете общего процента загрузки в сводных показателях. Рекомендуемое значение - выключен. Влияет на расчет процента загрузки в отчете "Сводные показатели". А именно, номера, заблокированные с данным видом блокировки, считаются "проданными", соответственно, не уменьшают количество номеров в продаже и увеличивают количество проданных номеров. Включение флажка приводит к "математическому" завышению процента продаж номеров. 
  • Цвет в карте загрузки НФ. Определяет цвет блокировки в графической карте номерного фонда.  
  • Примечания. Произвольный комментарий с пояснением к виду блокировки. 

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Виды блокировки номеров"
