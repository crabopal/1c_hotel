Справочник "Свойства номеров"

Назначение

Свойства номеров могут отражать наличие или отсутствие какого-либо оборудования в номере (телевизор, телефон, кондиционер, ...), качество отделки номера, вид из окон, расположение номера по отношению к лифтам, комнате горничной и т.д.

Пользователь должен указать код свойства (обычно заглавными буквами, например НК для "Некурящий") и наименование.

Свойства показываются при подборе свободного номера при поселении. В списке номеров для каждого свойства добавляется колонка и напротив номера, обладающего свойством, ставится отметка в виде кода свойства. Поэтому код рекомендуется выбирать коротким и информативным. Также все свойства номеров перечислены в правом списке с  отметками. При выделении номера, свойства принадлежащие номеру, подсвечиваются. Если у свойства включить флажок "Показывать номера без данного свойства при отборах", то в списке номеров останутся только те номера, которые не обладают выбранным свойством.

Для быстрой установки свойств по номерам можно воспользоваться формой "Мастер заполнения свойств".

Относится к подсистеме: «Стойка администратора».

Реквизиты

  • Код. Строка, 5 символов. Задает краткое представление свойства в форме подбора номеров.
  • Наименование. Строка, 50 символов. Основное представление элемента.
  • Порядок сортировки. Определяет порядок, в котором свойства отображаются в списке номеров для подбора.
  • Показывать в списке свойств номера в списках номеров. Это свойство будет показываться при подборе свободного номера.
  • Показывать номера без данного свойства при отборах. Если включен, то при отборе будут показываться номера, у которых данного свойства нет.
  • Примечания. Строковый комментарий к свойству.
