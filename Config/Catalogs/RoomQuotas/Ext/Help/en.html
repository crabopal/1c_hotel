Справочник "Квоты номеров"

Назначение

Квота (Allotment) позволяет гостинице выделить часть номерного фонда для какого-то агента. При этом номера, выделенные в квоту, снимаются с продажи (если стоит соответствующий флажок «Списывать число доступных номеров»), и в эти номера можно будет селить только по заявкам этого агента. Номера в квоту могут выделяться как по номеру комнаты («Квота по номерам»), так и по категории без выбора конкретных номеров. Квоту можно использовать для блокирования продаж номеров и резервирования их за выбранным агентом, при этом никаких дополнительных начислений для агента не делается.

Чтобы добавить номера в квоту необходимо ввести документ "Состав квоты" с видом движения "Добавить номера в квоту". Чтобы убрать номера из квоты нужно ввести документ "Состав квоты" с видом движения "Убрать номера из квоты". Удобнее добавлять и снимать номера из формы "Свободные номера по квотам".

Относится к подсистеме: «Продажи квот номеров».

Реквизиты

  • Код. Строка, 10 символов. Задается вручную. Является кратким представлением.
  • Наименование. Строка, 100 символов. Задает название квоты, является основным представлением.
  • Порядок сортировки. Используется для сортировки в отчетах.
  • Гостиница. Ссылается на справочник «Гостиницы». Указывает гостиницу, номера которой выделены в квоту.
  • Агент. Ссылается на справочник «Контрагенты». Указывает контрагента, который будет подставлен в поле "Агент" в документах Бронь и Размещение при выборе данной квоты. На этого агента будет начисляться комиссия.
  • Контрагент. Ссылается на справочник «Контрагенты». Контрагент, с которым заключен договор и которому выделена квота. Подставляется автоматически в Бронь и Размещение при выборе квоты.
  • Договор. Ссылается на справочник «Договоры». Договор, который будет подставлен в документы при выборе квоты.
  • Тариф. Ссылается на справочник «Тарифы».
  • Тариф для расчета стоимости при недоборе квоты. Ссылается на справочник «Тарифы». Доступен для указания при включенной галочке "Начислять штраф за недобор номеров по квоте". Если указан, то контрактная стоимость квоты за день при недоборе проданных по квоте номеров рассчитывается по этому тарифу. Если это поле не заполнено, то используется тариф указанный в предыдущем поле. Подробнее алгоритм расчета штрафа смотри в описании галочки "Начислять штраф за недобор номеров по квоте".
  • Тариф для расчета стоимости при переборе квоты. Ссылается на справочник «Тарифы». Если параметр указан, то при создании новой брони, если по квоте брони нет больше свободных номеров на всем периоде бронирования, программа предложит заменить текущий тариф на данный.
  • Набор услуг начисляемый по тарифу. Ссылается на справочник «Наборы услуг».
  • Время освобождения в днях. Количество дней, за которое до даты заезда должны быть проданы все номера в квоте. Иначе квота снимается и возвращается гостинице. Чтобы квота снималась и номера этой квоты возвращались в продажу автоматически, необходимо обработку "Снять просроченные остатки по квотам номеров" запланировать в фоновых заданиях. Галочка не доступна при включенной галочке "Начислять штраф за недобор номеров по квоте".
  • Списывать число доступных номеров. Выделенные в квоту номера снимаются с продажи и доступны только при бронировании по квоте.
  • Это "жесткий" блок. Галочка устанавливается, если это квота, оплата номеров которой гарантирована договором с контрагентом. Такие квоты могут учитываться в отчете "Прогноз загрузки" и "Обороты по продажам номеров". В этих отчетах остаток номеров в таких квотах может прибавляться числу проданных номеров. Если в карточке квоты указан тариф, то отчет "Обороты по продажам номеров" добавляет стоимость проживания в номере по этому тарифу умноженную на остаток свободных номеров к суммам продаж.
  • Начислять штраф за недобор номеров по квоте. Галочка доступна для "жестких" блоков. Начисление штрафов выполняется процедурой закрытия периода в конце месяца за прошедший месяц. При включенной галочке квота должна быть привязана к фирме. Не поддерживается режим бронирования по одному "жесткому" блоку по разным фирмам.
    Алгоритм расчета суммы штрафа: 
    Программа, по каждому типу номера в квоте, определяет число номеров в квоте и число проданных номеров на каждую дату в прошедшем месяце. В те даты, когда число проданных номеров меньше, чем число номеров в квоте программа рассчитывает контрактную стоимость квоты по типу номера в день как произведение количества номеров в квоте на стоимость проживания в номере текущей категории в сутки. Цена проживания рассчитывается по числу взрослых гостей указанному в параметре "Количество гостей в номере для получения цены". Далее программа рассчитывает общую сумму начислений выполненных за проживание по квоте за день. Эта сумма включает проживание на доп. местах и прочие услуги, которые были начислены по квоте с включенной галочкой "Входит в цену". Если сумма начислений за день меньше, чем контрактная сумма по квоте, то разница начисляется как штраф услугой, указанной в параметре квоты "Услуга". Количество начисления устанавливается равным числу недопроданных по квоте и типу номера в этот день номеров. Начисление выполняется в лицевой счет указанный в параметре квоты "Начислять на лицевой счет". Рекомендуется (но не требуется) чтобы контрагент и договор указанные в квоте, совпадали с контрагентом и договором указанными в лицевом счете. Фирма указанная в квоте должна совпадать с фирмой указанной в лицевом счете. Дата начисления устанавливается в обрабатываемую дату из прошедшего месяца. Если в гостинице включен режим запрета изменений начислений в закрытых датах, то начисление штрафа всегда выполняется датой закрытия месяца (последним днем месяца). Дата, за которую рассчитан штраф указывается в примечаниях начисления.
  • Это квота по номерам. Если флажок включен, то номера в квоту выделяются по номеру комнаты. Если выключен - то указывается только тип номера и количество номеров.
  • Перебронирование запрещено. Если флажок включен (рекомендуемое значение), то по данной квоте нельзя будет забронировать/поселить большее количество номеров, чем выделено в квоту. В случае, если от контрагента поступит заявка на большее количество номеров, чем выделено в квоту, и гостиница решит удовлетворить эту заявку, то сначала необходимо будет добавить номера в квоту, а потом проводить заявку.
  • Запрещено указание в брони/размещениях контрагента или договора отличных от них в квоте. Если флажок включен, то при бронировании контрагент и договор будут подставлены в документ из квоты и нельзя будет указать другого контрагента-плательщика.
  • Цвет в карте загрузки НФ. Выбранным цветом будут отражаться бронирования и размещения по этой квоте.
  • Примечания. Произвольный текстовый комментарий, описание квоты.

Способ вызова

Вызывается из меню "Номерной фонд/Продажи квот номеров/Квоты номеров"
