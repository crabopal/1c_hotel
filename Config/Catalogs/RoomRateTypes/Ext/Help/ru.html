Справочник "Типы тарифов"

Назначение

Справочник позволяет определить набор тарифов объединяемых какой-либо маркетинговой политикой. Используется в аналитических отчетах. Пример: Тарифы длительного проживания, Туристические, Базовые, Почасовые.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Может быть использован для задания сортировки в отчетах.
  • Примечания. Произвольный комментарий к типу тарифа.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Типы тарифов"
