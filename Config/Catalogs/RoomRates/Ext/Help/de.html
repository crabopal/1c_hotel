Справочник "Тарифы"

Назначение

Справочник тарифов. Используется для формирования пакетов услуг начисляемых гостям автоматически при бронировании и проживании. В карточке тарифа цен нет. Они вводятся в приказах об изменении цен. В карточке тарифа указываются параметры, которые влияют на доступность тарифа, алгоритмы работы различных функций программы.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Объекты, вводимые на основании: «Приказ об изменении цен тарифа».

Реквизиты

  • Переводы наименования на различные языки. Задает представление тарифа на разных языках при печати документов счет, акт, счет гостю и др. Если перевод указан, то в печатных формах будет использоваться именно он, если перевод не задан, то будет использовано значение из основных полей (наименования). 
  • Порядок сортировки. Определяет порядок следования тарифов в отчетных формах. 
  • Тип тарифа. Ссылается на справочник «Типы тарифов». Используется в аналитических отчетах. 
  • Пакет услуг. Ссылается на справочник «Пакеты услуг».  Если заполнен, то по тарифу будут начислены не только услуги, указанные в приказе об изменении цен, то и услуги, указанные в пакете. Используется для добавления к тарифу доп. услуг вроде завтрака, обеда или ужина. 
  • Действует с даты. Указывает дату начала применения тарифа. Если период проживания гостя будет раньше этой даты, то для этого гостя тариф нельзя будет выбрать, документ не проведется.  
  • Действует по и включая дату. Указывает дату окончания применения тарифа. Дата выезда гостя должна быть раньше чем дата окончания тарифа.  
  • Календарь. Ссылается на справочник «Календари». Обязательное поле, используется для определения типа дня в периоде проживания гостя и получения цены на соответствующий тип дня. 
  • Период проживания в часах. Обычно – сутки, т.е. 24 часа. В редких случаях может быть другим. 
  • Вид расчета продолжительности проживания. Ссылается на перечисление «Виды расчета продолжительности проживания». Влияет на работу и значение поля «Продолжительность» в брони и в размещении, т.е. определяет как при заданной дате заезда и вводе продолжительности проживания программа должна рассчитать дату выезда. Пример: если выбрано значение "по расчетному часу", дата заезда = 10.05 и продолжительность 2 дня, то дата выезда будет установлена на 12.05. Если же выбрано значение "по дням", то при тех же условиях дата выезда будет установлена на 11.05 (этот режим используется в пансионатах и домах отдыха).  
  • Расчетный час. Указывает расчетный час по тарифу. Используется при расчете раннего заезда и задержки выезда.   
  • Первые сутки проживания строго до расчетного часа. Тип значения: «Булево». Если выключен и гость поселяется на 1 день, то по умолчанию программа поставит гостю дату выезда следующий день, а время выезда равное времени заезда. Если включен, то время выезда будет установлено на расчетный час. 
  • Время заезда по умолчанию. Используется при бронировании для автоматической подстановки в документ в качестве времени заезда. Если не указано, то будет подставлен расчетный час. 
  • Открытый тариф. Флажок должен быть включен для тарифов используемых при открытой продаже номеров. Обычно это тарифы, которые может применять служба приема и размещения. Это тарифы с ценой "от стойки", тарифы раннего бронирования, невозвратные тарифы и т.д. Используется в отчетах для разделения выручки между специальными и открытыми тарифами. Также используется в наборах прав для указания прав доступа сотрудников к специальным тарифам 
  • On-line тариф. При включенном флажке тариф участвует в выдаче цен в модуль On-line бронирования. Флажок учитывается программой в случае, когда в настройках модуля on-line бронирования тариф не указан.  
  • Гостиница. Ссылается на справочник «Гостиницы». Обязательный реквизит. Определяет гостиницу, к которой относится тариф. Для бронирования в других гостиницах тариф нельзя будет выбрать.  
  • Фирма. Ссылается на справочник «Фирмы». Юридическое лицо вашей организации. Заполнять не обязательно. Если указать, то при выборе этого тарифа в размещении или брони фирма в документе будет установлена в фирму тарифа. 
  • Набор услуг начисляемый по тарифу. Ссылается на справочник «Наборы услуг». Если указан, то гостям по этому тарифу будут начисляться только те услуги, которые входят в набор. Если не указан, то гостям по этому тарифу будут начисляться все услуги, цены по которым определены в действующем приказе об изменении цен. Обычно поле должно быть пустым. 
  • Тип скидки. Указанный тип скидки будет автоматически подставляться в документ при выборе тарифа.   
  • Скидки запрещены. Если флажок включен, то любая скидка, выбранная в Брони или Размещении по этому тарифу применена не будет. Включается для тех тарифов, цены по которым уже указаны с учетом всех возможных скидок и по которым далее снижать цену запрещено. Этот флажок в том числе отключает и действие накопительных скидок. 
  • Агентские отчисления запрещены. Если флажок включен, то агентские по данному тарифу начисляться не будут. Обычно используется для тарифов, которые уже уменьшены на сумму агентского процента, для выставления счета на оплату по "безналичному расчету".  
  • Бесплатный тариф. Должен быть установлен для всех специальных тарифов, по которым стоимость проживания = 0. Это всевозможные тарифы "Директора", "Без оплаты", "Complimentary" и т.д. Используется в отчете сводные показатели для выделения из общего числа проданных номеров числа номеров занимаемых «бесплатными» гостями. Программа рассчитывает проценты загрузки, как с учетом, так и без учета «бесплатных» гостей. 
  • Не печатать тариф. В печатных формах анкеты гостя, подтверждения брони цена за проживание по этому тарифу отображаться не будет. 
  • Примечания. Произвольный комментарий к тарифу. Обычно это объяснение, зачем тариф был создан, и в каких случаях его нужно использовать. 
  • Тип путевки. Содержит ссылку на группу справочника "Путевки". Если указан, то при вводе номера путевки в документах будет автоматически использован указанный тип путевки и пользователю не будет показываться окно для выбора типа путевки.  
  • Условия бронирования. Текст с условиями бронирования, который выводится в подтверждении брони. Если не задан, то будет использован текст из параметров гостиницы.  
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга». Если заполнено, то при выборе тарифа будет автоматически подставлено в броньили размещение. Используется в аналитических отчетах. 
  • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице». Если заполнено, то при выборе тарифа будет автоматически подставлено в бронь или размещение в соответствующий реквизит. Используется в аналитических отчетах. 
  • Квота номеров. Ссылается на справочник «Квоты номеров». Если заполнено и у тарифа включен флажок On-line тариф, то при on-line бронировании данный тариф попадет в выдачу только, если в указанной квоте будут свободные номера на выбранный клиентом период.  
  • Автор. Ссылается на справочник «Сотрудники». Указывает пользователя, который создал тариф. 
  • Дата регистрации в программе. Указывает дату и время создания тарифа.

Закладка «Связи»

  • Привязан к тарифу. В поле выбирается тариф, на основании которого будет вычислена цена для данного тарифа. Использование такой связи позволяет быстро задать цены нового тарифа, без настройки календаря и ввода приказов по ценам, т.к. все данные автоматически подберутся из настроек выбранного тарифа. После того как выбран тариф, необходимо задать правила расчёта цены нового тарифа по ценам выбранного. Вы можете указать процент скидки и/или ввести формулы. Порядок пересчета цен следующий: 
    • Сначала к ценам выбранного тарифа применяется скидка 
    • Далее цены будут скорректированы по формулам из таблицы.  
    • Затем полученные цены будут округлены по правилам округления указанным внизу закладки "Связи".
  • Скидка %. Указанный процент скидки применяется в момент проведения приказов по тарифу. Например, если в приказе по тарифу указана цена 1000 руб, а в тарифе указана скидка "10%", то при проведении приказа по тарифу будет задана цена 900 руб. В дальнейшем, при бронировании и размещении, по этому тарифу будет применена цена со скидкой, т.е. 900 руб. Используется для того чтобы одним приказом задать цены сразу на группу тарифов. Программа позволяет указывать цены в одном приказе об изменении цен, который действует на группу тарифов. Цены в приказе на группу тарифов указываются без скидки. Если у тарифа в группе указан процент скидки, то при выборе этого тарифа в брони или размещении гостю будут начислены услуги с ценами уменьшенными на указанный процент. Процент скидки также действует при заполнении поля "Привязан к тарифу". 
  • Набор услуг, на который действует скидка. Ссылается на справочник «Наборы услуг». Если скидка указана, а набор услуг нет, то скидка будет применена ко всем услугам из приказа. Используется вместе с реквизитом "Скидка". Если нужно, чтобы скидка применялась, например, только к проживанию, а к завтраку нет, то в этом поле нужно указать набор услуг, в котором будет только услуга проживания. 
  • Округлять цену. Позволяет указать, что цена услуги, которая получилась после применения скидки, должна быть округлена до рублей, или десятков рублей. Округление происходит всегда «в пользу» гостя, т.е. округление всегда выполняется «вниз». 
  • Разрядность округления цены (...; -2 до 100; -1 до 10; 0 до 1; 1 до 0.1; 2 до 0.01; ...). Задает способ округления: 
    • 2 - округлять до копеек 
    • 1 - округлять до десяти копеек 
    • 0 - округлять до целых рублей 
    • -1 - округлять до десятков рублей 
    • -2 - округлять до сотен рублей  
  • Формулы.  

    В таблице указывается как нужно скорректировать цену относительно привязанного тарифа. Берется цена привязанного тарифа, затем к ней добавляется сумма, и полученный итог умножается на коэффициент, заданный в формуле. Далее к результату прибавляется второй коэффициент. 

    Общий вид формулы: <Новая цена> = (<Цена выбранного тарифа> + <Коэффициент 1>) * <Множитель> + <Коэффициент 2>

    Например, если цену для вида размещения "Номер", относительно привязанного тарифа нужно увеличить на 100 руб, то формула будет такая: Проживание = (Номер + 100) * 1 + 0. 

    Формулы могут быть разными для разных гостиниц, типов номеров, типов клиентов, услуг и видов размещений. Если гостиница, тип номера, услуга или вид размещения не указаны, то формула применяется ко всем услугам и видам размещения из базового тарифа. У формул также есть дата начала действия. Если указана, то формула применяется только к тем приказам привязанного (основного) тарифа, дата которых больше или равна дате начала действия формулы.

    Важно! Формулы применяются после скидки.

    • Закладка «Пакеты услуг»

  • Позволяет указать несколько пакетов услуг, начисляемых по тарифу. Если заполнен, то по тарифу будут начислены не только услуги, указанные в приказе об изменении цен, но и услуги, указанные в перечисленных пакетах. Используется для добавления к тарифу доп. услуг вроде завтрака, обеда или ужина. Один и тот же пакет указывать несколько раз нельзя.
