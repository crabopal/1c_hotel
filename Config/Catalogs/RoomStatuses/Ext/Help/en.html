Справочник "Статусы номеров"

Назначение

Содержит список используемых статусов номеров. Справочник поставляется с одним уже введенным статусом «Занят». Этот статус программа автоматически проставляет для номеров, в которые заехали гости и автоматически очищает при выселении последнего гостя из номера. При желании контролировать статусы номеров более детально, можно добавить в справочник новые статусы.

Например, самый простой вариант статусов: «Занят», «Грязный», «Чистый». Чтобы при выселении автоматически устанавливался статус "Грязный" необходимо в гостинице, на закладке "Константы 2" заполнить реквизит "Статус номера после выезда". При такой комбинации статус "Занят" устанавливается автоматически при поселении, статус "Грязный" устанавливается автоматически при выселении, а статус "Чистый" устанавливается горничными и администратором вручную.

При подборе свободного номера для поселения статус отображается в списке выбора и позволяет быстро выбрать чистый, готовый к поселению номер.

Кроме того можно ввести дополнительные статусы, например:

  • "На инспекции" - устанавливается после уборки номера. Означает, что номер убран, но еще не проверен и не готов к поселению. После проверки номера супервайзером, номеру ставится статус "Чистый".
  • "Занят грязный" - может устанавливаться автоматически регламентной процедурой ("Управление статусами занятых номеров"), которая обычно в 5 или 6 утра устанавливает этот статус у всех номеров, где проживают гости. При использовании этого статуса, необходимо также завести парный ему статус "Занят чистый", который устанавливается вручную после текущей уборки номера.
  • "На ремонте" - используется для номеров на ремонте.
  • и проч.

Относится к подсистеме: «Стойка администратора».

Реквизиты

  • Код. Строка, 5 символов. Используется для быстрого выбора в документах и для краткого представления.
  • Наименование. Имя статуса, основанное представление.
  • Порядок сортировки. Задает порядок в котором показывается список элементов для выбора. Также используется в отчетах для сортировки.
  • Иконка статуса номеров. Картинка с представлением статуса. Отображается в списке номеров и в списке статусов при выборе.
  • Размещение в номера с этим статусом запрещено. Если флажок включен, то пользователь, у которого в наборе прав выключен флажок "067 - Есть права селить гостей в номера с запрещенным статусом номера", не сможет поселить в номер с таким статусом. Например, можно запретить селить в номер со статусом "Грязный".
  • Код работы в телефонной АТС. Используется при использовании интерфейса с АТС, при котором изменение статуса передается автоматически с телефона. Должен совпадать с кодом, набираемым на телефоне.
  • Примечания. Комментарий к статусу.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Статусы/Статусы номеров"
