Справочник "Классы типов номеров"

Назначение

Справочник классов типов номеров: люксы, полу-люксы, стандартные, и т.д. Используется, например, для группировки разных типов номеров, которые продаются по одной цене в 1 класс, который может использоваться в приказах по ценам. Класс типа номера можно использовать в аналитических отчетах, формах приказов по ценам тарифов проживания. Использование классов в ценообразовании позволяет уменьшить кол-во строк в приказах по ценам и таблицах с формулами.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 5.

Длина наименования: 100.

Неиерархический.

Владельцы справочника: «Гостиницы».
