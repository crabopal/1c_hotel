Справочник "Типы номеров"

Назначение

Справочник типов (категорий) номеров: одноместный, двухместный, люкс, и т.д. Источником информации для формирования типов номеров гостиницы служит прайс-лист гостиницы на проживание. Тип номера, в первую очередь, определяет стоимость номера. Если в гостинице 2 номера имеют разную стоимость, то у них должны быть разные типы.

Также в разрезе типов номеров учитываются остатки свободных номеров/мест в продаже.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина наименования: 50.

Иерархический.

Владельцы справочника: «Гостиницы».

Реквизиты

  • Код. Строка, 5 символов. Является основным представлением. Необходимо заранее задать систему кодов типов номеров гостиницы, так чтобы код кратко и ясно отображал категорию.
  • Наименование. Вспомогательное представление типа номера. Является расшифровкой кода.
  • Переводы наименования на различные языки. Задает представление типа номера при печати на разных языках.
  • Количество мест в номере. Указывает количество основных мест в номере данной категории.
  • Количество гостей в номере. Указывается максимальное количество гостей в номере данной категории с учетом доп. мест.
  • Фирма. Ссылается на справочник «Фирмы». Если номерной фонд разделен между несколькими организациями (фирмами), то в этом поле можно привязать создаваемый тип номера к одной из фирм. Если все номера продаются по одной фирме, то реквизит рекомендуется оставить пустым.
  • Виртуальный тип номера. Тип значения: «Булево». Позволяет исключить номер из картины загрузки. Используется для тех номеров, которые не должны попадать в список заселяемых гостями номеров, но нужны в справочнике, например для целей планирования работ горничных и т.д.
  • Снят с продажи. Пока флажок включен, будет запрещено бронировать и селить в номера по данной категории. При этом поселение по брони будет возможно, но создание новой брони и поселение с улицы будет запрещено. Используется менеджеров в случаях, когда необходимо приостановить продажу номеров данной категории на некоторое время.
  • Примечания. Строковый комментарий к категории. Может содержать подробное описание типа номера.
  • Порядок сортировки. В данном порядке показываются остатки номеров в отчетах "Загрузка по дням" и в форме "Что свободно". В этом же порядке отображаются категории в списке для выбора в документах.
  • Картинка номера. Содержит картинку для данного типа номера.
  • Линк на картинку типа номера на сайте гостиницы. Содержит относительный путь к файлу с картинкой для данной категории. Используется модулем он-лайн бронирования.
  • Линк на страницу с описанием типа номера на сайте гостиницы. Содержит ссылку с описанием номеров данной категории. Используется модулем он-лайн бронирования. Путь должен быть задан относительный к месту расположения модуля он-лайн бронирования.

Табличная часть «Периоды снятия с продажи»

Позволяет задать период, на который запрещено бронировать и селить в номера по данной категории. При этом поселение по брони введенной ранее будет возможно, но создание новой брони и поселение "с улицы" будет запрещено. Используется менеджером в случаях, когда необходимо приостановить продажу номеров данной категории на некоторое время.

  • Период с. Указывает дату начала периода на который запрещена продажа категории.
  • Период по. Указывает дату окончания периода на который запрещена продажа.
  • Примечания. Необходимо указывать причину запрета. Именно этот текст показывается пользователю, который попытается вести "Бронь" или "Размещение" пересекающиеся с указанным периодом.

Способ вызова
