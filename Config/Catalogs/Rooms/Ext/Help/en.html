Справочник "Номерной фонд"

Назначение

Справочник "Номерной фонд" предназначен для ведения списка номеров гостиницы. 
Номера в справочнике могут быть сгруппированы, обычно группа в справочнике это этаж или корпус гостиницы.

Основная характеристика номера это его категория, или тип номера. Именно тип номера определяет цену, а также в разрезе типов номеров учитываются остатки номеров/мест в продаже.

У номера также указывается количество основных мест и максимальное количество гостей,
которое можно разместить в данном номере. При бронировании и поселении количество мест/гостей контролируется.

Номер в справочник добавляется документом "Добавить номер", т.к. при вводе номера необходимо проинициализировать остатки в регистрах. Если при вводе нового номера ошиблись и необходимо исправить параметры номера, то необходимо открыть журнал документов и исправить соответствующий документ.

Если же в процессе эксплуатации гостиницы, меняется какой-то реквизит номера, например тип номера или количество мест, то для изменения реквизитов номера необходимо использовать документ "Изменить номер". Изменения вступят в силу начиная с даты документа.

Относится к подсистеме: «Стойка администратора».

Параметры

Нет кода. 

Длина наименования: 25.

Иерархический.

Владельцы справочника: «Гостиницы».

Объекты, вводимые на основании: «Добавить номер», «Изменить номер», «Статус доп. услуги на номер», «Установить блокировку».

Реквизиты

  • Порядок сортировки. Задает порядок, в котором показывается список номеров при подборе свободных номеров при бронировании и поселении. Задает порядок в котором показываются номера в журнале проживающих и в карте номерного фонда.  
  • Тип номера. Ссылается на справочник «Типы номеров». Определяет стоимость номера. В разрезе типов номеров учитываются остатки свободных номеров/мест в продаже. 
  • Количество мест в номере. Указывает количество основных мест в номере. Первоначально задается документом "Ввод номера в эксплуатацию". Может быть изменено документом "Изменить номер". 
  • Количество гостей в номере. Максимальное количество гостей, которых можно поселить в номер с учетом доп. мест и детских мест. 
  • Дата ввода номера в эксплуатацию. Дата начала эксплуатации номера.   
  • Дата вывода номера из эксплуатации. Дата окончания эксплуатации номера. При наступлении этой даты номер будет выведен из эксплуатации, и не будет отражаться в отчетах. Дата может быть пустой (не заполнена), что означает, что номер учитывается всегда, без ограничений. 
  • Фирма. Ссылается на справочник «Фирмы». Используется, если номерной фонд разделён между несколькими юридическими лицами. Если указана фирма, то при поселении в этот номер будет использована указанная фирма. В результате, все документы (счет, чек, акт) будут оформлены на эту фирму. Если же в гостинице только одна фирма, то рекомендуется оставить реквизит незаполненным, и тогда будет использоваться фирма "по-умолчанию" из параметров гостиницы.  
  • Секция номеров. Ссылается на справочник «Секции номерного фонда». Позволяет разделить номерной фонд на несколько частей. Используется для планирования работ горничных. 
  • Статус номера. Ссылается на справочник «Статусы номеров». Отображается текущий статус номера. Например: грязный или чистый. Историю изменения статуса выбранного номера можно посмотреть по кнопке "Перейти/История изменения статуса".  
  • Есть блокировки. Флажок означает, что у номера есть действующие блокировки. Тип блокировки и период ее действия можно посмотреть в карточке номера на закладке "Блокировки". 
  • Снят с продажи. Флажок означает, что у номер снят с продажи. Период и причину снятия с продажи можно посмотреть на закладке "Снят с продажи". 
  • Код в системе эл. замков. Используется для работы интерфейса с системой электронных замков в случае, когда коды в системе электронных замков не совпадают с наименованием номера, или в случае, когда электронные замки установлены не на всех номерах. Для использования этого реквизита необходимо в настройках параметров подключения электронных замков включить флажок "При отправке команд на сервер электронных замков использовать коды номеров в системе, а не наименования номеров". 
  • Права доступа в системе электронных замков. Ссылается на справочник «Наборы прав доступа в системах электронных замков». Задает коды доступа для карты гостя. 
  • Код номера в системе охраны. используется интерфейсом с охранной системой в случае, когда код номера в системе не совпадает с наименованием номера. 
  • Примечания. Произвольный комментарий к номеру. Может содержать описание номера.  
  • Виртуальный номер. Если флажок включен, то номер не учитывается в загрузке номерного фонда. Обычно в такой номер не селят гостей. Используются "виртуальные" номера для задания списка служебных помещений и планирования работ горничных, либо для создания служебных номеров и специальных счетов для расчетов с гостями не проживающими в гостинице.  
  • Наименования свойств номера. Заполняется автоматически строкой с перечислением свойств номера. Используется для вывода в отчетах и в журналах. 
  • Коды свойств номера. Заполняется автоматически строкой с перечислением кодов свойств номера. Используется для вывода в отчетах и в журналах. 

Закладка «Периоды снятия с продажи»

Позволяет задать период, на который запрещено бронировать и селить в номер. При этом поселение по брони, введенной ранее будет возможно, но создание новой брони и поселение "с улицы" будет запрещено. Используется менеджером в случаях, когда необходимо приостановить продажу номера на некоторое время. 

  • Период с. Указывает дату начала периода на который запрещена продажа номера. 
  • Период по. Указывает дату окончания периода на который запрещена продажа номера. 
  • Примечания. Необходимо указывать причину запрета. Именно этот текст показывается пользователю, который попытается вести "Бронь" или "Размещение" пересекающееся с указанным периодом.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Номерной фонд"
