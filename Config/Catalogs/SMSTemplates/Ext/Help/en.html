Справочник "Шаблоны текста сообщений"

Назначение

Справочник позволяет хранить шаблоны текста сообщений, которые используются при СМС или E-Mail рассылках. Относится к подсистеме: «Управление СМС».

Параметры

Длина кода: 5, тип кода: Число.

Длина наименования: 50. Наименование шаблона.

Иерархический.

Реквизиты

  • Текст сообщения. Тип значения: «Строка». Текст шаблона сообщения 
  • Отправитель СМС сообщения. Тип значения: «Строка», номер телефона (максимум 15 цифр) или строка латиницей (максимум 11 символов). Эту строку получатель СМС увидит в качестве отправителя сообщения. Может быть названием отеля или телефонным номером в международном формате без разделителей, например: 79876543210. Если в качестве отправителя указан телефонный номер, то получатель может на этот номер отправить ответный СМС. Если в шаблоне отправитель не указа, то при отправке СМС сообщений по этому шаблону будет использован основной отправитель указанный в договоре о предоставлении услуг рассылки СМС сообщений

Способ вызова

Вызывается из меню "СМС/Шаблоны текста сообщений"

Дополнительно

В тексте шаблонов сообщений возможно использование подстановочных выражений:

  • &FirstName. Имя клиента, например "Иван" 
  • &LastName. Фамилия клиента, например "Иванов" 
  • &SecondName. Отчество клиента, например "Иванович" 
  • &CheckInDate. Дата заезда гостя в гостиницу 
  • &CheckOutDate. Дата выезда гостя из гостиницы 
  • &Duration. Продолжительность проживания гостя в днях 
  • &GuestGroup. Номер группы гостя 
  • &GroupTotalAmount. Общая сумма оказываемых по группе услуг  
  • &Room. Номер комнаты где проживает гость 
  • &RoomType. Тип номера где проживает гость 
  • &RoomClass. Класс номера где проживает гость 
  • &Resource. Ресурс из шапки брони ресурса 
  • &ResourceType. Тип ресурса из шапки брони ресурса 
  • &FolioBalance. Баланс по лицевым счетам гостя 
  • &Dear. Строка обращения к клиенту в зависимости от его пола: "уважаемый" или "уважаемая". Если данное выражение стоит первым словом в тексте шаблона, то слово уважаемый будет подставлено с заглавной буквой "У". 
  • &PaymentAmount. Строка с представлением суммы платежа при отправке СМС сообщения из документов регистрации оплаты 
  • &QRCodePath. QR код с данными брони для экспресс заселения
  • &ReservationUUID. Уникальный идентификатор брони. Используется при отправке ссылок на оплату брони
  • &GuestReservationLink. Ссылка на страницу брони в модуле он-лайн бронирования 1С:Отель
  • &CardID. ID карты лояльности
  • &DiscountCardBalance. Баланс карты лояльности
  • &BonusesOperationAmount. Сумма операции по карте лояльности
  • &WalletURL. Ссылка на регистрацию карты лояльности в личном кошельке мобильного телефона гостя
  • &ProformaInvoiceLink. Ссылка на страницу оплаты счета в модуле он-лайн бронирования 1С:Отель так же, для отправки приглашений агентам можно использовать следующие выражения:
  • &email. E-Mail адрес агента 
  • &ContractNumber. Номер договора агента 
  • &ContractDesc. Наименование договора агента 
  • &CustomerDesc. Наименование агента 
  • &HotelDesc. Наименование гостиницы 
  • &RegLink. Ссылка на завершение регистрации агента 
  • &VerificationCode. Код подтверждения участия клиента в акции/промо программе.
