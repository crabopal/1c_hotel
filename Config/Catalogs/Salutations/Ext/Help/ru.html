Справочник "Обращения"

Назначение

Справочник "Обращения" содержит список используемых в регионе гостиницы обращений к гостям: "Господин", "Госпожа", "Herr", "Frau", "Mr.", "Ms." и т.д. Поле доступно для выбора в карточке клиента рядом с полем "Пол". Используется в печатных формах при указании имени гостя/клиента.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 50, тип кода: Строка. Здесь указывается краткое обращение, например: "Господин", "Госпожа"

Длина наименования: 150. Здесь указывается текст полного обращения, например "Уважаемая госпожа" 

Не иерархический.

Реквизиты

  • Титул. Длина строки: 50. Содержит титул клиента, например "Др.", "Проф.", "Dr.", "Prof.", "Dr. Prof." и т.д.
  • Тип. Тип: Перечисление "Типы обращений". Здесь указывается, какая часть имени (фамилия или имя) обычно следует после обращения. Значение по умолчанию "Фамилия". 

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Обращения к клиентам"
