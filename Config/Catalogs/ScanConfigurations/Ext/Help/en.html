Справочник "Конфигурации сканирования"

Назначение

Справочник настроенных конфигураций сканирования документов гостей. Обычно на каждый вид документа удостоверяющего личность создается своя конфигурация сканирования. Пример: для сканирования паспортов используется конфигурация "Паспорт", для сканирования миграционных карт используется конфигурация "Миграционная карта". Каждой конфигурации сканирования соответствует имя файла, например, "ScanPassportAndDriveLic", в котором описаны параметры этой конфигурации.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 100.

Не иерархический.

Реквизиты

  • Тип документа удостоверяющего личность. Тип значения: «Виды документов удостоверяющих личность». Указывается при распознавании сканов документов для определения состава полей документа
  • Имя конфигурации сканирования. Тип значения: «Строка», длина 250. Имя файла конфигурации сканирования, например, "ScanPassportAndDriveLic". Указывается только для драйвера «Cognitive»  
  • Размер бумаги. Тип значения: «Перечисление.Размеры бумаги». Если не указано, то используется настройка сканера по умолчанию. Указывается только для драйвера «1C Scan»
  • Поворот. Тип значения: «Число (3, 0)». Указывается количество градусов для поворота отсканированной картинки перед ее сохранением в программе. Указывается только для драйвера «1C Scan»
  • Глубина цвета. Тип значения: «Перечисление.Глубина цвета». Если не указано, то принимается равным 24 бита. Указывается только для драйвера «1C Scan»

    Способ вызова

    Вызывается из меню "Настройки/Конфигурации сканирования"
