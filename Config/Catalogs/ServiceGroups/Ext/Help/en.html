Справочник "Наборы услуг"

Назначение

Справочник содержит список используемых в работе наборов услуг. Предназначен для того, чтобы объединить некоторые услуги в группу или набор. Для разных целей могут понадобиться различные группировки.  

Наборы услуг используются:

  • в отчетах для установки отборов и фильтров;
  • в тарифах для установки ограничения по начисляемым услугам;
  • при выборе скидок для ограничения применения скидок к услугам;
  • в правилах начисления для задания автоматического перенаправления начислений;
  • и проч., везде, где требуется наложить отбор на несколько услуг сразу.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Порядок сортировки. Может использоваться в отчетах для сортировки.
  • Включить все услуги. Если флажок включен, то считается что в данный набор услуг включены все, без исключения услуги справочника..
  • Примечания. Произвольный строковый комментарий.

Табличная часть «Услуги в наборе»

  • Услуга. Ссылается на справочник «Услуги». Указывает какая услуга включена в набор.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Наборы услуг"
