Справочник "Позиции меню"

Назначение

Используется при бронировании ресурсов и мероприятий. Позволяет указать состав банкетного меню и кофе-брейков по позициям.
Обычно содержит позиции меню ресторанов, кафе, баров. Так же может использоваться для детализации работ выполняемых при оказании любых услуг. Позиции меню можно указывать для услуги в карточке услуги справочника услуг и в строке услуги на закладке "Услуги" документов "Бронь ресурса". Детализация услуг выводится при печати заказов по брони ресурсов, и является с одной стороны детализацией контракта на проведение мероприятия/банкета, с другой стороны используется различными службами гостиницы в качестве задания на подготовку к мероприятию/банкету.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина кода: 6, тип кода: Число.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Выход. Строка с указанием выхода блюда. Используется при печати.  
  • Переводы наименования на различные языки. Задает перевод наименования для печати на разных языках.
  • Цена. Цена за единицу.
  • Валюта. Ссылается на справочник «Валюты». Указывает в какой валюте задана цена. 
  • Количество. Указывает количество по-умолчанию при выборе в документе.
  • Единица измерения. Строковое представление единицы измерения для печати.
  • Переводы единиц измерения на различные языки. Используется при печати на разных языках.
  • Примечания. Произвольный комментарий или подробное описание товара/блюда.
  • Код во внешней системе. Используется для синхронизации справочника с внешними системами. Например со справочником "Меню" в ресторанной системе.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Позиции меню"
