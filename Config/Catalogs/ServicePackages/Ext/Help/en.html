Справочник "Пакеты услуг"

Назначение

Пакет – некая группа услуг, по которым может быть проведено начисление на лицевой счет клиента. Объединяются услуги в пакет, чтобы не добавлять каждую по отдельности. Пакеты услуг можно указывать в карточках тарифов. При этом, при поселении или бронировании гостя по такому тарифу, в список услуг гостя будут автоматически добавлены как услуги из приказа об изменении цен, так и услуги из пакета.

В списке услуг пакета можно указывать цену услуги, валюту цены, количество, ставку НДС и ряд признаков: начислять услугу по числу гостей или нет; вид расчета количества услуги; порядковый номер дня в периоде проживания, на который начислять услугу; учетная дата, на которую начислять услугу. Если указать порядковый номер дня в периоде проживания равным 9999, то программа будет начислять услугу на последний день периода проживания.Справочник могут редактировать только пользователи у которых в наборе прав включена галочка "094 – Есть права управлять ценами и услугами"

Относится к подсистеме: «Управление взаиморасчетами».

Реквизиты

  • Код. Строка, 5 символов. Краткое представление пакета. Используется для быстрого выбора в документах и для краткого представления в отчетах и при печати документов. Задается вручную.
  • Наименование. Основное представление, задает краткое наименование.
  • Примечания. Тип значения: «Строка».
  • Порядок сортировки. Числовое значение, используется для сортировки.
  • Действует с даты. Задает дату начала действия пакета. Если гость заехал ранее даты начала действия, то пакет не будет начислен.
  • Действует по и включая дату. Дата окончания действия пакета. Если гость выезжает позже этой даты, то пакет не будет начислен.

Табличная часть «Услуги»

Содержит услуги составляющие пакет. При выборе пакета для начисления будут добавлены все услуги, перечисленные в пакете. Учетная дата начисления будет рассчитана в зависимости от заданных параметров в таблице.

  • Период. Тип значения: "Дата". Поле обязательно для заполнения. Задает дату, с которой действует указанная в строке цена услуги. При необходимости изменить цену услуги начиная с какой-либо даты необходимо скопировать существующую строку пакета услуг, изменить дату (на ту, с которой должна действовать новая цена) и указать новую цену.
  • Тип клиента. Ссылается на справочник «Типы клиентов». Указывает для каких типов клиентов услуга должна начисляться. Позволяет задать разный набор услуг в зависимости от типа клиента.
  • Вид размещения. Ссылается на справочник «Виды размещения». Указывает для каких видов размещения услуга должна начисляться. Например, можно указать, что завтрак начисляется для вида размещения "Номер", и не начисляется для вида размещения "Совместно". Либо задать для разных видов размещения разный набор услуг.
  • Услуга. Ссылается на справочник «Услуги». Указывает какую услугу необходимо начислить.
  • Цена. Указывает цену начисления.
  • Валюта. Ссылается на справочник «Валюты». Валюта, в которой указана цена. При начислении будет пересчитано в валюту лицевого счета по курсу на дату курса начисления.
  • Количество. Количество выбранной услуги, которую необходимо начислить.
  • Единица измерения. Строковое представление единицы измерения. Используется при печати в счетах.
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». Указывает ставку НДС для начисления.
  • Примечания. Произвольный комментарий к начисленной услуге. При начислении копируется в документ "Начисление" и, соответственно, отображается в лицевом счете гостя.
  • Входит в цену. Если флажок включен, то услуга будет включена в цену, при отображении справки "Что свободно".
  • Это услуга на человека. Если флажок включен, то при добавлении пакета количество услуги будет умножено на количество человек, указанное в документе "Бронь", "Размещение" или "Бронь ресурса".
  • Правило вычисления количества. Ссылается на справочник «Правила вычисления количества услуг». Указывает по какому правилу начислять услугу.
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях». Если указан, то услуга будет начислена только на указанный тип дня.
  • Учетная дата. Если выбрано значение, то услуга будет начислена строго на указанную дату. Если не указано, то для расчета учетной даты будут использованы правила вычисления количества или номер дня в периоде проживания.
  • Номер дня в периоде проживания. Указывает на какой номер дня в периоде проживания гостя нужно начислить услугу. Например: 1= начислить на дату заезда гостя, 2= начислить на следующий день после заезда гостя, т.д. Если указать 9999, то это будет означать, что услугу нужно начислить на день выезда гостя. Например: 1 - Трансфер аэропорт-отель; 9999 - Трансфер отель-аэропорт.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Пакеты услуг"
