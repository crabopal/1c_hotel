Справочник "Услуги"

Назначение

Справочник услуг, которые оказываются гостям гостиницы и сторонним посетителям.

Относится к подсистеме: «Управление взаиморасчетами».

Реквизиты

  • Код. Строка, 5 символов. Задает краткое представление услуги. Используется для быстрого выбора в документах. Рекомендуется заранее продумать систему кодов услуг. 
  • Наименование. Основное представление услуги. 
  • Порядок сортировки. Используется для сортировки в отчетах. 
  • Примечания. Произвольный строковый комментарий. 

Закладка "Основные параметры"

  • Переводы наименования на различные языки. Тип значения: «Строка». Позволяет задать различные переводы названия услуги, которые будут использоваться для печати, например, счетов гостям на иностранных языках.
    Перевод задается в виде строки на разных языках, разделенных символом ";" (точка с запятой). 
    Строка на одном языке состоит из кода языка, указанного в метаданных, символа "=" (равно) и, собственно, строки текста на данном языке в одинарных кавычках. 
    Например: RU='Завтрак'; EN='Breakfast' 
  • Переводы наименования на различные языки в случае, когда услуга используется как группирующая услуга. Тип значения: «Строка». Используется в основном для услуги проживания в тех случаях, когда необходимо гостю распечатать «свернутый» счет и название услуги проживания в печатной форме должно быть специальным, например "Пакет услуг". 
  • Единица измерения. Тип значения: «Строка». Название того, в чем измеряется количество услуги. Печатается в счете.  
  • Переводы единиц измерения на различные языки. Тип значения: «Строка». Аналогично переводам наименования используется для правильного форматирования строк счетов гостям на иностранных языках. 
  • Получать единицу измерения по правилам расчета количества. Тип значения: «Булево». Количество любой оказанной услуги в программе хранится в виде десятичного числа формата 17.7, т.е всего под число отводится 17 символов и из них 7 отводится под десятичные доли. Максимальное число таким образом будет 9999999999.9999999. При этом, например, если гость прожил в гостинице 3 суток и 5 часов (т.е. выехал в 17:00 при расчетном часе 12:00), в поле количество будет число 3.2083333. Если же флажок включить, то количество будет напечатано в гораздо более «дружественном» к клиенту формате: 3д. 5ч. 
  • Разрешить менять цену. Если флажок выключен, то Пользователь программы не сможет, при начислении услуги клиенту, поменять цену, которая автоматически подставится в документ из настроечной таблицы цен услуг. 
  • Пересчет цены при изменении суммы. Если флажок включен, то при изменении суммы в документе "Начисление" программа будет пересчитывать цену услуги, оставляя неизменным указанное количество, иначе пересчитывается количество при сохранении цены. 
  • Правило вычисления количества по умолчанию. Ссылается на справочник «Правила вычисления количества услуг». Ссылка на элемент специального настроечного справочника, в котором хранятся и настраиваются алгоритмы автоматического вычисления количества услуг по периоду и условиям проживания гостей. Значение, заданное у элемента, подставляется автоматически в "Приказ об изменении цен", а также используется для вычисления представления единицы измерения. У услуги "Завтрак" рекомендуется заполнять значением, у которого тип алгоритма расчета количества установлен в "Завтрак". 
  • По умолчанию это доход от продажи номеров. Если флажок включен, то начисление по этой услуге будет учитываться как продажа номеров (ночей) и, соответственно, учитываться при расчете показателей работы гостиницы, таких как средняя цена номера и RevPar и процент продаж. 
  • Используется только для расчета дохода за проживание. Тип значения: «Булево». Услуга учитывается в аналитическом ресурсе "Доход от продажи номеров" но не влияет на число проданных номеро-дней. Примеры такой услуги: Ранний заезд, Поздний выезд и т.д. 
  • Услуга начисляется по числу гостей, а не по числу номеров/мест. Тип значения: «Булево». Количество услуги автоматически начисленной по тарифу или пакету услуг будет зависеть от указанного в документе (брони, размещении, брони ресурсов) числа гостей. 
  • По умолчанию входит в цену. Используется при отображении формы "Что свободно", цена за номер будет включать цену услуги, если эта услуга включена в "Приказ об изменении цен".   
  • По умолчанию это доход от продажи ресурсов. Значение по-умолчанию при определении цены ресурса. 
  • Не сворачивать в проживание при печати. Используется при печати счетов и актов. Если флажок включить, то при выборе варианта печати, при котором доп. услуги сворачиваются в строку проживания, данная услуга сворачиваться не будет и будет всегда выделена отдельно. Т.е. услуга всегда, при любом варианте печати, будет выделена в счете. 
  • Цена указывается за минуту. Используется в начислениях при бронировании ресурсов. Если флажок включен, то цена услуги будет умножена на количество забронированных минут. Если выключен, то количество будет равно количеству часов. 

Закладка "Учетные параметры"

  • При формировании бухгалтерской реализации создавать для этой услуги отдельные акты. Используется процедурой закрытия периодов. Если флажок включен, то на услугу будет создаваться отдельный акт. Т.е. услуга не будет включена в общий акт с проживанием.  
  • Не выгружать в бухгалтерскую систему. Используется процедурой закрытия периода. Если флажок включен, то услуга будет выделена в отдельный акт, и у акта будет установлен признак "Не выгружать". Таким образом данный акт не будет выгружен в бухгалтерскую базу. Используется для услуг, реализацию по которым бухгалтерия получает из другой учетной системы, например из фронт-офиса ресторана.  
  • Регистрировать фактическое оказание. Если флажок включен, то по услуге будет регистрироваться планируемое оказание услуги. Используется модулем "Контроль услуг". Этот флажок обычно включают у услуг питания, если хотят контролировать фактическую явку гостей в ресторан.  
  • Код во внешней системе. Используется для синхронизации с другими системами и базами данных, например, с базой бухгалтерии. Для бухгалтерии должен содержать код справочника "Номенклатура". Заполняется автоматически при синхронизации справочников в момент загрузки.   
  • Тип услуги. Ссылается на справочник «Типы услуг». Используется для аналитики в отчетах, в том числе в отчете "Сводные показатели". 
  • Секция оплаты. Ссылается на справочник «Секции оплаты». Позволяет проводить платежи по ККМ по разным кассовым секциям (отделам). Используется только, если в параметрах гостиницы включен режим балансов по секциям. В этом случае начисление при проведении заполняет секцию и баланс лицевого счета разбивается по секциям. Также может использоваться для аналитики в отчетах.  
  • Это товар. Используется процедурой "Закрытие периода". Флажок необходим для того, чтобы акты об оказании услуги в бухгалтерию передавались в день начисления услуги, а не на день выселения гостя. Причиной может являться отчетность о наличии товара на складе. 
  • Тип ресурса. Ссылается на справочник «Типы ресурсов». Заполняется, если услуга является производной ресурса. 
  • Ресурс. Ссылается на справочник «Ресурсы».  Указывает к какому ресурсу относится услуга. Используется для быстрого перехода между документами "Размещение" и "Бронь ресурса". 
  • Связанная услуга. Услуга, которая будет списываться при начислении данной услуги. Механизм связанных услуг позволяет реализовать схему, в которой, например, по тарифу начисляется услуга "Медицина" и, затем, по мере фактического оказания гостю медицинских услуг, услуга "Медицина" списывается в 0. Для этого, при начислении какой-либо медицинской процедуры отдельной услугой, документ "Начисление" по всем регистрам делает два движения: 
    1. Обычное движение по мед. процедуре
    2. Корректирующее движение по связанной услуге с ресурсами у которых инвертирован знак.
    Связанную услугу можно указывать у папки обычных услуг. 

Закладка "Характеристики"

Отражаются характеристики, привязанные к данной услуге. Каждой характеристике может быть присвоено строковое или числовое значение. Может быть вес, цвет, размер и т.д. Может быть использовано для печати в счетах, или других печатных формах.

  • При печати свернуть текущую услугу в выбранную. Ссылается на справочник «Услуги».  Используется для печати заказа на мероприятие. При выводе печатной формы данная услуга будет заменена на другую - ту, что выбрана в этом реквизите.

    Закладка "Цены"

    Задаются цены и ставка НДС по выбранной услуге. Для каждой услуги необходимо создать хотя бы одну запись для того, чтобы указать ставку НДС. Цены могут меняться со временем, поэтому указывается период начала действия цены.

      Закладка "Состав услуги"

      • Состав услуги. Используется в документе "Бронь ресурса". Является текстовым описанием услуги и используется для печати заказов на мероприятия. 

      Кнопка "Заполнить состав услуги" заполняет реквизит текстом, сформированным на основании выбранных позиций меню.

        Закладка "Позиции меню"

        Используется при составлении и печати бронирования мероприятий и ресурсов. Обычно содержит стандартный набор банкетного меню. Например у услуги "Кофе-брейк №1" можно указать из каких позиций меню этот кофе-брейк состоит. Сумма будет начислена одной услугой, но в печатной форме документа "Бронь ресурса" будет отражено, какие именно позиции меню и в каком количестве необходимо предоставить. Позиции меню, прикрепленные к услуге, используются как значения по-умолчанию для первоначального заполнения. В дальнейшем, после выбора услуги в документ, позиции меню можно будет отредактировать, если для конкретной брони ресурса нужно незначительно изменить состав меню.

        • Позиция меню. Ссылается на справочник «Позиции меню».Указывает какая позиция должна быть использована. 
        • Выход. Строковое значения выхода блюда (в граммах, миллилитрах) для печати. 
        • Цена. Цена блюда. 
        • Валюта. Ссылается на справочник «Валюты». Указывает в какой валюте указана цена. Из этой валюты будет производится пересчет в валюту заказа. 
        • Количество. Количество, соответствующее единице для выбранной услуги. 
        • Единица измерения. Строковое представление единицы измерения, используется для печати. 
        • Сумма. Сумма за позицию, равняется цене * количество. 
        • Индекс замен. Тип значения: «Число». - Устанавливается произвольным одинаковым значением у позиций, которые взаимозаменяемы, т.е. реально предоставляется одна позиция из перечисленных.

        Способ вызова

        Вызывается из меню "Взаиморасчеты/Справочники/Услуги"
