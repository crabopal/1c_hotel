Справочник "Улицы"

Назначение

Справочник "Улицы" содержит список улиц из адресного классификатора (КЛАДР). Справочник может редактироваться конечным пользователем, однако для его заполнения и обновления следует использовать обработку "Загрузка классификаторов адресов".

Справочник используется при вводе адреса проживания гостя. 

Относится к подсистеме: «Классификатор адресов».

Параметры

Длина кода: 12, тип кода: Строка. Код из КЛАДР.

Длина наименования: 52. Имя улицы. 

Не иерархический.

Реквизиты

  • Сокращение. Ссылается на справочник «Сокращения». Содержит сокращение обозначения улицы, бульвара, переулка и проч. 
  • Почтовый индекс. Содержит почтовый индекс, к которому относится улица. 
  • Город. Ссылается на справочник «Населенные пункты». Указывает город, к которому относится улица. 
  • Район. Ссылается на справочник «Районы». Указывает район к которому относится населенный пункт, где находится улица. 
  • Регион. Ссылается на справочник «Регионы». Регион города. 
  • Страна. Ссылается на справочник «Страны». Страна, в которой находится город. 
  • Код внешнего классификатора. Код из КЛАДР.

Способ вызова

Вызывается из меню "Настройки/Адреса/Улицы"
