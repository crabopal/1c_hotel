Справочник "Опросы"

Назначение

Справочник "Опросы" используется для создания опросных листов. Опросный лист состоит из списка вопросов из справочника "Вопросы для отзывов" и поясняющих текстов вначале перед списком вопросов и в конце после списка вопросов. Опрос указывается в шапке документа "Отзывы клиентов".

Относится к подсистеме: «Настройки/Отзывы».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 200.

Иерархический.

Реквизиты

  • Гостиница. Разделитель учета. Используется если в различных отелях сети используются разные опросные листы.
  • Текст перед списком вопросов. Поясняющий текст перед списком вопросов.
  • Текст после списка вопросов. Поясняющий текст после списка вопросов.
  • Табличная часть со списком вопросов.
    • Вопрос из справочника "Вопросы для отзывов".

Способ вызова

Вызывается из меню "Настройки/Отзывы/Опросы"
