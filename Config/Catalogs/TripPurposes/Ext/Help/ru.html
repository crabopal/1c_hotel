Справочник "Цели поездки"

Назначение

Справочник содержит перечень целей поездки гостей в гостиницу. Цель поездки может быть выбрана при заполнении размещения. Используется для предоставления сведений об иностранных гражданах в службу УФМС. Также может использоваться для аналитики гостей по целям поездки. Справочник имеет предопределенные значения для печати формы "Уведомления" для УФМС. 

Если в наборе прав пользователя выключить флажок "054 - Есть права на отказ от заполнения у гостей цели поездки", то в Размещении поле "Цель поездки" будет обязательным, т.е. документ не проведется пока не будет заполнено это поле.

Если в наборе прав пользователя выключить флажок "103 - Есть права на отказ от заполнения в брони цели поездки гостя", то поле "Цель поездки" будет обязательным в документе "Резервирование".

Относится к подсистеме: «Стойка администратора».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Не иерархический.

Реквизиты

  • Порядок сортировки. Тип значения: «Число». В документах поле выбирается с помощью выпадающего списка, элементы которого отсортированы по данному полю. Если сортировка не задана, или у реквизитов одинаковый порядок сортировки, то они будут отображены в порядке наименования.
  • Код во внешней системе. Тип значения: «Строка». Обычно код элемента в справочнике ППО "Территория" УФМС РФ 
  • Примечания. Произвольный комментарий.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Настройки/Цели поездки"
