Справочник "Параметры подключения WEB камер"

Назначение

Справочник параметров подключения WEB камер. Для подключения используется драйвер Scan 1C (1CScan.dll)

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 5, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Имя Twain устройства. Тип значения: «Строка», длина 250. Указывается название TWAIN устройства нужной WEB камеры, который будет использоваться для получения фотографий с камеры. Если не указано, то будет использоваться устройство по умолчанию 
  • Глубина цвета. Тип значения: «Перечисление.Глубина цвета». Если не указано, то принимается равным 24 бита

    Формы

    • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора элементов.
    • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
    • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.

    Способ вызова

    Вызывается из меню "Настройки/Параметры подключения WEB камер"
