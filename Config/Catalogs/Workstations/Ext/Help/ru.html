Справочник "Рабочие места"

Назначение

Список рабочих мест (компьютеров). В справочнике хранятся настройки рабочих мест. Для каждого компьютера, с которого хотя бы 1 раз запускалась программа автоматически создается элемент с кодом равным имени компьютера. В справочнике можно создавать "виртуальные" рабочие места. Это позволяет для разных пользователей использовать разные настройки рабочих мест в случае использования программы в терминальном режиме.

Относится к подсистеме: «Управление настройками».

Параметры

Длина кода: 50, тип кода: Строка.

Длина наименования: 150.

Иерархический.

Реквизиты

  • Выполнять фоновые задания. Обычно используется только при работе с базой в файловом варианте. Указывает, что на этом рабочем месте будет выполняться менеджер фоновых заданий. В серверном варианте этот флажок, если включен, запускает менеджер формирования отчетов по расписанию. 
  • Настройки печати на рабочем месте. Ссылается на справочник «Настройки печати на рабочих местах».  Указывает какие настройки печати используются на данном рабочем месте. 
  • Подключен к системе управления электронными замками. Если флажок включен, то необходимо заполнить реквизит с параметрами системы электронных замков. На таких рабочих местах, в журнале "Брони", "Размещения" и "Лицевые счета" будет работать кнопка "Ключи" по которой подается команда в систему электронных  замков на выдачу ключа.   
  • Параметры подключения к системе электронных замков. Ссылается на справочник «Параметры системы электронных замков». 
  • Подключен к системе процессинга кредитных карт. Если флажок включен, что необходимо заполнить параметры подключения системы процессинга карт. На данном рабочем месте, при проведении платежа по способу оплаты "Кредитная карта" будет выполнен запрос в банк, и, в случае одобрения платежа банком, платеж будет проведен. 
  • Параметры подключения к системе процессинга кредитных карт. Ссылается на справочник «Параметры системы процессинга кредитных карт». 
  • Подключен к системе карт идентификации клиентов. Тип значения: «Булево». 
  • Параметры подключения к системе карт идентификации клиентов. Ссылается на справочник «Параметры системы карт идентификации клиентов». 
  • Подключен к ленточному принтеру. Тип значения: «Булево».
  • Параметры подключения к ленточному принтеру. Ссылается на справочник «Параметры подключения к ленточным принтерам».
  • Параметры рабочего места. Заполняется автоматически при первом запуске. Содержит данные о параметрах компьютера, предоставленные информационной системой. Это справочная информация. 
  • Примечания. Произвольный комментарий с описанием рабочего места. 
  • Локальный каталог. Тип значения: «Строка». Содержит путь к каталогу, в котором находятся компоненты системы защиты конфигурации. Заполняется автоматически, при первом запуске на данном рабочем месте. Если очистить значение, то при следующем запуске запустится мастер системы защиты, который скопирует компоненты защиты в каталог по-умолчанию. 
  • ID ключа системы защиты. Используется, если лицензии на программу предоставлены несколькими ключами. 
  • Валюта платежей по умолчанию. Ссылается на справочник «Валюты».  В указанной валюте создаются документы вида "Платеж". 
  • Параметры подключения к Интернет. Ссылается на справочник «Параметры подключения к Интернет». Позволяет определить для этого рабочего места параметры подключения к прокси серверам.

Табличная часть «Контрольно Кассовые Машины»

  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». Указывает список ККМ, с которыми разрешена работа на данном рабочем месте. 

Способ вызова

Вызывается из меню "Настройки/Рабочие места"
