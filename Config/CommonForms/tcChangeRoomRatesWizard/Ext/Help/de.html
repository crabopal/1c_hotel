Мастер изменения цен

Назначение

Мастер позволяет быстро и в удобной форме изменить цены по тарифу на любой период по нужным категориям номеров. Использование мастера позволяет изменять цены сотрудниками, которые не обучены правилам создания приказов об изменении цен и управлению календарями.

Использование

  • Отметьте те дня недели на которые вы планируете изменить цены. Ниже под списком дней недели вы должны указать период времени на который будут изменяться цены. Если цены должны изменяться на все дни из этого периода, то в списке дней недели нужно отметить все дни. Если, например, планируется изменить цены только на субботы и воскресенья, которые попадают в указанный период, то в спсике дней недели должны быть отмечены только "Сб" и "Вс".
  • Отметьте тариф, по которому будут изменяться цены. Если отмечено несколько тарифов, то в результате работы мастера по этим тарифам будет установлена одна и таже цена.
  • Отметьте типы номеров по которым будут изменяться цены.
  • Отметьте тип клиента, по которому изменяются цены. Обычно это "Пустой тип". Если отмечено несколько типов, то в результате работы мастера по всем отмеченным типам будут установлены одинаковые цены.
  • Отметьте признаки цены. Обычно это "Пустой признак". Выбор признаков цены имеет смысл только для тарифов, в которых цены зависят от длительности проживания или процента загрузки... Если отмечено несколько признаков цены, то в результате работы мастера по всем отмеченным признакам будут установлены одинаковые цены.
  • Укажите период, на котором планируется изменить цены
  • Нажмите кнопку "Получить цены". Программа покажет по каждому отмеченному типу номера списком по видам размещений цены, которые действуют для первого отмеченного тарифа на дату начала периода изменения цен.
  • Отредактируйте таблицу с ценами
  • Нажмите кнопку "Установить цены"

Особенности

  • Все основные тарифы должны ссылаться на разные календари. Если программа видит, что мастером изменяются цены по тарифу, в котором указан календарь, используемый в других основных тарифах, то после выполнения мастера по отмеченному тарифу будет создан новый календарь. Основныими тарифами считаются тарифы, цены по которым указываются в приказах об изменения цен, а не рассчитываются по формулам или через процент скидки от других тарифов.
  • Перед использованием мастера необходимо вручную создать как минимум один приказ об изменении цен по отмеченному тарифу, где указать услуги, которые будут начисляться по тарифу, правила расчета кол-ва услуг и прочие детальные параметры.
  • Мастер изменяет цены только по услугам проживания (строки в приказах об изменении цен отмеченные 2-мя галочками: "Входит в цену", "Это доход от продажи номеров". Если стоимость номера формируется из стоимости услуги проживания и услуг питания, то при указании цен в мастере необходимо указывать цену проживания за вычетом стоимости питания в сутки.
