1. Зарегистрируйтесь в сервисе sms.1chotel.ru по ссылке http://sms.1chotel.ru/reg/
  2. Зайдите в личный кабинет и подтвердите свой телефон, указанный при регистрации. Для подтверждения нужно запросить и ввести проверочный код. После этого ваш баланс будет пополнен на 15 руб. для тестирования и проверки работы сервиса.
  3. Стоимость смс зависит от региона кому вы отправляете смс. Подробные тарифы http://sms.1chotel.ru/tariffs/
  4. Для пополнения баланса введите в поле сумму пополнения и нажмите кнопку "Заказать" чтобы сформировать и распечатать счет на оплату. После поступления оплаты сумма, будет зачислена на ваш лицевой счет, и вы можете использовать ее для рассылки смс. Сумма доступна для использования на любой срок.
  5. В кабинете клиента вы можете указать имя отправителя. Для этого нужно пройти по ссылке "имена". Зарегистрировать имя и через некоторое время, после модерации, имя будет доступно. Это имя показывается в поле "Отправитель" в смс. Вам всегда доступно имя "hotel". Но вы также можете указать свое имя длинной до 11 символов. Также можно указывать ваш номер телефона в качестве имени отправителя. Чтобы имя или ваш телефон подставлялись в качестве имени отправителя, в кабинете клиента нужно включить галочку "разрешить более дорогие тарифы".
  6. СМС можно использовать в рассылках, которые создаются с помощью документа "Рассылка сообщений"
  7. С помощью мастера настройки рассылки вы можете задать расписание по автоматической рассылке уведомлений и сообщений гостям. Например напоминание об оплате счета, приветствие в день заезда, поздравление с днем рождения, уведомление о долге по лицевому счету гостя.
  8. СМС может быть автоматически отправлено гостю при бронировании или при изменении статуса брони. Эта возможность используется как при он-лайн бронировании, так и при бронировании другими средствами. Гостю обычно отправляется номер брони и телефон гостиницы.
    Для того чтобы гость автоматически получил номер бронирования нужно в статусе бронирования указать шаблон сообщения. Текст шаблона может быть например такой: "Ваш номер брони &GuestGroup. Отель. +7___ваш телефон__".
    У каждого статуса брони может быть свой шаблон - при бронировании один, при аннулировании другой.
  9. При поступлении оплаты также может быть отправлено уведомление гостю. Для этого в справочнике "Способы оплаты" необходимо указать шаблон сообщения.
