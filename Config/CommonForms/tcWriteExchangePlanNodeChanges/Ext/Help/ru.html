Форма используется для записи изменений текущей базы в удаленный узел распределенной базы. 

В форме необходимо указать узел, для которого выполняется запись изменений, и указать путь к сетевой папке или директории на FTP сервере, куда будет выложен файл с изменениями.

Если нужно выкладывать изменения в zip архиве, то на форме нужно включить галочку "Архивировать в ZIP архив" и, если нужно, указать пароль для упаковки.

Если для обмена используется директория на FTP сервере, то необходимо прописать параметры подключения к FTP серверу: логин пользователя, пароль, параметры прокси-сервера для выхода с текущего компьютера в Интернет.

По умолчанию программа выполняет выгрузку всех изменений в одной транзакции, что гарантирует, что либо все изменения будут выгружены корректно, либо, в случае возникновения ошибки блокировки, никаких изменений выгружено не будет. Этот режим используется при значении поля "Кол-во объектов в одной транзакции" равным 0. В некоторых случаях, когда выгружается большой объем изменений, в этом поле можно указать например 1000, тогда изменения будут выгружаться в БД порциями по 1000 объектов.
