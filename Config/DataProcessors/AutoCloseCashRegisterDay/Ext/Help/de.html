Обработка "Автоматическое закрытие кассовой смены"

Назначение

Обработка используется для автоматического закрытия кассовых смен по выбранной ККМ.

Относится к подсистеме: «Управление взаиморасчетами».

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

Режим запуска: фоновое задание, периодичность: ежедневно, до полуночи, например в 23:55

Обработка обычно используется для закрытия кассовых смен по онлайн ККМ.
