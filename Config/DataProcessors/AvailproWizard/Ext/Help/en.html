Обработка "Мастер настройки взаимодействия с channel manager Availpro"

Назначение

Обработка используется для первоначальной настройки синхронизации с CM:Availpro (https://site.availpro.com/), для управления соответствиями данных между системой CM:Availpro и 1С:Отель, а также для выполнения ручного обмена данными с CM:Availpro

Относится к подсистеме: «Управление Номерным фондом».

Форма обработки открывается по кнопке "Настройка" из справочника "Взаимодействия с внешними системами", при этом тип взаимодействия должен быть установлен в "CM:Availpro"

Шаги

  1. Настройка параметров подключения к Availpro. Выберите Гостиницу, данные которой будут синхронизироваться с системой CM:Availpro, укажите код гостиницы в системе Availpro и введите Логин и Пароль для доступа к данным channel manager'a. Укажите, если нужно, квоту номеров по которой будут выгружаться остатки свободных номеров. Заполните кол-во дней на которое будут выгружаться остатки свободных номеров и укажите частоту обновления (кэша) цен в минутах (по умолчанию = 60)
  2. Настройте соответствия между типами номеров в CM и типами номеров в программе
  3. Настройте соответствия между тарифами в CM и тарифами в программе
  4. Настройте частоту выполнения фонового задания по обмену данными с CM. Рекомендуется выполнять обмен один раз в 10 минут.
