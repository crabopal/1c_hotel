Обработка "Драйвер интерфейса с АТС Avaya"

Назначение

Обработка осуществляет взаимодействие с АТС Avaya по протоколу RS232. Сервером является АТС. В обработке реализованы следующие команды:

  • Изменение статуса номера. Код статуса должен быть указан в справочнике "Статусы номеров" в реквизите PBXCode

Относится к подсистеме: «Интеграции».

Способ вызова

Обработку необходимо зарегистрировать в справочнике "Обработки". Для этого необходимо открыть форму списка справочника из меню "Настройки" и нажать кнопку "Добавить" в панели инструментов списка. Далее нужно указать название обработки, например "Интерфейс с АТС Avaya" и в поле "Обработка" выбрать из выпадающего списка "AvayaPBXDriver - Драйвер интерфейса с АТС Avaya". Сохраните обработку и далее из меню "Главное" запустите ее. Нажмите ссылку "Параметры" (ссылка доступна только если программа запущена с правами системного администратора).

В форме настроек обработки укажите номер COM порта, к которому подключена АТС и скорость обмена (9600 по умолчанию). Если необходимо детально отслеживать обмен сообщениями между АТС и 1С:Отель, то нужно включить галочку "Режим отладки". Сохраните настройки.

Для запуска обработки в интерактивном режиме в панели действий формы настроек необходимо нажать на кнопку "Запустить".

Обработка может выполняться в режиме фонового задания. Для этого в консоли управления фоновыми заданиями нужно создать новое задание с типом метаданных "Выполнить обработку" и указать ключ "AvayaPBXDriver" (этот же, ключ должен быть указан в справочнике обработок). Расписание запуска рекомендуется установить на раз в 15 - 20 минут. В нормальных условиях фоновое задание с этой обработкой будет постоянно висеть в статусе выполняется и, в случае возникновения каких-либо ошибок, будет автоматически перезапускаться с указанной вами периодичностью. Для остановки фонового задания можно открыть форму настроек обработки из справочника обработок и нажать на кнопку "Остановить" в панели действий формы настроек.

Для работы интерфейса, на сервере 1С:Предприятия (если АТС подключена по COM порту к серверу) или на интерфейсном компьютере (если АТС подключена по COM порту к этому компьютеру) должна быть установлена внешняя компонента работы по протоколу RS232. Для установки внешней компоненты необходимо открыть справочник рабочих мест и перейти на закладку "Внешние компоненты", затем нажать на ссылку "Установить компоненту работы по RS232". 1С:Предприятие при этом должно быть запущено с правами системного администратора. Если АТС подключена к интерфейсному компьютеру на котором нет сервера 1С:Предприятия, то работа интерфейса возможна только в интерактивной сессии программы.
