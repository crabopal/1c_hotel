Обработка "Мастер настройки взаимодействия с CRM системой Bitrix24"

Назначение

Обработка используется для первоначальной настройки синхронизации с CRM:Bitrix24 (https://www.bitrix24.ru/), для управления соответствиями данных между системой CRM:Bitrix24 и 1С:Отель, а также для выполнения ручного обмена данными с CRM:Bitrix24

Относится к подсистеме: «Интеграции/Bitrix24».

Форма обработки открывается по кнопке "Настройка" из справочника "Взаимодействия с внешними системами", при этом тип взаимодействия должен быть установлен в "CRM:Bitrix24"

Шаги

  1. Настройка параметров подключения к CRM:Bitrix24. Выберите Гостиницу, данные которой будут синхронизироваться с системой CRM:Bitrix24. Введите Логин и Пароль для доступа к CRM системе.
  2. Настройте соответствия между полями в CRM системе и 1С:Отель
  3. Настройте обработчики событий
