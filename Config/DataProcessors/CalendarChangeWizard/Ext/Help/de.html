Обработка "Управление календарем тарифа"

Назначение

Обработка используется для управления календарем выбранного тарифа. Обработка позволяет:

  • изменять типы дней календаря по датам как по гостинице, так и отдельно по каждому типу номера.
  • изменять ограничения тарифа по датам как по гостинице, так и отдельно по каждому типу номера.

Способ вызова

Вызывается из меню "Тарифы и договоры"
