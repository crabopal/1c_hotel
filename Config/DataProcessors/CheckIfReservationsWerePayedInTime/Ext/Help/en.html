Обработка "Проверить поступление оплаты по брони"

Назначение

Обработка используется для автоматической проверки брони у которой просрочена или получена оплата. Оплата брони считается просроченной если на контрольную дату, которая указывается в карточке группы гостей, по группе не поступила оплата на любую сумму.

В параметрах обработки можно указать:

  • "Статус гарантированной брони" -- если указан, то у брони с полученной оплатой будет установлен этот статус.
  • "Статус гарантированной он-лайн брони" -- если указан, то у он-лайн брони с полученной оплатой будет установлен этот статус. 
  • "Вид гарантии" -- если указан, то при изменении у брони статуса на гарантированный также у брони будет установлен данный вид гарантии.
  • "Тип отправки сообщения об изменении статуса брони" -- если указан, то после установки статуса гарантированной брони, если в брони введен контактный E-Mail или факс, программа создаст автоматическое сообщение об изменении статуса и подготовит его к отправке клиенту. Открыть и отредактировать сообщение можно по кнопке "Прикрепленные документы" в карточке группы. Отправка сообщений выполняется отдельной регламентной процедурой "Отправить уведомления по группам гостей". Параметр имеет смысл только при заполненном статусе гарантированной брони. E-Mail и номер факса для отправки сообщения программа берет из карточки главного гостя в группе или, если в карточке гостя эти поля не указаны, из карточки контрагента группы. 
  • "Статус брони с просроченной оплатой" -- если указан, то у брони с просроченной оплатой будет установлен этот статус.
  • "Отдел, сотрудникам которого отправлять сообщения о брони с просроченной оплатой" -- если указан, то по каждой группе с просроченной оплатой будет отправлено внутреннее сообщение сотрудникам из указанного отдела.  
  • "Статус новой он-лайн брони" -- если указан, то система при анализе оплаты по брони в этом статусе для определения просрочена оплата по брони или нет использует не параметр "Дата проверки оплаты" из карточки группы, а время в минутах прошедшее с момента создания брони. Время указывается в параметре этой обработки. Если с момента создания брони до момента выполнения процедуры прошло минут больше, чем указано в параметре "Время ожидания оплаты по on-line брони", то программа установит у такой брони статус из параметра "Статус он-лайн брони с просроченной оплатой". Если этот параметр не заполнен, то программа просто отправит сотрудникам отдела "Отдел, сотрудникам которого отправлять сообщения о брони с просроченной оплатой" уведомление, что оплата по он-лайн брони просрочена.

Относится к подсистеме: «Стойка администратора».

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

Рекомендуемый режим запуска обработки: фоновое задание с периодичностью запуска раз в день в 09:00.

Допускается указание какого-либо одного параметра настроек обработки. Если указан только отдел, то обработка будет отправлять сообщения о группах с просроченной оплатой, но не будет изменять статус брони. Если указан только статус, то статус будет изменен, а сообщения отправляться не будут.

Контрольная дата в карточке группы может указываться вручную при бронировании или устанавливаться автоматически по параметрам контроля оплаты, которые можно указать:

а) в карточке гостиницы на закладке "Константа 2" (действуют на всю новую бронь)

б) в карточке контрагента на закладке "Тарифы" (действует только на бронь от этого контрагента)

в) в карточке договора на закладке "Тарифы" (действует только на бронь от контрагента по данному договору)
