Обработка "Выбрать документы из списка"

Назначение

Обычно используется для выбора одной брони из списка брони, которая входит в группу гостей. Также может использоваться и для выбора размещения из списка размещений.

Относится к подсистеме: «Стойка администратора».

Способ вызова

Из меню не вызывается. Вызывается в процессе работы с программой, например, по кнопке "Выбрать" в поле "Документ основание" карточки размещения.
