Обработка "Автоматическое заполнение тегов клиентов"

Назначение

Обработка используется для автоматической сегментации клиентов. Для каждого автоматического тега из справочника "Теги" выполняется поиск подходящих клиентов. Всем найденным клиентам тег назначается. У всех клиентов, у которых этот тег был установлен ранее, но они больше не подходят по условиям и данным, тег удаляется.
