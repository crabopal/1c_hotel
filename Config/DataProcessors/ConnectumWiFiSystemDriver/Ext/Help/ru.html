Обработка "Драйвер системы управления Wi-Fi Connectum"

Назначение

Обработка осуществляет взаимодействие с системой управления Wi-Fi www.connectum.ru по протоколу HTTP. Обработка выступает в качестве клиента. Сервером является интерфейсная служба Connectum. В обработке реализованы следующие команды:

  • Регистрация гостя при заезде
  • Изменение срока проживания гостя
  • Выселение гостя

Относится к подсистеме: «Фронт-офис».

Способ вызова

Обработку необходимо зарегистрировать в справочнике "Обработки". Для это необходимо открыть справочник из меню настроек и нажать кнопку "Добавить" в панели инструментов списка обработок. Далее нужно указать название обработки, например "Интерфейс с системой управления Wi-Fi Connectum" и в поле "Обработка" выбрать из выпадающего списка "ConnectumWiFiSystemDriver - драйвер системы управления Wi-Fi Connectum". Далее в поле "Ключ" нужно также указать строку "ConnectumWiFiSystemDriver". Сохраните обработку по кнопке ОК. Она появится в списке обработок. 

В форме настроек обработки необходимо указать IP адрес и порт, на котором запущен интерфейсный сервер Connectum. Если необходимо детально отслеживать обмен сообщениями между Connectum и 1С:Отель, то нужно включить галочку "Режим отладки".

Для того чтобы быстро создать настроечные записи в справочнике "Виды доп. услуг в номерах" можно нажать на кнопку "Настройки по умолчанию" в панели инструментов формы настроек обработки.

Для запуска обработки в панели действий формы настроек необходимо нажать на кнопку "Запустить".

Обработка может выполняться в режиме фонового задания. Для этого в консоли управления фоновыми заданиями нужно создать новое задание с типом метаданных "Выполнить обработку" и указать ключ "ConnectumWiFiSystemDriver" (тот же, который вы указывали при регистрации обработки в справочнике обработок). Расписание запуска рекомендуется установить на раз в 2 - 5 минут. Для остановки фонового задания можно открыть форму настроек обработки из справочника обработок и нажать на кнопку "Остановить" в панели действий формы настроек.
