Обработка "Копирование настроек отчетов"

Назначение

Обработка используется для копирования настроек отчетов. Позволяет скопировать настройки отчета из справочника отчетов в другие отчеты из справочника отчетов, у которых вид отчета совпадает с видом отчета, настройки которого копируются. При копировании можно выбирать какие группы настроек должны быть скопированы.

Относится к подсистеме: «Управление настройками».

Способ вызова

Вызывается из формы списка отчетов, которая открывается из меню "Отчеты" по кнопке ".../Копировать настройки отчета" в панели инструментов списка
