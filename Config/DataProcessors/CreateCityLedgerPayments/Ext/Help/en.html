Обработка "Создание платежей со способом оплаты Акт для выезжающих гостей от контрагентов"

Назначение

Обработка используется для автоматического создания платежей со специальным способом оплаты "Акт" по лицевым счетам выезжающих на указанную дату гостей от контрагентов. После выполнения обработка может распечатать реестр таких платежей при помощи указанного в настройках отчета. Обработка не создает платежи по тем лицевым счетам, в которых уже есть хотя бы 1 платеж со способом оплаты "Акт".

Внимание: обработка создает платежи только по лицевым счетам фирм (юридических лиц отеля), у которых в учетных параметрах включен флажок "Закрывать балансы на City Ledger платежами"!

В параметрах обработки можно указать:

  • "Дата" -- дата на которую получать список выезжающих гостей. Обычно текущая дата отеля.    
  • "Гостиница" -- задает отбор выезжающих гостей по гостинице.
  • "Заказчик" -- задает контрагента (группу контрагентов), гости от которого отбираются. Если не указан, то обрабатываются все не-индивидуальные гости
  • "Отчет по платежам" -- задает отчет, который будет формироваться по созданным платежам. 
  • "Имя принтера" -- если указано, то программа распечатает отчет на указанном принтере

Способ вызова

Вызывается из меню "Обработки"
