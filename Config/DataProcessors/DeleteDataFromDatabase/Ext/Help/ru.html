Обработка "Удалить данные из базы данных"

Назначение

Обработка используется для удаления данных за период по отелю и/или фирме. Обработка выполняет следующие действия:

  1. Удаляет из базы данных все документы, которые имеют отношение к указанным на форме обработке периоду, гостинице, фирме.
  2. Если включен флажок "Удалять клиентов", то удаляет из базы карточки клиентов, которые встречались в удаленных документах.
Документы и клиенты удаляются вместе с их историей изменений.
Относится к подсистеме: «Управление настройками».

Способ вызова

Вызывается из меню "Обработки".

По умолчанию этой обработки в справочнике обработок нет, ее нужно добавлять явно.

Дополнительная информация

Права на выполнение обработки есть только у системного администратора программы.
