Обработка "Автоназначение скидок"

Назначение

Обработка устанавливает тип скидки клиенту в автоматическом режиме. По условиям заданным в настройках данной обработки.

Настройки:

  • Гостиница - устанавливает отбор по отелю. Если пустая, то по всем. 
  • Дней для расчета - за сколько дней брать оборот для расчета. Например 365  берем оборот за последние 365 дней 
  • Дата начала программы - Берем оборот за последние X дней но не ранее чем дата начала. 
  • Набор услуг - в расчете оборота учитываются только услуги из этого набора. 
  • Измерение расчета: Клиент или Дисконтная карта. Если клиент - то берем оборот в разрезе по Клиенту/Гостю, иначе - по Дисконтной карте. 
  • Табличная часть "Правила назначения скидок" DiscountTypeRules:
    DiscountType - тип скидки который нужно установить
    Amount - минимальное значение суммы для установки этого типа скидки
    Nights - минимальное число ночей для установки этого типа скидки
    CheckIns - минимальное число заездов.
    Числа учитываются в логике И. Т.е. должны выполниться все условия по Сумме, числу заездов и числу ночей.
    Если же, например, число заездов учитывать не нужно, то значение должно быть = 0. 

Табличная часть "Правила назначения скидок"

  • Тип скидки - тип скидки который нужно установить 
  • Сумма - минимальное значение суммы для установки этого типа скидки 
  • Число ночей - минимальное число ночей для установки этого типа скидки 
  • Число заездов - минимальное число заездов. 

Числа учитываются в логике "И". Т.е. должны выполниться все условия по Сумме, Числу заездов и Числу ночей. 
Если же, например, число заездов учитывать не нужно, то значение должно быть = 0.
