Обработка "Закрытие дня"

Назначение

Обработка используется для выполнения процедуры закрытия дня вручную.

Обработка позволяет:

  • настроить ряд проверок, которые обязательно должны быть выполнены перед переводом учетной даты;
    • проверить есть ли выезжающие гости, по которым не обнулены балансы по лицевым счетам
    • проверить есть ли незаселенные брони
    • проверить закрыты ли кассовые смены на всех POS
  • указать список отчетов, которые должны быть распечатаны за день
  • выполнить отчет "Анализ начислений" для проверки правильности транзакций созданных за день 

В случае, если все проверки прошли успешно, система позволит нажать кнопку "Сменить дату" и выполнит штатное закрытие периода. 

Способ вызова

Вызывается из командного интерфейса основного раздела тонкого и web-клиента

Дополнительная информация

Перед использованием необходимо один раз запустить обработку с правами системного администратора. В этом случае справа от поля текущей гостиницы появится кнопка "Настройки". При нажатии на эту кнопку откроется форма настроек где галочками нужно отметить, какие проверки требуется выполнять и выбрать соответствующие формы отчетов. В поле ежедневных отчетов можно выбирать папку отчетов.
