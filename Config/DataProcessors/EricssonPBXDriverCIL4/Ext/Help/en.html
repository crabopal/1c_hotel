Обработка "Драйвер интерфейса с АТС Ericsson HOTELCIL4"

Назначение

Обработка осуществляет взаимодействие с АТС Ericsson по протоколу RS232. Поддерживается логический протокол TYPE 4 и частично TYPE 3. Обработка выступает в качестве клиента. Сервером является АТС. В обработке реализованы следующие команды:

  • Заезд
  • Выезд
  • Изменение имени гостя в АТС
  • Установка будильника на телефоне в номере
  • Включение на телефоне в номере лампочки "Есть сообщение" с автоматическим набором номера ресепшен при снятии трубки телефона
  • Изменение статуса номера (На телефоне обычно набирают *33*код статуса# (код команды лучше уточнить у поставщика АТС). Код статуса должен быть указан в справочнике "Статусы номеров" в реквизите PBXCode
  • Логирование информации о телефонных разговорах в текстовый файл в формате CIL4.

Относится к подсистеме: «Управление взаиморасчетами».

Способ вызова

Обработку необходимо зарегистрировать в справочнике "Обработки". Для этого необходимо открыть форму списка справочника из меню "Настройки" и нажать кнопку "Добавить" в панели инструментов списка. Далее нужно указать название обработки, например "Интерфейс с АТС Ericsson" и в поле "Обработка" выбрать из выпадающего списка "EricssonPBXDriverCIL4 - Драйвер интерфейса с АТС Ericsson HOTELCIL4". Сохраните обработку и далее из меню "Главное" запустите ее. Нажмите ссылку "Параметры" (ссылка доступна только если программа запущена с правами системного администратора).

В форме настроек обработки укажите номер COM порта, к которому подключена АТС и скорость обмена (2400 по умолчанию). Если необходимо детально отслеживать обмен сообщениями между АТС и 1С:Отель, то нужно включить галочку "Режим отладки". Для того чтобы администраторы ресепшен получали уведомления о пропущенных будильниках необходимо указать отдел, например "СПиР". Сохраните настройки.

Для того чтобы создать настроечные записи в справочнике "Виды доп. услуг в номерах" можно нажать на кнопку "Инициализировать настройки команд интерфейса" в выпадающем меню "Еще..." панели инструментов формы обработки.

Для запуска обработки в интерактивном режиме в панели действий формы настроек необходимо нажать на кнопку "Запустить".

Обработка может выполняться в режиме фонового задания. Для этого в консоли управления фоновыми заданиями нужно создать новое задание с типом метаданных "Выполнить обработку" и указать ключ "EricssonPBXDriver" (этот же, ключ должен быть указан в справочнике обработок). Расписание запуска рекомендуется установить на раз в 15 - 20 минут. В нормальных условиях фоновое задание с этой обработкой будет постоянно висеть в статусе выполняется и, в случае возникновения каких-либо ошибок, будет автоматически перезапускаться с указанной вами периодичностью. Для остановки фонового задания можно открыть форму настроек обработки из справочника обработок и нажать на кнопку "Остановить" в панели действий формы настроек.
