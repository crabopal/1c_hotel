Обработка "Экспорт данных гостей в УФМС (Россия) в XML формате ПО Территория"

Назначение

Обработка используется для экспорта данных журнала регистрации иностранных граждан, а также данных граждан РФ в УФМС России в XML формате доступном на сайте УФМС России.

Относится к подсистеме: «Стойка администратора».

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

Для каждого гостя в указанной в настройках обработки папке создается отдельный XML файл. Перед началом выгрузки данных указанные в настройках папки очищаются!
