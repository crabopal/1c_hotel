Обработка "Выгрузка остатков свободных номеров"

Назначение

Обработка используется для выполнения автоматической выгрузки остатков свободных номеров в формате XML файла. Файл можно выгружать либо в папку, либо на FTP сервер. Файл может быть заархивирован и закрыт паролем.

Относится к подсистеме: «Управление Номерным Фондом».

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

В файле по каждой категории номеров возвращаются остатки свободных номеров по всей гостинице или по выбранной на форме обработки квоте. Остатки свободных номеров вычисляются на конец каждого дня, который попадает в период, указанный на форме настроек параметров обработки.

Состав возвращаемых ресурсов настраивается на второй закладке обработки. Кроме числа свободных номеров программа может возвращать число занятых/забронированных номеров. Остатки могут возвращаться в местах.

Дополнительно, на каждый день программа возвращает цены проживания по тарифу, который выбирается на второй закладке формы настроек параметров обработки.
