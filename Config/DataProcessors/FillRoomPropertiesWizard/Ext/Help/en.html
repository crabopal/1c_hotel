Обработка "Мастер заполнения свойств номеров"

Назначение

Мастер позволяет упростить и ускорить назначение набора свойств набору номеров. При работе мастера указанные на форме мастера свойства добавляются в таблицу свойств номеров из указанного списка номеров.

Относится к подсистеме: «Стойка администратора».

Способ вызова

Вызывается из формы списка свойств номеров по кнопке "Мастер заполнения свойств номеров" в панели инструментов списка.

Дополнительная информация

Если необходимо заменить список свойств номеров на новый набор свойств, то текущий список свойств номеров нужно сначала очистить. Для этого на форме мастера нужно указать номера, оставить список свойств пустым и нажать кнопку "Выполнить". После подтверждения действия программа у выбранных номеров очистит список свойств.
