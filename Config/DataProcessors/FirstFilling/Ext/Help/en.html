Обработка "Мастер первоначального заполнения базы"

Назначение

Является мастером по первоначальному заполнению базы. Необходимо выбрать значения для компании и отеля, после чего база будет заполнена объектами по умолчанию и создан пользователь с правами администратора.

Относится к подсистеме: «Управление настройками».

Способ вызова

Вызывается автоматически при открытии пустой базы без пользователей.
