Обработка "Выгрузка в Guest Joy"

Назначение

Обработка используется для первоначальной настройки синхронизации с Guest Joy, для управления соответствиями данных между системой Guest Joy и 1С:Отель, а также для выполнения ручного обмена данными с Guest Joy.

Относится к подсистеме: «Интеграции».

Способ вызова

Вызывается из справочника "Взаимодействия с внешними системами", нажатием на кнопку "Настройки". У элемента справочника должен быть установлен тип интеграции - "Guest Joy". 

Запуск в фоновом режиме

Запуск и управление работой обработки в фоновом режиме производится на второй вкладке в обработке - "Фоновое задание".
На данной вкладке настраивается расписание фонового задания,  пользователь/сотрудник из под которого оно будет выполняться и включение/выключение фонового задания.   

Дополнительная информация

На основной вкладке "Настройки" указываются параметры подключения к внешней системе. На остальных вкладках находятся таблицы с соответствиями данных между внешней системой и 1С:Отель.

Для корректной работы требуется заполнить все соответствия данных.
