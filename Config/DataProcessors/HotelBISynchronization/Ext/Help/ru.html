Обработка "Синхронизация данных с системой 1С:Отель BI"

Назначение

Обработка используется для выгрузки данных в систему 1С:Отель BI и загрузки изменений из неё:

  • Выгружаются клиенты
  • Выгружаются контрагенты
  • Выгружаются все данные по продажам (регистры "Продажи" и "Прогноз продаж")
  • Обратно загружаются изменения в карточках клиентов и контрагентов

Способ вызова

Вызывается из справочника обработок или запускается автоматически по расписанию как фоновое задание. Рекомендуемая периодичность запуска обработки: раз в сутки.

Дополнительная информация

Система 1С:Отель BI -- это облачная база, которая позволяет собрать в одном месте данные продаж по нескольким разным отелям и анализировать продажи в разрезе клиентов и контрагентов интегрально. При загрузке данных в 1С:Отель BI производится идентификация клиентов по их ФИО, датам рождения, адресам, телефонам и e-mail таким образом, чтобы данные о продажах из разных отелей собирались на одной карточке клиента/организации в 1С:Отель BI
