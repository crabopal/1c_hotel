Processing "Wizard for configuring interaction with channel manager Igloorooms"

Appointment

Processing is used for the initial synchronization setup with CM:Igloorooms, as well as for performing manual data exchange with CM:Igloorooms

Refers to the subsystem: «Channel Managers».

Steps


  1. Select a Hotel whose data will be synchronized with the CM system:Igloorooms and enter the Hotel code, Username, Password, Server and Resource Address to access the channel manager's data
  2. Configure matching reservation statuses
