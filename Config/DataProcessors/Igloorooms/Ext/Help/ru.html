Обработка "Мастер настройки взаимодействия с channel manager Igloorooms"

Назначение

Обработка используется для первоначальной настройки синхронизации с CM:Igloorooms, а также для выполнения ручного обмена данными с CM:Igloorooms

Относится к подсистеме: «Менеджеры каналов». 

Шаги

  1. Выберите Гостиницу, данные которой будут синхронизироваться с системой CM:Igloorooms и введите Код отеля, Имя пользователя, Пароль, Сервер и Адрес ресурса для доступа к данным channel manager'a
  2. Настройте соответствия статусов брони
