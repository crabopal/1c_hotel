Обработка "Загрузка телефонных разговоров из внешней SQL базы"

Назначение

Обработка используется для загрузки данных и начисления стоимости телефонных звонков на лицевые счета гостей на основе записей в базе тарификатора телефонных разговоров. Обработка подключается к БД тарификатора через API ADODB. Параметры подключения к базе, так же как и текст запроса, настраиваются на форме параметров обработки. Названия полей запроса, указанные в шаблоне запроса, менять нельзя.

Относится к подсистеме: «Управление настройками».

Способ вызова

Вызывается из меню "Обработки"
