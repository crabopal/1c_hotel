Обработка "Загрузка телефонных разговоров из тарификатора компании Logisoft"

Назначение

Обработка используется для загрузки данных и начисления стоимости телефонных звонков на лицевые счета гостей на основе записей в файле pabxd.dbf тарификатора телефонных разговоров Logisoft (http://www.logisoft-cy.com/)

Относится к подсистеме: «Управление настройками».

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

Режим запуска: фоновое задание, периодичность: запуск каждые несколько минут
