Обработка "Драйвер системы управления телевидением Locatel Eclipse"

Назначение

Обработка осуществляет взаимодействие с системой платного телевидения Locatel Eclipse по протоколу TCP/IP. Обработка выступает в качестве клиента. Сервером является интерфейсная служба Locatel Eclipse. В обработке реализованы следующие команды:

  • Заезд
  • Выезд
  • Установка будильника на телевизоре
  • Отправка гостю на телевизор сообщения с подтверждением его прочтения
  • Просмотр счета и баланса гостя
  • Заказ гостем экспресс-выселения
  • Загрузка в программу начисления за платные каналы или просмотр платного фильма

Относится к подсистеме: «Управление взаиморасчетами».

Способ вызова

Обработку необходимо зарегистрировать в справочнике "Обработки". Для это необходимо открыть справочник из меню подсистем и нажать кнопку "Добавить" в панели инструментов списка обработок. Далее нужно указать название обработки, например "Интерфейс с системой платного телевидения Locatel Eclipse" и в поле "Обработка" выбрать из выпадающего списка "LocatelEclipseTVDriver - драйвер системы управления телевидением Locatel Eclipse". Далее в поле "Ключ" нужно также указать строку "LocatelEclipseTVDriver". Сохраните обработку по кнопке ОК. Она появится в списке обработок. Выделите ее и, для того чтобы открыть форму настроек обработки, нажмите в панели инструментов кнопку "Открыть форму" (или используйте комбинацию клавиш Ctrl+F5).

В форме настроек обработки необходимо указать IP адрес и порт, на котором запущен интерфейсный сервер Locatel Eclipse. Если в настройках Locatel Eclipse не задана кодировка UTF-8, то в обработке нужно включить галочку "Транслитерировать имена гостей". Если необходимо детально отслеживать обмен сообщениями между Eclipse и 1С:Отель, то нужно включить галочку "Режим отладки". Для того чтобы администраторы ресепшен получали уведомления о заказах экспресс-выселения и о пропущенных будильниках необходимо указать отдел, например "СПиР".

Для того чтобы быстро создать настроечные записи в справочнике "Виды доп. услуг в номерах" можно нажать на кнопку "Настройки по умолчанию" в панели инструментов формы обработки.

Для запуска обработки в панели действий формы настроек необходимо нажать на кнопку "Запустить".

Обработка может выполняться в режиме фонового задания. Для этого в консоли управления фоновыми заданиями нужно создать новое задание с типом метаданных "Выполнить обработку" и указать ключ "LocatelEclipseTVDriver" (тот же, который вы указывали при регистрации обработки в справочнике обработок). Расписание запуска рекомендуется установить на раз в 15 - 20 минут. В нормальных условиях фоновое задание с этой обработкой будет постоянно висеть в статусе выполняется и, в случае возникновения каких-либо ошибок, будет автоматически перезапускаться с указанной вами периодичностью. Для остановки фонового задания можно открыть форму настроек обработки из справочника обработок и нажать на кнопку "Остановить" в панели действий формы настроек.
