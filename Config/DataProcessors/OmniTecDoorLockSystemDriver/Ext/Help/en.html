Обработка "Драйвер систем электронных замков OmniTec"

Назначение

Драйвер систем электронных замков OmniTec. Позволяет кодировать новые и дополнительные ключи-карты, проверять данные на картах-ключах.

Подключение

1. Подключение по TCP\IP
   а) В папку с базой(C:\Omnitec\GestHotel) ключей нужно положить файл GestHotel_TCPIP.exe и запустить
   б) В настройках программы нужно включить PMS Interface
   в) На вкладке Interface задается порт, по умолчанию 1028
2. Подключение по COM
   а) В папку с базой(C:\Omnitec\GestHotel) ключей нужно положить файл InterGH.dll и зарегистрировать в реестре
   б) В настройках программы нужно включить PMS Interface 
 
На стороне отеля указываем Сервер, порт, номер энкодера, если СОМ, то только энкодер
 

Возможности

По TCP\IP: Выдача, Копия ключа,
по СОМ: Выдача, Копия ключа, Отмена, Проверка

 

Относится к подсистеме: «Управление Номерным Фондом».

Способ вызова

Системная обработка. Из меню не вызывается.
