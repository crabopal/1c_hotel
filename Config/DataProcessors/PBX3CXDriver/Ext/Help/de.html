Обработка "Драйвер интерфейса с АТС 3CX"

Назначение

Обработка осуществляет взаимодействие с АТС 3CX по протоколу TCP/IP. Сервером является АТС. В обработке реализованы следующие команды:

  • Изменение статуса номера. Код статуса должен быть указан в справочнике "Статусы номеров" в реквизите PBXCode

Способ вызова

Обработку необходимо зарегистрировать в справочнике "Обработки". Для этого необходимо открыть форму списка справочника из меню "Настройки" и нажать кнопку "Добавить" в панели инструментов списка. Далее нужно указать название обработки, например "Интерфейс с АТС 3CX" и в поле "Обработка" выбрать из выпадающего списка "PBX3CXDriver - Драйвер интерфейса с АТС 3CX". Сохраните обработку и далее из меню "Главное" запустите ее. Нажмите ссылку "Параметры" (ссылка доступна только если программа запущена с правами системного администратора).

В форме настроек обработки укажите адрес интерфейсного сервера, к которому подключена АТС и порт интерфейсного сервера. Если необходимо детально отслеживать обмен сообщениями между АТС и 1С:Отель, то нужно включить галочку "Режим отладки". Сохраните настройки.

Для запуска обработки в интерактивном режиме в панели действий формы настроек необходимо нажать на кнопку "Запустить".

Обработка может выполняться в режиме фонового задания. Для этого в консоли управления фоновыми заданиями нужно создать новое задание с типом метаданных "Выполнить обработку" и указать ключ "PBX3CXDriver" (этот же, ключ должен быть указан в справочнике обработок). Расписание запуска рекомендуется установить на раз в 15 - 20 минут. В нормальных условиях фоновое задание с этой обработкой будет постоянно висеть в статусе выполняется и, в случае возникновения каких-либо ошибок, будет автоматически перезапускаться с указанной вами периодичностью. Для остановки фонового задания можно открыть форму настроек обработки из справочника обработок и нажать на кнопку "Остановить" в панели действий формы настроек.

Для работы интерфейса, на сервере 1С:Предприятия или на интерфейсном компьютере должна быть установлена внешняя компонента работы по протоколу TCP/IP. Для установки внешней компоненты необходимо открыть справочник рабочих мест и перейти на закладку "Внешние компоненты", затем нажать на ссылку "Установить компоненту работы по TCP/IP". 1С:Предприятие при этом должно быть запущено с правами системного администратора. Если АТС подключена к интерфейсному компьютеру на котором нет сервера 1С:Предприятия, то работа интерфейса возможна только в интерактивной сессии программы.
