Обработка "Драйвер интерфейса с АТС Panasonic через PMSi"

Назначение

Обработка осуществляет взаимодействие с программой PMSi через которую выполняется управления гостиничными функциями в цифровых АТС компании Panasonic. Взаимодействие обработки с программой PMSi выполняется по протоколу TCP/IP. Обработка выступает в качестве клиента. Сервером является Panasonic PMSi. В обработке реализованы следующие команды:

  • Заезд
  • Выезд
  • Изменение имени гостя в АТС
  • Установка будильника на телефоне в номере
  • Включение на телефоне в номере лампочки "Есть сообщение" с автоматическим набором номера ресепшен при снятии трубки телефона
  • Изменение статуса номера по нажатию на телефоне доп. кнопки "Изменить статус" (доступно только для телефонов с минимум двухстрочным дисплеем и наличием доп. кнопок)  
  • Изменение статуса номера и регистрация работ горничных после набора на телефоне функции Gather digits и далее указания персонального кода горничной. Для отправки команды об изменении статуса номера горничная должна набрать на телефоне, например, *717101#, где 717 - код функции Gather digits (как настроить см. документацию к вашей модели АТС), 101 - персональный код горничной, который указывается в справочнике "Сотрудники" в карточке горничной в поле "Код доступа в АТС". Для изменения статусов необходимо в справочнике "Статусы номеров" прописать последовательность изменения статусов. Следующий статус указывается в карточке статуса в соответствующем поле. Для регистрации работ горничных в справочнике статусов номеров необходимо прописать работы, которые должны выполняться при смене статуса.

Относится к подсистеме: «Управление взаиморасчетами».

Способ вызова

Обработку необходимо зарегистрировать в справочнике "Обработки". Для это необходимо открыть справочник из меню подсистем и нажать кнопку "Добавить" в панели инструментов списка обработок. Далее нужно указать название обработки, например "Интерфейс с АТС Panasonic" и в поле "Обработка" выбрать из выпадающего списка "PanasonicPMSiDriver - Драйвер интерфейса с АТС Panasonic через PMSi". Далее в поле "Ключ" нужно также указать строку "PanasonicPMSiDriver". Сохраните обработку по кнопке ОК. Она появится в списке обработок. Выделите ее и, для того чтобы открыть форму настроек обработки, нажмите в панели инструментов кнопку "Открыть форму" (или используйте комбинацию клавиш Ctrl+F5).

В форме настроек обработки необходимо указать IP адрес и порт, на котором слушает команды программа PMSi. Если в настройках АТС не задана кодировка UTF-8, то в обработке нужно включить галочку "Транслитерировать имена гостей". Если необходимо детально отслеживать обмен сообщениями между PMSi и 1С:Отель, то нужно включить галочку "Режим отладки". Для того чтобы администраторы ресепшен получали уведомления о пропущенных будильниках необходимо указать отдел, например "СПиР".

Для того чтобы выполнить настройку программы PMSi и создать настроечные записи в справочнике "Виды доп. услуг в номерах" можно нажать на кнопку "Настройки по умолчанию" в панели инструментов формы обработки. 1С:Отель должен быть запущен с правами системного администратора Windows. Программа предложит указать папку (обычно это c:\Program Files (x86)\M.T.S.\PMSi\), где установлена программа PMSi и скопирует в эту папку файлы настроек PMSi. При запуске PMSi вам нужно в меню "Файл/Открыть" программы PMSi указать файл 1CHotel-TDA2.pmi. Все пути в настроечных файлах заданы для 64 битных операционных систем Windows и содержат строку "Program Files (x86)". Если в вашем случае установка PMSi выполнена на 32 битную ОС, то настроечные файлы PMSi нужно откорректировать убрав в них строку " (x86)".

Для запуска обработки в панели действий формы настроек необходимо нажать на кнопку "Запустить".

Обработка может выполняться в режиме фонового задания. Для этого в консоли управления фоновыми заданиями нужно создать новое задание с типом метаданных "Выполнить обработку" и указать ключ "PanasonicPMSiDriver" (тот же, который вы указывали при регистрации обработки в справочнике обработок). Расписание запуска рекомендуется установить на раз в 15 - 20 минут. В нормальных условиях фоновое задание с этой обработкой будет постоянно висеть в статусе выполняется и, в случае возникновения каких-либо ошибок, будет автоматически перезапускаться с указанной вами периодичностью. Для остановки фонового задания можно открыть форму настроек обработки из справочника обработок и нажать на кнопку "Остановить" в панели действий формы настроек.
