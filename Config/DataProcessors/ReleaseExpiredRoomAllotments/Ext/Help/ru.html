Обработка "Снять просроченные остатки по квотам номеров"

Назначение

Обработка используется для автоматического снятия просроченных остатков квот номеров. Основным параметром для обработки является период освобождения квоты в днях, который указывается в карточке квоты. Обработка отбирает квоты у которых период освобождения указан и для каждой такой квоты снимает остатки номеров в квоте в 0 начиная с даты выполнения обработки и до даты освобождения номеров квоты. Дата освобождения номеров квоты вычисляется прибавлением числа дней периода освобождения квоты к текущей дате выполнения обработки. Т.е., если период освобождения указан, например, равным 1, то остатки по квоте будут сняты на период от текущей даты до завтра.

Относится к подсистеме: «Продажи квот номеров».

Способ вызова

Вызывается из меню "Обработки"
