Обработка "Настройка обмена данными с он-лайн личным кабинетом военнослужащего (СКК Подмосковье и другие СКК МО)"

Назначение

Обработка используется для первоначальной настройки синхронизации с skkpodmoskovie.ru, для управления соответствиями данных между системой skkpodmoskovie.ru и 1С:Отель, а также для выполнения ручного обмена данными с skkpodmoskovie.ru
