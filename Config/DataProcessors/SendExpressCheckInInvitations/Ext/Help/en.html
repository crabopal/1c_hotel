Обработка "Рассылка приглашений на экспресс-заселение"

Назначение

Обработка используется для автоматической рассылки E-Mail приглашений на экспресс-заселение. Обработка ищет действующие брони, по которым полностью поступила оплата и у которых в карточке гостя указаны паспортные данные. По таким броням программа рассылает печатную форму "Приглашение на экспресс-заселение" с графическим QR-кодом номера брони. Если в карточке брони и карточке гостя E-Mail не указан, то такая бронь пропускается. Если в настройках обработки указан "Статус экспресс-заселения", то этот статус устанавливается у брони.

В параметрах обработки можно указать:

  • Статус брони по которой возможен экспресс-заезд - если указан, то у оплаченной брони в которой у гостя введены паспортные данные будет установлен этот статус.
  • Отдел, сотрудникам которого отправлять сообщения о брони в статусе экспресс-заезд - если указан, то по каждой группе где найден гость с возможностью экспресс заселения будет отправлено внутреннее сообщение сотрудникам из указанного отдела.  

Относится к подсистеме: «Стойка администратора».

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

Рекомендуемый режим запуска обработки: фоновое задание с периодичностью запуска раз в день в 13:00.

Допускается не указывать параметры настроек обработки. Если указан только отдел, то обработка будет отправлять сообщения о группах с гостями на экспресс-заезде, но не будет изменять статус брони. Если указан только статус, то статус будет изменен, а сообщения отправляться не будут. E-Mail приглашения отправляются гостям в любом случае независимо от настроек обработки.
