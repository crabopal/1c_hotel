Обработка "Отправить приглашение на онлайн регистрацию"

Назначение

Обработка используется для автоматизированной рассылки исходящих Email писем с ссылкой на онлайн регистрацию по брони. 

При запуске обработка отбирает по указанной гостинице, дате и (или) группе гостей документы брони и отсылает по ним E-mail сообщения. Сообщение не отсылается, если в нем не определен адрес E-Mail получателя.  

Для подключения к почтовому серверу обработка использует параметры сотрудника, под которым она выполняется.

Способ вызова

Вызывается из меню "Обработки"

Дополнительная информация

Режим запуска: фоновое задание.
