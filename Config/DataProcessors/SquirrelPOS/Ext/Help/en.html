Обработка "Squirrel POS"

Назначение

Обработка используется для первоначальной настройки синхронизации с Squirrel POS, для управления соответствиями данных между системой Squirrel POS и 1С:Отель, а также для установки токена доступа.

Относится к подсистеме: «Интеграции».

Способ вызова

Вызывается из справочника "Взаимодействия с внешними системами", нажатием на кнопку "Настройки". У элемента справочника должен быть установлен тип интеграции - "Squirrel POS". 

Запуск в фоновом режиме

Запуск в фоновом режиме не нужен. Используется HTTP-Сервис. 

Дополнительная информация

На основной вкладке "Настройки" указываются параметры подключения к внешней системе. На остальных вкладках находятся таблицы с соответствиями данных между внешней системой и 1С:Отель.

Для корректной работы требуется заполнить все соответствия данных. 

Интеграция работает с использованием HTTP-Сервиса "tcp".
