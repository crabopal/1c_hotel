Обработка "Мастер настройки взаимодействия с channel manager Travelline"

Назначение

Обработка используется для первоначальной настройки синхронизации с CM:Travelline, для управления соответствиями данных между системой CM:Travelline и 1С:Отель, а также для выполнения ручного обмена данными с CM:Travelline

Относится к подсистеме: «Управление Номерным фондом».

Шаги

  1. Выберите Гостиницу, данные которой будут синхронизироваться с системой CM:Travelline и введите Логин и Пароль для доступа к данным channel manager'a
  2. Выберите, будут ли в CM:Travelline выгружаться остатки по всему номерному фонду Гостиницы или только по определенной квоте
  3. Настройте соответствия для типов номеров и выберите рабочие шаблоны видов размещения для каждого типа номера
  4. Настройте соответствия тарифов
  5. Настройте соответствия контрагентов. Если галочка "Использовать клиента в качестве контрагента" стоит, то в качестве Контрагента в документе "Бронирование" будет всегда выбран Гость
  6. Настройте соответствия прочих справочников
