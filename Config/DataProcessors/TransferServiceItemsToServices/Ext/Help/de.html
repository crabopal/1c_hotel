Datenverarbeitung "Menüpositionen in Dienstleistungen übertragen"

Zweck

Erstellt Elemente des Katalogs "Dienstleistungen" aus dem Katalog "Menüpositionen". Die Verarbeitung ist für die erste Beladung gedacht, wenn der Dienstleistungskatalog leer ist.

Ordnerhierarchie, Bezeichnungen und Übersetzungen, Maßeinheiten, Anmerkungen, Hotel und Sortierung werden kopiert. Der Preis wird in das Informationsregister "Preise der Dienstleistungen" geschrieben. Die Quell-Menüposition wird in den tabellarischen Teil der Dienstleistung übernommen.

Ein erneuter Lauf überspringt bereits erstellte Dienstleistungen mit demselben Code im externen System.

Parameter

Hotel ist Pflichtfeld und wird für die Auswahl der Menüpositionen und das Schreiben der Preise verwendet.

Menüpositionsordner begrenzt die Übertragung optional auf einen Zweig.

Dienstleistungsordner legt optionale Wurzelelemente in den angegebenen Ordner.

MwSt.-Satz ist Pflichtfeld und wird in die Preise geschrieben.

Art der Dienstleistung und Sektion der Bezahlung werden bei den erstellten Dienstleistungen gefüllt.

Preisdatum ist die Periode des Preiseintrags.

Codepräfix wird dem Code der Menüposition vorangestellt. Bei Kollision wird automatisch ein neuer Code vergeben.
