Data processor "Transfer service items to services"

Purpose

Creates Services catalog items from Service items (menu items). Use it for the first load when the Services catalog is empty.

Folder hierarchy, descriptions and translations, units, remarks, hotel and sort code are copied. The menu item price is written to the Service prices information register. The source menu item is added to the service tabular section.

A repeated run skips services that already have the same external system code.

Parameters

Hotel is required and is used to filter menu items and write prices.

Service item folder optionally limits the transfer to one branch.

Service folder optionally places root-level items under the selected services folder.

VAT rate is required and is written to service prices.

Service type and Payment section are filled on created services.

Price date is the period of the price record.

Code prefix is prepended to the menu item code. On collision a new code is assigned automatically.
