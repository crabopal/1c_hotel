Обработка "Мастер настройки взаимодействия с channel manager WebHotelier"

Назначение

Обработка используется для первоначальной настройки синхронизации с CM:WebHotelier (https://www.webhotelier.net/), для управления соответствиями данных между системой CM:WebHotelier и 1С:Отель, а также для выполнения ручного обмена данными с CM:WebHotelier

Относится к подсистеме: «Управление Номерным фондом».

Форма обработки открывается по кнопке "Настройка" из справочника "Взаимодействия с внешними системами", при этом тип взаимодействия должен быть установлен в "CM:WebHotelier"

Шаги

  1. Настройка параметров подключения к CM:WebHotelier. Выберите Гостиницу, данные которой будут синхронизироваться с системой CM:WebHotelier, укажите код гостиницы в системе CM:WebHotelier и введите Логин и Пароль для доступа к данным channel manager'a. Укажите, если нужно, квоту номеров по которой будут выгружаться остатки свободных номеров. Заполните кол-во дней на которое будут выгружаться остатки свободных номеров и укажите частоту обновления (кэша) цен в минутах (по умолчанию = 60)
  2. Настройте соответствия между типами номеров в CM и типами номеров в программе
  3. Настройте соответствия между тарифами в CM и тарифами в программе
  4. Настройте частоту выполнения фонового задания по обмену данными с CM. Рекомендуется выполнять обмен один раз в 10 минут.
