Обработка "Списание остатков просроченных бонусов"

Назначение

Формирует список бонусных карт из указанной в параметрах обработки программы лояльности (папки типов скидок или типа скидки с типом Бонусы), у которых есть остатки бонусов на даты, которые раньше, чем дата указанная в параметрах обработки. По каждой карте и дате списывает остаток бонусов отдельной операцией по бонусам с источником указанным в параметрах обработки. Список карт для обработки формируется по картам выданным в указанном в параметрах обработки отеле. Если необходимо обрабатывать всех участников программы лояльности, то параметр Гостиница заполнять не нужно.

Способ вызова

Вызывается и настраивается из меню "Главное/Обработки". Обычно настраивается и выполняется в фоновом режиме раз в сутки после ночного аудита с текущей (новой) учетной датой. При этом будут списаны просроченные остатки бонусов за предыдущую дату.
