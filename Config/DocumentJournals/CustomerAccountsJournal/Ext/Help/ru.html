Журнал документов "Журнал взаиморасчетов с контрагентами"

Назначение

Журнал используется для работы с документами влияющими на баланс взаиморасчетов с контрагентами. В журнале показывается баланс на начало периода журнала, сумма оказанных услуг в актах, сумма текущих услуг оказанных проживающим гостям, сумма платежей, баланс на конец периода журнала.

Список регистрируемых документов: «Платеж», «Возврат», «Акт», «Платеж от контрагента», «Распределение аванса».

Относится к подсистеме: «Управление взаиморасчетами».

Графы

  • Контрагент. 
  • Договор. 
  • Группа гостей.
  • Сумма. Сумма оказания.
  • Оплата. Сумма платежа.
  • Валюта. Валюта оказания/оплаты.
  • Способ оплаты.
  • ККМ. 
  • Документ основание. 
  • Номер счета-фактуры.
  • Примечания. 
  • Гостиница.
  • Фирма.
  • Автор.

Способ вызова

Вызывается из главного меню программы по кнопке "Взаиморасчеты с контрагентами"

Дополнительная информация

В журнале есть фильтр по группам гостей. Фильтр, если установлен, не показывает платежи контрагентов, т.к. в этих документах группа является реквизитом табличной части и один документ может быть оформлен сразу по нескольким группам
