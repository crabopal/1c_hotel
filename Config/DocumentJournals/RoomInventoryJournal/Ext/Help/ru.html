Журнал документов "Журнал номерного фонда"

Назначение

Журнал используется для работы со списком документов инициализирующих номера и изменяющих их параметры.

Список регистрируемых документов: «Добавить номер», «Изменить номер».

Относится к подсистеме: «Управление Номерным Фондом».

Графы

  • Гостиница. 
  • Номер комнаты. 
  • Группа номера.
  • Номер комнаты строкой. 
  • Тип номера.
  • Количество мест в номере.
  • Количество гостей в номере.
  • Дата вывода номера из эксплуатации.
  • Порядок сортировки.
  • Код в системе эл. замков.
  • Код номера в системе охраны.
  • Примечания.
  • Виртуальный номер. 
  • Автор. Сотрудник, который ввел номер в эксплуатацию.

Способ вызова

Вызывается из списка номеров по кнопке "Перейти/Открыть журнал операций с НФ" в панели инструментов
