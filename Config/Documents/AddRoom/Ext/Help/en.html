Документ "Добавить номер"

Назначение

Документ используется для регистрации новых номеров в справочнике Номерной Фонд. Документ создает новый элемент в справочнике и инициализирует регистры по загрузке номеров.

Документ создается, когда в справочнике Номерной Фонд нажимают кнопку "Добавить".

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Номерной фонд».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». Необходимо выбрать гостиницу, к номерному фонду которой относится данный номер
  • Группа номера. Ссылается на справочник «Номерной фонд». Для облегчения просмотра номерного фонда все номера можно распределить по папкам, которые, в свою очередь будут обозначать, например, этажи гостиницы. В данном реквизите указывается, в какую папку будет помещен данный номер.
  • Номер комнаты. Тип значения: «Строка». Представление номера новой комнаты.
  • Тип номера. Ссылается на справочник «Типы номеров». По типам номеров задается стоимость проживания и учитываются остатки номеров в продаже.
  • Количество мест в номере. Количество основных мест в номере для размещения. 
  • Количество гостей в номере. Максимальное количество гостей в номере, которых можно разместить с учетом дополнительных мест.
  • Дата вывода номера из эксплуатации. Дата по наступлении которой номер будет выведен из эксплуатации. Позже этой даты номер будет не доступен ни для каких операций. Рекомендуется оставлять незаполненной. В дальнейшем номер можно вывести из эксплуатации документом "Изменить номер".
  • Фирма. Ссылается на справочник «Фирмы». Если номерной фонд разделен между несколькими вашими организациями (фирмами), то в этом поле вы можете привязать создаваемый номер к одной из фирм. В этом случае, при выборе номера, в "Размещении" и "Брони" будет подставлена соответствующая фирма.
  • Секция номеров. Ссылается на справочник «Секции номерного фонда». Дает возможность группировать номера способом альтернативным группам справочника номерного фонда.
  • Порядок сортировки. Определяет порядок вывода номеров в отчетах и формах. В том числе в списке проживающих гостей. 
  • Код в системе эл. замков. Тип значения: «Строка». Код в системе охраны. Можно указывать, если в соответствующих охранных системах идентификаторы номеров отличаются от их наименований в гостиничной системе. Используется при кодировании ключа для гостя через интерфейс с системой электронных замков. 
  • Код номера в системе охраны. Используется в интерфейсе с системой охраны в случае, когда код номера в охранной системе не совпадает с наименованием номера.
  • Примечания. Произвольный комментарий к номеру.
  • Виртуальный номер. Позволяет исключить номер из картины загрузки. Используется для тех номеров, которые не должны попадать в список заселяемых гостями номеров, но нужны в справочнике, например для целей планирования работ горничных, регистрации гостей и т.д.
  • Автор. Ссылается на справочник «Сотрудники». Автор данного документа. Фигурирует фамилия сотрудника, зарегистрированного в системе.
  • Номер. Ссылается на справочник «Номерной фонд». Заполняется автоматически созданным номером. При изменении реквизитов документа все изменения будут применены к этому номеру.

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/Добавить-изменить номер"

Журналы отображающие документ: «Журнал номерного фонда».

Движения

  • «Загрузка номеров». Инициализируются начальные остатки по номерам/местам/гостям в продаже по номеру и по типу номера.
