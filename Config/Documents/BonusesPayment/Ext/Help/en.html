Документ "Оплата бонусами"

Назначение

Используется для регистрации в программе факта использования клиентом накопленных бонусов для оплаты товаров/услуг. Используется в интерфейсах обмена данными с внешними системами лояльности.

Относится к подсистеме: «Бонусы».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Непериодический

Тип номера: Строка

Реквизиты

  • Источник. Наименование внешней системы/внутренней операции, которые инициировали транзакцию по бонусам
  • Гостиница. Гостиница транзакции.
  • Карта. Дисконтная карта по которой выполняется операция.
  • Гость. Клиент по которому выполняется операция.
  • Сумма. Количество бонусов в транзакции.
  • Примечания. Произвольный комментарий к операции. Обычно описывает источник денег.
  • СМС код авторизации. Код авторизации клиента обычно присылаемый по СМС.
  • Статус платежа. Строковое описание статуса платежа.
  • Автор. Ссылается на справочник «Сотрудники». Указывает пользователя, который произвел операцию.
  • Параметры периода проживания гостя

Способ вызова

Документ предназначен для программного заполнения. Пользователями вручную обычно не формируется. Доступен для вызова из меню "Все функции".

Движения

  • Регистр накопления «Бонусы». Хранит суммы по бонусам по карте или клиенту
