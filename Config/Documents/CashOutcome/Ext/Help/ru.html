Документ "Инкассация"

Назначение

Используется для регистрации выема денег из денежного ящика ККМ. Обычно используется в момент инкассации денег. В документе указывается сумма, которая сдается инкассаторам.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Фирма. Ссылается на справочник «Фирмы». По кассе какой фирмы проводится операция.
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины».  Указывает кассу, в отчете которой будет отражена операция.
  • Валюта. Ссылается на справочник «Валюты». Валюта сдаваемой суммы.
  • Сумма. Указывается сумма, которую сдают.
  • Примечания. Произвольный комментарий к операции, обычно содержит причину или цель выема денег.
  • Автор. Ссылается на справочник «Сотрудники». Указывается пользователь, который ввел операцию.

Способ вызова

Вызывается из главного меню кнопка "Касса", далее кнопка "Внесения/Инкассации", кнопка "Добавить".

Журналы отображающие документ: «Журнал внесений/инкассации наличных».

Движения

  • «Наличность в кассах». Уменьшает ресурс наличности в кассах.
