Документ "Изменить номер"

Назначение

Документ используется для изменения параметров номеров (типа номера, количества мест в номере) в Номерном Фонде. Вызывается, если в справочнике номеров нажать кнопку "Изменить". Изменения реквизитов справочника "Номерной фонд" производятся документом, т.к. необходимо на дату изменения произвести соответствующие движения в регистре остатков номеров/мест в продаже.

Важно. На дату изменения номера и позже этой даты не должно быть никаких действующих размещений, бронирований, блокировок номера. Т.е. прежде чем изменить реквизиты номера, необходимо сначала отменить все бронирования этого номера с датой заезда или выезда позже даты изменения, выселить гостей, у которых дата выезда позже даты изменения, отменить блокировки, которые начинаются или заканчиваются позже даты изменения, и только после этого провести изменение параметров номера. После того как реквизиты номера изменены, бронирования, размещения и блокировки можно будет вернуть обратно.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Номерной фонд».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». Указывает номер какой гостиницы изменяется. 
  • Группа номера. Ссылается на справочник «Номерной фонд».  Указывает новую группу, в которой должен быть номер после изменения. 
  • Номер. Ссылается на справочник «Номерной фонд». Указывает номер, реквизиты которого необходимо изменить. 
  • Номер комнаты. Новое строковое представление номера. Например: был 301,стал 301А. 
  • Тип номера. Ссылается на справочник «Типы номеров». Новый тип номера, который должен быть у выбранного номера после изменения. 
  • Количество мест в номере. Новое количество основных мест в номере. 
  • Количество гостей в номере. Новое максимальное количество гостей в номере после изменения. 
  • Дата вывода номера из эксплуатации. Указывается дата, когда номер выводится из эксплуатации. После этой даты номер не будет доступен ни для каких операций. Заполняется только когда номер выводится из эксплуатации. Если эта дата не определена, то поле нужно оставить пустым. 
  • Фирма. Ссылается на справочник «Фирмы». Новая фирма, по которой нужно будет оформлять все документы при поселении в этот номер. 
  • Секция номеров. Ссылается на справочник «Секции номерного фонда».  Новая секция номеров. 
  • Порядок сортировки. Задает порядок сортировки в котором номера отображаются в форме подбора номера, форме списка, журнале проживающих. 
  • Код в системе эл. замков. Используется интерфейсом с системой для кодирования карт в случае, когда код номера в системе электронных замков не совпадает с наименованием. 
  • Код номера в системе охраны. Используется интерфейсом с охранной системой. 
  • Примечания. Комментарий к номеру. 
  • Виртуальный номер. Если флажок включен, то по номеру не делаются движения в регистре остатков номеров в продаже. 
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, который создал документ.

Способ вызова

В справочнике "Номерной фонд" кнопка "Изменить"

Журналы отображающие документ: «Журнал номерного фонда».

Движения

  • «Загрузка номеров». Делает сторнирующие движения по старым реквизитам номера и положительные движения по новым реквизитам.
