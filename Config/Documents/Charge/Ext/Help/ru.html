Документ "Начисление"

Назначение

Документ регистрирует начисление услуги на лицевой счет гостя. При проведении заполняет аналитические регистры информацией о госте, фолио и документе основании.

Единственный документ в системе, который проводит начисление услуг.

Может вводится:

  • вручную по лицевому счету;
  • может начисляться автоматически при проведении размещения, брони или брони ресурсов;
  • может начисляться интерфейсом с внешними системами тарификации документами "Телефонные разговоры" или "Услуга на номер";
  • может начисляться автоматически при создании "жесткой" квоты номеров. 

    Относится к подсистеме: «Управление взаиморасчетами».

    Параметры

    Длина номера: 12, тип номера: Строка

    Периодичность номера: Год

    Тип номера: Строка

    Вводится на основании: «Фолио».

    Объекты, вводимые на основании: «Перемещение начисления», «Сторно».

    Реквизиты

    • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение», «Состав квоты».  Указывает на основание какого документа был введен.
    • Гостиница. Ссылается на справочник «Гостиницы». Указывает в какой гостинице оказана услуга.
    • Дата курса. На эту дату рассчитывается курс, если валюта начисления отличается от валюты счета.
    • Лицевой счет. Ссылается на документ «Фолио». Обязательный реквизит. Указывает по какому лицевому счету проводится начисление.
    • Тип клиента. Ссылается на справочник «Типы клиентов». Заполняется из документа основания и используется для проведения по аналитическим регистрам. При начислении доп. услуг по лицевому счету может быть установлен вручную.
    • Строка подтверждения для типа клиента. Заполняется из документа основания или вводится вручную. Используется в аудиторских отчетах в качестве подтверждения выбора данного типа гостя.
    • Услуга. Ссылается на справочник «Услуги». Обязательный реквизит. Указывает по какой услуге проведена транзакция.
    • Цена. Цена за единицу услуги.
    • Единица измерения. Строковое представление для печати в счете.
    • Количество. Количество оказанной услуги.
    • Сумма в валюте лицевого счета. Заполняется автоматически по курсу валюты.
    • Ставка НДС %. Ссылается на справочник «Ставки НДС».
    • Сумма НДС. Вычисляется по выбранной ставке НДС.
    • Примечания. Комментарий к начислению. Печатается в счете гостю.
    • Это доход от продажи номеров. Если флажок включен, то сумма начисления будет учтена как продажа номера и будет участвовать при расчете таких параметров как ADR, RevPAR, процент загрузки. Включается автоматически при начислении услуг проживания.
    • Входит в цену. Используется при печати краткого "свернутого" варианта счета.
    • Это доход от продажи ресурсов. Если флажок включен, то сумма начисления учитывается как продажа ресурса и участвует в расчете дохода от продажи ресурсов и в расчете процента загрузки ресурса
    • Тип дня календаря. Ссылается на справочник «Типы дней в календарях». Заполняется автоматически при начислении по тарифу, указывает на какой тип дня приходится начисление.
    • Расписание дня. Ссылается на справочник «Расписания». Заполняется автоматически при начислении из брони ресурсов. 
    • Валюта лицевого счета. Ссылается на справочник «Валюты».  В этой валюте ведутся взаиморасчеты с клиентом.
    • Курс обмена валюты лицевого счета по отношению к базовой валюте. Заполняется на дату курса автоматически.
    • Отчетная валюта. Ссылается на справочник «Валюты». Заполняется по параметрам гостиницы. Указывается валюта в которой формируются все аналитические отчеты. По всем аналитическим регистрам движения проводятся именно в этой валюте.
    • Курс обмена отчетной валюты по отношению к базовой валюте. Заполняется автоматически значением на дату курса.
    • Фирма. Ссылается на справочник «Фирмы». Указывает по какой фирме проводится начисление. По этой же фирме должна будет пройти оплата и будет сформирован акт по реализации для выгрузки в бухгалтерию.
    • Продано номеров. Количество проданных номеров. Учитывается для расчета процента загрузки и прочих показателей работы гостиницы. Заполняется автоматически при начислении по тарифу из Размещения.
    • Продано мест. Количество проданных мест. Учитывается для расчета процента загрузки по местам и прочих показателей работы гостиницы. Заполняется автоматически при начислении по тарифу из Размещения. 
    • Продано дополнительных мест. Количество проданных доп. мест. Заполняется автоматически при начислении по тарифу из Размещения по виду размещения "Доп. место".
    • Человеко-дни. Рассчитывается и заполняется автоматически при начислении по тарифу из Размещения. Учитывается во всех отчетах с данным показателем. 
    • Заезд гостей. Рассчитывается и заполняется автоматически при начислении по тарифу из Размещения. Указывает количество заехавших гостей на дату начисления по данному фолио.
    • Дисконтная карта. Ссылается на справочник «Дисконтные карты». Заполняется значением из документа основания. По указанной дисконтной карте будут сделаны движения для расчета накопительных скидок, если они определены.
    • Тип скидки. Ссылается на справочник «Типы скидок».  Заполняется значением из документа основания.
    • Основание предоставления скидки. Комментарий, введенный при выборе скидки, если тип скидки требовал ввода такового.
    • Скидка %. Процент скидки рассчитанный для данной транзакции.
    • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг». Заполняется из документа основания.
    • Сумма скидки. Рассчитывается по проценту скидки.
    • НДС с суммы скидки. Рассчитывается от суммы скидки по выбранной ставке НДС.
    • Комиссия агента. Рассчитывается по проценту комиссии. Используется в дальнейшем отчетами для сверки взаиморасчетов с агентами.
    • Вид комиссии агента. Заполняется из документа основания. 
    • Набор услуг, по которому начисляется комиссия агентам. Ссылается на справочник «Наборы услуг». Заполняется из документа основания. В выбранном наборе услуг перечислены услуги по которым рассчитывается комиссия.
    • Комиссия в валюте лицевого счета. Рассчитывается в валюте лицевого счета по курсу на дату курса.
    • НДС с суммы комиссии. Рассчитывается по выбранной ставке НДС.
    • Путевка или курсовка. Ссылается на справочник «Путевки и курсовки». Указывается путевка/курсовка, по которой выполнено начисление. 
    • Тариф. Ссылается на справочник «Тарифы». Заполняется по документу основанию.
    • Вид размещения. Ссылается на справочник «Виды размещения». Заполняется по документу основанию, указывает как был поселен гость.
    • Документ начисления услуг на номера. Ссылается на документы «Телефонный разговор», «Услуга на номер». Заполнен, если начисление выполнено интерфейсом с внешней системой и было загружено из биллинга телефонных разговоров или других систем.
    • Секция оплаты. Ссылается на справочник «Секции оплаты». Заполняется значением из выбранной услуги. Используется, когда в параметрах гостиницы включен режим "Вести баланс лицевых счетов по секциям".
    • Это фиксированное начисление. Тип значения: «Булево». Истина у услуг фиксированной наценки на телефонный разговор или доп. услугу на номер. Интерфейсные документы "Телефонный разговор" и "Доп. услуга на номер" позволяют автоматически, кроме начисления собственно стоимости разговора или доп. услуги, отдельной транзакцией и отдельной услугой начислять некоторую фиксированную сумму. Такие начисления отмечаются этим флажком.
    • Это дополнительная услуга. Флажок включается автоматически для услуг, начисленных вручную.  
    • Добавлена или изменена вручную. Тип значения: «Булево». Флажок может быть включен только у услуг добавленных вручную или измененных в таблице "Услуги" документов "Бронь", "Бронь ресурса" или "Размещение". Флажок указывает, что эти услуги не начислены строго по тарифу, а редактировались сотрудником при поселении. Может использоваться в отчетах аудита начислений совместно с реквизитом "Сумма по тарифу проживания".
    • Это разделение. Служебный флажок, используется при разделении начисления между разными лицевыми счетами. Рассчитывается и выставляется автоматически, в случаях, когда необходимо избежать двойного учета по параметрам проживания, таким как "Продано номеров/мест", "Заезд гостей".
    • Используется только для расчета дохода за проживание. Тип значения: «Булево». Указывает, что при проведении этого начисления сумму начисления необходимо провести как доход от продажи номеров, но не изменять остальные учетные параметры проживания, такие как "Продано номеров/мест", "Заезд гостей".
    • Перемещение начисления. Ссылается на документ «Перемещение начисления». Заполняется операцией перемещения, в случае, если услуга была перемещена с одного фолио на другое. Используется для отката операции при отмене перемещения и для отображения куда была перемещена услуга в форме лицевого счета на закладке "Перемещения".
    • Детали начисления. Строка содержит копию счета из ресторана при загрузке заказа из фронт-офиса ресторана.
    • Сумма по тарифу проживания. Справочная сумма по тарифу. Используется в отчетах для выявления расхождений между фактически начисленной суммой и суммой, рассчитанной строго по тарифу проживания. 
    • Автор. Ссылается на справочник «Сотрудники». Пользователь, который выполнил начисление.

    Способ вызова

    Все начисления отображаются в лицевых счетах клиентов. Чтобы открыть или ввести начисление сначала необходимо открыть лицевой счет.

    Движения

    • «Взаиморасчеты». Главный регистр по которому ведется баланс взаиморасчетов по лицевым счетам. Движение увеличивает сумму долга.
  • Аналитически регистры
    • «Продажи». Анализ продаж.
    • «Продажи путевок и курсовок». Анализ продаж по путевкам/курсовкам.
  • Специальные регистры
    • «Ресурсы накопительных скидок». Накапливается база для расчета накопительных скидок.
    • «Реализация за текущий отчетный период». Специальный регистр для подготовки выгрузки данных в бухгалтерию.
    • «Регистрация услуг». Специальный регистр для работы модуля "Контроль услуг".
    • «Распределение платежей по услугам». Специальный регистр для работы отчета "Распределение платежей по услугам".
