Документ "Сканы данных клиента"

Назначение

Используется для хранения и работы с картинками сканов документов клиентов. Позволяет оптимизировать работу службы приема и размещения таким образом, что ввод данных клиента производится не в момент поселения, а позже, в любое свободное время по сканам: страниц документа удостоверяющего личность, миграционной карты, визы.

Документ позволяет сканировать страницы документов и распознавать сканы.

При проведении со статусом "Проверен" данные записываются в карточку гостя и в запись журнала регистрации иностранцев.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Непериодический

Тип номера: Строка

Вводится на основании: «Размещение».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». Указывается в номере какой гостиницы проживает гость. 
  • Статус. Ссылается на перечисление «Статусы сканов». При создании получает статус "Новый". После распознавания (если оно выполнялось) получает статус "Распознан". После того как все данные с картинок введены в поля документа и проверены, получает статус "Проверен" и при проведении записывает эти данные в карточку гостя и запись журнала регистрации иностранцев 
  • Документ основание. Ссылается на документ «Размещение». Документ-основание, которым было оформлено поселение.
  • Номер. Ссылается на справочник «Номерной фонд». Номер, в котором живет гость.
  • Гость. Ссылается на справочник «Клиенты (гости)».  Ссылка на карточку клиента.
  • У гостя уже есть уведомление о регистрации. Если включен, то у гостя уже есть уведомление, оформленное, например в другой гостинице. В этом случае такой гость регистрируется и отмечается, чтобы другие смены не печатали ему уведомление. Гость с включенным флажком не попадает в выгрузку данных иностранных гостей в УФМС
  • Фамилия (Ru). Фамилия гостя, так, как указано в миграционной карте на русском языке. Рекомендуется в карточке гостя указывать ФИО гостя из паспорта, т.е. на иностранном языке 
  • Имя (Ru). Имя гостя, как указано в миграционной карте на русском языке.
  • Отчество (Ru). Отчество или второе имя, как указано в миграционной карте на русском языке. 
  • Пол. Мужской или Женский.
  • Гражданство. Ссылается на справочник «Страны». Страна гражданство гостя.
  • Дата рождения.
  • Место рождения. Желательно заполнять в форме классификатора адресов. 
  • Вид документа удостоверяющего личность. Ссылается на справочник «Виды документов удостоверяющих личность».
  • Паспортные данные:
    • Серия документа удостоверяющего личность.
    • Номер документа удостоверяющего личность. 
    • Дата выдачи документа удостоверяющего личность. 
    • Документ удостоверяющий личность действителен до. 
    • Кем выдан документ удостоверяющий личность. 
  • Данные миграционной карты: 
    • Цель визита. Ссылается на справочник «Цели визита».
    • Профессия или должность. Тип значения: «Строка».
    • Стаж работы. Тип значения: «Строка».
    • Страна или город откуда прибыл. Тип значения: «Строка».
    • Из-за границы. Тип значения: «Булево».
    • Номер миграционной карты. Тип значения: «Строка».
    • Срок прибывания по миграционной карте с даты. Тип значения: «Дата».
    • Срок прибывания по миграционной карте по дату. Тип значения: «Дата».
    • Принимающая организация. Тип значения: «Строка».
  • Данные визы:
    • Номер визы. Тип значения: «Строка».
    • Тип визы. Ссылается на справочник «Типы въездных виз».
    • Дата выдачи визы.
    • Дата с визы. Дата начала действия визы.
    • Место выдачи визы.
    • Дата по визы. Дата окончания действия визы.
    • Число дней действия визы.
    • Дата пересечения границы. Дата пересечения границы по штампу в паспорте.
    • Номер контрольно-пропускного пункта (КПП). Тип значения: «Строка». Вводится значение по штампу на миграционной карте. Если в правах доступа включен флажок "097 - Есть права добавлять любые КПП в справочник и использовать их ...", то можно вводить произвольную строку. Все введенные варианты автоматически сохраняются в справочнике КПП и возможны в дальнейшем для выбора. Если же это право выключить, тогда пользователь сможет только выбирать КПП из заранее введенного списка.
    • Маршрут. Строкой указывается маршрут гостя. 
  • Сведения о законных представителях. Заполняется, если необходимо. Печатается на форме уведомления.
  • Примечания. Комментарий к документу. 
  • Автор. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается в главном меню по кнопке "Еще.../Закладка "3"/Сканы данных клиентов"
