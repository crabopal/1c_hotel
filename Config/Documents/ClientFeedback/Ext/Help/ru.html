Документ "Отзыв клиента"

Назначение

Документ используется для регистрации опросного листа (отзыва) заполненного клиентом. Вопросы опросного листа заполняются на основе ссылки на опросный лист, который указывается в шапке документа.

Относится к подсистеме: «Отзывы».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Непериодический

Тип номера: Строка

Вводится на основании: «Размещение».

Реквизиты

  • Опросный лист. Ссылается на элемент справочника «Опросы». Задает список вопросов. 
  • Гостиница. Ссылается на справочник «Гостиницы». Разделитель учета.
  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение». Заполняется автоматически при создании опроса по документу клиента. 
  • Клиент. Ссылается на справочник «Клиенты». Клиент, который заполнил отзыв.
  • Номер. Ссылается на справочник "Номерной фонд". Справочно, номер где проживал клиент.
  • Примечания. Тип значения: «Строка». Обычно здесь указывается причина выполнения операции. Указывается автором операции.
  • Автор. Ссылается на справочник «Сотрудники». Автор операции.

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения реквизитов.
  • Форма списка. Журнал документов. Используется для отображения списка или выбора документов данного типа.

Способ вызова

Вызывается из формы документа размещение по кнопке "Отзыв"
