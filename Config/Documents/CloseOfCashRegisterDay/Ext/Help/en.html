Документ "Закрытие кассовой смены"

Назначение

Документ закрытия кассовой смены. Фиксирует время закрытия кассовой смены. Временем начала смены считается время закрытия предыдущей смены. Гостиница работает круглосуточно.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Фирма. Ссылается на справочник «Фирмы». Указывается фирма, которой принадлежит ККМ.
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». Касса, которая закрывается.
  • Дата и время начала смены. Заполняется автоматически датой закрытия предыдущей смены.
  • Тип Z-Отчета. Указывает детализацию Z-Отчета при его печати (задает тип печатной формы). 
  • Примечания. Комментарий к закрытию.
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, выполнивший закрытие смены.

Способ вызова

В главном меню по кнопке "Касса" открывается журнал кассовых смен. В журнале кассовых смен в панели инструментов списка кассовых смен по кнопке "Закрыть смену"

Движения

  • «Наличность в кассах». Если в ККМ выключен (это значение по умолчанию) флажок "Не обнулять сумму наличных при Z-отчете", то делается движение, уменьшающее сумму наличных в кассе. Тем самым предполагается, что при окончании смены вся наличная выручка инкассируется и сдается в бухгалтерию.
