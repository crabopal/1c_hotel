Документ "Кредитовая корректировка взаиморасчетов"

Назначение

Документ используется для уменьшения суммы долга контрагента по актам.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Контрагенты», «Договоры», «Акт».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Фирма. Ссылается на справочник «Фирмы».
  • Контрагент в бухгалтерии. Ссылается на справочник «Контрагенты». Контрагент, по которому будут отбираться акты для корректировки
  • Договор в бухгалтерии. Ссылается на справочник «Договоры». Договор, по которому будут отбираться акты для корректировки
  • Валюта взаиморасчетов. Ссылается на справочник «Валюты». Валюта сумм в документе
  • Группа гостей. Ссылается на справочник «Группы гостей». Группа, по которой будут отбираться акты для корректировки.
  • Сумма аванса. Тип значения: «Число». Сумма аванса по выбранной группе до перераспределения
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».

Табличная часть «Акты»

  • Акт. Ссылается на документ «Акт». Акт по которому выполняется корректировка долга.
  • Сумма акта. Тип значения: «Число». Вспомогательный реквизит, не редактируется. Показывает сумму из выбранного в строке акта.
  • Сумма. Тип значения: «Число». Новая сумма акта как она должна быть.
  • Сумма корректировки. Тип значения: «Число». Разница между старой суммой акта и новой суммой акта.

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных и вспомогательных реквизитов.

Способ вызова

Вызывается из журналов "Акты" и "Журнал взаиморасчетов с контрагентами" по кнопке "Кредитовая корректировка взаиморасчетов".

Журналы отображающие документ: «Журнал взаиморасчетов с контрагентами».

Движения

  • «Взаиморасчеты по актам».
  • «Взаиморасчеты с контрагентами».
