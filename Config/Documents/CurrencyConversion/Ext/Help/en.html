Документ "Конвертация валют"

Назначение

Документ используется для регистрации операций конвертации наличных денежных средств в разных валютах на стойке размещения. Документ не влияет на балансы по лицевым счетам. Документ не влияет на управленческий баланс по Контрагентам/Договорам/Группам гостей..

В документе есть таблица конвертаций между валютами.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Номер комнаты. Ссылается на справочник «Номерной фонд». Справочный реквизит, который позволяет указать, гостям из какого номера выполнялась конвертация
  • Клиент. Ссылается на справочник «Клиенты». Справочный реквизит, который позволяет указать клиента, которому выполнялась конвертация
  • Дата курса обмена. Тип значения: «Дата». Дата курсов конвертируемых валют. По-умолчанию - текущая рабочая дата.
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». По умолчанию в документ подставляется ККМ текущего рабочего места. Привязка операции к ККМ позволяет в конце смены распечатать отчет по остаткам денег в разных валютах на руках у кассира. 
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники». Автор документа

Табличная часть «Конвертации»

  • Валюта, в которой получены деньги для конвертации. Ссылается на справочник «Валюты».
  • Курс обмена валюты полученных денег по отношению к базовой валюте. Тип значения: «Число».
  • Сумма полученных денег. Тип значения: «Число».
  • Валюта, в которую необходимо выполнить конвертацию. Ссылается на справочник «Валюты».
  • Курс обмена валюты, в которую необходимо выполнить конвертацию, по отношению к базовой валюте. Тип значения: «Число».
  • Сумма денег к выдаче. Тип значения: «Число».

Формы

  • Форма документа "Конвертация валют". Основная форма объекта. Используется для заполнения данных операции.
  • Печатная форма результатов конвертации с указанием кросс курсов. 

Способ вызова

Вызывается из журнала "Конвертации валют" меню подсистемы "Взаиморасчеты"
