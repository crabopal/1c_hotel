Документ "Платеж от контрагента"

Назначение

Документ используется для регистрации поступления денег от юридических лиц (контрагентов) на расчетные счета гостиницы. Обычно вводится вручную по банковской выписке. Документ позволяет распределить поступившие на расчетный счет суммы между неоплаченными счетами-требованиями контрагента или провести эти суммы как авансы/оплаты по группам гостей или как аванс по "пустой" группе.

Документ не влияет на балансы по лицевым счетам. Документ влияет на управленческий баланс по Контрагентам/Договорам/Группам гостей. Документ может использоваться для инициализации начального баланса взаиморасчетов с контрагентами и последующей, например, ежегодной выверки таких балансов.

В документе две табличных части. В левой таблице перечисляются счета-требования с не нулевыми балансами по выбранному в шапке документа контрагенту. Таблица со счетами-требованиями вспомогательная. Используется в случаях разнесения оплаты по неоплаченным счетам-требованиям. Основная таблица - это правая таблица договоров, где в каждой строке указывается сумма оплаты в разрезе Договор/Группа (основных измерений управленческого баланса). Если сумма оплаты указывается в левой таблице у какого-либо счета-требования, то эта же сумма автоматически переносится в правую таблицу, т.к. счет-требование всегда выставлен по какому-то договору (возможно пустому) и какой-то группе гостей. Соответственно в правой таблице автоматически создается/изменяется строка с договором/группой из счета-требования. В случае поступления аванса без счета-требования выставленного в программе, пользователь может добавлять строки непосредственно в правую таблицу оплат. Если тур-оператор в начале года, например, прислал аванс за будущее проживание своих гостей, то эту оплату можно отразить документом, у которого левая таблица будет пустая, а в правой таблице будет одна строка с пустым договором, пустой группой и суммой поступившей оплаты.

Внизу справа формы документа показывается итог по колонке "Сумма" правой таблицы оплат. Эта сумма не редактируется, т.к. все изменения нужно делать в табличных частях, и является итоговой суммой оплаты по документу в целом.

Документ можно использовать для переноса сумм оплаты с одной группы на другую. Пример, в результате того, что по одной из групп фактически заехало гостей меньше чем планировалось, на этой группе осталась сумма переплаты контрагента, которую необходимо перенести в счет оплаты проживания гостей из другой группы. Для этого создается документ с пустой левой таблицей, в правой таблице добавляются две строки. В первой строке указывается первая группа и сумма переплаты со знаком минус, во второй строке указывается вторая группа и сумма переплаты со знаком плюс. Итоговая сумма по документу остается равной нулю, т.е. никакого поступления денег этот документ не отражает. При проведении такого документа управленческий баланс по первой группе будет увеличен, а управленческий баланс по второй группе уменьшен (оплата отражается со знаком минус) на сумму переплаты. Итоговый баланс по контрагенту в целом не изменится.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Контрагенты», «Счет-требование», «Акт», «Договоры», «Платеж от контрагента».

Объекты, вводимые на основании: «Платеж от контрагента».

Реквизиты

  • Документ основание. Ссылается на документы «Акт», «Счет-требование». 
  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Фирма. Ссылается на справочник «Фирмы». 
  • Контрагент в бухгалтерии. Ссылается на справочник «Контрагенты». Контрагент чей управленческий баланс изменяет документ 
  • Сумма в валюте документа. Тип значения: «Число». Итоговая сумма оплаты по документу. Вручную не редактируется. Вычисляется как итог по колонке "Сумма" табличной части "Договоры". 
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». 
  • Сумма НДС. Тип значения: «Число». Сумма НДС от итоговой суммы по документу  
  • Секция оплаты. Ссылается на справочник «Секции оплаты». 
  • Способ оплаты. Ссылается на справочник «Способы оплаты». Способ оплаты, обычно "На расчетный счет" 
  • Дата курса обмена. Тип значения: «Дата». 
  • Валюта платежа. Ссылается на справочник «Валюты». 
  • Курс обмена валюты платежа по отношению к базовой валюте. Тип значения: «Число». 
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». Документ может пробивать чек на фискальном регистраторе, если платеж от контрагента принимается наличными или по корпоративной кредитной карте 
  • Кредитная карта. Ссылается на справочник «Кредитные карты». 
  • Референс номер операции. Тип значения: «Строка». 
  • Код авторизации операции. Тип значения: «Строка». 
  • Платеж контрагента. Ссылается на документ «Платеж от контрагента». Заполняется в случае, когда оформляется возврат по предыдущему наличному платежу проведенному по ККМ. 
  • Текст слипа. Тип значения: «Строка». 
  • Текст слипа аннулирования. Тип значения: «Строка».  
  • Примечания. Тип значения: «Строка». 
  • Тип аннуляции. Ссылается на перечисление «Типы отмены действий». Заполняется при аннулировании наличного платежа проведенного по ККМ 
  • Автор аннуляции. Ссылается на справочник «Сотрудники». Сотрудник выполнивший аннуляцию 
  • Дата аннуляции. Тип значения: «Дата». Дата и время аннуляции 
  • Код во внешней системе. Тип значения: «Строка». 
  • Тип карты. Ссылается на справочник «Типы кредитных карт». 
  • Автор. Ссылается на справочник «Сотрудники». Автор документа

Табличная часть «Договоры»

  • Договор в бухгалтерии. Ссылается на справочник «Договоры». Договор по которому пройдет сумма оплаты указанная в этой строке 
  • Группа гостей. Ссылается на справочник «Группы гостей». Группа гостей по которой пройдет сумма оплаты указанная в этой строке 
  • Баланс в валюте платежа. Тип значения: «Число». Информационное поле, не редактируется, заполняется суммой управленческого баланса по договору/группе на дату и время документа. Используется в качестве справочного значения при вводе сумм оплаты. 
  • Сумма в валюте платежа. Тип значения: «Число». Сумма оплаты по выбранным договору/группе 
  • Сумма в валюте взаиморасчетов с контрагентом. Тип значения: «Число». Сумма оплаты автоматически пересчитанная в валюту взаиморасчетов выбранного контрагента/договора 
  • Валюта взаиморасчетов с контрагентом. Ссылается на справочник «Валюты». Валюта взаиморасчетов с контрагентом из карточки контрагента или карточки договора (если договор указан) 
  • Курс обмена валюты взаиморасчетов с контрагентом по отношению к базовой валюте. Тип значения: «Число».  

Табличная часть «Счета-требования»

  • Счет-требование. Ссылается на документ «Счет-требование».  
  • Баланс в валюте платежа. Тип значения: «Число».  Информационное поле, не редактируется, заполняется суммой баланса по выбранному счету-требованию на дату платежа. Используется в качестве справочного значения при вводе суммы оплаты по счету-требованию. 
  • Сумма в валюте платежа. Тип значения: «Число». Сумма оплаты по счету-требованию 
  • Сумма в валюте взаиморасчетов с контрагентом. Тип значения: «Число». Сумма оплаты пересчитанная в валюту взаиморасчетов контрагента/договора 
  • Валюта взаиморасчетов с контрагентом. Ссылается на справочник «Валюты». Валюта взаиморасчетов с контрагентом из карточки контрагента или карточки договора (если договор указан в счете-требовании) 
  • Курс обмена валюты взаиморасчетов с контрагентом по отношению к базовой валюте. Тип значения: «Число». 

Формы

  • Форма документа "Платеж контрагента". Основная форма объекта. Используется для заполнения обязательных реквизитов. 
  • Печатная форма платежа от контрагента.
