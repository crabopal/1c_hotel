Документ "Запись в журнал регистрации иностранных граждан"

Назначение

Запись в журнал регистрации иностранных граждан. Используется для регистрации визовых/миграционных данных иностранных граждан и передачи сведений в УФМС. Из документа можно распечатать форму "Уведомление о регистрации иностранного гражданина по месту пребывания".

Документ вводится на основании Размещения кнопкой "Уведомление" на форме размещения, или по кнопке "Действия" и выбрать пункт "Уведомление".

В документе указываются все данные, необходимые для регистрации и печати "Уведомления о прибытии...", а именно - паспортные данные, визовые данные, данные миграционной карты.

Паспортные данные сотрудника, подписывающего уведомления указываются в справочнике "Сотрудники" на закладке "Основные". При печати документа используются только данные тех сотрудников, у которых в наборе прав включен флажок "051 - Есть права подписывать уведомление о регистрации иностранных граждан". Если это право включено у пользователя, который печатает уведомление, то будут распечатаны его паспортные данные, если же у него таких прав нет, то пользователь должен будет выбрать ответственного сотрудника в момент печати. На выбор предлагаются только сотрудники с включенным в наборе прав правом 051.

Если у пользователя в наборе прав включен флажок "012 - Есть права на удаление записей в журнале регистрации иностранных граждан", то он сможет удалять записи из журнала.

При проведении документ в случаях, когда:

  • цель поездки гостя указанная в документе не совпадает с целью поездки указанной в размещении
  • страна гражданства гостя в документе не совпадает с страной гражданства в карточке гостя,

перепроводит документ размещение для того, чтобы правильно заполнились параметры в аналитических регистрах

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Непериодический

Тип номера: Строка

Вводится на основании: «Размещение».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». Указывается в номере какой гостиницы проживает гость. 
  • Документ основание. Ссылается на документ «Размещение». Документ-основание, которым было оформлено поселение.
  • Номер. Ссылается на справочник «Номерной фонд». Номер, в котором живет гость.
  • Гость. Ссылается на справочник «Клиенты (гости)».  Ссылка на карточку клиента.
  • У гостя уже есть уведомление о регистрации. Если включен, то у гостя уже есть уведомление, оформленное, например в другой гостинице. В этом случае такой гость регистрируется и отмечается, чтобы другие смены не печатали ему уведомление. Гость с включенным флажком не попадает в выгрузку данных иностранных гостей в УФМС
  • Дата заезда. Фактическая дата заезда в номер.
  • Дата выезда. Дата выезда из номера. Обычно не печатается на отрывном талоне уведомления. Эта дата вводится как планируемая дата выезда. В талоне заполняется в день выезда гостя вручную. Но, если включить флажок "047 - Есть права на печать даты освобождения номера в отрывной части уведомления о регистрации иностранных граждан", то дата будет распечатана в талоне.
  • Гость выехал. Устанавливается при выселении гостя.
  • Фамилия. Фамилия гостя, так, как указано в миграционной карте на русском языке. Рекомендуется в карточке гостя указывать ФИО гостя из паспорта, т.е. на иностранном языке 
  • Имя. Имя гостя, как указано в миграционной карте на русском языке.
  • Отчество. Отчество или второе имя, как указано в миграционной карте на русском языке. 
  • Пол. Мужской или Женский.
  • Гражданство. Ссылается на справочник «Страны». Страна гражданство гостя.
  • Дата рождения.
  • Место рождения. Желательно заполнять в форме классификатора адресов. 
  • Вид документа удостоверяющего личность. Ссылается на справочник «Виды документов удостоверяющих личность».
  • Паспортные данные:
    • Серия документа удостоверяющего личность.
    • Номер документа удостоверяющего личность. 
    • Дата выдачи документа удостоверяющего личность. 
    • Документ удостоверяющий личность действителен до. 
    • Кем выдан документ удостоверяющий личность. 
  • Данные миграционной карты: 
    • Цель визита. Ссылается на справочник «Цели визита».
    • Профессия или должность. Тип значения: «Строка».
    • Стаж работы. Тип значения: «Строка».
    • Страна или город откуда прибыл. Тип значения: «Строка».
    • Из-за границы. Тип значения: «Булево».
    • Номер миграционной карты. Тип значения: «Строка».
    • Срок прибывания по миграционной карте с даты. Тип значения: «Дата».
    • Срок прибывания по миграционной карте по дату. Тип значения: «Дата».
    • Принимающая организация. Тип значения: «Строка».
  • Данные визы:
    • Номер визы. Тип значения: «Строка».
    • Тип визы. Ссылается на справочник «Типы въездных виз».
    • Дата выдачи визы.
    • Дата с визы. Дата начала действия визы.
    • Место выдачи визы.
    • Дата по визы. Дата окончания действия визы.
    • Число дней действия визы.
    • Дата пересечения границы. Дата пересечения границы по штампу в паспорте.
    • Номер контрольно-пропускного пункта (КПП). Тип значения: «Строка». Вводится значение по штампу на миграционной карте. Если в правах доступа включен флажок "097 - Есть права добавлять любые КПП в справочник и использовать их ...", то можно вводить произвольную строку. Все введенные варианты автоматически сохраняются в справочнике КПП и возможны в дальнейшем для выбора. Если же это право выключить, тогда пользователь сможет только выбирать КПП из заранее введенного списка.
    • Маршрут. Строкой указывается маршрут гостя. 
  • Сведения о законных представителях. Заполняется, если необходимо. Печатается на форме уведомления.
  • Примечания. Комментарий к документу. 
  • Автор. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается в главном меню по кнопке "Еще.../Закладка "1"/Журнал регистрации иностранцев"
