Документ "Отгрузка путевок"

Назначение

Документ используется для регистрации в специальном регистре сведений «Отгруженные путевки» номеров бланков отгруженных сторонней организации путевок/курсовок. При вводе номера отгруженного бланка в размещении/брони, если этот номер найден в регистре отгруженных бланков, программа создает путевку/курсовку с параметрами из регистра.

В программе реализован отчет "Отгруженные, но не проданные путевки/курсовки", который позволяет распечатать список отгруженных бланков, по которым еще не заезжали гости.

Относится к подсистеме: «Продажи путевок и курсовок».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Размещение», «Фолио», «Бронь», «Группы гостей».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Фирма. Ссылается на справочник «Фирмы».
  • Контрагент. Ссылается на справочник «Контрагенты». Контрагент, которому отгружаются бланки путевок
  • Договор. Ссылается на справочник «Договоры». Договор с контрагентом, по которому отгружаются бланки путевок
  • Группа гостей. Ссылается на справочник «Группы гостей». Группа гостей, по которой отгружаются бланки, обычно не заполняется
  • Документ основание. Ссылается на документы «Бронь», «Размещение», «Фолио». Обычно не заполняется.
  • Квота номеров. Ссылается на справочник «Квоты номеров». Квота номеров по которой должно происходить бронирование и поселение гостей по отгружаемым бланкам. Обычно не заполняется.
  • Накладная на отгрузку. Тип значения: «Строка». Номер накладной на отгрузку из бухгалтерской системы. Справочное значение.
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». 
  • Фиксировать период проживания . Тип значения: «Булево». Определяет значение одноименного флажка в карточке путевки/курсовки. Используется при регистрации путевки/курсовки в справочнике путевок в момент ввода номера бланка в размещении или брони
  • Фиксировать стоимость путевки. Тип значения: «Булево». Определяет значение одноименного флажка в карточке путевки/курсовки. 
  • Дата курса обмена. Тип значения: «Дата».
  • Валюта накладной. Ссылается на справочник «Валюты». 
  • Курс обмена валюты. Тип значения: «Число». 
  • Примечания. Тип значения: «Строка». 
  • Автор. Ссылается на справочник «Сотрудники». Сотрудник, который создал документ

Табличная часть «Путевки»

  • Тип путевки. Ссылается на группы справочника «Путевки и курсовки». Наследуется в карточку путевки/курсовки при регистрации путевки/курсовки в справочнике в момент ввода номера бланка в размещении или брони
  • Услуга. Ссылается на справочник «Услуги». Услуга, которая будет использоваться в счете-требовании или акте созданном на основании документа отгрузки.
  • Номер начала диапазона. Тип значения: «Строка». Первый номер из непрерывного диапазона номеров отгружаемых бланков. Можно указывать как с символьным префиксом, так и с символьным суффиксом.
  • Количество. Тип значения: «Число». Количество бланков в пачке
  • Номер конца диапазона. Тип значения: «Строка». Последний номер из непрерывного диапазона номеров отгружаемых бланков. Можно указывать как с символьным префиксом, так и с символьным суффиксом. Вычисляется автоматически по первому номеру в пачке и количеству бланков.
  • Дата заезда. Тип значения: «Дата». Поле может быть пустым. Если заполнена, то наследуется в карточку путевки/курсовки при регистрации путевки/курсовки в справочнике путевок в момент ввода номера бланка в размещении или брони.
  • Продолжительность в днях или часах. Тип значения: «Число». 
  • Дата выезда. Тип значения: «Дата». Поле может быть пустым. Если заполнена, то наследуется в карточку путевки/курсовки при регистрации путевки/курсовки в справочнике путевок в момент ввода номера бланка в размещении или брони.
  • Тип номера. Ссылается на справочник «Типы номеров». Поле может быть пустым. Если заполнено, то наследуется в карточку путевки/курсовки при регистрации путевки/курсовки в справочнике путевок в момент ввода номера бланка в размещении или брони.
  • Стоимость путевки. Тип значения: «Число». Стоимость одного отгружаемого бланка
  • Сумма. Тип значения: «Число». Сумма по всей отгружаемой пачке.
  • Сумма НДС. Тип значения: «Число». Сумма НДС с пачки

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма списка. Основная форма списка. Используется для отображения списка документов данного типа.
  • Печатная форма накладной. Документ можно распечатать в виде накладной на отгрузку бланков.

Способ вызова

Вызывается из основного меню программы по кнопке "Еще.../Закладка "3"/Отгрузка путевок"

Движения
