Документ "Заказ"

Назначение

Документ используется для регистрации в программе заказов на доп. услуги. Заказы могут быть различных типов: заказ из ресторана, заказ трансфера, заказ утюга или гладильной доски и др. Для разных типов заказов программа показывает разный набор полей. Типы заказов вводятся в справочнике "Типы заказов" и могут изменяться пользователями.

Для каждого типа заказа в программе настраивается список статусов, которые доступны для документа. В журнале заказов можно отслеживать бизнес процессы изменения статусов заказов.

Относится к подсистеме: «Заказы».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Реквизиты

  • Тип заказа. Тип заказа из справочника "Типы заказов"  
  • Статус заказа. Статус заказа из справочника "Статусы заказов"  
  • Отдел. Структурный отдел гостиницы, отвечающий за обработку заказов данного типа, из справочника "Отделы". 
  • Клиент. Клиент заказа. 
  • Сумма и количество. Сумма и количество заказа. 
  • Примечания. Произвольный комментарий к заказу. Обычно описывает источник денег. 
  • Параметры соответствующие различным типам заказов. 

Табличные части

  • Позиции заказа. Хранит детальный список позиций заказа. Например для заказов ресторана это будет перечень позиций меню заказа. Для заказов прачечной это будет список вещей.
