Документ "Платеж"

Назначение

Документ используется для регистрации оплаты по лицевым счетам гостей и сторонних посетителей. Авансы (депозиты/залоги) также регистрируются этим документом.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Фолио», «Преавторизация».

Объекты, вводимые на основании: «Возврат».

Реквизиты

  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение».
  • Лицевой счет. Ссылается на документ «Фолио». Указывает лицевой счет, по которому проводится оплата.
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Фирма. Ссылается на справочник «Фирмы». Указывается фирма, по кассе которой проводится платеж.
  • Плательщик. Ссылается на справочники «Клиенты (гости)», «Контрагенты». Заполняется автоматически значением из фолио, но может быть изменено пользователем для целей печати счета.
  • Контрагент в бухгалтерии. Ссылается на справочник «Контрагенты». Заполняется значением из Фолио. Если в фолио контрагент не указан, то это означает, что оплачивает гость, при этом подставляется контрагент "Физ.лица" для выгрузки в бухгалтерию.
  • Договор в бухгалтерии. Ссылается на справочник «Договоры».  Заполняется значением из фолио.
  • Группа гостей. Ссылается на справочник «Группы гостей». Заполняется значением из фолио.
  • Секция оплаты. Ссылается на справочник «Секции оплаты». Заполняется значением из фолио. Используется для разделения платежей по разным секциям ККМ. 
  • Способ оплаты. Ссылается на справочник «Способы оплаты». Выбирается пользователем. При выборе способа оплаты, "Наличные" или "Кред.карты" пробивается чек по ККМ.
  • Валюта платежа. Выбирается валюта, которой расплачивается гость. Это может быть любая валюта, которую принимают к оплате в гостинице. При проведении платежа сумма будет пересчитана в валюту взаиморасчетов с гостем, т.е. в валюту фолио. По кассовому отчету будет указана именно сумма в валюте платежа.
  • Сумма в валюте документа. Сумма платежа.
  • Ставка НДС %. Ссылается на справочник «Ставки НДС» Заполняется значением из выбранной секции, либо ставкой "по-умолчанию" из Фирмы.
  • Сумма НДС. Рассчитывается по выбранной ставке.
  • Сумма в валюте лицевого счета. Пересчитывается из суммы платежа по курсу на дату курса. 
  • Сумма НДС в валюте лицевого счета. Рассчитывается по выбранной ставке.
  • Дата курса обмена. На указанную дату получается курс валюты.
  • Курс обмена валюты платежа по отношению к базовой валюте. Рассчитывается на дату курса.
  • Валюта лицевого счета. Ссылается на справочник «Валюты». Заполняется по данным фолио. Используется для пересчета.
  • Курс обмена валюты лицевого счета по отношению к базовой валюте.
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». По указанной ККМ будет пробит чек. 
  • Кредитная карта. Ссылается на справочник «Кредитные карты».  Выбирается из списка карт, привязанных к клиенту; либо вводится новая карта, при выполнении голосовой авторизации; либо заполняется автоматически при выполнении платежа с помощью драйвера работы с терминалом банка. Используется для сверки платежей по картам с банком.
  • Референс номер операции. Заполняется кассиром вручную по данным со слипа платежа, распечатанного банковским терминалом в случае одобрения платежа. При использовании драйвера работы с банковскими терминалами реквизит заполняется автоматически.
  • Код авторизации операции. Заполняется кассиром вручную по данным со слипа платежа, распечатанного банковским терминалом в случае одобрения платежа. При использовании драйвера работы с банковскими терминалами реквизит заполняется автоматически.
  • Примечания. Комментарий пользователя к операции. 
  • Текст слипа. Заполняется автоматически при использовании драйвера работы с банковскими терминалами. Используется для печати слипа на кассовой ленте ККМ.
  • Текст слипа аннулирования. Заполняется автоматически при использовании драйвера работы с банковскими терминалами. Используется для печати слипа на кассовой ленте ККМ.
  • Тип аннуляции. Причина аннуляции платежа: "Ошибка сотрудника" либо "Отказ клиента". 
  • Автор аннуляции. Пользователь, выполнивший аннуляцию.
  • Дата аннуляции. Дата и время выполнения аннуляции.
  • Счет-требование. Ссылается на документ «Счет-требование». Заполняется в случае, если платеж выполнен по счету. 
  • Преавторизация. Ссылается на документ «Преавторизация». Заполняется при выполнении команды "Расчет" по преавторизации по кред.карте. 
  • Тип карты. Ссылается на справочник «Типы кредитных карт». Заполняется по данным карты. Используется в отчетах для сверки с банком, как аналитика при выгрузке в бухгалтерию.
  • Код во внешней системе. Используется для выгрузки документа во внешнюю систему, например в бухгалтерию.
  • Автор. Пользователь создавший документ. 

Табличная часть «Платежные секции»

Показывается и используется только в случае, когда в параметрах гостиницы включен флажок "Вести баланс лицевых счетов по секциям". Таблица, при вводе нового документа, заполняется остатками по секциям по выбранному лицевому счету.

  • Секция оплаты. Ссылается на справочник «Секции оплаты». Заполняется при наличии баланса по секции. При добавлении строк вручную может выбираться из списка.
  • Сумма в валюте документа. Указывается сумма, которую нужно провести по выбранной секции.
  • Ставка НДС %. Заполняется значением из свойств секции. 
  • Сумма НДС. Рассчитывается по выбранной ставке.
  • Сумма в валюте лицевого счета. Рассчитывается по курсу валюты (в форме документа не отображается).
  • Сумма НДС в валюте лицевого счета. Рассчитывается по выбранной ставке НДС (в форме документа не отображается)

Способ вызова

Открыть список транзакций лицевого счета (фолио) и нажать кнопку "Оплатить"

Журналы отображающие документ: «Журнал взаиморасчетов с контрагентами».

Движения

  • «Распределение платежей по услугам». Вспомогательный регистр для отчета "Распределение платежей по услугам".
  • «Взаиморасчеты по счетам». Движения выполняются в случае, если платеж был введен с указанием счета-требования. 
  • «Выручка по кассовым сменам». Регистр для формирования отчета кассира.
  • «Взаиморасчеты». Основной регистр для ведения взаиморасчетов по лицевым счетам (фолио) клиентов.
  • «Платежи». Оборотный регистр для отчета "Платежи"
  • «Наличность в кассах». Регистр для формирования отчета кассира.
  • «Взаиморасчеты с контрагентами». Движения по контрагенту, договору и группе, указанным в параметрах платежа. Изменяет управленческий баланс по контрагенту/договору/группе.
  • «Депозиты». Вспомогательный регистр для работы закладки "Платежи" в деталях лицевого счета
