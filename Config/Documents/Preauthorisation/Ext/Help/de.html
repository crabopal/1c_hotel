Документ "Преавторизация"

Назначение

Документ используется для регистрации преавторизации (блокировки) денежных средств на кредитной карте клиента. Документ доступен для ввода только пользователям, у которых в наборе прав включен флажок "114 - Есть права на операции преавторизации по кредитным картам".

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Фолио».

Объекты, вводимые на основании: «Платеж».

Реквизиты

  • Статус. Принимает значение: "Авторизован" после успешной авторизации суммы; "Отказ" после неудачной попытки авторизации; "Рассчитан" после того, как по авторизации выполнен окончательный расчет; "Отмена" после команды отмены преавторизации; "В архиве" после того как гость выехал, а операции "расчет" по преавторизации выполнено не было. Устанавливается процедурой закрытия периода. 
  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение». Заполняется значением из фолио. 
  • Лицевой счет. Ссылается на документ «Фолио».
  • Гостиница. Ссылается на справочник «Гостиницы». Гостиница, в которой проживает гость.
  • Фирма. Ссылается на справочник «Фирмы». По указанной фирме оформлен счет гостю.
  • Плательщик. Ссылается на справочники «Клиенты (гости)», «Контрагенты». Клиент, на имя которого оформлен документ.
  • Группа гостей. Ссылается на справочник «Группы гостей». Заполняется из фолио.
  • Способ оплаты. Ссылается на справочник «Способы оплаты». Выбранный способ оплаты, указывается пользователем. Обычно "Кред.карта."
  • Сумма в валюте документа. Сумма авторизации.
  • Сумма в валюте лицевого счета. Рассчитывается на дату курса.
  • Дата курса обмена. По этой дате получается курс валюты
  • Валюта. Ссылается на справочник «Валюты». В этой валюте указывается сумма авторизации.
  • Курс обмена валюты платежа по отношению к базовой валюте.
  • Валюта лицевого счета. Ссылается на справочник «Валюты». Заполняется из лицевого счета.
  • Курс обмена валюты лицевого счета по отношению к базовой валюте. Рассчитывается на дату курса.
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». По выбранной ККМ печатается слип операции.
  • Кредитная карта. Ссылается на справочник «Кредитные карты».  Данные карты сохраняются в справочнике и используются в дальнейшем для операции "Расчет", а также для сверки с банком.
  • Референс номер операции. Заполняется драйвером ответом из банка. Содержит уникальный номер операции, который присваивается банком и печатается на слипе операции. 
  • Код авторизации операции. Присваивается банком в случае успешной операции.
  • Примечания. Комментарий к документу.
  • Текст слипа. Возвращается драйвером при проведении платежа. Печатается на кассовой ленте ККМ как нефискальный документ.
  • Текст слипа отмены. Возвращается драйвером при отмене операции. Печатается на кассовой ленте ККМ как нефискальный документ.
  • Автор отмены преавторизации. Ссылается на справочник «Сотрудники». Пользователь, выполнивший отмену.
  • Дата отмены преавторизации. Дата и время отмены.
  • Счет-требование. Ссылается на документ «Счет-требование».
  • Код во внешней системе. Используется при обмене с внешними системами для синхронизации документов. 
  • Тип карты. Ссылается на справочник «Типы кредитных карт». Заполняется драйвером или вручную. Используется для сверки отчетов с банком и для аналитики в бухгалтерии. 
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, выполнивший операцию. 

Способ вызова

Вызывается в списке транзакций лицевого счете по кнопке "Преавторизация"
