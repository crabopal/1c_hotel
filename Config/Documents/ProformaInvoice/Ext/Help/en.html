Документ "Счет-требование"

Назначение

Документ счет-требование используется для выставления счетов на оплату услуг контрагентами. Предназначен для формирования печатной формы счета. Варианты печати отличаются степенью детализации и выбираются по кнопке "Печать". Язык печати задается в карточке контрагента.

Счет может вводится на основании документов: «Бронь», «Размещение», «Акт», «Фолио» и справочника «Группы гостей». Состав услуг заполняется услугами из документа-основания. Если счет вводится по группе, то выбираются услуги по всем документам группы. При этом в счет попадают только те услуги, которые, по правилам начислений, должны быть оплачены контрагентом (т.е оплачены "по безналу").

По кнопке "Пересчитать" табличная часть перезаполняется по текущему состоянию услуг в документе основании. Кнопка используется при изменении условий бронирований.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Бронь», «Размещение», «Акт», «Фолио», «Группы гостей», «Контрагенты», «Договоры».

Объекты, вводимые на основании: «Распределение аванса», «Платеж от контрагента», «Акт».

Реквизиты

  • Документ основание. Ссылается на документы «Акт», «Бронь», «Бронь ресурса», «Отгрузка путевок», «Размещение», «Фолио». 
    • Если выбрано "По номерам и ресурсам" - то состав услуг заполнится всеми услугами к оплате контрагентом - и по брони номеров и по ресурсам. 
    • Если выбрано "Только по номерам" - то состав услуг заполнится только услугами из документов "Бронь". 
    • Если выбрано "Только по ресурсам" - то состав услуг заполнится по всем документам "Бронь ресурсов" с выбранной группой. 
    • Если выбран документ - то состав услуг будет заполнен только по этому, выбранному документу.
  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Фирма. Ссылается на справочник «Фирмы». Реквизиты этой фирмы будут распечатаны в счете. 
  • Банковский счет фирмы. Ссылается на справочник «Банковские счета». Реквизиты для печати счета. 
  • Контрагент. Ссылается на справочник «Контрагенты». Указывается контрагент-плательщик по счету. 
  • Договор. Ссылается на справочник «Договоры». Договор контрагента. 
  • Группа гостей. Ссылается на справочник «Группы гостей».  Номер подтверждения брони или группа, по которой выставлен счет. 
  • Контактное лицо. Строковое представление для записи контактного лица. 
  • Контакты контрагента.
    • Телефон. 
    • Факс. 
    • E-mail. на указанный адрес можно будет отправить счет из программы, если у пользователя настроена учетная запись электронной почты. 
  • Сумма. 
  • Сумма НДС. 
  • Дата курса обмена. на указанную дату рассчитывается курс обмена валюты. 
  • Валюта взаиморасчетов с контрагентом. Ссылается на справочник «Валюты».  Заполняется по данным контрагента. 
  • Курс обмена валюты взаиморасчетов с контрагентом по отношению к базовой валюте. Рассчитывается на дату курса. 
  • Примечания. Комментарий к счету. 
  • Печатать с печатью фирмы. Если включить флажок, то печатная форма будет выведена с картинкой печати и подписи. Картинки задаются в параметрах фирмы на закладке "Печать, подпись".  
  • Код во внешней системе. Используется для выгрузки документов во внешнюю систему (например, в бухгалтерию). 
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, создавший документ.

Способ вызова

Вызывается из главного меню по кнопке "Еще.../Закладка "1"/Счета-требования"

Движения

  • «Взаиморасчеты по счетам». Делает движение-приход на сумму счета. По данному регистру ведется баланс оплаты счетов. Если счет оплачен, то отметка об оплате показывается в журнале бронирования и видна при поселении гостя.
