Документ "Телефонный разговор"

Назначение

Документ регистрирует телефонные разговоры из номеров и автоматически создает начисления на лицевые счета звонивших гостей. Документы создаются автоматически обработкой загрузки из телефонных тарификаторов.

Главная задача документа - определить фолио на которое начислить стоимость разговора. Фолио определяется в момент загрузки. При проведении начисление производится на счет указанный в документе.

Алгоритм определения лицевого счета для начисления следующий:

  • Учитываются только открытые лицевые счета номера, т.е. счета, у которых признак «Закрыто» выключен. Как правило, это счета проживающих гостей или мастер-счета.
  • Учитываются правила начисления.
  • Если подходящих счетов несколько, то приоритет выбора счета устанавливается по следующим критериям:
    • гость платит за весь номер
    • у гостя есть депозит
    • более ранняя дата заезда

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». Указывается гостиница, в которой проживает гость.
  • Фирма. Ссылается на справочник «Фирмы». Фирма лицевого счета, на который необходимо выполнить начисление.
  • НДС входит в цену телефонного разговора. Влияет на расчет начисленной суммы. Если флажок включен, то при загрузке считается что в тарификаторе указаны суммы с НДС.
  • Дата курса обмена. На выбранную дату получается курс валюты.
  • Валюта. Ссылается на справочник «Валюты». В этой валюте сумма хранится в биллинговой системе.
  • Курс обмена валюты документа по отношению к базовой валюте.
  • Услуга телефонного разговора. Ссылается на справочник «Услуги». На выбранную услугу, будет начислена стоимость разговора.
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». Используется для расчета суммы НДС. Заполняется значением из секции лицевого счета, либо из секции услуги, либо значением основной ставки из фирмы.
  • Номер телефона. Ссылается на справочник «Телефонные номера». Внутренний номер телефона откуда был звонок.
  • Номер. Ссылается на справочник «Номерной фонд». Если номер телефона привязан к номеру комнаты, то указывается номер откуда был звонок.
  • Дата и время разговора. Дата и время звонка по данным тарификатора.
  • Лицевой счет. Ссылается на документ «Фолио». Лицевой счет, определенный при загрузке. На выбранный лицевой счет будет начислена услуга.
  • Валюта лицевого счета. Ссылается на справочник «Валюты». Сумма начисления будет пересчитана в валюту фолио.
  • Курс обмена валюты лицевого счета по отношению к базовой валюте.
  • Отчетная валюта. Ссылается на справочник «Валюты». Заполняется из параметров гостиницы. В указанной валюте формируются отчеты, в том числе отчет "Телефонные разговоры".
  • Курс обмена отчетной валюты по отношению к базовой валюте. 
  • Тип клиента. Ссылается на справочник «Типы клиентов». Заполняется по фолио или по документу-основанию.
  • Строка подтверждения для типа клиента. Заполняется из документа основания.
  • Номер телефона куда был звонок. Набранный номер телефона (куда звонили).
  • Тип телефонного разговора. Заполняется при загрузке из тарификатора. Может быть "Международный", "Междугородний", "Местный", "Внутренний", "Входящий", "Мобильный".
  • Регион телефонного разговора. Регион, куда был звонок по данным тарификатора. 
  • Примечания. Комментарий к документу.
  • Цена. Цена за звонок.
  • Единица измерения. Заполняется из услуги. Обычно "минута".
  • Количество. Количество по данным тарификатора.
  • Сумма в валюте документа. Сумма по данным тарификатора. 
  • Сумма НДС в валюте документа.
  • Сумма в валюте фолио. Сумма в валюте взаиморасчетов пересчитанная на дату курса.
  • Сумма НДС в валюте фолио.
  • Услуга сбора за разговор. Ссылается на справочник «Услуги». Дополнительная услуга фиксированного сбора за каждый телефонный разговор, заполняется в случае, если требуется начислять такую услугу параллельно с основной услугой со стоимостью разговора полученной из тарификатора. Указывается в настройках карточки гостиницы.
  • Ставка НДС % услуги сбора за разговор. Ссылается на справочник «Ставки НДС».
  • Сумма услуги сбора за разговор в валюте документа.
  • Сумма НДС услуги сбора за разговор в валюте документа. 
  • Сумма услуги сбора за разговор в валюте фолио.
  • Сумма НДС услуги сбора за разговор в валюте фолио.
  • Комиссия агента. Рассчитывает по проценту комиссии агента.
  • Вид комиссии агента. "Процент".
  • Набор услуг, по которому начисляется комиссия агентам. Ссылается на справочник «Наборы услуг».
  • Комиссия в валюте фолио. Пересчитанная в валюту фолио сумма комиссии.
  • НДС с суммы комиссии в валюте фолио.
  • Комиссия в валюте фолио на сбор за телефонный разговор .
  • НДС с суммы комиссии на сбор за телефонный разговор в валюте фолио.
  • Дисконтная карта. Ссылается на справочник «Дисконтные карты». Заполняется из документа-основания, в случае, если у гостя при поселении была указана.
  • Тип скидки. Ссылается на справочник «Типы скидок».
  • Основание предоставления скидки.
  • Скидка %. Значение скидки.
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг».
  • Сумма скидки в валюте фолио.
  • НДС с суммы скидки в валюте фолио. 
  • Сумма скидки на сбор в валюте фолио.
  • НДС с суммы скидки на сбор в валюте фолио.
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, создавший документ.
