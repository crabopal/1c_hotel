Документ "Услуга на номер"

Назначение

Документ «Услуга на номер» предназначен для загрузки и начисления дополнительных услуг из внешних систем, таких как платное телевидение, мини-бары, интернет биллинг, фронт-офис ресторана. Данный документ всегда создается автоматически, и предназначен для облегчения создания интерфейсов с внешними системами учета услуг.

Главная задача документа - определить фолио на которое начислить стоимость услуги. Фолио определяется в момент загрузки. При проведении начисление производится на счет указанный в документе.
Алгоритм определения лицевого счета для начисления следующий:

  • Учитываются только открытые лицевые счета номера, т.е. счета, у которых флажок «Закрыто» выключен. Как правило, это счета проживающих гостей или мастер-счета.
  • Учитываются правила начисления.
  • Если подходящих лицевых счетов несколько, то приоритет выбора счета устанавливается по следующим критериям:
    • Гость платит за весь номер
    • У гостя есть депозит
    • Более ранняя дата заезда

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».  Указывается гостиница, в которой проживает гость
  • Фирма. Ссылается на справочник «Фирмы». Фирма лицевого счета, на который необходимо выполнить начисление
  • НДС входит в цену услуги на номер. Тип значения: «Булево». Если флажок включен, то при загрузке считается, что сумма во внешней системе указана с НДС
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». Используется для расчета суммы НДС. Заполняется значением из секции лицевого счета, либо из секции услуги, либо значением основной ставки из фирмы.
  • Дата курса обмена. На указанную дату получается курс обмена валюты.
  • Валюта. Ссылается на справочник «Валюты». Валюта суммы начисления.
  • Курс обмена валюты документа по отношению к базовой валюте. 
  • Номер. Ссылается на справочник «Номерной фонд». Номер, в котором была оказана услуга.
  • Клиент. Ссылается на справочник «Клиенты (гости)». Клиент, на имя которого начислена услуга.
  • Услуга на номер. Ссылается на справочник «Услуги». Указывается услуга, на которую начисляется сумма транзакции.
  • Тип начисления на номер. Заполняется при загрузке из тарификатора. Дополнительная информация по услуге. Например для платного ТВ может быть номер канала.
  • Дата и время услуги. Дата и время услуги по данным внешней системы.
  • Примечания. Комментарий к начислению.
  • Лицевой счет. Ссылается на документ «Фолио». На указанный лицевой счет начисляется услуга. 
  • Валюта лицевого счета. Ссылается на справочник «Валюты».
  • Курс обмена валюты лицевого счета по отношению к базовой валюте. 
  • Отчетная валюта. Ссылается на справочник «Валюты». В указанной валюте формируются движения по аналитическим регистрам и отчеты.
  • Курс обмена отчетной валюты по отношению к базовой валюте.
  • Тип клиента. Ссылается на справочник «Типы клиентов». Заполняется по данным документа-основания.
  • Строка подтверждения для типа клиента.
  • Цена. Цена, по данным внешней системы.
  • Единица измерения. Строка, Представление единицы измерения услуги.
  • Количество. По данным внешней системы.
  • Сумма в валюте документа. Сумма, по данным внешней системы. 
  • Сумма НДС в валюте документа. Рассчитывается по выбранной ставке НДС.
  • Сумма в валюте фолио. Пересчитывается по курсу на дату курса.
  • Сумма НДС в валюте фолио.
  • Сбор начисляемый на каждую услугу на номер. Ссылается на справочник «Услуги». Указывается услуга, которая будет начислена дополнительно к основной услуги и представляет собой дополнительный фиксированный сбор за каждый факт оказания услуги.
  • Ставка НДС % сбора с услуги на номер. Ссылается на справочник «Ставки НДС».
  • Сумма сбора в валюте документа. Заполняется загрузчиком, если определено.
  • Сумма НДС сбора в валюте документа. Рассчитывается по ставке НДС.
  • Сумма сбора в валюте фолио. Пересчитывается по курсу на дату курса. 
  • Сумма НДС сбора в валюте фолио.
  • Комиссия агента. Сумма комиссии, получаемой агентом за услугу.
  • Вид комиссии агента. "Процент".
  • Набор услуг, по которому начисляется комиссия агентам. Ссылается на справочник «Наборы услуг».
  • Комиссия в валюте фолио. Сумма комиссии пересчитанная в валюту фолио.
  • НДС с суммы комиссии в валюте фолио.
  • Комиссия в валюте фолио на сбор за начисление. Комиссия за разовый сбор к начислению.
  • НДС с суммы комиссии на сбор за начисление в валюте фолио. 
  • Дисконтная карта. Ссылается на справочник «Дисконтные карты». Заполняется по данным документа-основания.
  • Тип скидки. Ссылается на справочник «Типы скидок». Заполняется из документа-основания.
  • Основание предоставления скидки. Комментарий к примененной скидке.
  • Скидка %. Процент скидки.
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг».
  • Сумма скидки в валюте фолио. Сумма скидки пересчитанная в валюту фолио.
  • НДС с суммы скидки в валюте фолио.
  • Сумма скидки на сбор за начисление в валюте фолио. Сумма скидки к сбору на начисление.
  • НДС с суммы скидки на сбор за начисление в валюте фолио.
  • Детали начисления. Строковое значение содержит детали начисления, например, копию чека из ресторана.
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, создавший документ.

Способ вызова
