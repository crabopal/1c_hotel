Документ "Бронь"

Назначение

Документ используется для бронирования номеров по категориям или для резервирования конкретных номеров комнат. В документе указывается количество бронируемых номеров/мест, период планируемого проживания гостей, их количество, категория номера, номер комнаты (не обязательно), тариф, рассчитывается состав и суммы услуг, которые будут начислены гостям когда они приедут.

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка.

Периодичность номера: Непериодический

Тип номера: Строка

Вводится на основании: «Путевки и курсовки», «Размещение», «Шаблоны операций».

Объекты, вводимые на основании: «Размещение», «Счет-требование», «Отгрузка путевок», «Акт».

Реквизиты

  • Документ основание. Ссылается на документы «Бронь», «Размещение». Обычно либо пустое, либо содержит ссылку на размещение на основании которого выполнено бронирование. Бронирование на основании размещения позволяет в размещении указать только тот срок проживания, который гость может сразу оплатить. Если гость планирует, что будет проживать дольше, то на основании его размещения можно ввести бронь от даты планируемого выезда по размещению до даты окончания проживания по словам гостя. При дальнейшем продлении периода проживания гостя срок бронирования будет автоматически сокращаться. 
  • Гостиница. Ссылается на справочник «Гостиницы».  
  • Контрагент. Ссылается на справочник «Контрагенты».  Организация от которой приехал гость. 
  • Тип контрагента. Ссылается на справочник «Типы контрагентов». Аналитический параметр, заполняется автоматически при выборе контрагента 
  • Договор. Ссылается на справочник «Договоры». Договор с контрагентом. Существует две схемы работы с договорами. В первом варианте в программе регистрируются договора так как они заключены с организациями. Во втором варианте для каждого контрагента заводят два договора: наличный расчет (обычно это агентский договор), безналичный расчет (в карточке договора указывается тариф по умолчанию со скидкой и безналичные правила начисления услуг). Соответственно при выборе такого виртуального договора в брони/размещении автоматически устанавливаются все важные учетные параметры, такие как: тариф, правила начисления услуг, планируемый способ оплаты, агентский процент. 
  • Контактное лицо. Тип значения: «Строка». Строка в произвольном формате, обычно ФИО и контактный телефон человека (на стороне контрагента) с которым гостиница договаривалась о брони. Если контрагент выбран, то при вводе контактного лица оно сохраняется в таблице контактных лиц карточки контрагента и назначается контактным лицом по умолчанию, т.е. при создании следующей брони/размещения и выборе этого контрагента, контактное лицо заполнится автоматически. 
  • Телефон. Тип значения: «Строка». Контактный телефон гостя или контрагента 
  • Факс. Тип значения: «Строка». Факс гостя или контрагента 
  • E-mail. Тип значения: «Строка». E-Mail гостя или контрагента. Если указан, то его можно выбрать при печати счетов-требований и подтверждений брони 
  • Группа гостей. Ссылается на справочник «Группы гостей». Один из основных учетных параметров, по которому ведутся взаиморасчеты с контрагентами. По смыслу является номером подтверждения брони. Новые группы создаются автоматически при создании новой брони или размещения. Если заезжает один человек "с улицы", то для него также создается новая группа из одного человека. Добавлять гостей в группу и редактировать условия их проживания можно на закладке "Состав группы". 
  • Путевка/курсовка. Ссылается на справочник «Путевки и курсовки». В случае если ведется учет путевок/курсовок порядок работы с этим полем следующий. При поселении гостя администратор берет очередной пустой бланк путевки, в поле "Путевка/курсовка" с клавиатуры вбивает номер бланка (с префиксом или суффиксом, так как указано на бланке) и нажимает клавишу Enter. Если в программе заведены типы путевок (группы справочника "Путевки и курсовки") или социальные показатели, то программа попросит их указать и после этого автоматически зарегистрирует путевку/курсовку в справочнике. Проверить или отредактировать параметры путевки/курсовки можно нажав на кнопку "Лупа" справа от номера путевки/курсовки. Внимание: Заранее создавать путевки/курсовки в справочнике обычно не нужно!   
  • Статус брони. Ссылается на справочник «Статусы брони». Статус брони определяет в первую очередь действующая это бронь или нет. Действующая бронь может быть гарантированной или не гарантированной. Не действующая бронь может быть в статусе "отказ", "заезд", "незаезд" (no show) или "аннуляция". По аннулированной брони программа может требовать ввода причины аннуляции. Статус "Заезд" устанавливается программой автоматически после того, как по брони заехали ВСЕ гости. Т.е. если в брони указано число человек больше одного, например 5, то пока по этой брони не заедут все 5 гостей у брони статус будет действующий (хотя число реально бронируемых номеров будет уменьшаться пропорционально числу уже заехавших гостей). Если по такой брони заедут только 4 человека, то после выполнения процедуры снятия просроченной брони ее статус будет установлен в "Незаезд". 
  • Дата заезда. Тип значения: «Дата». 
  • Продолжительность в днях или часах. Тип значения: «Число». 
  • Дата выезда. Тип значения: «Дата». 
  • Квота номеров. Ссылается на справочник «Квоты номеров». Заполняется, если гость заселен по квоте. Если заполнен, то из числа номеров в квоте документ списывает в занятые 1 номер или место (в зависимости от вида размещения). 
  • Тип номера. Ссылается на справочник «Типы номеров». Категория номера, где проживает гость 
  • Вид размещения. Ссылается на справочник «Виды размещения». Указывает как гость занимает номер: весь номер целиком, место в номере, дополнительное место (раскладушку, кресло, диван) или проживает совместно с тем, кто оплачивает весь номер. 
  • Номер. Ссылается на справочник «Номерной фонд». Номер комнаты, который будет зарезервирован за гостем. 
  • Количество. Тип значения: «Число». Если вид размещения "место" или "доп. место", то в этом реквизите указывается количество бронируемых мест, если вид размещения "номер", то количество бронируемых номеров, если вид размещения "совместно", то кол-во гостей. 
  • Количество человек. Тип значения: Сколько гостей будет проживать в номерах по этой брони (если в программе создается отдельная бронь на каждого человека то 1). 
  • Количество номеров. Тип значения: «Число». Технический реквизит. Заполняется автоматически по виду размещения и количеству номеров/мест, указываемому на первой закладке брони. 
  • Количество мест. Тип значения: «Число». Технический реквизит. Заполняется автоматически по виду размещения и количеству номеров/мест, указываемому на первой закладке брони. 
  • Количество дополнительных мест. Тип значения: «Число». Технический реквизит. Заполняется автоматически по виду размещения и количеству номеров/мест, указываемому на первой закладке брони. 
  • Количество мест в номере. Тип значения: «Число». Технический реквизит, который хранит общее кол-во мест в номере на момент создания брони. 
  • Количество гостей в номере. Тип значения: «Число». Технический реквизит, который хранит максимально возможное кол-во гостей в номере на момент создания брони.
  • Тип клиента. Ссылается на справочник «Типы клиентов». Тип клиента определяет категорию цен тарифа. 
  • Строка подтверждения для типа клиента. Тип значения: «Строка».  
  • Гость. Ссылается на справочник «Клиенты (гости)». Ссылка на карточку гостя. При бронировании рекомендуется в это поле вручную ввести фамилию (без инициалов) и нажать Enter. Программа выполнит поиск гостей с такой фамилией и откроет их список. Если в списке ничего не найдено или нет подходящего гостя, то далее можно создать новую карточку гостя. Если в списке подходящий гость есть, то его можно выбрать. 
  • Полное имя гостя. Тип значения: «Строка». Технический реквизит, содержит ФИО гостя полностью (Иванов Иван Иванович), заполняется автоматически при записи документа в базу по данным в карточке гостя. Отображается в журнале брони. Позволяет сортировать документы в журнале по ФИО гостей. 
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга». Один из основных аналитических параметров. Заполняется либо вручную, либо автоматически по параметрам тарифа или контрагента/договора. В наборах прав можно установить, что этот параметр является обязательным для ввода (право номер 104). 
  • Строка подтверждения для направления маркетинга. Тип значения: «Строка». 
  • Цель визита. Ссылается на справочник «Цели визита». Один из основных аналитических параметров. Обычно заполняется вручную. В наборах прав можно установить, что этот параметр является обязательным для ввода (право номер 103). 
  • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице». Один из основных аналитических параметров. Заполняется либо вручную, либо автоматически по параметрам тарифа или контрагента/договора. В наборах прав можно установить, что этот параметр является обязательным для ввода (право номер 105). 
  • Начислять услуги. Тип значения: «Булево». Флажок устанавливается автоматически в зависимости от статуса брони. Если включен, то при проведении брони, услуги рассчитанные по тарифу проживания из таблицы на закладке "Услуги" будут начислены на лицевые счета брони. если флажок выключен (это его обычное состояние), то услуги по действующей брони начисляются в регистры планируемых продаж. Услуги по недействующей брони никуда не начисляются и нигде не отражаются. Этот флажок в нормальных условиях эксплуатации включен только у статусов брони "Незаезд со штрафом" или "Поздняя аннуляция". Внимание: Если у брони включен флажок "Начислять услуги" и, затем, по этой брони оформлено размещение, то услуги из таблицы услуг размещения начисляться на лицевые счета не будут, т.к. считается, что все необходимые услуги уже начислены бронью.  
  • Тариф. Ссылается на справочник «Тарифы». Тариф, по которому выполняется расчет основных услуг (проживание, питание) 
  • Тип тарифа. Ссылается на справочник «Типы тарифов». Аналитический параметр. Обычно заполняется автоматически по значению в карточке тарифа. 
  • Набор услуг начисляемый по тарифу. Ссылается на справочник «Наборы услуг». Заполняется, если необходимо ограничить состав услуг, который начисляется по тарифу. Пример: в тарифе определены услуги: проживание; завтрак; обед; ужин, но необходимо, чтобы данному гостю было начислено только проживание и завтрак, тогда нужно выбрать набор услуг, куда входят проживание и завтрак и не входят обед и ужин. Если поле пустое, то начисляются все услуги указанные в приказах по тарифу и пакетах услуг. 
  • Пакет услуг. Ссылается на справочник «Пакеты услуг». Пакет услуг, который добавляется к услугам начисляемым по приказам об изменении цен тарифа. 
  • Дисконтная карта. Ссылается на справочник «Дисконтные карты». Дисконтная карта заполняется либо при ручном вводе ее номера в поле, либо автоматически по событию чтения карты на форме документа. По данным дисконтной карты заполняется тип скидки и уже по типу скидки заполняется процент и прочие параметры скидки. 
  • Тип скидки. Ссылается на справочник «Типы скидок». Тип скидки определяет процент скидки. Для получения процента скидки используется дата и время планируемого заезда гостя. 
  • Основание предоставления скидки. Тип значения: «Строка». 
  • Скидка %. Тип значения: «Число». 
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг». Заполняется, если необходимо ограничить состав услуг, к которым применяется скидка. Если поле не заполнено, то скидка будет применена ко всем услугам начисленным по тарифу. Если необходимо, чтобы скидка применялась, например, только к проживанию, то необходимо выбрать набор услуг, в который входит только проживание. 
  • Отключить автоматические скидки. Тип значения: «Булево». Если включена, то программа не будет начислять по этому размещению накопительные скидки. 
  • Планируемый способ оплаты. Ссылается на справочник «Способы оплаты». Заполняется автоматически по правилам начисления услуг. Устанавливается в способ оплаты того лицевого счета из правил начисления, на который начисляется услуга проживания. Внимание: При вводе ручных цен в таблице услуг на закладке "Услуги", программа запоминает (фиксирует) не только цену, но и лицевой счет, на который будет начислена услуга. Соответственно, если сначала установить ручные цены у услуг проживания, затем в правилах начисления нажать кнопку "Добавить безнал", то скорее всего планируемый способ оплаты у документа не изменится, т.к. услуги проживания останутся прикреплены к "старому" наличному лицевому счету. Для избежания таких ситуаций рекомендуется для указания "ручных" цен использовать закладку "Цены" и таблицу "ручных" цен, а не редактировать цены непосредственно в таблице услуг. 
  • Кредитная карта. Ссылается на справочник «Кредитные карты». 
  • Автомобиль. Тип значения: «Строка». Строка с гос. номером и маркой автомобиля, на котором приехал гость 
  • Примечания. Тип значения: «Строка». Произвольные примечания по документу 
  • Текст подтверждения/отказа в бронировании. Тип значения: «Строка». Текст объясняющий причину отказа в бронировании или описывающий дополнительные условия на которых бронирование предоставляется. Данный текст включается в тело электронного письма, которое автоматически отсылает клиенту программа по кнопке в печатной форме подтверждения/отказа в бронировании.  
  • Фирма. Ссылается на справочник «Фирмы». Юридическое лицо гостиницы по которому "пройдут" начисления и оплаты этого гостя. Обычно заполняется из карточки гостиницы или из параметров номера/типа номера или тарифа, если в гостинице принят многофирменный учет. Из этого параметра заполняется реквизит "Фирма" в лицевых счетах перечисленных в правилах начисления. 
  • Агент. Ссылается на справочник «Контрагенты». Контрагент, которому гостиница заплатит агентский процент за проживание гостя. Может как совпадать с основным контрагентом документа так и отличаться от него. 
  • Комиссия агента. Тип значения: «Число». Значение процента комиссии агента. 
  • Вид комиссии агента. Ссылается на перечисление «Виды комиссий агентам». В текущей версии поддерживается только схема начисления агентских по проценту от суммы начисленных услуг. 
  • Набор услуг, по которому начисляется комиссия агентам. Ссылается на справочник «Наборы услуг». Определяет набор услуг, по которому будет рассчитана комиссия. Если не заполнен, то комиссия рассчитывается от суммы начислений по всем услугам из тарифа.  
  • Закрыт для редактирования. Тип значения: «Булево». Если флажок включен, то пользователи с обычными правами не смогут редактировать документ. Документ у таких пользователей будет открываться только на просмотр. Для того чтобы изменить такой документ в наборе прав пользователя должен быть включен флажок с номером 025. 
  • Дата курса обмена. Тип значения: «Дата». Дата курса, по которой происходит перерасчет цен в таблице услуг документа из цен тарифа в цены в валюте лицевого счета. При ежедневном изменении курсов валют. Внимание: Цены основных услуг начисленных по тарифу в момент выселения пересчитываются по курсам на учетные даты начислений. Т.о. цены реально начисленных услуг могут отличаться от цен услуг указанных в таблице на закладке "Услуги". 
  • Отчетная валюта. Ссылается на справочник «Валюты». Валюта в которой заполняются суммы продаж аналитических регистров, т.е. валюта в которой формируются отчеты "Сводные показатели", "Доходность и загрузка" и проч. Обычно устанавливается в карточке гостиницы один раз перед началом эксплуатации программы и далее не изменяется. 
  • Курс обмена отчетной валюты по отношению к базовой валюте. Тип значения: «Число».  
  • Представление цены. Тип значения: «Строка». Строка, которая вычисляется автоматически алгоритмом начисления услуг по тарифу. Строка содержит строковое представление цены проживания за сутки по типам дней календаря или по датам, если цены у проживания редактировались вручную в таблице услуг. 
  • Главный в группе. Тип значения: «Булево». Если включен устанавливает, что все начисления по тарифу остальных гостей из группы должны выполняться на лицевые счета этого гостя. Редактируется на закладке "Состав группы" в первой строке таблицы, т.е. для того чтобы установить/снять отметку "Главный в группе" необходимо открыть карточку брони именно этого гостя и переключиться в ней на закладку "Состав группы" 
  • Тип номера для расчета цены. Ссылается на справочник «Типы номеров». Используется когда гостя селят в тип номера отличный от забронированного, но с сохранением цены указанной в брони. Если поле заполнено, то для расчета цены программа использует не категорию номера где проживает гость, а указанное здесь значение. Эта операция обычно называется "upgrade" номера. Способ заполнения поля зависит от прав пользователя. Пользователь может иметь права на установку только той категории, которая указана в брони (право номер 109) или может иметь право выбрать в этом поле любую категорию номера из доступных (право номер 110). 
  • Автор. Ссылается на справочник «Сотрудники». Сотрудник который создал документ. 
  • Не печатать тариф. Тип значения: «Булево». Если флажок включен, то в карте гостя и подтверждении брони в графе "цена" будет распечатан код тарифа, если флажок выключен, то будет распечатано представление цены. 
  • Код во внешней системе. Тип значения: «Строка». Хранит код брони в любой внешней системе. Заполнен только в случаях когда программа интегрирована с какой-либо внешней системой бронирования. 
  • Дата получения цен. Тип значения: «Дата». Хранит максимальную дату приказов об изменении цен, по которым была рассчитана таблица услуг документа. Заполняется автоматически при формировании таблицы основных услуг. Используется для защиты цен по тарифу в документе от возможных будущих изменений цен тарифа новыми приказами об изменении цены. Для того чтобы новые приказы, если такие были созданы, начали действовать на это размещение, эту дату нужно очистить, тогда она автоматически перезаполнится. Дата автоматически очищается и перезаполняется при смене тарифа или даты заезда. 
  • Условия начисления штрафов. Ссылается на справочник «Условия начисления штрафов за незаезд и позднюю аннуляцию», в котором определяются формулы расчета штрафов за незаезд и позднюю аннуляцию. По этим формулам сумма штрафа автоматически вычисляется и начисляется на лицевые счета брони при установке у брони статуса "Незаезд" (обработкой "Снятие просроченной брони" или вручную) или при установке у брони статуса "Поздняя аннуляция".  
  • Автор аннуляции. Ссылается на справочник «Сотрудники». Сотрудник, который аннулировал бронь 
  • Дата аннуляции. Тип значения: «Дата». Дата и время, когда сотрудник установил у брони статус "Аннуляция" 
  • Причина аннуляции. Ссылается на справочник «Причины выполнения типовых операций». Причина аннуляции указанная сотрудником.

Табличная часть «Цены»

Используется для установки ручных цен на услугу проживание или любые другие услуги, которые начисляются по тарифу или из пакета услуг. Ручные цены рекомендуется устанавливать именно в этой таблице, а не редактировать цены непосредственно в строках табличной части "Услуги".

  • Услуга. Ссылается на справочник «Услуги». Услуга для которой устанавливается ручная цена. В первой строке автоматически устанавливается по умолчанию в проживание. 
  • Цена. Тип значения: «Число». Значение ручной цены 
  • Валюта. Ссылается на справочник «Валюты». Валюта ручной цены 
  • Единица измерения. Тип значения: «Строка». Единица измерения ручной цены 
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях». Тип дня календаря, для которого устанавливается цена. Если поле оставить пустым, то указанная цена будет установлена у всех таких услуг в таблице услуг на закладке "Услуги"

Табличная часть «Услуги»

Содержит таблицу услуг рассчитанную по тарифу, типу номера, периоду проживания гостя и остальным параметрам документа. Именно эти услуги будут начислены гостю после поселения. Не рекомендуется редактировать непосредственно строки этой таблицы. Она носит информационный характер.

  • Лицевой счет. Ссылается на документ «Фолио». Лицевой счет (обычно из таблицы правил начисления), на который будет выполнено начисление услуги 
  • Учетная дата. Тип значения: «Дата». Учетная дата услуги 
  • Услуга. Ссылается на справочник «Услуги».  
  • Цена. Тип значения: «Число». 
  • Количество. Тип значения: «Число». 
  • Единица измерения. Тип значения: «Строка». 
  • Сумма в валюте лицевого счета. Тип значения: «Число». Сумма по услуге без учета скидки. 
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». 
  • Сумма НДС. Тип значения: «Число». 
  • Это доход от продажи номеров. Тип значения: «Булево». Истина у услуг проживания. 
  • Включать в цену. Тип значения: «Булево». Истина у услуг проживания и питания. 
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях». 
  • Расписание дня. Ссылается на справочник «Расписания». 
  • Валюта лицевого счета. Ссылается на справочник «Валюты». 
  • Курс обмена валюты лицевого счета по отношению к базовой валюте. Тип значения: «Число». 
  • Продано номеров. Тип значения: «Число». Заполняется у услуг проживания в зависимости от вида размещения текущего гостя. 
  • Продано мест. Тип значения: «Число». Заполняется у услуг проживания в зависимости от вида размещения текущего гостя. 
  • Продано дополнительных мест. Тип значения: «Число». Заполняется у услуг проживания в зависимости от вида размещения текущего гостя. 
  • Человеко-дни. Тип значения: «Число». Заполняется у услуг проживания в зависимости от вида размещения текущего гостя и от количества гостей, указанных в документе. 
  • Заезд гостей. Тип значения: «Число». Заполняется у услуги проживания, у которой учетная дата совпадает с датой заезда и в зависимости от вида размещения текущего гостя и от количества гостей, указанных в документе. 
  • Тип скидки. Ссылается на справочник «Типы скидок». Тип действующей на услугу скидки. В случае использования накопительных скидок может отличаться от типа скидки указанного в шапке документа. 
  • Скидка %. Тип значения: «Число». Процент скидки действующий на услугу. 
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг». 
  • Сумма скидки. Тип значения: «Число». 
  • НДС с суммы скидки. Тип значения: «Число». 
  • Основание предоставления скидки. Тип значения: «Строка». 
  • Комиссия в валюте лицевого счета. Тип значения: «Число». 
  • НДС с суммы комиссии. Тип значения: «Число». 
  • Примечания. Тип значения: «Строка».

  • Вид размещения. Ссылается на справочник «Виды размещения». Вид размещения по которому вычислялась цена этой услуги. Может отличаться от вида размещения из шапки документа, т.к. может быть переопределен на эту учетную дату в таблице "План услуг". 
  • Добавлена вручную. Тип значения: «Булево». Истина, если услуга в таблицу услуг была добавлена вручную кнопкой "Добавить" или "Скопировать". 
  • Ручная цена. Тип значения: «Булево». Истина, если цена услуги была отредактирована непосредственно в таблице услуг. Приводит к фиксации не только цены услуги, но и лицевого счета, на который будет выполнено начисление. 
  • Это разделение. Тип значения: «Булево». Эта услуга является второй услугой в операции разделения проживания на две услуги, начисляемые разным плательщикам. Используется для того, чтобы программа в таких случаях не задвоила количество проданных номеров и число заехавших гостей. 
  • Используется только для расчета дохода за проживание. Тип значения: «Булево». истина у таких услуг как "Поздний выезд" или "Ранний заезд", т.е. у тех услуг, начисления которых должны попадать в графу "Доход от продажи номеров" аналитических отчетов, но не должны изменять число проданных номеров и число заехавших гостей. 
  • Сумма по тарифу проживания. Тип значения: «Число». Сумма по этой же услуге рассчитанная исходя из цен по тарифу указанному в шапке документа (без учета скидок и "ручных" цен). Используется для формирования аудиторских отчетов по расхождениям реальных цен размещения от цен в согласованных с руководством тарифах. 
  • Количество изменено вручную. Тип значения: «Булево». Устанавливается автоматически у тех услуг, у которых количество в строке таблицы "Услуги" было изменено вручную. Отключает автоматический пересчет количества при изменении, например, числа гостей в документе.

Используется обычно в большой брони перед заездом группы, по которой не предоставлены списки приезжающих гостей.

  • Количество гостей в номере. Тип значения: «Число». Максимальное число гостей, которые могут проживать в номере 
  • Использован. Тип значения: «Булево». В этот номер уже поселили 
  • Размещение. Ссылается на документ «Размещение». Размещение, которым гостя поселили в этот номер

Формы

  • Форма списка. Основная форма журнала брони. Используется для поиска брони или просмотра брони созданной сотрудником за период. 
  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов. 
  • Форма подтверждения брони. Печатная форма подтверждения брони. Это детальная форма, которая показывает параметры брони по каждому гостю из группы 
  • Форма подтверждения брони с услугами. Печатная форма подтверждения брони. Это краткая форма, которая группирует гостей перед печатью по условиям проживания, т.е. выводит перечислением фамилий тех гостей, у кого совпадает период проживания, тип номера, вид размещения и тариф 
  • Форма аннуляции брони. Печатная форма отказа в бронировании. 
  • Форма платежного поручения. Печатная форма платежного поручения на стоимость брони в виде квитанции для оплаты через Сбербанк РФ

Дополнительная информация

Если необходимо забронировать номера для группы гостей с различными условиями проживания, то, после ввода данных по первой бронируемой категории номеров или по первому гостю, необходимо переключиться на закладку состав группы и добавить в таблицу группы новые строки с нужными условиями. При проведении брони на каждую строку в таблице группы будет создан отдельный документ. Номер группы у всех таких документов будет совпадать.
