Документ "Бронь ресурса"

Назначение

Документ используется для бронирования ресурсов: конференц-залов, саун, кабинетов и т.д.

Относится к подсистеме: «Ресурсы».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Непериодический

Тип номера: Строка

Вводится на основании: «Размещение», «Шаблоны операций».

Реквизиты

  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение». Обычно не заполняется.
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Контрагент. Ссылается на справочник «Контрагенты». Контрагент, который бронирует ресурс. Если указан способ оплаты "На расчетный счет", то этот контрагент будет являться плательщиком.
  • Тип контрагента. Ссылается на справочник «Типы контрагентов». Аналитический параметр, используется в отчетах планового отдела. Заполняется автоматически значением из карточки контрагента.
  • Договор. Ссылается на справочник «Договоры». Договор с выбранным контрагентом.
  • Контактное лицо. Тип значения: «Строка». Строка в произвольном формате, обычно ФИО и контактный телефон человека (на стороне контрагента) с которым гостиница договаривалась о брони. Если контрагент выбран, то при вводе контактного лица оно сохраняется в таблице контактных лиц карточки контрагента и назначается контактным лицом по умолчанию, т.е. при создании следующей брони ресурсов и выборе этого контрагента, контактное лицо заполнится автоматически.
  • Телефон. Тип значения: «Строка». Контактный телефон гостя или контрагента
  • Факс. Тип значения: «Строка». Факс клиента или контрагента
  • E-mail. Тип значения: «Строка». E-Mail клиента или контрагента. Если указан, то его можно выбрать при печати счетов-требований и заказов на мероприятие
  • Группа гостей. Ссылается на справочник «Группы гостей». Один из основных учетных параметров, по которому ведутся взаиморасчеты с контрагентами. По смыслу является номером подтверждения брони. Новые группы создаются автоматически при создании новой брони ресурса. По номеру группы можно объединять бронь ресурсов и бронь номеров. В этом случае после выезда гостей и оказания всех услуг по мероприятию, по группе можно создать один акт об оказании услуг.
  • Статус брони ресурсов. Ссылается на справочник «Статусы брони ресурсов». Статус брони определяет в первую очередь действующая это бронь или нет. Действующая бронь может быть гарантированной или не гарантированной и по ней могут начисляться услуги на лицевой счет брони. Если у статуса брони установлен флажок "Услуги оказаны", то такая бронь считается "закрытой" и по ней процедурой закрытия периода формируются акты об оказании услуг. Статус "Услуги оказаны" является аналогом статуса размещения "Выезд". Этот статус может устанавливаться либо вручную, либо регламентной процедурой "Обработка завершенной брони ресурсов". Не действующая бронь может быть в статусе "Отказ", "Аннуляция". Статус "Аннуляция" используется в случаях, когда бронь была создана по ошибке.
  • Время начала брони. Тип значения: «Дата». Дата и время начала периода бронирования
  • Продолжительность в часах. Тип значения: «Число». Продолжительность периода бронирования в часах
  • Время окончания брони. Тип значения: «Дата». Дата и время окончания периода бронирования
  • Тип ресурса. Ссылается на справочник «Типы ресурсов». Тип бронируемого ресурса.
  • Ресурс. Ссылается на справочник «Ресурсы». Бронируемый ресурс. Поля тип ресурса и ресурс не обязательные. Бронь ресурсов может быть создана без указания бронируемых ресурсов для того, чтобы часть бронируемых услуг "провести" по другому контрагенту или отдельному способу оплаты.
  • Количество человек. Тип значения: «Число». Количество человек на которое бронируется ресурс. Обязательно для заполнения в случаях, когда стоимость услуг аренды ресурса зависит от числа клиентов.
  • Тип клиента. Ссылается на справочник «Типы клиентов». Определяет категорию используемых цен ресурса. 
  • Строка подтверждения для типа клиента. Тип значения: «Строка». 
  • Клиент. Ссылается на справочник «Клиенты (гости)». Клиент, на которого бронируется ресурс. Указывается в печатной форме лицевого счета и в печатной форме заказа на мероприятие
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга». Аналитический параметр. Заполняется вручную или наследуется из карточки контрагента/договора.
  • Строка подтверждения для направления маркетинга. Тип значения: «Строка». 
  • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице». Аналитический параметр. Заполняется вручную или наследуется из карточки контрагента/договора.
  • Начисляемый набор услуг. Ссылается на справочник «Наборы услуг». Если заполнен позволяет ограничить состав автоматически начисляемых услуг только тем набором, который перечислен в элементе справочника.
  • Пакет услуг. Ссылается на справочник «Пакеты услуг». Является аналогом тарифа в обычной брони. Определяет какие услуги и по каким ценам должны быть начислены по брони ресурсов.
  • Дисконтная карта. Ссылается на справочник «Дисконтные карты». Дисконтная карта заполняется либо при ручном вводе ее номера в поле, либо автоматически по событию чтения карты на форме документа. По данным дисконтной карты заполняется тип скидки и уже по типу скидки заполняется процент и прочие параметры скидки. 
  • Тип скидки. Ссылается на справочник «Типы скидок». Тип скидки определяет процент скидки. Для получения процента скидки используется дата и время начала периода брони.
  • Основание предоставления скидки. Тип значения: «Строка». 
  • Скидка %. Тип значения: «Число».
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг». Заполняется, если необходимо ограничить состав услуг, к которым применяется скидка. Если поле не заполнено, то скидка будет применена ко всем услугам перечисленным в таблице услуг на закладке "Услуги". Если необходимо, чтобы скидка применялась, например, только к аренде, то необходимо выбрать набор услуг, в который входит только эта услуга.
  • Отключить автоматические скидки. Тип значения: «Булево». Позволяет отключить применение к документу автоматических накопительных скидок.
  • Планируемый способ оплаты. Ссылается на справочник «Способы оплаты». Определяет планируемый способ оплаты услуг по лицевому счету указанному в документе. При выбранном контрагенте и способе оплаты "наличные" или "кредитная карта" считается, что услуги оплачиваются клиентом. В этом случае реквизит "Владелец фолио" остается установлен в "Физ. лица". Если в способе оплаты включен флажок "Оплата от контрагента" (по умолчанию он установлен у способа оплаты "На расчетный счет"), то считается, что выбранный контрагент является плательщиком по брони и на закладке "Услуги" реквизит "Владелец фолио" заполняется выбранным контрагентом.
  • Кредитная карта. Ссылается на справочник «Кредитные карты».
  • Начислять услуги. Тип значения: «Булево». Устанавливается автоматически по выбранному статусу брони ресурсов.
  • Фирма. Ссылается на справочник «Фирмы». Фирма, которая будет установлена в лицевом счете брони.
  • Автомобиль. Тип значения: «Строка». Строка с гос. номером и маркой автомобиля, на котором приехал клиент
  • Примечания. Тип значения: «Строка». Произвольные примечания по документу. Выводятся в печатной форме заказа на мероприятие.
  • Текст подтверждения/отказа в бронировании. Тип значения: «Строка». Текст объясняющий причину отказа в бронировании или описывающий дополнительные условия на которых бронирование предоставляется. Данный текст включается в тело электронного письма, которое автоматически отсылает клиенту программа по кнопке в печатной форме заказа на мероприятие.
  • Агент. Ссылается на справочник «Контрагенты». Контрагент, которому гостиница заплатит агентский процент за аренду ресурса. Может как совпадать с основным контрагентом документа, так и отличаться от него.
  • Комиссия агента. Тип значения: «Число». Значение процента комиссии агента.
  • Вид комиссии агента. Ссылается на перечисление «Виды комиссий агентам». В текущей версии поддерживается только схема начисления агентских по проценту от суммы начисленных услуг.
  • Набор услуг, по которому начисляется комиссия агентам. Ссылается на справочник «Наборы услуг». Определяет набор услуг, по которому будет рассчитана комиссия. Если не заполнен, то комиссия рассчитывается от суммы начислений по всем услугам из таблицы услуг документа.
  • Закрыт для редактирования. Тип значения: «Булево». Если флажок включен, то пользователи с обычными правами не смогут редактировать документ. Документ у таких пользователей будет открываться только на просмотр. Для того чтобы изменить такой документ в наборе прав пользователя должен быть включен флажок с номером 025.
  • Дата курса обмена. Тип значения: «Дата». Дата курса, по которой происходит перерасчет цен в таблице услуг документа из цен ресурса или цен услуг в пакетах.
  • Отчетная валюта. Ссылается на справочник «Валюты». Валюта в которой заполняются суммы продаж аналитических регистров, т.е. валюта в которой формируются отчеты "Сводные показатели", "Доходность и загрузка" и проч. Обычно устанавливается в карточке гостиницы один раз перед началом эксплуатации программы и далее не изменяется.
  • Курс обмена отчетной валюты по отношению к базовой валюте. Тип значения: «Число».
  • Представление цены. Тип значения: «Строка». Строка, которая вычисляется автоматически алгоритмом начисления услуг по документу. Строка содержит строковое представление цены аренды ресурса за час.
  • Владелец лицевого счета. Ссылается на справочники «Договоры», «Контрагенты». Определяет контрагента-плательщика услуг по документу. Проставляется при проведении документа в лицевой счет документа. Если услуги оплачиваются клиентом наличными или кредитной картой, то в этом поле указывается контрагент "Физ. лица". Если в брони контрагент указан и способ оплаты "На расчетный счет", то этот контрагент устанавливается в качестве владельца лицевого счета. Это поле может редактироваться вручную и может отличаться от контрагента/договора указанных на первой закладке документа.
  • Код во внешней системе. Тип значения: «Строка». Код брони в любой внешней системе бронирования
  • Начислять на лицевой счет. Ссылается на документ «Фолио». Лицевой счет, на который начисляться услуги из таблицы услуг документа при его проведении при условии, что в документе включен флажок "Начислять услуги".
  • Валюта лицевого счета. Ссылается на справочник «Валюты». Валюта выбранного в документе лицевого счета.
  • Курс обмена валюты лицевого счета по отношению к базовой валюте. Тип значения: «Число».
  • Вид расстановки мебели. Ссылается на справочник «Варианты расстановки мебели». Определяет вид расстановки столов/стульев при бронировании конференц-залов или мед. кабинетов.
  • Начислять услуги игнорируя запреты начислений. Тип значения: «Булево». У услуг в таблице услуг документа может быть выбран тип услуги с включенным флажком "Не начислять на лицевые счета из брони ресурсов". Если в документе флажок "Начислять услуги" включен, а флажок "Начислять услуги игнорируя запреты начислений" выключен, то такие услуги при проведении документа начислены на лицевой счет не будут. Если флажок "Начислять услуги игнорируя запреты начислений" включить, то на лицевой счет будут начислены все услуги из таблицы услуг документа.
  • Автор. Ссылается на справочник «Сотрудники». Сотрудник, который создал документ.

Табличная часть «Услуги»

  • Ид услуги. Тип значения: «Строка». Уникальный 36 символьный UUID услуги. Используется для привязки к услуге позиций меню из табличной части "Позиции меню"
  • Учетная дата. Тип значения: «Дата». Учетная дата услуги, переносится в дату начисления при начислении услуги на лицевой счет документа. 
  • Услуга. Ссылается на справочник «Услуги». Услуга, которая будет начислена на лицевой счет
  • Позиция меню. Тип значения: «Строка», Ссылается на справочник «Позиции меню». Позиция меню, которая будет распечатана под названием услуги в заказе на мероприятие
  • Цена. Тип значения: «Число». Цена услуги
  • Цена в базовой валюте. Тип значения: «Число». Цена услуги в базовой валюте. используется в случаях, когда валюта лицевого счета отличается от базовой, но необходимо знать и соответствующую ей цену в базовой валюте для выгрузки заказа, например, в Фронт Офис ресторана
  • Количество. Тип значения: «Число». Количество услуги
  • Единица измерения. Тип значения: «Строка». Единица измерения услуги
  • Сумма в валюте лицевого счета. Тип значения: «Число». Сумма по услуге в валюте лицевого счета.
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». Ставка НДС услуги.
  • Сумма НДС. Тип значения: «Число». Сумма НДС по услуге
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях». Тип дня выбранного в ресурсе календаря на учетную дату услуги
  • Расписание дня. Ссылается на справочник «Расписания». Расписание дня выбранного в ресурсе календаря на учетную дату услуги
  • Время начала брони. Тип значения: «Дата». Обычно совпадает с датой и временем начала периода брони ресурса из шапки документа.
  • Время окончания брони. Тип значения: «Дата». Обычно совпадает с датой и временем окончания периода брони ресурса из шапки документа. 
  • Продано часов работы ресурса. Тип значения: «Число». Заполняется автоматически у услуг, у которых включен флажок "Это доход от продажи ресурсов". Указывает сколько часов аренды ресурса будет оплачено по данной услуге. Используется в аналитических отчетах по продаже ресурсов
  • Тип скидки. Ссылается на справочник «Типы скидок». Тип скидки действующий на услугу. Может отличаться от типа скидки в шапке документа, например может быть типом автоматической накопительной скидки.
  • Скидка %. Тип значения: «Число». Действующий на услугу процент скидки
  • Группа услуг, на которую действует скидка. Ссылается на справочник «Наборы услуг». Набор услуг действующей скидки
  • Сумма скидки. Тип значения: «Число». Сумма скидки.
  • НДС с суммы скидки. Тип значения: «Число». НДС вычисленный от суммы скидки
  • Основание предоставления скидки. Тип значения: «Строка».
  • Комиссия в валюте лицевого счета. Тип значения: «Число». Сумма комиссии агенту по услуге
  • НДС с суммы комиссии. Тип значения: «Число». НДС с суммы комиссии
  • Примечания. Тип значения: «Строка». Описание услуги
  • Фирма. Ссылается на справочник «Фирмы». Фирма услуги
  • Это доход от продажи ресурсов. Тип значения: «Булево». Устанавливается у услуг, которые отражают аренду ресурса.
  • Добавлена вручную. Тип значения: «Булево». Устанавливается у услуг добавленных вручную в таблицу услуг документа (кнопкой "Добавить").
  • Ручная цена. Тип значения: «Булево». Устанавливается у услуг начисленных автоматически, но у которых цена изменена вручную в таблице услуг документа.
  • Время начала услуги. Тип значения: «Дата». Время начала оказания услуги внутри периода бронирования. Используется, например, для указания времени начала кофе-брейка внутри периода аренды конференц-зала. Используется в печатной форме заказа на мероприятие.
  • Время окончания услуги. Тип значения: «Дата». Время окончания оказания услуги внутри периода бронирования. Используется, например, для указания времени окончания кофе-брейка внутри периода аренды конференц-зала. Используется в печатной форме заказа на мероприятие. 
  • Ресурс услуги. Тип значения: «Строка», Ссылается на справочник «Ресурсы». Может заполняться для того, чтобы в заказе на мероприятие показать, что услуга "Кофе-брейк" оказывается, например, не в бронируемом конференц-зале, а в коридоре или зале какого-либо ресторана. Указанный здесь ресурс не бронируется, а лишь указывается в печатной форме заказа на мероприятие.
  • Вид расстановки мебели. Ссылается на справочник «Варианты расстановки мебели». Вариант расстановки столов/стульев в ресурсе услуги.

Табличная часть «Пакеты услуг»

  • Пакет услуг. Ссылается на справочник «Пакеты услуг». В таблице перечисляются пакеты, услуги из которых должны автоматически начисляться по этой брони

Табличная часть «Позиции меню»

Позиции меню являются подчиненными услугам из таблицы услуг. Связь между позициями меню и услугами устанавливается автоматически при помощи уникального идентификатора, который автоматически назначается любой услуге в таблице услуг документа. Позиции меню задают обычно перечень блюд, которые входят, например, в услугу "Праздничный обед" или услугу "Кофе-брейк". Позиции меню печатаются в заказе на мероприятие в качестве детализации услуги.

  • Ид услуги. Тип значения: «Строка». Идентификатор услуги из таблицы услуг к которой "привязана" текущая позиция меню
  • Позиция меню. Тип значения: «Строка», Ссылается на справочник «Позиции меню». Позиция меню, которая входит в услугу
  • Выход. Тип значения: «Строка». Выход блюда в граммах/миллилитрах по данной позиции меню (блюду)
  • Цена. Тип значения: «Число». Цена блюда в составе услуги. Сумма стоимостей всех позиций меню услуги должна совпадать с ценой услуги
  • Цена в базовой валюте. Тип значения: «Число». Цена позиции меню в базовой валюте
  • Валюта. Ссылается на справочник «Валюты». Валюта цены позиции меню
  • Количество. Тип значения: «Число». Количество позиций меню в единице услуги
  • Единица измерения. Тип значения: «Строка». Единица измерения позиций меню
  • Сумма. Тип значения: «Число». Сумма по строке позиции меню

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма списка. Основная форма журнала брони ресурсов. Используется для поиска брони или просмотра списка брони созданной сотрудником за выбранный период времени.
  • Форма подтверждения брони ресурсов. Печатная форма заказа на мероприятие. Для клиента может печататься одним документом, а для служб гостиницы может быть распечатана по дням. В варианте печати по дням является заданием для служб гостиницы на подготовку мероприятия.
  • Форма платежного поручения. Форма платежного поручения сбер. банка РФ на оплату стоимости брони ресурса
  • Позиции меню. Форма редактирования состава позиций меню услуги документа. При сохранении позиций меню услуги также проводится и сохраняется вся бронь ресурсов.

Способ вызова

Вызывается из основного меню программы по кнопке "Еще../Бронь ресурсов"

Движения

  • «Прогноз продаж».
  • «История бронирования ресурсов». 
  • «Прогноз реализации».

Дополнительная информация

Документ может создаваться и редактироваться либо в графическом календаре бронирования ресурсов либо в обычном журнале. Открыть журнал брони ресурсов можно из панели инструментов календаря по кнопке "Журнал".
