Документ "Возврат"

Назначение

Документ используется для оформления возвратов платежей по лицевым счетам. Печатается комплект документов на возврат - Заявление, Акт КМ-3 и РКО.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Фолио», «Платеж».

Реквизиты

  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение».
  • Лицевой счет. Ссылается на документ «Фолио». Указывает счет, по которому проводится возврат
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Фирма. Ссылается на справочник «Фирмы». Указывается фирма, по кассе которой проводится возврат.
  • Плательщик. Ссылается на справочники «Клиенты (гости)», «Контрагенты». Заполняется автоматически значением из фолио, но может быть изменено пользователем для целей печати.
  • Контрагент в бухгалтерии. Ссылается на справочник «Контрагенты». Заполняется значением из Фолио. Если в фолио контрагент не указан, то это означает, что возврат оформляется частному лицу, при этом подставляется контрагент "Физ.лица" для выгрузки в бухгалтерию
  • Договор в бухгалтерии. Ссылается на справочник «Договоры». Заполняется значением из фолио или основным договором контрагента.
  • Группа гостей. Ссылается на справочник «Группы гостей». Заполняется значением из фолио
  • Секция оплаты. Ссылается на справочник «Секции оплаты». Заполняется значением из фолио или платежа по которому оформляется возврат. Используется для разделения платежей по разным секциям ККМ. В случае если платеж был проведен по секции, возврат необходимо оформлять по той же секции.
  • Способ оплаты. Ссылается на справочник «Способы оплаты». Выбирается пользователем. Если у способа оплаты выключен флажок "Пробивать чек", то при проведении документа не будет пробиваться чек по ККМ.
  • Ставка НДС %. Ссылается на справочник «Ставки НДС». Заполняется из фолио или платежа, на основании которого делается возврат. 
  • Сумма в валюте документа. Сумма возврата в выбранной валюте.
  • Сумма НДС. Рассчитана по выбранной ставке НДС.
  • Сумма в валюте лицевого счета. Пересчитанное значение суммы по курсу на дату курса. 
  • Сумма НДС в валюте лицевого счета.
  • Дата курса обмена. На указанную дату определяется курс. Обычно равна дате курса платежа.
  • Валюта. Ссылается на справочник «Валюты». В выбранной валюте выдается возврат.
  • Курс обмена валюты платежа по отношению к базовой валюте. 
  • Валюта лицевого счета. Ссылается на справочник «Валюты». Заполняется из фолио.
  • Курс обмена валюты лицевого счета по отношению к базовой валюте. Используется для пересчета валюты. 
  • ККМ. Ссылается на справочник «Контрольно-Кассовые Машины». По указанной ККМ будет пробит чек (если так настроен способ оплаты) и возврат будет отражен в отчете кассира по выбранной ККМ.
  • Документ оплаты. Ссылается на документ «Платеж». На основании указанного платежа оформляется возврат. Обязательно указывать, если возврат оформляется на полную сумму чека. Также обязательно указывать, если валюта взаиморасчетов отличается от базовой, т.к. в этом случае возврат выполняется по курсу на дату платежа.
  • Кредитная карта. Ссылается на справочник «Кредитные карты». Выбирается из списка карт, привязанных к клиенту; либо вводится новая карта, при выполнении голосовой авторизации; либо заполняется автоматически при выполнении возврата с помощью драйвера работы с терминалом банка. Используется для сверки платежей по картам с банком.
  • Референс номер операции. Заполняется кассиром вручную по данным со слипа операции, распечатанного банковским терминалом в случае одобрения операции. При использовании драйвера работы с банковскими терминалами реквизит заполняется автоматически.
  • Код авторизации операции. Заполняется кассиром вручную по данным со слипа операции, распечатанного банковским терминалом в случае одобрения операции. При использовании драйвера работы с банковскими терминалами реквизит заполняется автоматически.
  • Примечания. Комментарий к документу. Обычно указывают причину возврата.
  • Текст слипа. Заполняется автоматически при использовании драйвера работы с банковскими терминалами. Используется для печати слипа на кассовой ленте ККМ.
  • Счет-требование. Ссылается на документ «Счет-требование». Указывает счет на оплату, по которому был первоначальный платеж.
  • Код во внешней системе. Используется для обмена данными с внешними системами.
  • Тип карты. Ссылается на справочник «Типы кредитных карт». Заполняется по данным картам. Используется в отчетах для сверки с банком, как аналитика при выгрузке в бухгалтерию
  • Автор. Ссылается на справочник «Сотрудники». Пользователь оформивший документ.

Табличная часть «Платежные секции»

Показывается и используется только в случае, когда в параметрах гостиницы включен флажок "Вести баланс лицевых счетов по секциям". Таблица, при вводе нового документа, заполняется остатками по секциям по выбранному лицевому счету, либо копируется из Платежа, на основании которого оформляется возврат.

  • Секция оплаты. Ссылается на справочник «Секции оплаты». Заполняется при наличии баланса по секции. При добавлении строк вручную может выбираться из списка.
  • Сумма в валюте документа. Указывается сумму, которую нужно провести по выбранной секции.
  • Ставка НДС %. Заполняется значением из свойств секции. 
  • Сумма НДС. Рассчитывается по выбранной ставке.
  • Сумма в валюте лицевого счета. Рассчитывается по курсу валюты (в форме документа не отображается).
  • Сумма НДС в валюте лицевого счета. Рассчитывается по выбранной ставке НДС (в форме документа не отображается)

Способ вызова

В списке транзакций лицевого счета по кнопке "Возврат"

Журналы отображающие документ: «Журнал взаиморасчетов с контрагентами».

Движения

  • «Распределение платежей по услугам». Вспомогательный регистр для отчета "Распределение платежей по услугам".
  • «Взаиморасчеты по счетам». Движения выполняются в случае, если возврат был введен с указанием счета-требования. 
  • «Выручка по кассовым сменам». Регистр для формирования отчета кассира.
  • «Взаиморасчеты». Основной регистр для ведения взаиморасчетов по лицевым счетам (фолио) гостей.
  • «Платежи». Оборотный регистр для отчета "Платежи"
  • «Наличность в кассах». Регистр для формирования отчета кассира.
  • «Взаиморасчеты с контрагентами». Движения по контрагенту, договору и группе указанным в параметрах возврата.
  • «Депозиты». Вспомогательный регистр для формирования таблицы "Платежи" в списке транзакций лицевого счета
