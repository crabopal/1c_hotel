Документ "Рассылка сообщений"

Назначение

Документ используется для рассылки однотипных СМС или E-Mail сообщений списку клиентов/контрагентов. В шапке документа указывается текст шаблона сообщения, в табличной части документа перечисляются телефонные номера или E-Mail адреса, на которые необходимо выполнить рассылку. В каждой строке документа указывается текст сообщения (заполненный по шаблону), которое будет отправлено этому адресату.

Относится к подсистеме: «Управление СМС».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Непериодический

Тип номера: Строка

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Вид рассылки. Ссылается на перечисление «Виды рассылок сообщений». Поле обязательно для заполнения. Должно быть либо "E-Mail" либо "СМС". 
  • По контрагентам. Тип значения: «Булево». Если флажок выключен, то рассылка выполняется по гостям отеля. Если включен, то по контрагентам. 
  • Шаблон сообщений. Ссылается на справочник «Шаблоны сообщений». Необязательное для заполнения поле. При выборе текст шаблона подставляется в поле "Шаблон текста сообщения". Если заполнено позволяет формировать отчет по статистике отправленных СМС в разрезе шаблонов (типов сообщений). В режиме отправки E-Mail сообщений наименование шаблона используется в качестве темы письма.
  • Текст шаблона сообщения. Тип значения: «Строка». Содержит текст шаблона сообщения. Шаблон может содержать подстановочные выражения. При заполнении документа для каждого получателя текст сообщения формируется на основании шаблона заменой подстановочных выражений на соответствующие этому клиенту значения. Перечень возможных подстановочных выражений указан ниже.
  • Примечания. Тип значения: «Строка». Произвольные примечания к документу. Примечания показываются в журнале документов.
  • Статус. Ссылается на перечисление «Статусы рассылки сообщений». Статус может быть: "Новый" - устанавливается у новых документов. "Частично отправлен" - означает, что в процессе отправки сообщений были ошибки и часть сообщений не дошла до адресата/шлюза. "Отправлен" - означает, что все сообщения документа успешно отправлены по E-Mail или получены шлюзом СМС рассылки. 
  • Автор. Ссылается на справочник «Сотрудники». Сотрудник, который создал документ.
  • Отправитель. Строка. Не обязательный для заполнения реквизит. Если указан, то показывается в СМС как его отправитель. Может быть, например, названием гостиницы или любым телефонным номером. Если указан телефонный номер, то на него клиент может, при получении СМС от отеля, отправить ответное сообщение.

Табличная часть «Получатели»

  • Телефонный номер. Номер телефона куда будет отправлен СМС. Строка длиной максимум 15 цифр в формате <Код страны><Код города><Номер> без символов разделителей и знака "+". Пример: 74957654321 для отправки на московский номер. 
  • E-Mail. Строка E-Mail адреса, на который будет отправлено сообщение.
  • Текст сообщения. Тип значения: «Строка». Текст СМС/E-Mail сообщения, которое будет отправлено.
  • Отправлено. Тип значения: «Булево». Устанавливается в "Истина" если сообщение успешно получено шлюзом СМС рассылки/почтовым сервером. Если при отправке сообщения произошла ошибка, то она указывается в колонке "Результат".
  • Результат. Тип значения: «Строка». Содержит описание ошибки отправки сообщения.
  • ID сообщения. Тип значения: «Строка». Заполняется автоматически при успешной отправки СМС сообщения в шлюз и является уникальным идентификатором сообщения, по которому в дальнейшем можно получить статус доставки сообщения получателю.
  • Клиент. Ссылается на справочник «Клиенты». Заполняется обычно автоматически алгоритмом заполнения и содержит ссылку на клиента, которому отправляется сообщение. Не обязательно для заполнения. Используется и доступно при выключенном флажке "По контрагентам".
  • Документ клиента. Ссылается на бронь или размещение. Заполняется обычно автоматически алгоритмом заполнения и содержит ссылку на документ, по которому клиент проживал в отеле, или ссылку на действующую бронь этого клиента. Используется программой для работы механизма поиска и замены подстановочных выражений, таких как &CheckInDate и т.д. Не обязательно для заполнения.
  • Контрагент. Ссылается на справочник «Контрагенты». Заполняется обычно автоматически алгоритмом заполнения и содержит ссылку на контрагента, которому отправляется сообщение. Не обязательно для заполнения. Используется и доступно при включенном флажке "По контрагентам".
  • Кол-во сегментов. Число. Кол-во сегментов из которых состояло СМС сообщение
  • Стоимость. Число. Стоимость отправки СМС сообщения.

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма списка. Основная форма журнала документов. Используется для отображения списка или выбора документов данного типа.

Способ вызова

Вызывается из меню "СМС/Рассылка сообщений" или из главного меню программы по кнопке "Сообщения", кнопка "Рассылка сообщений".

Движения

  • При успешной отправке сообщения в СМС шлюз документ добавляет запись в регистр «СМС сообщения».

Дополнительно

В тексте шаблонов сообщений возможно использование следующих подстановочных выражений:

  • &FirstName. Имя клиента, например "Иван"
  • &SecondName. Фамилия клиента, например "Иванов"
  • &LastName. Отчество клиента, например "Иванович"
  • &CheckInDate. Дата заезда гостя в гостиницу
  • &CheckOutDate. Дата выезда гостя из гостиницы
  • &Duration. Продолжительность проживания гостя в днях
  • &GuestGroup. Номер группы гостя
  • &GroupTotalAmount. Общая сумма оказываемых по группе услуг
  • &Room. Номер комнаты где проживает гость
  • &FolioBalance. Баланс по лицевым счетам гостя
  • &Dear. Строка обращения к клиенту в зависимости от его пола: "уважаемый" или "уважаемая". Если данное выражение стоит первым словом в тексте шаблона или с этого слова начинается новое предложение, то слово уважаемый будет подставлено с заглавной буквой "У".
  • &PaymentAmount. Строка с представлением суммы платежа при отправке СМС сообщения из документов регистрации оплаты

Для вызова мастера автоматического заполнения документа необходимо нажать либо на кнопку "Заполнить по клиентам (F5)" в правой панели кнопок на форме документа либо на кнопку "Заполнить по контрагентам (Ctrl+F5)". Примеры алгоритмов отбора гостей, которые могут быть реализованы через форму мастера:

  • Список гостей у которых сегодня день рождения
  • Список проживающих гостей по типу клиента/группе/контрагенту
  • Список заехавших гостей по дате/типу клиента/группе/контрагенту
  • Список заезжающих гостей по брони по дате/типу клиента/группе/контрагенту
