Форма используется для указания условий отбора гостей, которым необходимо выполнить рассылку СМС или E-Mail сообщений. Открыть форму можно из документа "Рассылка сообщений" по кнопке "Заполнить" в правой панели инструментов формы документа.

На форме сначала необходимо указать период проживания и выбрать тип отбора гостей по периоду. Программа позволяет отобрать гостей, которые заезжали/заедут в указанном периоде, выехали или проживали/проживают. Если указан период с пустой датой окончания периода или с датой в будущем, то программа будет обрабатывать действующие брони. Если указан период в прошлом, то обрабатывается только архив размещений. Также программа позволяет отбирать карточки клиентов по дате их регистрации в программе. В этом случае программа обрабатывает все карточки, а не только те, по которым есть действующие брони/размещения.

После того как период указан, необходимо указать дополнительные условия поиска гостей. Например, если на форме выбрать тип клиента, то программа будет отбирать только тех гостей, у которых в карточке клиента указан тип совпадающий с выбранным. Разные условия поиска, если указаны одновременно, объединяются через логическое "И". При необходимости использовать логическое "ИЛИ" можно сначала выполнить отбор по одному условию и, затем, выключив галочку "Сначала очистить список получателей сообщений" выполнить отбор по второму условию.

Важно: программа отбирает только те карточки гостей, которые не помечены на удаление, у них заполнено поле "Телефон" или "E-Mail" и на закладке "Параметры" выключена галочка "Отказ от рассылок"

На верхней панели инструментов формы находятся кнопки, которые позволяют сохранить текущие настройки в справочник действий на формах объектов. После того как настройка поиска сохранена, ее может использовать любой сотрудник отеля. Список настроек открывается кнопкой "Действия" в правой панели инструментов документа "Рассылка сообщений".
