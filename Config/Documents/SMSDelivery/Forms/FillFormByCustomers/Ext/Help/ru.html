Форма используется для указания условий отбора контрагентов, которым необходимо выполнить рассылку СМС или E-Mail сообщений. Открыть форму можно из документа "Рассылка сообщений" по кнопке "Заполнить по контрагентам" в правой панели инструментов формы документа.

На форме сначала необходимо указать период отбора контрагентов по дате регистрации контрагента в программе. Если оставить даты пустыми, то в будут обрабатываться все контрагенты.

После того как период указан, необходимо указать дополнительные условия поиска. Например, если на форме выбрать тип контрагента, то программа будет отбирать только тех контрагентов, у которых в карточке указан тип совпадающий с выбранным. Разные условия поиска, если указаны одновременно, объединяются через логическое "И". При необходимости использовать логическое "ИЛИ" можно сначала выполнить отбор по одному условию и, затем, выключив галочку "Сначала очистить список получателей сообщений", выполнить отбор по второму условию.

Важно: программа отбирает только те карточки контрагентов, которые не помечены на удаление и у них указан телефон или E-Mail.

На верхней панели инструментов формы находятся кнопки, которые позволяют сохранить текущие настройки в справочник действий на формах объектов. После того как настройка поиска сохранена, ее может использовать любой сотрудник отеля. Список настроек открывается кнопкой "Действия" в правой панели инструментов документа "Рассылка сообщений".
