Документ "Установить блокировку"

Назначение

Документ устанавливает блокировку на номер на указанный период времени. Заблокированные номера снимаются с продажи и уменьшают остаток номеров в продаже.

В поле "Вид блокировки" указывается причина из справочника видов блокировок, а в поле "примечания" указывается детальное описание проблемы/работ в номере.

При необходимости снять блокировку номера необходимо открыть уже созданный документ установки блокировки, исправить дату и время окончания действия блокировки, включить флажок "Завершен" и перепровести документ.

Примеры блокировок: ремонт, аренда, ...

Относится к подсистеме: «Стойка администратора».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Виды блокировки номеров», «Номерной фонд».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы». Указывает, к какой гостинице относится номер на блокировке.
  • Номер. Ссылается на справочник «Номерной фонд». Номер, который необходимо заблокировать.
  • Вид блокировки номера . Ссылается на справочник «Виды блокировки номеров». Указывает вид блокировки.
  • Дата и время начала периода блокировки. Начиная с этой даты и времени номер снимается с продажи.
  • Продолжительность в днях. Вычисляется по времени начала и времени окончания. Если ввести число, то дата окончания будет рассчитана автоматически.
  • Дата и время окончания периода блокировки. Начиная с этой даты номер возвращается в продажу и его можно бронировать.
  • Завершен. Выставляется по окончании блокировки. При включении галочки дата и время окончания периода блокировки автоматически заполняются текущим временем.
  • Примечания. Комментарий к блокировке. Указывается причина, по которой номер поставили на блокировку.
  • Автор. Ссылается на справочник «Сотрудники». Пользователь создавший документ.

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.

Способ вызова

Открыть карточку номера в Номерном фонде, на закладке "Блокировки" кнопка "Добавить"

Движения
