Документ "Состав квоты"

Назначение

Документ устанавливает количество добавленных в квоту или списанных из квоты номеров. Изменение количества номеров в квоте выполняется на указанном в документе периоде. Документ можно вводить/редактировать вручную, но удобнее использовать специальную графическую форму работы с квотами. В этой форме достаточно выделить мышкой нужный период в строке категории номера, указать количество номеров и нажать на кнопку "Добавить" или "Убрать".

Относится к подсистеме: «Продажи квот номеров».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: справочник «Квоты номеров», документ «Состав квоты».

Объекты, вводимые на основании: «Состав квоты».

Реквизиты

  • Документ основание. Ссылается на документ «Состав квоты». Обычно не используется. Может заполняться при вводе на основании документа "Состав квоты" при создании документов снимающих номера из квоты.
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Квота номеров. Ссылается на справочник «Квоты номеров». Квота по которой выполняется изменение количества номеров
  • Дата начала периода. Тип значения: «Дата». Дата и время начала периода, на который добавляются номера в квоту
  • Продолжительность в днях. Тип значения: «Число». Продолжительность периода в днях
  • Дата окончания периода. Тип значения: «Дата». Дата и время окончания периода, на который добавляются номера в квоту
  • Тип номера. Ссылается на справочник «Типы номеров». Тип номера по которому добавляются/снимаются номера
  • Номер. Ссылается на справочник «Номерной фонд». Можно редактировать если в квоте включен флажок "По номерам". Позволяет поставить в квоту конкретную комнату.
  • Вид движения по квоте. Ссылается на перечисление «Виды движений по квоте». Тип операции: либо добавление номеров в квоту, либо удаление (снятие) номеров из квоты
  • Количество номеров. Тип значения: «Число». Количество добавляемых в квоту/удаляемых из квоты номеров выбранной категории
  • Количество мест. Тип значения: «Число». Количество мест вычисляется автоматически по количеству номеров и числу мест в номере
  • Количество мест в номере. Тип значения: «Число». Количество основных мест в номерах выбранной категории. Заполняется автоматически при выборе типа номера.
  • Количество гостей в номере. Тип значения: «Число». Максимальное количество гостей, которое можно разместить в номерах выбранной категории. Заполняется автоматически при выборе типа номера.
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники». Сотрудник, который создал документ

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма списка. Основная форма списка. Используется для отображения списка документов данного типа.
  • Форма выбора. Основная форма выбора квоты в формах брони/размещения.

Способ вызова

Графическая форма работы с квотами номеров вызывается из основного меню программы по кнопке "Еще.../Закладка "1"/Квоты номеров"

Движения

  • «Продажи квот номеров».
  • «Загрузка номеров».
