Документ "Приказ об изменении формул тарифа"

Назначение

В приказах об изменении формул тарифа указываются формулы, которые будут автоматически применяться к ценам базового тарифа при бронировании и проживании по указанному в шапке приказа тарифу. Дата и время документа задают момент времени, когда приказ начинает действовать. Программа определяет, какие формулы применить к периоду проживания гостя, путем поиска действующего на дату и время заезда гостя приказа об изменении формул.

Формулы задаются для тарифа у которого включен режим зависимости от цен базового тарифа. Тариф является обязательным полем.

Формулы в приказе задаются в разрезе типов клиентов. На форме приказа всегда можно указать формулы для пустого типа клиента. Формулы по пустому типу клиента используются программой в случаях, когда в брони/размещении тип клиента не указан или указан, но для него явно не определены формулы в приказах.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Тарифы».

Реквизиты

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тариф. Ссылается на справочник «Тарифы». Обязательное для заполнения поле. Тариф по которому вводится приказ.
  • Примечания. Тип значения: «Строка». Произвольные примечания к документу.
  • Автор. Ссылается на справочник «Сотрудники». Сотрудник, который создал документ.

Табличная часть «Формулы»

  • Тип клиента. Ссылается на справочник «Типы клиентов». Поле непосредственно в таблице не редактируется, а отображается в виде закладок над таблицей формул. Закладки выводятся по всем не помеченным на удаление типам клиентов из справочника.
  • Тип номера. Ссылается на справочник «Типы номеров». Тип номера по которому будет действовать формула. Можно указать папку типов номеров или оставить пустым. Если оставить пустым, то при проведении документа в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление типов номеров из справочника. Если указана папка типов номеров, то при проведении приказа в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление типов номеров из выбранной папки
  • Класс номера. Ссылается на справочник «Классы номеров». Класс номера по которому будет действовать формула. Можно указать папку классов номеров или оставить пустым. Если оставить пустым, то при проведении документа в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление типов номеров из справочника. Если указана папка классов номеров, то при проведении приказа в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление типов номеров у которых класс номера входит в выбранную папку. Если указан класс номера, то в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление типов номеров у которых класс номера совпадает с указанным.
  • Вид размещения. Ссылается на справочник «Виды размещения». Вид размещения на который действует указанная формула. Можно указать папку видов размещений или оставить пустым. Если оставить пустым, то при проведении документа в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление видов размещений из справочника. Если указана папка видов размещений, то при проведении приказа в регистр формул по тарифам будут добавлены строки для всех не помеченных на удаление видов размещений из выбранной папки
  • Услуга. Ссылается на справочник «Услуги». Услуга на которую действует формула. Если не указана, то формула применяется ко всем услугам тарифа.
  • Заменить на услугу. Ссылается на справочник «Услуги». Услуга которая будет использоваться в брони и размещении вместо услуги указанной в базовом тарифе.
  • Коэффициенты формулы. Числа. Представляют собой коэффициенты К1, К2, К3 формулы вида: <Новая цена> = (<Цена из базового тарифа> + К1) * К2 + К3

Формы

  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.
  • Форма списка. Основная форма журнала приказов. Используется для отображения списка или выбора документов данного типа.

Способ вызова

Вызывается из меню "Взаиморасчеты/Справочники/Спецификации формул тарифов" или из главного меню программы по кнопке "Еще../Закладка "2"/Тарифы", кнопка "Перейти" в панели инструментов списка тарифов. Также приказы редактируются в карточке тарифа на закладке "Спецификации формул".

Движения

  • «Формулы по тарифам».

Дополнительная информация

Существует более простой вариант указания формулы расчета цен связанного тарифа. В приказе можно указать процент скидки. Если процент скидки указан, то таблица формул не доступна для редактирования и при заполнении регистра формул документ создаст записи для всех типов номеров и видов размещений с коэффициентом К2 = (100 - <Процент скидки>)/100 и коэффициентами К1 и К3 равными 0.
