Документ "Акт"

Назначение

Акт по оказанию услуг. Документ используется для заполнения регистра "Реализация" и выгрузки данных в бухгалтерию.

Документ заполняется по данным вспомогательного регистра "Текущая реализация услуг".

Акты формируются либо вручную на основании документов "Размещение" или "Фолио", либо автоматически процедурой "Закрытие периода". Чтобы ввести Акт по размещению, нужно открыть размещение, нажать на кнопку "Действия" и выбрать пункт "30 - Ввод акта по размещению" - будет сформирован акт по услугам только одного, выбранного гостя; если выбрать пункт " 35 - Ввод акта по размещениям в группе" - то будет сформирован акт по всем гостям из группы.

В Фолио Акт вводится также по кнопке "Действия".

При формировании акта в состав услуг подбираются все начисления, баланс по которым в регистре "Текущая реализация услуг" не равен 0. Таким образом, если какое-то начисление уже попало в акт, то это начисление нельзя будет включить в другой акт.

У Акта есть несколько печатных форм, отличающихся степенью детализации.

"Счет-фактура" - это печатная форма акта. Номер счета-фактуры вводится на закладке "Счет-фактура", может быть получен из базы бухгалтерии по кнопке "Действия".

Акт участвует во взаиморасчетах с контрагентами и формирует сумму оказанных контрагенту услуг в разрезе "Контрагент/Договор/Группа".

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Длина номера: 12, тип номера: Строка

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Бронь», «Размещение», «Фолио», «Счет-требование», «Группы гостей», «Контрагенты», «Договоры».

Объекты, вводимые на основании: «Платеж от контрагента», «Счет-требование».

Реквизиты

  • Тип акта. 
    • Оказание услуг контрагенту - акт увеличивает сумму оказанных контрагенту услуг. Акт формирует движения оплаты по фолио, тем самым закрывает баланс. Акты с таким типом программа создает по лицевым счетам, у которых способ оплаты "На расчетный счет" (у способа оплаты включен флажок "Оплата контрагентом"). Поскольку оплата указанных услуг будет осуществляться не наличными на стойке ресепшн, а безналичным платежом, баланс по данному фолио закрывается и переносится во взаиморасчеты с контрагентом.
    • Счет-фактура подведения итогов - акт увеличивает сумму оказанных контрагенту услуг. Акт такого типа формируется по лицевым счетам оплачиваемым наличными или кредитными картами на стойке ресепшн. Поскольку баланс по таким фолио уже закрыт в 0, то нет необходимости делать движения оплаты по фолио. Акт с данным типом формируется для целей выгрузки данных в бухгалтерию. Также такой акт может формироваться вручную, когда гость просит распечатать ему счет-фактуру.
  • Документ основание. Ссылается на документы «Бронь», «Бронь ресурса», «Размещение», «Счет-требование», «Фолио». Если заполнено, то в акт попадут только те услуги, которые были начислены по указанному документу-основанию и еще не были включены ни в один акт.
  • Гостиница. Ссылается на справочник «Гостиницы». Указывается, по какой гостинице проводились начисления акта.
  • Фирма. Ссылается на справочник «Фирмы». Выбирается по какой фирме проводились начисления.
  • Контрагент в бухгалтерии. Ссылается на справочник «Контрагенты». На данного контрагента будет сформирована сумма оказанных услуг во взаиморасчетах с контрагентом. Также этот контрагент будет указан при выгрузке в бухгалтерию.
  • Договор в бухгалтерии. Ссылается на справочник «Договоры». Договор контрагента.
  • Группа гостей. Ссылается на справочник «Группы гостей». Начисления в акт выбираются по выбранной группе. Если документ-основание не выбран, то будут подобраны все услуги, начисленные по выбранной группе, но еще не включенные ни в один акт.
  • Сумма. Итоговая сумма акта.
  • Сумма НДС. Сумма НДС акта, рассчитывается как итог по колонке "Сумма НДС" в таблице услуг. 
  • Валюта взаиморасчетов с контрагентом. Ссылается на справочник «Валюты». Заполняется из договора или контрагента.
  • Примечания. Комментарий к документу.
  • Номер счета-фактуры. Заполняется по кнопке "Действия", пункт " 20 - Получить номер счета-фактуры". Если обработка подключена к базе бухгалтерии, то из бухгалтерии получается следующий порядковый номер счет-фактуры, а в бухгалтерии создается документ, чтобы занять этот номер. Если такая обработка не подключена, то будет просто предложен следующий порядковый номер по внутреннему нумератору базы.
  • Грузоотправитель. Строка, используется для печати "Счет-фактуры".
  • Грузополучатель. Строка, используется для печати "Счет-фактуры".
  • Документ закрытия периода. Ссылается на документ «Закрытие периода». Заполняется при формировании акта процедурой закрытия периода.
  • Способ оплаты. Ссылается на справочник «Способы оплаты». Не редактируется. Всегда равен специальному предопределенному значению "Акт".
  • Тип путевки. Ссылается на группы справочника «Путевки и курсовки». Заполняется при формировании акта по начислениям выполненным по путевке/курсовке. Используется при выгрузке в бухгалтерию.
  • Код во внешней системе. Заполняется при выгрузке в бухгалтерию. Используется при синхронизации документов.
  • Не выгружать в бухгалтерскую систему. Если флажок включен, то такой акт не будет выгружен в бухгалтерию. Включается для услуг, у которых включен флажок "Не выгружать в бухгалтерию". Устанавливается процедурой закрытия периода.
  • Автор. Ссылается на справочник «Сотрудники». Пользователь, создавший документ.

Табличная часть «Услуги»

Заполняется при создании документа или по кнопке "Пересчитать". Отбираются только те начисления, которые еще не были включены ни в один акт и по которым баланс в регистре "Текущая реализация услуг" не равен нулю. Колонки табличной части заполняются параметрами из начисления и используются для печати документа. 

Табличная часть «Платежно-расчетные документы»

Используется для печати счета-фактуры. Заполняется вручную.

  • Номер платежно-расчетного документа. Строка, номер документа для печати 
  • Дата платежно-расчетного документа. Дата для печати.
