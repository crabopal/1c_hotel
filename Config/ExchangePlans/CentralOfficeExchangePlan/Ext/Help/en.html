План обмена используется для организации схемы работы сети гостиниц где есть главный центральный офис. 

В центральном офисе должны быть данные по всем гостиницам сети. В центральном офисе можно бронировать номера в любой из гостиниц сети и вести взаиморасчеты с контрагентами.

В подчиненных базах гостиниц сети хранятся данные только этой гостиницы.

В центральной базе у главного узла фильтр по гостинице должен быть пустым.

В периферийных базах у узлов, которые соответствуют центральному офису фильтр по гостинице должен быть установлен на периферийную гостиницу.

В режиме отладки в журнал регистрации логируется тип выгружаемых данных
