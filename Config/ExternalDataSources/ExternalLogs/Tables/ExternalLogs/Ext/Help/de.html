The table "Interaction with the PostgreSQL database"

Appointment

The table is used to provide a link to the Logs table stored on the PostgreSQL server. Allows you to store and receive data about logs of interaction with external systems.

Refers to the subsystem: «Integration with external systems».

Parameters

Code length: 19, code type: String..

The length of the name: 18.

Fields

  • The period of interaction..The date and time of the action are indicated. 
  • The external system. The name of the external system with which the interaction took place is indicated. 
  • Uuid. The id of the request to the external system is specified.  
  • Function. The function that was used in relation to the external system is indicated. 
  • Type.Contains the type of response from the external system.
  • Description. Contains a description of the response from the external system.
  • Answer. Contains the response code from the external system.
  • Request. Contains the text of the request to the external system.
  • Integration ID. Contains the integration id of the external system.
  • Code.. Contains the code of the external system in the directory.

The method of calling

Called from the menu  "Integration/Logs of integrations with external systems"
