Таблица "Взаимодействие с базой данных PostgreSQL"

Назначение

Таблица используется для обеспечения связи с таблице Logs, хранящейся на сервере PostgreSQL. Позволяет хранить и получать данные о логах взаимодействия с внешними системами.

Относится к подсистеме: «Интеграции с внешними системами».

Параметры

Длина кода: 19, тип кода: Строка.

Длина наименования: 18.

Поля

  • Период взаимодействия. Указывается дата и время действия. 
  • Внешняя система. Указывается название внешней системы с которой было взаимодействие. 
  • Uuid. Указывается id запроса к внешней системе.  
  • Функция. Указывается функция которая была использована по отношению к внешней системе. 
  • Тип. Содержит тип ответа от внешней системы.
  • Описание. Содержит описание ответа от внешней системы.
  • Ответ. Содержит код ответа от внешней системы.
  • Запрос. Содержит текст запроса к внешней системе.
  • ID интеграции. Содержит id интеграции внешней системы.
  • Код. Содержит код внешней системы в справочнике.

Способ вызова

Вызывается из меню "Интеграции/Логи интеграций с внешними системами"
