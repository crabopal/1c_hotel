Регистр сведений "Записи в журнал регистрации иностранцев по размещениям"

Назначение

Технический регистр. Используется для быстрого получения списка записей в журнал регистрации иностранцев по размещению и для получения последней записи в журнале регистрации по размещению.

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: Одна запись на документ «Запись в журнал регистрации иностранных граждан».

Режим записи: Ручное редактирование регистра запрещено.

Измерения

  • Размещение. Ссылается на документ «Размещение».

Ресурсы

  • Запись в журнал регистрации иностранцев. Ссылается на документ «Запись в журнал регистрации иностранных граждан».

Способ вызова

Из меню не вызывается.

Дополнительная информация

Используется для работы отчёта «Журнал регистрации иностранных граждан».
