Регистр сведений "Накопительные скидки"

Назначение

Содержит актуальные на текущую дату значения действующих накопительных скидок по типам скидок и граничным значениям ресурсов.

Относится к подсистеме "Управление скидками".

Параметры

Периодичность: С точностью до секунды.

Режим записи: Независимый.

Измерения

  • Тип скидки. Ссылается на справочник «Типы скидок».
  • Граница ресурса. Тип значения: «Число».
  • Набор услуг. Ссылается на справочник «Наборы услуг».

Ресурсы

  • Скидка %. Тип значения: «Число».

Способ вызова

Из меню не вызывается
