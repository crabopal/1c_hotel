Регистр сведений "Ключи авторизации"

Назначение

Содержит сгенерированные программой ключи авторизации.

Регистр заполняется автоматически при получении от внешних систем запросов авторизации. У каждого клиента в рамках одной программы может быть активным только 3 кода подтверждения.

Относится к подсистеме: «OAuth».

Параметры

Периодичность: Не периодический

Режим записи: Независимый

Измерения

  • Клиент. Ссылается на справочник «Дисконтные и подарочные карты». 
  • Ключ. Тип значения: Строка до 36 символов.

Ресурсы

  • Дата создания. Тип значения: Дата и время. Дата и время создание ключа авторизации. 
  • Изменение пароля. Тип значения: Булево. Истина, если ключа авторизации предназначен для смены пароля клиента.
  • ua. Тип значения: Строка до 1000 символов.
  • Отпечаток пальца. Тип значения: Строка до 500 символов.
  • IP. Тип значения: Строка до 39 символов.
