Регистр сведений "Настройки списка детализации услуг"

Назначение

Программа позволяет любое начисление услуги разложить на составляющие его элементы. Это могут быть:

  • Скрытые местные налоги
  • Затраты по различным подразделениям
  • Технические услуги используемые для формирования специализированных отчетов

Пример списка детализации для начисления услуги "Полупансион":

  1. Завтрак
  2. Ужин
  3. Напитки

Каждая позиция в списке детализации это услуга из справочника Услуги

Для каждой позиции в списке детализации можно определить ее цену и количество. Например, если в номере живет 3 человека и начисление услуг выполняется только на основного гостя номера, то у услуги Завтрак в списке детализации должно быть количество 3.

Для определения цены и количества можно использовать либо константы, либо формулы. Формулы - это выражения на встроенном языке 1С, в которых используются переменные. Список доступных переменных:

  • [Amount] - сумма основной услуги (сумма начисления). Она корректируется после обработки каждого элемента списка детализации
  • [DiscountAmount] - сумма скидки. Она корректируется после обработки каждого элемента
  • [CommissionAmount] - сумма комиссии. Она корректируется после обработки каждого элемента
  • [Price] - цена основной услуги
  • [Quantity] - количество основной услуги
  • [RateAmount] - полная стоимость по тарифу в сутки включая все дополнительные и пакетные услуги, которые входят в цену
  • [VATRate] - ставка НДС основной услуги в виде числа
  • [VATAmount] - сумма НДС основной услуги. Она корректируется после обработки каждого элемента
  • [ItemVATRate] - ставка НДС текущего элемента в виде числа
  • [TouristTaxAmountRU] - сумма туристического налога (только для России)
  • [AccountingDate] - учетная дата основной услуги
  • [NumberOfPersons] - кол-во человек в брони
  • [NumberOfAdults] - кол-во взрослых в брони
  • [NumberOfTeenagers] - кол-во подростков в брони
  • [NumberOfChildren] - кол-во детей в брони
  • [NumberOfInfants] - кол-во младенцев в брони

Цена детализирующей услуги может зависеть от тарифа, типа номера, вида размещения гостя в номере, соответственно программа позволяет для одной детализируемой услуги указывать разные формулы в зависимости от комбинации 4-х параметров:

  1. Гостиница
  2. Тип тарифа
  3. Тип номера
  4. Вид размещения

У каждого правила детализации должен быть указан его порядковый номер. Порядковый номер указывает в каком порядке будут выполняться детализирующие начисления. В конце обработки правил детализации остаток суммы детализируемой услуги будет начислен этой детализируемой услугой.

В программе предусмотрен справочник формул. Вместо указания детальных параметров непосредственно в строке настроек правил детализации, можно создать элемент в справочнике "Формулы списка детализации" и указать его у услуги. Тогда при выборе этой услуги формула заполнится автоматически. В справочник рекомендуется выносить выражения, которые не зависят от гостиницы/типа тарифа/типа номера/вида размещения, а определяются, например, только суммой детализируемой услуги или количеством гостей в номере.
