Регистр сведений "Разрешенные типы дней календаря по типам номеров"

Назначение

Регистр позволяет указывать по датам диапазон разрешенных для выбора типов дней календаря. Разрешенными считаются все типы дней, которые находятся в одной папке с типами дней границ диапазона, и у которых "вес" попадает в диапазон "весов" типов дней границ диапазона.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Раз в день.

Режим записи: Независимый.

Измерения

  • Календарь. Ссылается на справочник «Календари»
  • Гостиница. Ссылается на справочник «Гостиницы»
  • Тип номера. Ссылается на справочник «Типы номеров»

Ресурсы

  • Тип дня (левая граница диапазона весов). Ссылается на справочник «Типы дней в календарях»
  • Тип дня (правая граница диапазона весов). Ссылается на справочник «Типы дней в календарях»
