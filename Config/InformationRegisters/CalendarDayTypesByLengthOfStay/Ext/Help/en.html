Регистр сведений "Типы дней календарей по продолжительности проживания"

Назначение

Регистр позволяет для тарифа задать шкалу выбора типа дня по продолжительности проживания гостя. Пример: для тарифа "Базовый" можно указать, что при продолжительности проживания от 4-х дней программа для расчета состава услуг должна использовать цены из типа дня "4 - 7 дней проживания". При продолжительности проживания от 7-ми дней должна использовать цены из типа дня "7 - 12 дней проживания". При продолжительности проживания от 12-ти дней должна использовать цены из типа дня "от 12 дней проживания".

При расчете услуг для каждого дня проживания гостя программа получает цены как по типам дней из основного календаря тарифа, так и по этому вспомогательному регистру. Для начисления услуг используется тот тип дня, цены в котором меньше.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Календарь. Ссылается на справочник «Календари».
  • Кол-во дней проживания. Тип значения: «Число». 

Ресурсы

  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях».

Способ вызова

Вызывается из меню "Взаиморасчёты\Справочники\Настройки\Типы дней календарей по продолжительности проживания"
