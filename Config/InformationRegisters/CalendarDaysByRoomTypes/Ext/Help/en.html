Регистр сведений "Дни календарей по типам номеров"

Назначение

Регистр позволяет указывать разные типы дней для разных типов номеров на одну и ту же дату. Эта возможность используется для того, чтобы, например для стандартных номеров на дату указывать тип дня "Высокий сезон", а для люксов - "Низкий сезон". Записи в регистре должны быть только по тем датам и типам номеров, по которым значение типа дня должно отличаться от типа дня указанного в регистре "Дни календарей". Регистр не используется при бронировании ресурсов.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Раз в день.

Режим записи: Независимый.

Измерения

  • Календарь. Ссылается на справочник «Календари»
  • Гостиница. Ссылается на справочник «Гостиницы»
  • Тип номера. Ссылается на справочник «Типы номеров»

Ресурсы

  • Тип дня. Ссылается на справочник «Типы дней в календарях»
