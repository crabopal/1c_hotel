Регистр сведений "Контекст сообщений"

Назначение

Регистр содержит контекст для сообщений телеграм бота.

Относится к подсистеме: «Чат бот».

Параметры

Периодичность: Непериодический.

Режим записи: Независимый.

Измерения

  • ID чата. Число.
  • ID сообщения. Число.
  • Название операции. Строка.
  • Ключ. Строка.

Ресурсы

  • Значение. Строка.
  • Пометка. Строка.
