Регистр сведений "Атрибуты чеков"

Назначение

Регистр используется для хранения атрибутов он-лайн чеков (фискальный признак документа, номер кассовой смены, номер чека в смене и т.д.). Регистр заполняется при пробитии чека по ККМ.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Непериодический

Режим записи: Автоматически при пробитии кассового чека, ручное редактирование регистра запрещено

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Платеж. Тип значения: «Платеж», «Возврат», «Платеж контрагента».

Ресурсы

  • Фискальный признак документа. Тип значения: "Число".
  • Номер смены. Тип значения: "Число".
  • Номер чека в смене. Тип значения: "Число".
  • Адрес покупателя. Тип значения: "Строка". E-Mail или телефон покупателя 

Способ вызова

Вызывается из меню "Взаиморасчеты/Кассовые операции/Атрибуты чеков"
