Регистр сведений "Сертификаты вакцинации"

Назначение

Содержит номера сертификатов о вакцинации по клиентам. 

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Клиент. Ссылается на справочник «Клиенты (гости)». 
  • Номер сертификата. Номер сертификата 

Ресурсы

  • QRCode. Тип значения: Хранилище значения. 
  • Действителен до. Тип значения: Дата.  
  • Дата рождения. Тип значения: Дата.  
  • Примечания. Тип значения: Строка.  
  • Ссылка на сертификат. Тип значения: Строка.  
  • Полное имя. Тип значения: Строка. 

Реквизиты

  • Дата регистрации. Тип значения: Дата.
