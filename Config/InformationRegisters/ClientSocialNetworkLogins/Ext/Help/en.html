Регистр сведений "Логины клиентов в социальных сетях"

Назначение

Регистр содержит список логинов клиентов в соц. сетях: vk.com, ok.ru, facebook.com и т.д. Регистр хранит технические логины, которые используются при авторизации клиента в модуле он-лайн бронирования через API соц. сетей. Эти логины могут не совпадать с адресом публичной страницы клиента в соц. сети.  

Относится к подсистеме: «Номера».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Клиент. Ссылка на справочник клиентов. Клиент, чей логин хранится в базе
  • Логин. Строка. Логин клиента в соц. сети
