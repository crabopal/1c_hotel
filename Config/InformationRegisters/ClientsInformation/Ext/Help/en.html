Регистр сведений "Доп. информация по клиентам"

Назначение

Содержит историю изменений дополнительной информации по клиентам. Структура хранения доп. информации задается в справочнике "Типы доп. информации по клиентам"

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Клиент. Ссылается на справочник «Клиенты (гости)».
  • Тип информации по клиентам. Ссылается на справочник «Типы информации по клиентам».

Ресурсы

  • Гостиница. Тип значения: Справочник «Гостиницы».
  • Примечания. Тип значения: «Строка». 
  • Автор примечаний. Тип значения: Справочник «Сотрудники». 
  • Действие предпринятое персоналом отеля для исправления проблемы. Тип значения: Строка. 
  • Автор действия. Тип значения: Справочник «Сотрудники». 
  • Дата и время действия. Тип значения: «Дата и время».
