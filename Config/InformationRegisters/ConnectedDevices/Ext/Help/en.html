Information register "Connected devices"

Appointment

The register contains a list of connected devices.

Parameters

Periodicity: Non-periodic

Recording Mode: Independent

Measurements

  • Workstation. Refers to the catalog «Workstations» enumeration. 
  • Device type.  Refers to the «Device types». 
  • Device settings. Composite data type. Refers to the reference catalog «Cash registers», «Door Lock System Connection Parameters», «Credit Card Processing System Parameters», «Параметры дисплея покупателя», «Параметры подключения сканеров изображений», «Параметры системы карт идентификации клиентов», «Параметры подключения сканеров штрихкодов», «Параметры подключения к ленточным принтерам», «Параметры подключения купюроприемников». 

Method of calling

It is edited in a table that opens in the form of an element of the directory «Workstations».
