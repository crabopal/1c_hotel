Регистр сведений "История изменений реквизитов договоров"

Назначение

Содержит историю изменений реквизитов договоров.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность:С точностью до секунды

Режим записи: Независимый

Измерения

  • Договор. Ссылается на справочник «Договоры».

Ресурсы

  • Код. Тип значения: «Строка».
  • Наименование. Тип значения: «Строка».
  • Фирма. Ссылается на справочник «Фирмы».
  • Действует с даты. Тип значения: «Дата».
  • Действует по и включая дату. Тип значения: «Дата».
  • Квота номеров. Ссылается на справочник «Квоты номеров».
  • Тариф. Ссылается на справочник «Тарифы».
  • Набор услуг начисляемый по тарифу. Ссылается на справочник «Наборы услуг».
  • Тип скидки. Ссылается на справочник «Типы скидок». 
  • Основание предоставления скидки. Тип значения: «Строка».
  • Валюта договора. Ссылается на справочник «Валюты». 
  • Планируемый способ оплаты. Ссылается на справочник «Способы оплаты».
  • Комиссия агента. Тип значения: «Число».
  • Вид комиссии агента. Ссылается на перечисление «Виды комиссий агентам».
  • Набор услуг, по которому начисляется комиссия агентам. Ссылается на справочник «Наборы услуг».
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга».
  • Источник информации о гостинице. Ссылается на справочник «Источники информации о гостинице». 
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Строка подтверждения для типа клиента. Тип значения: «Строка». 
  • Правила начисления. Тип значения: «Хранилище значения».
  • Код во внешней системе. Тип значения: «Строка».
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».

Реквизиты

  • Пользователь. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается из карточки договора по кнопке "История изменения" или из меню "Взаиморасчёты\Справочники\История изменений реквизитов договоров"
