Регистр сведений "Документы прикрепленные к договорам"

Назначение

Регистр используется для хранения связанных с договорами документов. Обычно это собственно тексты договоров и приложений и доп. соглашений.

Относится к подсистеме: «Тарифы и договоры»

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Договор. Ссылается на справочник «Договоры с контрагентами».

Ресурсы

  • Тип договора. Ссылается на справочник "Типы договоров". Не обязательный реквизит. Уточняет тип документа сохраненного в регистре
  • Внешний файл. Тип значения: «Хранилище значения».
  • Имя файла. Тип значения: «Строка».
  • Дата и время загрузки файла. Тип значения: «Дата».
  • Дата и время последнего изменения файла. Тип значения: «Дата».
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается из карточки договора по кнопке "Прикрепленные документы"
