Регистр сведений "Текущие статусы телефонных номеров"

Назначение

Содержит по телефонным номерам текущие значения флага доступности межгорода и флага наличия сообщения абоненту.

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Телефонный номер. Ссылается на справочник «Телефонные номера». 

Ресурсы

  • Управляется вручную. Тип значения: «Булево».
  • Междугородние/международные звонки заблокированы. Тип значения: «Булево».
  • Для абонента есть сообщение. Тип значения: «Булево».
  • Изменена. Тип значения: «Булево».
  • Примечания. Тип значения: «Строка».

Способ вызова

Вызывается из меню "Номерной фонд\Справочники\Настройки\Текущие статусы телефонных номеров"
