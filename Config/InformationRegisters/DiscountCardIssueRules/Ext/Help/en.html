Регистр сведений "Правила выдачи дисконтных карт"

Назначение

Содержит условия при выполнении которых при завершении процедуры поселения гостя программа предложит портье выдать гостю дисконтную карту.

Относится к подсистеме "Управление скидками".

Параметры

Периодичность: Нет.

Режим записи: Независимый.

Измерения

  • Тип накопления. Ссылается на перечисление «Виды накопления ресурсов».
  • Начальная граница ресурса. Тип значения: «Число». Проверяется на больше либо равно 
  • Конечная граница ресурса. Тип значения: «Число». Проверяется на меньше. Если верхняя граница не определена, укажите в этом поле 9999999999

Ресурсы

  • Тип скидки. Ссылается на справочник «Типы скидок». Задает тип скидки, который будет установлен у дисконтных карт выданных по этому правилу. Поле обязательно для ввода.
  • Тип клиента. Ссылается на справочник «Типы клиентов». Задает тип клиента, который будет установлен у дисконтных карт выданных по этому правилу. Может быть пустым.
  • Действует с, Действует по. Тип значения: «Дата». Указывается период действия выдаваемых по этому правилу дисконтных карт. Может быть пустым.
  • Текст уведомления. Тип значения: «Строка». Задает текст уведомления, которое будет видеть портье для тех гостей, которым нужно выдать дисконтную карту удовлетворяющую текущему правилу. Может указываться на нескольких языках в формате "en='Text in english'; ru='Текст по русски'" (без двойных кавычек). Портье увидит сообщение на языке в котором работает его программа. Если текст уведомления здесь не указан, то программа покажет стандартное системное уведомление "Гостю необходимо выдать дисконтную карту!"

Способ вызова

Вызывается из меню "Взаиморасчеты\Скидки\Правила выдачи дисконтных карт"
