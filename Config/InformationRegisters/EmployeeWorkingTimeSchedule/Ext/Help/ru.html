Регистр сведений "Записи графиков рабочего времени сотрудников"

Назначение

В регистре ведутся графики работы сотрудников. По каждому дню, кроме числа рабочих часов можно указать тип дня: рабочий; выходной; отпуск; праздник и т.д. и произвольный комментарий.

Относится к подсистеме: «Управление службой номеров».

Параметры

Периодичность: Раз в день

Режим записи: Независимый

Измерения

  • Сотрудник. Ссылается на справочник «Сотрудники».

Ресурсы

  • Отдел. Ссылается на справочник «Отделы».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Номер. Ссылается на справочник «Номерной фонд». 
  • Секция номеров. Ссылается на справочник «Секции номерного фонда».
  • Тип дня в расписании. Ссылается на справочник «Типы дней в графиках работы». 
  • Расписание дня. Ссылается на справочник «Расписания». 
  • Рабочих часов в день. Тип значения: «Число».
  • Примечания. Тип значения: «Строка».

Способ вызова

Вызывается из меню "Служба номеров/Записи графиков рабочего времени сотрудников" или из главного меню по кнопке "График работы сотрудников"
