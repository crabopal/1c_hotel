Регистр сведений "Данные плана обмена"

Назначение

Регистр используется для регистрации и хранения данных планов обмена.

Относится к подсистеме: «Обмен данными».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Номер сообщения. Тип значения: «Число».
  • Узел-отправитель. Ссылается на узел плана обмена «Узел плана обмена».
  • Узел-получатель. Ссылается на узел плана обмена «Узел план обмена».

Ресурсы

  • XML-значение. Тип значения: «Строка».
  • Отправлено. Тип значения: «Булево».
  • Дата отправки. Тип значения: «Дата».
  • Получено. Тип значения: «Булево».
  • Дата получения. Тип значения: «Дата».
  • Загружен. Тип значения: «Булево».
  • Дата загрузки. Тип значения: «Дата».
