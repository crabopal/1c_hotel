Регистр сведений "Логи интеграций со внешними системами"

Назначение

Регистр используется для хранения логов обмена данными между 1С:Отель и внешними системами.

Относится к подсистеме: «Интеграции».

Параметры

Периодичность: В пределах секунды

Режим записи: Независимый

Измерения

  • Внешняя система. Ссылается на справочник «Взаимодействия с внешними системами».
  • Функция. Тип значения: «Строка».
  • Тип события. Тип значения: Перечисление «Типы событий внешних систем».

Ресурсы

  • Запрос. Тип значения: «Строка».
  • Ответ. Тип значения: «Строка».
  • Описание. Тип значения: «Строка».
