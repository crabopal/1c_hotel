Регистр сведений "FIAS приоритетные события"

Назначение

Регистр позволяет добавлять и считывать информацию по приоритетным события FIAS

Относится к подсистеме: «Управление настройками».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Command UUID. Тип значения: «UUID».
  • Параметры взаимодействия: Ссылается на справочник «Взаимодействия с внешними системами».
  • Workstation ID. Тип значения: «Строка».
  • KeyCoder. Тип значения: «Строка».

Ресурсы

  • Request. Тип значения: «Строка».
  • Response. Тип значения: «Строка».
  • CommandType. Тип значения: «Строка».
  • IsCommandSent. Тип значения: «Логический».
  • IsResponseReceived. Тип значения: «Логический».
  • AnswerStatus. Тип значения: «Строка».
  • ClearText. Тип значения: «Строка».
