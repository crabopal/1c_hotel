Регистр сведений "История изменений записи в журнал регистрации иностранцев"

Назначение

Регистр хранит историю изменений реквизитов документов "Запись в журнал регистрации иностранных граждан".

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Запись в журнал регистрации иностранцев. Ссылается на документ «Запись в журнал регистрации иностранных граждан».

Ресурсы

  • Номер документа. Тип значения: «Строка».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Документ основание. Ссылается на документ «Размещение».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Гость. Ссылается на справочник «Клиенты (гости)».
  • У гостя уже есть уведомление о регистрации. Тип значения: «Булево».
  • Дата заезда. Тип значения: «Дата».
  • Дата выезда. Тип значения: «Дата».
  • Гость выехал. Тип значения: «Булево».
  • Фамилия. Тип значения: «Строка».
  • Имя. Тип значения: «Строка».
  • Отчество. Тип значения: «Строка».
  • Пол. Ссылается на перечисление «Пол».
  • Гражданство. Ссылается на справочник «Страны».
  • Дата рождения. Тип значения: «Дата».
  • Место рождения. Тип значения: «Строка». 
  • Вид документа удостоверяющего личность. Ссылается на справочник «Виды документов удостоверяющих личность».
  • Серия документа удостоверяющего личность. Тип значения: «Строка».
  • Номер документа удостоверяющего личность. Тип значения: «Строка».
  • Дата выдачи документа удостоверяющего личность. Тип значения: «Дата».
  • Документ удостоверяющий личность действителен до. Тип значения: «Дата».
  • Кем выдан документ удостоверяющий личность. Тип значения: «Строка».
  • Цель визита. Ссылается на справочник «Цели визита».
  • Профессия или должность. Тип значения: «Строка».
  • Стаж работы. Тип значения: «Строка».
  • Страна или город откуда прибыл. Тип значения: «Строка».
  • Из-за границы. Тип значения: «Булево».
  • Номер миграционной карты. Тип значения: «Строка».
  • Срок прибывания по миграционной карте с даты. Тип значения: «Дата».
  • Срок прибывания по миграционной карте по дату. Тип значения: «Дата».
  • Принимающая организация. Тип значения: «Строка».
  • Номер визы. Тип значения: «Строка». 
  • Тип визы. Ссылается на справочник «Типы въездных виз».
  • Дата выдачи визы. Тип значения: «Дата».
  • Дата с визы. Тип значения: «Дата».
  • Дата по визы. Тип значения: «Дата».
  • Число дней действия визы. Тип значения: «Число».
  • Дата пересечения границы. Тип значения: «Дата».
  • Номер контрольно-пропускного пункта (КПП). Тип значения: «Строка».
  • Маршрут. Тип значения: «Строка».
  • Сведения о законных представителях. Тип значения: «Строка».
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».

Реквизиты

  • Пользователь. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается по кнопке "История изменений" в карточке записи в журнал регистрации граждан или из меню "Номерной фонд/История изменений записи в журнал регистрации иностранцев"
