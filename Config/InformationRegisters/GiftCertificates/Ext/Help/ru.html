Регистр содержит список проданных подарочных сертификатов. Запись в регистр добавляется при оплате сертификата.

Для каждого подарочного сертификата указывается:

  • Дата и время регистрации сертификата в системе. Автор регистрации - сотрудник, который указан в платеже, которым оплачивался сертификат.
  • Дата блокировки; сотрудник, который выполнил блокировку
    Для того чтобы установить блокировку сертификата необходимо указать дату блокировки.
    Если в константах программы включена галочка "Блокировать подарочные сертификаты при выселении", то программа, при закрытии лицевого счета, автоматически заблокирует (установит дату блокировки) подарочные сертификаты использованные в этом лицевом счете для оплаты услуг. Если в константах программы заполнен параметр: "Кол-во месяцев действия подарочных сертификатов", то дата о блокировке сертификата в будущем заполняется программой автоматически при покупке сертификата. Дата блокировки устанавливается равной дате оплаты + указанное число месяцев.
  • причина блокировки
    Показывается пользователю при попытке использования заблокированного сертификата.

Замечания:

  • Для удаления или изменения записей о существующих подарочных сертификатах у сотрудника в его наборе прав должно быть включено право "031 - Есть права на изменение или удаление проведенных транзакций по лицевым счетам".
  • Для того чтобы добавить новую блокировку сертификата или открыть список сертификатов необходимо зайти в список лицевых счетов, нажать на кнопку "Действия" и выбрать пункты с кодами 100 или 110.
  • Поле "Гостиница" заполняется только, когда в константах программы установлен флаг "Подарочные сертификаты выдаются в каждой гостинице свои"
