Регистр сведений "Документы прикрепленные к группам"

Назначение

Регистр используется для хранения связанных с группами гостей текстов электронных писем - заявок, картинок факсов заявок, файлов записей телефонных разговоров. По регистру разрешен полнотекстовый поиск, который выполняется по команде из панели инструментов списка брони.

Относится к подсистеме: «Стойка администратора», «Ресурсы», «Продажи квот номеров», «Продажи путевок и курсовок».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Группа гостей. Ссылается на справочник «Группы гостей».

Ресурсы

  • Входящий документ. Тип значения: «Булево». 
  • E-mail. Тип значения: «Строка».
  • Факс. Тип значения: «Строка».
  • Тип прикрепленного документа. Ссылается на перечисление «Виды прикрепленных документов».
  • Статус прикрепленного документа. Ссылается на перечисление «Статусы прикрепленных документов».
  • Текст документа. Тип значения: «Строка».
  • Внешний файл. Тип значения: «Хранилище значения».
  • Имя файла. Тип значения: «Строка».
  • Дата и время загрузки файла. Тип значения: «Дата».
  • Дата и время последнего изменения файла. Тип значения: «Дата».
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается из карточки группы гостей по кнопке "Прикрепленные документы"
