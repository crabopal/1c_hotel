Регистр сведений "Нереплицируемые реквизиты гостиниц"

Назначение

Регистр используется в случаях развертывания распределенной базы данных, когда для одной и той же гостиницы в разных узлах информационной базы необходимо установить разные значения атрибутов гостиницы. Если регистр заполнен, то значения одноименных с ресурсами регистра атрибутов гостиницы игнорируются программным кодом и вместо них используются значения из записи регистра.

Относится к подсистеме: «Управление настройками».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».

Ресурсы

  • Префикс номеров документов. Тип значения: «Строка». 
  • Папка групп гостей. Ссылается на справочник «Группы гостей». 
  • Путь к папке на диске для хранения BLOB данных (картинок сканов документов и т.д.). Тип значения: «Строка».

Способ вызова

Редактируется в карточке гостиницы на закладке "Нереплицируемые реквизиты"
