Регистр сведений "Изображения"

Назначение

В регистре хранятся изображения объектов.

Относится к подсистеме: «Фронт-офис».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Измерение. Тип значения: CatalogRef.Rooms, CatalogRef.RoomTypes, CatalogRef.Customers, CatalogRef.Hotels, CatalogRef.Resources, CatalogRef.Clients  
  • Имя. Наименование изображения.

Ресурсы

  • Изображение. Тип значения: ХранилищеЗначений. Файл картинки
  • Основное. Тип значения: Булево. Флаг указывающий является ли изображение главным для объекта
