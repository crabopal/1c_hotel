Регистр сведений "Отгруженные путевки"

Назначение

Регистр используется для хранения номеров и данных путевок отгруженных контрагентам. При регистрации новых путевок в программе в размещении или брони, если номер введенной путевки есть в данном регистре, то данные новой путевки заполняются из соответствующей записи регистра. Записи в регистр добавляются документом "Отгрузка путевок".

Относится к подсистеме: «Продажи путевок и курсовок».

Параметры

Периодичность: Непериодический

Режим записи: Ручное редактирование регистра запрещено

Измерения

  • Номер путевки. Тип значения: «Строка».

Ресурсы

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Фирма. Ссылается на справочник «Фирмы».
  • Контрагент. Ссылается на справочник «Контрагенты».
  • Договор. Ссылается на справочник «Договоры».
  • Группа гостей. Ссылается на справочник «Группы гостей».
  • Документ основание. Ссылается на документы «Бронь», «Размещение», «Фолио».
  • Квота номеров. Ссылается на справочник «Квоты номеров».
  • Накладная на отгрузку. Тип значения: «Строка».
  • Тип номера. Ссылается на справочник «Типы номеров». 
  • Ставка НДС %. Ссылается на справочник «Ставки НДС».
  • Фиксировать период проживания . Тип значения: «Булево».
  • Фиксировать стоимость путевки. Тип значения: «Булево».
  • Тип путевки/курсовки. Ссылается на группы справочника «Путевки и курсовки».
  • Дата заезда. Тип значения: «Дата».
  • Продолжительность в днях или часах. Тип значения: «Число».
  • Дата выезда. Тип значения: «Дата».
  • Стоимость путевки. Тип значения: «Число».
  • Валюта накладной. Ссылается на справочник «Валюты».
  • Курс обмена валюты. Тип значения: «Число».
  • Дата курса обмена. Тип значения: «Дата».
  • Услуга. Ссылается на справочник «Услуги».

Способ вызова

Вызывается из меню "Номерной фонд/Продажа путевок и курсовок/Отгруженные путёвки"
