Регистр сведений "Потерянные вещи"

Назначение

Регистр используется для ведения истории обнаружения в гостинице забытых вещей.

Относится к подсистеме: «Управление службой номеров».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Код (порядковый номер). Тип значения: «Число».
  • Дата обнаружения. Тип значения: «Дата».
  • Номер. Ссылается на справочник «Номерной фонд».
  • Гость. Ссылается на справочник «Клиенты (гости)».
  • Сотрудник. Тип значения: «Строка». 

Ресурсы

  • Кем найдено. Тип значения: «Строка», Ссылается на справочник «Сотрудники».
  • Примечания. Тип значения: «Строка».
  • Место хранения. Тип значения: «Строка».
  • Возвращено. Тип значения: «Булево». 
  • Дата возврата. Тип значения: «Дата».
  • Кому возвращено. Тип значения: «Строка», Ссылается на справочник «Сотрудники».
  • Есть сообщение. Тип значения: «Булево».

Способ вызова

Вызывается из меню "Служба номеров/Потерянные вещи"
