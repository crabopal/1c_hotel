Регистр сведений "История медицинских записей"

Назначение

Содержит историю медицинских записей.

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Клиент. Ссылается на справочник «Клиенты (гости)».
  • Размещение. Ссылается на документ «Размещения».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Номер диагноза. Тип значения: Число.

Ресурсы

  • Дата. Тип значения: Дата.
  • Основной диагноз. Тип значения: Булево.
  • МКБ-10. Ссылается на справочник «МКБ-10».
  • Результат лечения. Ссылается на на перечисление «Статусы результатов лечения».
