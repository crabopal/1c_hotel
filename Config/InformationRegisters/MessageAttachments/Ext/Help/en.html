Регистр сведений "Документы прикрепленные к задачам"

Назначение

Регистр используется для хранения связанных с задачами текстов электронных писем - заявок, картинок факсов заявок, файлов записей телефонных разговоров. По регистру разрешен полнотекстовый поиск, который выполняется по команде из панели инструментов журнала задач.

Относится к подсистеме: «Ресурсы», «Управление задачами».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Сообщение. Ссылается на документ «Задача». 

Ресурсы

  • Текст документа. Тип значения: «Строка».
  • Внешний файл. Тип значения: «Хранилище значения».
  • Имя файла. Тип значения: «Строка».
  • Дата и время загрузки файла. Тип значения: «Дата».
  • Дата и время последнего изменения файла. Тип значения: «Дата».
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается из меню "Задачи/Документы прикреплённые к задачам"
