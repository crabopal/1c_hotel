Регистр сведений "История задач"

Назначение

Регистр используется при выполнении поиска активных задач для сотрудников. Заполняется документами "Задача".

Относится к подсистеме: «Управление задачами».

Параметры

Периодичность: Одна запись на документ

Режим записи: Ручное редактирование регистра запрещено

Измерения

  • По объекту. Ссылается на справочники «Ресурсы», «Номерной фонд», «Контрагенты», «Клиенты (гости)», «Договоры», Ссылается на документы «Фолио», «Счет-требование», «Состав квоты», «Размещение», «Приказ об изменении цен тарифа», «Отгрузка путевок», «Запись в журнал регистрации иностранных граждан», «Закрытие кассовой смены», «Бронь ресурса», «Бронь», «Акт».

Ресурсы

  • Статус задачи. Ссылается на справочник «Статусы задач».
  • Действует с даты и времени. Тип значения: «Дата».
  • Действует по дату и время. Тип значения: «Дата».
  • Текст сообщения. Тип значения: «Строка».
  • Для сотрудника. Ссылается на справочник «Сотрудники».
  • Для отдела. Ссылается на справочник «Отделы».
  • Закрыта. Тип значения: «Булево».
  • Автоматически показать сообщение при получении. Тип значения: «Булево».
  • Автор. Ссылается на справочник «Сотрудники».
  • Закрыл сотрудник. Ссылается на справочник «Сотрудники».
  • Дата и время закрытия. Тип значения: «Дата».

Способ вызова

Вызывается из меню "Задачи/История задач"
