Регистр сведений "Запросы из on-line систем"

Назначение

Содержит историю вызовов из on-line систем (модуль он-лайн бронирования, менеджеры каналов и т.д.) функции расчета вариантов и стоимости проживания на заданный период с заданным числом гостей. Регистр используется для анализа востребованности тех или иных дат и прочей аналитики по запросам.

Регистр заполняется автоматически при получении и обработке запроса из внешней системы на получение вариантов и стоимости проживания.

Относится к подсистеме: «Управление номерным фондом».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Период. Дата и время запроса.
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Код во внешней системе. Строка. Название внешней системы откуда выполняется запрос. 
  • Дата. Дата из периода запроса.

Ресурсы

  • Счетчик запросов. Тип значения: Число. Каждый запрос добавляет 1 на каждую дату из периода запроса 

Реквизиты

  • Дата и время начала периода запроса. Тип значения: Дата и время. Обычно дата и время заезда
  • Дата и время окончания периода запроса. Тип значения: Дата и время. Обычно дата и время выезда
  • Кол-во взрослых. Число, кол-во взрослых в поиске
  • Кол-во детей. Число, кол-во детей всех возрастов в поиске
  • ID сессии. Строка. Идентификатор сессии в браузере при вызове из модуля он-лайн бронирования
  • ID пользователя. Строка. Идентификатор пользователя в браузере при вызове из модуля он-лайн бронирования
  • UTM метки. Строка. Метки utm_source, utm_medium, utm_campaign при вызове из модуля он-лайн бронирования
