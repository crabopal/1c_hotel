Регистр сведений "Нормативы работ"

Назначение

Содержит список нормативов времени и площади по работам. Нормативы можно указывать по типам номеров или номерам. Программа в первую очередь выполняет поиск норматива по номеру и если не находит, то, затем, по типу номера. Значение норматива указывается в минутах. Также можно указывать значение норматива в квадратных метрах.

Относится к подсистеме: «Управление службой номеров».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Работа. Ссылается на справочник «Работы».
  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Номер. Ссылается на справочник «Номерной фонд».

Ресурсы

  • Норматив в минутах. Тип значения: «Число».
  • Площадь номера. Тип значения: «Число».

Способ вызова

Вызывается из меню "Служба номеров/Справочники/Нормативы работ", редактируется в карточке работы на закладке "Нормативы"
