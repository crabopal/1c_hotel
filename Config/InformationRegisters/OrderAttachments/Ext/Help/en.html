Information register "Order Attachments"

Purpose

The register is used to store order-related files. By case, full-text search is allowed, which is performed by command from the order history toolbar.

Refers to the subsystem: «Orders».

Parameters

Periodicity: Accurate to the second

Recording mode: Independent

Measurements

  • Order. Refers to «Order» document. 

Resources

  • Document text. Value type: "String".
  • External file. Value type: "Value storage".
  • External file preview.  Value type: "Value storage".
  • File name. Value type: "String".
  • File load date & time. Value type: "Date".
  • File last change date & time. Value type: "Date".
  • Remarks. Value type: "String".
  • Author. Refers to the «Employees» directory.

Call method

Called from the menu "Orders"
