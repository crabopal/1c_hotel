Регистр сведений "Документы прикрепленные к заказам"

Назначение

Регистр используется для хранения связанных с заказами файлов. По регистру разрешен полнотекстовый поиск, который выполняется по команде из панели инструментов журнала заказов.

Относится к подсистеме: «Заказы».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Сообщение. Ссылается на документ «Заказ».  

Ресурсы

  • Текст документа. Тип значения: «Строка». 
  • Внешний файл. Тип значения: «Хранилище значения». 
  • Представление внешнего файла. Тип значения: «Хранилище значения».
  • Имя файла. Тип значения: «Строка». 
  • Дата и время загрузки файла. Тип значения: «Дата». 
  • Дата и время последнего изменения файла. Тип значения: «Дата». 
  • Примечания. Тип значения: «Строка». 
  • Автор. Ссылается на справочник «Сотрудники». 

Способ вызова

Вызывается из меню "Заказы"
