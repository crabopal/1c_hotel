Регистр сведений "Уведомления о статусе заказа"

Назначение

Регистр содержит сообщения об отправленных уведомлениях у статусе заказа.

Если заказ записан через api и для типа заказ настроены уведомления, то ответственному сотруднику будут отправлены уведомления. 

Чтобы избежать дублирования сообщений при каждой записи заказа, в регистр записываются все отправленные уведомления.

Если по текущему статусу заказа сотруднику уже отправлялось сообщение - то повторной отправки не будет.

Также регистр полезен для анализа скорости обработки заказов, т.к. дает ответ на вопрос кто и когда получил уведомление и по какому каналу.

Относится к подсистеме: «Заказы».

Параметры

Периодичность: Непериодический.

Режим записи: Независимый.

Измерения

  • Заказ. Ссылка на документ "Заказ". 
  • Тип заказа. Ссылка на элемент "Тип заказа" - значение из документа Заказ.
  • Статус заказа. Ссылка на статус заказа.
  • Сотрудник. Ссылка на сотрудника кто получил уведомление
  • Кому. Строка с представлением канала доставки сообщения. При отправке СМС - номера телефонов, при отправке email - адрес электронной почты, при отправке уведомления в чат-бот Телеграм - ссылка на сотрудника.
  • Текст. Содержит текст отправленного сообщения с уведомлением
  • Статус сообщения. Текстовое представление статуса сообщения. При отправке принимает значение "Отправлено". Если подключена проверка доставки, то статус меняется на "доставлено".
  • Дата отправки. Содержит дату и время когда уведомление было отправлено.
  • Дата статуса. Содержит дату и время когда был выставлен текущий статус уведомления. если производится проверка доставки, например для СМС, то содержит время когда сообщение поменяло статус на "Доставлено".
