Регистр сведений "Диапазоны признаков цены"

Назначение

Регистр содержит таблицу используемых при ценообразовании диапазонов значений признаков цены.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: С точностью до позиции документа регистратора

Режим записи: Подчинен документу «Приказ об изменении диапазонов признаков цены»

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип признака цены. Ссылается на перечисление «Типы признаков цены».

Ресурсы

  • Начальное значение диапазона значений признака. Тип значения: «Число».
  • Конечное значение диапазона значений признака. Тип значения: «Число».
  • Признак цены. Ссылается на справочник «Признаки цены». 

Способ вызова

Пользователями не редактируется. Заполняется при проведении документа «Приказ об изменении диапазонов признаков цены»
