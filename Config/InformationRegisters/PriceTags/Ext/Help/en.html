Регистр сведений "Действующие приказы по изменению диапазонов признаков цены"

Назначение

Периодический регистр сведений, который позволяет получить действующий на указанную дату по указанной гостинице приказ об изменении диапазонов признаков цены.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Одна запись на документ

Режим записи: Ручное редактирование регистра запрещено

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тип признака цены. Ссылается на перечисление «Типы признаков цены».

Ресурсы

  • Приказ об изменении диапазонов признаков цены. Ссылается на документ «Приказ об изменении диапазонов признаков цены».

Способ вызова

Открывается из меню "Взаиморасчёты/Справочники/Настройки/Действующие приказы по изменению диапазонов признаков цены" или из журнала приказов об изменении диапазонов признаков цены по кнопке "Перейти..."

Дополнительная информация

Регистр заполняется при проведении документов "Приказ об изменении диапазонов признаков цены"

Регистр не предназначен для работы с ним пользователей, используется алгоритмами расчета стоимости проживания.
