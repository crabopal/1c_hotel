Регистр сведений "Лист ожидания по брони"

Назначение

Регистр содержит резервирования в листе ожидания. В лист ожидания документы попадают автоматически при проведении брони с установленным статусом брони с включенным признаком "В листе ожидания". Обычно такая бронь недействующая.

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: Непериодический

Режим записи: Ручное редактирование регистра запрещено

Измерения

  • Резервирование. Ссылается на документ «Бронь».

Ресурсы

  • Рейтинг. Тип значения: «Число».
  • Бронь может быть подтверждена. Тип значения: «Булево».

Способ вызова

Вызывается из меню "Номерной фонд/Лист ожидания по брони"

Дополнительная информация

Для просмотра регистра используется отчет "Лист ожидания брони"
