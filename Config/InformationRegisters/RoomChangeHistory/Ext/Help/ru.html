Регистр сведений "История изменений реквизитов номеров"

Назначение

Хранит историю изменений реквизитов номеров. Программа во всех случаях получения атрибутов номера использует данные из регистра актуальные на нужную дату, а не получает их напрямую из карточки номера. Данные в карточке номера носят информационный характер.

Относится к подсистеме: «Стойка администратора».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Номер. Ссылается на справочник «Номерной фонд». Номер.

Ресурсы

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Группа номера. Ссылается на справочник «Номерной фонд».
  • Номер комнаты. Тип значения: «Строка».
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Количество мест в номере. Тип значения: «Число».
  • Количество гостей в номере. Тип значения: «Число».
  • Дата ввода номера в эксплуатацию. Тип значения: «Дата».
  • Дата вывода номера из эксплуатации. Тип значения: «Дата».
  • Фирма. Ссылается на справочник «Фирмы».
  • Секция номеров. Ссылается на справочник «Секции номерного фонда».
  • Порядок сортировки. Тип значения: «Число».
  • Код в системе эл. замков. Тип значения: «Строка».
  • Код номера в системе охраны. Тип значения: «Строка».
  • Примечания. Тип значения: «Строка». Краткое описание.
  • Виртуальный номер. Тип значения: «Булево».
  • Автор. Ссылается на справочник «Сотрудники».
  • Документ регистратор. Ссылается на документы «Добавить номер», «Изменить номер».

Реквизиты

  • Пользователь. Ссылается на справочник «Сотрудники».

Способ вызова

Вызывается из меню "Номерной фонд/Справочники/История изменения реквизитов номеров"

Дополнительная информация

В нормальном режиме эксплуатации записи в регистр добавляются документами "Ввод номера в эксплуатацию" и "Изменение реквизитов номеров"
