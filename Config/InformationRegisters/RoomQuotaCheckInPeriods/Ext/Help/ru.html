Регистр сведений "Графики заездов по квотам"

Назначение

Регистр сведений, который хранит разрешенные для размещения гостей периоды проживания (заезды).

Относится к подсистеме: «Управление Номерным Фондом».

Параметры

Периодичность: Непериодический

Режим записи: Регистр заполняется вручную, автоматически по данным из таблицы настроек заездов карточки квоты или при помощи мастера заполнения.

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тариф. Ссылается на справочник «Тарифы».
  • Квота. Ссылается на справочник «Квоты номеров».
  • Период проживания. Дата заезда, выезда и продолжительность периода проживания.

Ресурсы

  • Не действует. Булево. Позволяет временно запретить использование периода.
  • Ручной. Булево. Устанавливается у периодов, которые созданы вручную, а не мастером из карточки квоты или формы списка регистра.

Способ вызова

Вызывается из меню "Номерной фонд/Продажи квот номеров/Графики заездов по квотам"
