Регистр сведений "Связи между тарифами и типами карт"

Назначение

Регистр содержит таблицу, в которой прописываются условия для определения типа карты идентификации гостя по его параметрам проживания: тарифу, виду размещения, типу клиента, типу контрагента, направлению маркетинга и типу скидки.

В простых случаях тип карты достаточно указать в карточке тарифа. Например, для тарифа "Полный пансион" тип карты может быть "Зелёная". Таблицу соответствий можно использовать в случаях, когда для одного тарифа могут использоваться разные типы карт, например, для взрослых один тип карты, для детей другой. В этом случае в таблице соответствий можно добавить запись, заполнить в ней колонку "Тариф", в колонке "Вид размещения" выбрать детский вид размещения, в колонке "Тип карты" выбрать "Зелёная детская", остальные колонки оставить пустыми. 

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Тариф. Ссылается на справочник «Тарифы».
  • Вид размещения. Ссылается на справочник «Виды размещения».
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Тип контрагента. Ссылается на справочник «Типы контрагентов».
  • Направление маркетинга. Ссылается на справочник «Направления маркетинга».
  • Тип скидки. Ссылается на справочник «Типы скидок».

Ресурсы

  • Тип карты идентификации клиента. Ссылается на справочник «Типы карт идентификации клиентов».

Способ вызова

Редактируется в таблице, которая открывается из списка тарифов по кнопке "Перейти" или вызывается из меню "Взаиморасчёты/Справочники/Параметры тарифов/Связи между тарифами и типами карт"
