Регистр сведений "Цены по тарифам по дням"

Назначение

Регистр содержит заранее рассчитанные цены по тарифам по датам. Регистр используется модулем он-лайн бронирования программы для быстрого расчета стоимости брони без учета раннего заезда/позднего выезда и накопительных скидок.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Периодический с периодичностью день.

Режим записи: Заполняется вручную или обработкой "Заполнение цен по тарифам по дням"

Измерения

  • Дата.
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тариф. Ссылается на справочник «Тарифы». 
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Признак цены. Ссылается на справочник «Признаки цены». Заполняется для тарифов в которых стоимость проживания зависит от загрузки отеля или продолжительности проживания  
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Вид размещения. Ссылается на справочник «Виды размещения». 

Ресурсы

  • Цена. Тип значения: «Число».
  • Валюта. Ссылается на справочник «Валюты».
  • Тип дня даты в календаре тарифа. Ссылается на справочник «Типы дней в календарях».

Способ вызова

Вызывается из меню "Взаиморасчёты/Справочники/Параметры тарифов/Цены тарифов по дням"
