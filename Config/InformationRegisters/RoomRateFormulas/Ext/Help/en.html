Регистр сведений "Формулы по тарифам"

Назначение

Регистр содержит строки документов об установке формул связанных тарифов и позволяет получить детальный состав формул нужного документа. В документе формулы могут указываться в кратком виде без детализации по типам номеров и видам размещений. В регистре хранятся формулы для каждой возможной комбинации типа номера и вида размещения.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: По позиции регистратора

Режим записи: Регистр заполняется при проведении документов установки формул тарифа. Ручное редактирование регистра запрещено

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы». 
  • Тариф. Ссылается на справочник «Тарифы».  
  • Тип клиента. Ссылается на справочник «Типы клиентов». 
  • Тип номера. Ссылается на справочник «Типы номеров». 
  • Вид размещения. Ссылается на справочник «Виды размещения».
  • Услуга. Ссылается на справочник «Услуги».

Ресурсы

  • Коэффициенты формулы. Тип значения: «Число». Коэффициенты К1, К2, К3 формулы вида <Новая цена> = (<Базовая цена> + К1) * К2 + К3 
  • Заменить на услугу. Ссылается на справочник «Услуги». 

Способ вызова

Вызывается из меню "Взаиморасчёты/Справочники/Параметры тарифов/Формулы тарифов"

Дополнительная информация

Регистр заполняется при проведении документов "Спецификации формул тарифов"
