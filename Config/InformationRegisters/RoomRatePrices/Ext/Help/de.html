Регистр сведений "Цены по тарифам"

Назначение

Регистр содержит строки приказов об изменении цен и позволяет получить состав строк нужного приказа об изменении цен в порядке определяемом правилами сортировки.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: Непериодический

Режим записи: Ручное редактирование регистра запрещено

Измерения

  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тариф. Ссылается на справочник «Тарифы». 
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях».
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Тип номера. Ссылается на справочник «Типы номеров».
  • Вид размещения. Ссылается на справочник «Виды размещения». 
  • Приказ об изменении цен. Ссылается на документ «Приказ об изменении цен тарифа».
  • Порядок сортировки. Тип значения: «Число».

Ресурсы

  • Услуга. Ссылается на справочник «Услуги».
  • Цена. Тип значения: «Число».
  • Валюта. Ссылается на справочник «Валюты».
  • Минимальное количество. Тип значения: «Число».
  • Ставка НДС %. Ссылается на справочник «Ставки НДС».
  • Правило вычисления количества. Ссылается на справочник «Правила вычисления количества услуг».
  • Это доход от продажи номеров. Тип значения: «Булево».
  • Включать в цену. Тип значения: «Булево».
  • Это цена за одного человека. Тип значения: «Булево».

Способ вызова

Вызывается из меню "Взаиморасчёты/Справочники/Параметры тарифов/Цены тарифов"

Дополнительная информация

Регистр заполняется при проведении документов "Спецификации цен тарифов"
