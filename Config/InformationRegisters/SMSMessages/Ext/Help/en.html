Регистр сведений "Отправленные СМС сообщения"

Назначение

Регистр содержит список отправленных из программы СМС сообщений. Регистр используется с одной стороны для контроля статуса получения СМС адресатом, с другой стороны для формирования отчетов по количеству отправленных СМС.

Относится к подсистеме: «Управление СМС».

Параметры

Периодичность: Периодический до секунды

Режим записи: Независимый

Измерения

  • ID сообщения. Строка. Уникальный идентификатор сообщения. Заполняется СМС шлюзом через который выполняется отправка сообщений

Ресурсы

  • Телефон. Строка. Номер телефона куда было отправлено СМС.
  • Текст. Строка. Текст СМС сообщения.
  • Кол-во сегментов. Число. Кол-во сегментов из которых состояло отправленное СМС сообщение. Заполняется шлюзом отправки. Именно на это число уменьшается баланс купленных гостиницей СМС.
  • Стоимость. Число. Стоимость отправленного СМС. Заполняется не у всех СМС шлюзов.
  • Результат. Строка. "ОК" или код ошибки обработки СМС шлюзом отправки сообщений.
  • Статус. Строка. Код статуса доставки сообщения до адресата. Заполняется специальным регламентным заданием, которое выполняется обычно раз в сутки рано утром.
  • Дата и время отправки. Дата и время отправки сообщения в СМС шлюз.
  • Отправитель. Строка текста, которая указывалась в качестве отправителя СМС.
  • Шаблон СМС сообщения. Ссылка на справочник "Шаблоны СМС". Позволяет формировать отчет по статистике отправленных СМС в разрезе шаблонов или, другими словами, типов СМС сообщений
  • Клиент. Ссылка на справочник "Клиенты". Клиент, которому отправлено СМС сообщение
  • Документ клиента. Ссылка на документ "Резервирование" или "Размещение". Документ, по которому клиент размещался в отеле
  • Статус документа клиента. Ссылка на справочники "Статусы брони" или "Статусы размещений". Статус документа клиента в момент отправки СМС. 

Способ вызова

Пользователями не редактируется. Вызывается из меню "Сообщения/Отправленные СМС сообщения"
