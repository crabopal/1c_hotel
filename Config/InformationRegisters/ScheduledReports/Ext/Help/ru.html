Регистр сведений "Отчеты по расписанию"

Назначение

Регистр используется для временного хранения списка ключей отчетов. которые должны быть автоматически выполнены. Регистр заполняется регламентной процедурой выполнения отчетов по расписанию. Регистр очищается и отчеты выполняются в тех клиентских сессиях, которые работают на рабочих местах с включенным флажком "Выполнять фоновые задания".

Относится к подсистеме: «Управление настройками».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Дата и время. Тип значения: «Дата».
  • Ключ отчета по расписанию. Тип значения: «Строка».

Способ вызова

Вызывается из меню "Сервис/Отчеты по расписанию"

Дополнительная информация

Платформа 1С:Предприятие 8 не позволяет формировать отчеты использующие построитель отчетов в фоновом режиме на сервере, поэтому на сервере происходит только заполнение данного регистра, который по сути является очередью отчетов на исполнение. Собственно формирование отчетов происходит в клиентских сессиях, в настройках параметров рабочего места которых включен флажок "Выполнять фоновые задания"
