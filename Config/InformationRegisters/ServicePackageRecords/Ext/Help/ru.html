Регистр сведений "Записи пакетов услуг"

Назначение

Регистр содержит записи из таблиц услуг справочника «Пакеты услуг». Регистр предназначен для программного получения действующих на заданную дату цен услуг пакета и не предназначен для редактирования пользователями программы. Регистр заполняется автоматически при сохранении пакетов услуг из справочника. Конечным пользователем регистр может использоваться для просмотра действующих на текущую дату цен услуг пакета. Для этого в форме списка регистра можно нажать кнопку "Срез последних".

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: С точностью до даты

Режим записи: Автоматически при записи элемента справочника «Пакеты услуг».

Измерения

  • Пакет услуг. Ссылается на справочник «Пакеты услуг».
  • Тип клиента. Ссылается на справочник «Типы клиентов».
  • Услуга. Ссылается на справочник «Услуги».
  • Вид размещения. Ссылается на справочник «Виды размещений».
  • Правило вычисления количества. Ссылается на справочник «Правила вычисления количества услуг». 
  • Тип дня календаря. Ссылается на справочник «Типы дней календарей».
  • Учетная дата. Тип значения: «Дата». 
  • Номер дня в периоде проживания. Тип значения: «Число».

Ресурсы

  • Цена. Тип значения: «Число».
  • Валюта. Ссылается на справочник «Валюты».
  • Количество. Тип значения: «Число».
  • Единица измерения. Тип значения: «Строка».
  • Ставка НДС %. Ссылается на справочник «Ставки НДС».
  • Примечания. Тип значения: «Строка».
  • Услуга входит в цену номера. Тип значения: «Булево». Если галочка включена, то программа включает цену этой услуги в цену номера за сутки
  • Это услуга на человека. Тип значения: «Булево». Если галочка включена, то при начислении услуг из пакета в брони и размещении программа умножит количество услуги указанное в пакете на количество человек указанное в документе (брони/размещении).
  • Номер строки в таблице пакета услуг. Тип значения: «Число». Используется для сортировки строк полученных из регистра в том же порядке как они указаны в табличной части пакета услуг 

Способ вызова

Заполняется автоматически при сохранении пакета услуг или вызывается из меню "Взаиморасчёты/Справочники/Параметры услуг/Записи пакетов услуг"
