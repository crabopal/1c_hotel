Регистр сведений "История изменений спецификаций формул тарифов"

Назначение

Регистр хранит историю изменений документов об установке формул тарифов.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Спецификации формул тарифа. Ссылается на документ «Спецификации формул тарифа».

Ресурсы

  • Номер документа. Тип значения: «Строка».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тариф. Ссылается на справочник «Тарифы».
  • Процент скидки. Число.
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».
  • Формулы. Тип значения: «Хранилище значения».

Реквизиты

  • Пользователь. Ссылается на справочник «Сотрудники». 

Способ вызова

Вызывается по кнопке "История изменений" на карточке документа или вызывается из меню "Взаиморасчёты/Справочники/Параметры тарифов/История изменений спецификаций формул тарифов"
