Регистр сведений "История изменений приказов об изменении цен"

Назначение

Регистр хранит историю изменений приказов об изменении цен по тарифам.

Относится к подсистеме: «Управление взаиморасчетами».

Параметры

Периодичность: С точностью до секунды

Режим записи: Независимый

Измерения

  • Приказ об изменении цен. Ссылается на документ «Приказ об изменении цен тарифа».

Ресурсы

  • Номер документа. Тип значения: «Строка».
  • Гостиница. Ссылается на справочник «Гостиницы».
  • Тариф. Ссылается на справочник «Тарифы».
  • Тип дня календаря. Ссылается на справочник «Типы дней в календарях».
  • Примечания. Тип значения: «Строка».
  • Автор. Ссылается на справочник «Сотрудники».
  • Цены. Тип значения: «Хранилище значения».

Реквизиты

  • Пользователь. Ссылается на справочник «Сотрудники». 

Способ вызова

Вызывается по кнопке "История изменений" на карточке приказа или вызывается из меню "Взаиморасчёты/Справочники/Параметры тарифов/История изменений приказов об изменении цен"
