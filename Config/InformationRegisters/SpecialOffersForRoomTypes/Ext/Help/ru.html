Регистр сведений "Специальные предложения по типам номеров"

Назначение

Регистр содержит список типов номеров (или классов номеров) на которые действует спец. предложения. Если в измерениях регистра указана гостиница, то выбранное спец. предложение действует для этой гостиницы. Если поле гостиница пустое, то спец. предложение действует для всех гостиниц базы. Если тип номера выбран, то спец. предложение действует на этот тип номера. Группу типов номеров выбирать нельзя. Если выбран класс номера, то предложение действует только на типы номеров этого класса. Группы классов выбирать нельзя.

Относится к подсистеме: «Тарифы и договоры».

Параметры

Периодичность: Непериодический

Режим записи: Независимый

Измерения

  • Спец. предложение. Ссылка на элемент справочника "Спец. предложения". Должно быть указано. 
  • Гостиница. Ссылка на группу или элемент справочника "Гостиницы". Если пустое, то спец. предложение действует на все гостиницы базы. Если выбрана папка, то спец. предложение действует на все гостиницы из папки.
  • Тип номера. Ссылка на элемент справочника "Типы номеров". Если пустое, то спец. предложение действует на все типы номеров ранее выбранной гостиницы.
  • Класс номера. Ссылка на элемент справочника "Классы типов номеров". Если пустое, то спец. предложение действует на все типы номеров ранее выбранной гостиницы.
