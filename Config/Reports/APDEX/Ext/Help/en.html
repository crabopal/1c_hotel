Отчет по показателю APDEX

Данный отчет предназначен для просмотра данных о производительности ключевых операций информационной базы, которые вычисляются по методике APDEX.

Отчет содержит в себе несколько вариантов просмотра данных:

·         APDEX по часам

·         APDEX по дням

·         APDEX по неделям

По умолчанию отчет формируется с отбором по тем ключевым операциям, у которых заполнено свойство «Приоритет». Эту настройку можно изменить, отредактировав вариант отчета вручную.

При настройке по умолчанию в отчет выводится единственный показатель – APDEX в разрезе ключевых операций. Однако в него могут быть дополнительно выведены следующие показатели:

·         Минимальная длительность ключевой операции

·         Максимальная длительность ключевой операции

·         Средняя длительность ключевой операции

·         Количество замеров по ключевой операции

·         Дисперсия длительности замеров

·         Стандартное отклонение длительности замеров
