Отчет "Аудит замен номеров комнат в размещениях"

Назначение

Имя отчета в конфигураторе «AccommodationChangeRoomAudit».

Отчет используется для формирования списка переселений гостей.

Отборы на форме отчета

  • Период отчета – отбирает за какой период сформировать отчет.
  • Гостиница – задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • Номер, откуда было переселение – задает отбор по номеру комнаты или по группе номеров.
  • Тип номера, откуда было переселение – задает отбор по типу номера или по группе типов номеров.
  • Номер, куда было переселение – задает отбор по номеру комнаты или по группе номеров. 
  • Тип номера, куда было переселение – задает отбор по типу номера или по группе типов номеров. 
  • Сотрудник – задает отбор по сотруднику, проведшему переселение.

Группировки

  • Размещение - ссылка на справочник «Размещения», указывает на текущее размещение.
  • Сотрудник – сотрудник, выполнивший переселение гостя.
  • Номер, откуда гость переселялся
  • Номер, куда гость переселялся
  • Тип номера, откуда гость переселялся
  • Тип номера, куда гость переселялся

Колонки

  • Параметры размещения до переселения
    • Сроки проживания, тариф, аналитика и т.д.
  • Параметры размещения после переселения
    • Сроки проживания, тариф, аналитика и т.д.
  • Время переселения - дата и время переселения
