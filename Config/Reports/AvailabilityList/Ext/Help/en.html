Отчет "Список доступности"

Назначение

Имя отчета в конфигураторе «AvailabilityList».

Отчет позволяет по дням формировать прогноз загрузки гостиницы в разрезе типов питания и/или видов из окна номера. Опционально данные отчета можно выводить по типам номеров. Отчет рассчитывает на каждую дату кол-во номеров/мест на заезде, на выезде, кол-во занятых номеров/мест. Отчет обычно формируется с текущей даты на 30 дней в будущее.

Отборы на форме отчета

  • По номеру - обычно указывается группа номеров номерного фонда (корпус или этаж). Если поле оставить пустым, то отчет будет сформирован по всему номерному фонду гостиницы.
  • По типу номера.
  • По заказчику - задает отбор брони по контрагенту (по группе или элементу).
  • По договору - задает отбор брони по договору.

Группировки колонок

  • По учетной дате - основная группировка, обычно всегда присутствует в отчете
  • По учетной неделе
  • По учетному месяцу
  • По учетному кварталу
  • По учетному году
  • По типу номера - дополнительная группировка, добавляется когда нужна детализация до категорий номеров
  • По виду из окна - дополнительная группировка, добавляется когда нужна детализация до вида из окна номера
  • По виду питания - дополнительная группировка, добавляется когда нужна детализация до вида питания
  • По типу записи - заезд/выезд/занято

Колонки

  • Кол-во номеров/мест
