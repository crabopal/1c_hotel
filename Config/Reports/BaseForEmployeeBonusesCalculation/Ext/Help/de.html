Отчет "Расчет базы для премирования сотрудников"

Назначение

Имя отчета в конфигураторе «BaseForEmployeeBonusesCalculation». 

Отчет позволяет получить сумму услуг проданных сотрудниками. Общая сумма продаж сотрудника формируется из нескольких частей:

1. Стоимости проданных сотрудником доп. услуг

2. Стоимости проданных сотрудником услуг повышения категории номера

3. Стоимости брони, созданной сотрудником, включая поселение "от стойки"

Отборы на форме отчета

  • Набор дополнительных услуг - задает отбор услуг, которые будут учитываться при формировании стоимости дополнительных услуг. Если поле оставить пустым, то будет посчитана стоимость всех услуг гостиницы, которые не входили в стоимость проживания. 
  • Набор услуг повышения категории номера - задает отбор услуг, которые будут учитываться при формировании стоимости услуг повышения категории номера. Если поле оставить пустым, то стоимость услуг повышения категории номера заполняться не будет. 
  • Типу номера - отбор услуг проданных гостям проживавшим в номерах выбранной категории/группы категорий. 
  • Источник - задает способ отбора броней созданных сотрудником. Если указан, то при формировании стоимости брони созданной сотрудником учитываются только брони, у которых указан этот источник. Можно указывать группу источников. Если параметр не заполнен, то отчет отбирает все размещения без брони и все брони созданные этим сотрудником. Учитываются только гости выехавшие в периоде отчета.
  • Сотрудник - задает отбор по сотруднику/группе сотрудников для которых необходимо рассчитать базу.
  • Отдел - задает отбор по отделу/группе отделов, для которых необходимо рассчитать базу.

Группировки

  • Сотрудник
  • Тип базы: доп. услуги, услуги повышения категории, брони
  • Учетная дата – дата оказания услуг, создания брони. 
  • Клиент – гость, ссылка на справочник «Клиенты».
  • Тип клиента – характеристика гостя, может использоваться как разделитель учета для аналитики, также используется для задания разных цен по разным типам клиентов (каждому типу клиента можно поставить в соответствие свой тариф).
  • Фирма – юр.лицо гостиницы, от имени которой оформлено размещение гостя. 
  • Договор – ссылка на договор контрагента, используется как разделитель учета взаиморасчетов с контрагентом. 
  • Контрагент – ссылка на справочник контрагентов, указывает на организацию, юр. лицо, от имени которого было произведено бронирование (размещение). 
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Направление маркетинга – ссылка на элемент справочника «Направления маркетинга». Используется для анализа, может быть использован в группировках и отборах.
  • Отчетная валюта – валюта, указанная в качестве отчетной для данной гостиницы.
  • Ресурс – ссылка на справочник «Ресурсы», указывает ресурс, использованный при оказании услуги. 
  • Номер – указывает номер комнаты, в которой размещен клиент. 
  • Тариф – показывает, по какому тарифу поселили гостя, или забронировали номер. Тариф определяет цену номера и набор начисляемых услуг. 
  • Тип тарифа – разделитель учета, в разрезе типа тарифа можно строить аналитические отчеты. 
  • Тип номера – ссылка на справочник «Типы номеров», указывает на тип номера, в котором размещен гость (планируется размещение). 
  • Услуга – название начисленной услуги. 
  • Источник информации. 
  • Цель поездки – ссылка на справочник «Цели визита», может использоваться для построения аналитических отчетов. 
  • Ставка НДС – размер ставки НДС. 

Колонки

  • Сумма проданных услуг/стоимость брони с НДС
  • Сумма проданных услуг/стоимость брони без НДС
  • Комиссия – сумма вычисленной комиссии для агента. 
  • Комиссия без НДС – та же сумма без НДС. 
  • Сумма скидки – сумма предоставленной скидки. 
  • Сумма скидки без НДС – та же сумма без НДС. 
  • Количество – количество проданной услуги.
