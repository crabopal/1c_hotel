Отчет "История бизнес-блоков"

Назначение

Имя отчета в конфигураторе «BusinessBlocksHistory».

Отчет позволяет сформировать список всех бизнес-блоков созданных, отмененных за указанный период или пересекающихся по периоду действия с указанным периодом по указанным гостиницам, типам номеров и контрагентам.

Отборы на форме отчета

  • По виду проверки периода отчета - проверка дат блоков относительно периода формирования отчета. Проверок существует несколько видов:
    • пересечение - в отчете отобразятся бизнес-блоки, период проживания которых пересекается с периодом отчета;
    • начинается в периоде - в отчет попадут только те блоки, дата начала периода которых попадает в период отчета;
    • дата создания блока попадает в период - в отчете отобразятся блоки, которые были созданы в периоде отчета.
    • дата отмены блока попадает в период - в отчете отобразятся отмененные блоки, которые были удалены в указанном периоде
  • По типу номера - задает отбор по типу номера который используется в блоке.
  • По контрагенту - задает отбор по заказчику бизнес блока. Можно указывать контрагента или выбирать папку. При указании папки контрагентов в отчет попадут бизнес-блоки у которых заказчик входит в указанную папку.
  • По статусу бизнес-блока - гарантированный или предварительный.
  • По автору - по сотруднику или папке сотрудников создавших/отменивших блок 

Группировки

  • Контрагент – ссылка на справочник контрагентов, указывает контрагента, указанного как заказчик в бизнес блоке
  • Автор – пользователь, создавший или отменивший бизнес блок.
  • Статус блока - предварительный или гарантированный блок.
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Источник информации – ссылка на справочник «Источник информации», может использоваться для построения аналитических отчетов. 
  • Направление маркетинга – ссылка на элемент справочника «Направления маркетинга». Используется для анализа, может быть использован в группировках и отборах.
  • Тариф – показывает, по какому тарифу создали блок
  • Тип номера – ссылка на справочник «Типы номеров», указывает на тип номера, в котором планируется размещение гостей.

Колонки

  • Причина отмены - причина отмены блока
  • Автор создания/отмены - пользователь, который создал или отменил блок
  • Дата начала – дата начала периода блока
  • Дата окончания – дата окончания периода блока
  • Примечания - текстовое пояснение к блоку
