Отчет "Туристическая Организация Кипра - Сведения о количестве гостей по странам - Месячная"

Назначение

Имя отчета в конфигураторе «CTOGuestsByCountriesMonthly».

Сведения о количестве гостей по странам гражданства и о количестве проданных номеров по датам месяца.

Выводимые показатели по странам

  • Код страны – код из шаблона отчета.
  • Страна (гражданство) – ссылка на справочник «Страны».
  • Количество заехавших гостей
  • Количество дней пребывания (человеко-дней) – продолжительность заезда, выраженная в человеко-днях.

Выводимые показатели по датам месяца

  • Количество занятых номеров
