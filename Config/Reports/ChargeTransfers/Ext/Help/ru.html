Отчет "Перемещения начислений"

Назначение

Имя отчета в конфигураторе «ChargeTransfers».

Отчет позволяет получить детальную распечатку перемещений начислений за указанный период. Отчет используется для аудита проведенных перемещений. Отчет показывает, какое начисление, от какого гостя и куда переместили.

Группировка может быть по любой колонке. Обычно отчет формируется без группировок за интересующий период, например за смену.

Отборы на форме отчета

  • Период отчета – отбирает за какой период включать перемещения в отчет. Отбор выполняется именно по дате перемещения, а не по дате начисления.
  • Фирма – если указано, то в отчет будут выведены только данные по указанной фирме.
  • Гостиница – задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • Контрагент – задает отбор по контрагенту или группе контрагентов, если не выбран, то данные будут выведены по всем контрагентам.
  • Договор – задает отбор по договору контрагента.
  • Группа – отбор по группе гостей.

Группировки производятся практически по всем переменным, встречающимся в отчете.

Колонки

  • Учетная дата – дата, когда было произведено перемещение (не включает время). Поле обычно используется для группировки отчета по датам.
  • Учетный месяц – месяц, когда произведено перемещение. Используется для группировки по месяцам.
  • Учетный квартал – квартал, когда было произведено перемещение. Используется для группировок или отборов.
  • Учетная неделя – номер недели, когда было произведено перемещение начисления.
  • Учетный год – год перемещения.
  • Автор – автор, выполнивший перемещение начисления.
  • Перемещение начисления – ссылка на документ перемещения.
  • Период – дата и время документа перемещения, отражает, когда именно было выполнено перемещение начисления.
  • Валюта – валюта начисления.
  • С лицевого счета – значение лицевого счета (фолио) до перемещения.
  • От клиента – значение клиента (гостя) до перемещения.
  • Из договора – значение договора до перемещения.
  • От контрагента – значение контрагента до перемещения.
  • Дата заезда (из) – значение даты и времени заезда в фолио до перемещения.
  • Дата выезда (из) – значение даты и времени заезда в фолио после перемещения.
  • Из группы гостей – значение группы в фолио до перемещения.
  • Из способа оплаты – значение планируемого способа оплаты до перемещения.
  • Из номера – значение номера комнаты в фолио до перемещения.
  • На лицевой счет – ссылка лицевой счет, куда начисление было перемещено.
  • К клиенту – значение клиента (гостя) после перемещения.
  • В договор – значение договора после перемещения.
  • К контрагенту – значение контрагента после перемещения.
  • Дата заезда (в) – значение даты и времени заезда гостя в фолио после перемещения.
  • Дата выезда (в) – значение даты и времени заезда гостя в фолио после перемещения.
  • В группу гостей – значение группы после перемещения.
  • В способ оплаты – планируемый способ оплаты в фолио после перемещения.
  • В номер – значение номера комнаты после перемещения.
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Начисление – ссылка на документ начисление.
  • Документ основание – документ основание, по которому прошло первоначальное начисление. Обычно размещение или бронь ресурсов.
  • Количество – значение количества, которое было перемещено.
  • Примечания – примечания к начислению.
  • Услуга – ссылка услугу, которая была начислена.
  • Сумма – сумма перемещения.
