Отчет "Сверка начислений по контрагентам"

Назначение

Имя отчета в конфигураторе «CheckCustomerServices». 

Отчет используется для сверки услуг оказанных по группе гостей. Отчет позволяет сравнить суммы по гостям запланированные к оказанию по брони и реальные начисления выполненные по размещениям. Отчет удобно использовать в случаях, когда бронь группы перед поселением была расписана по фамилиям. В этом случае отчет по каждому гостю выведет сумму фактических начислений, сумму планируемую по брони и, если есть разница, то выделит таких гостей цветом. Отчет выводит суммы в разрезе услуг и, если в списке колонок отчета есть колонка "Цена", то в разрезе цен услуг. 

Если по брони поселения не было, т.е. бронь находится в статусе "Незаезд" или "Отказ", то в отчет будет выведена строка с данными гостя в которой будет заполнена сумма из брони, а сумма фактических начислений будет равна 0. 

Вызвать отчет можно из карточки группы гостей по кнопке "Сверка оказанных по группе услуг".

Отчет группирует данные по контрагентам используя контрагентов указанных не в карточках брони/размещений, а в лицевых счетах. Т.е. отчет группирует суммы по контрагентам плательщикам услуг. Если необходимо группировать суммы по контрагентам указанным в карточках размещений/брони, то необходимо использовать отчет «Сверка начислений по гостям от контрагентов».

В списке колонок отчета колонка "Документ основание" является обычно ссылкой на карточку размещения, а колонка "Бронь" является ссылкой на бронь, по которой было оформлено размещение. Для сравнения параметров брони с параметрами фактического поселения, из поля "Бронь" через точку можно вывести в отчет основные параметры брони (тариф, тип номера, сроки проживания и т.д.).

Отборы на форме отчета

  • Период - задает отбор гостей заехавших в указанном периоде. Суммы по услугам всегда показываются за весь период проживания.  
  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам. 
  • По основным разрезам учета взаиморасчетов – по контрагенту, агенту, договору и группе гостей. 
  • По набору услуг. 
  • По дням. Если флажок включен, то оказанные суммы выводятся по учетным датам для проверки цены проживания на каждый день. 
  • Показывать суммы брони. Если флажок включен, то отчет выполняет сравнение фактически оказанных сумм услуг с суммами запланированными к оказанию по брони.

Группировки

  • Контрагент – ссылка на справочник контрагентов, указывает контрагента, на которого были начислены услуги (контрагент из «Фолио»). Если гость оплачивал на стойке как «физическое лицо», то значение контрагента в данном отчет будет пустым. 
  • Договор – договор из фолио, по которому проведено начисление. 
  • Группа – объединяет несколько гостей, но может также состоять и из одного гостя. Каждый гость обязательно принадлежит какой-либо группе. Номер группы – это номер брони. В разрезе групп ведется учет взаиморасчетов с контрагентами. 
  • Вид размещения – ссылка на справочник «Виды размещений», указывает на вид текущего размещения. 
  • Учетная дата - дата начисления услуги. Заполняется, если в правом верхнем углу отчета поставлена галочка «По дням». 
  • Агент – ссылка на справочник контрагентов, указывает контрагента, который получает комиссию за гостя. Может также использоваться для анализа эффективности работы агентов или туроператоров. 
  • Клиент – гость, ссылка на справочник «Клиенты». 
  • Фирма – юр. лицо гостиницы, от имени которого оформлено размещение гостя. 
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета. 
  • Документ основание – ссылка на документ по которому производился расчет и начисление услуг, принимает значения «Размещение», «Состав квот» или «Бронь ресурса». В случае если в колонке указано «Фолио», то начисления проводили для «стороннего посетителя», т.е. клиента не проживающего в гостинице. 
  • Ресурс – ресурс, задействованный в оказании услуги. 
  • Номер – номер комнаты, в которой разместили клиента. 
  • Тариф – показывает, по какому тарифу поселили гостя, или забронировали номер. Тариф определяет цену номера и набор начисляемых услуг. 
  • Тип номера – ссылка на справочник «Типы номеров», указывает на тип номера, в котором размещен гость. 
  • Услуга – услуга, начисленная клиенту. 
  • Статус – отражает статус размещения на момент формирования отчета, может быть «Заезд», «Выезд» или другое значение из справочника «Статусы размещений».

Колонки

  • Продано дополнительных мест – количество место-дней за период отчета. 
  • Продано мест – количество место-дней, начисленных за период отчета. 
  • Дата заезда – указание даты и времени заезда гостя. 
  • Дата выезда – указание даты и времени выезда заезда. 
  • Комиссия – сумма вычисленной комиссии для агента. 
  • Комиссия без НДС – та же сумма без НДС. 
  • Сумма скидки – сумма предоставленной скидки. 
  • Сумма скидки без НДС – та же сумма без НДС. 
  • Валюта лицевого счета - валюта фолио. 
  • Человеко-дни – количество человеко-дней за период отчета. Рассчитывается по каждому гостю независимо от стоимости проживания. 
  • Заезд гостей – количество заехавших за период отчета гостей. 
  • Доходы от продажи номеров – сумма, начисленная за услуги проживания клиента за период отчета. 
  • Доходы от продажи номеров без НДС – та же сумма без НДС. 
  • Продано номеров – количество номеро-дней начисленных за период отчета. 
  • Продажи – сумма, начисленная клиенту за период отчета. 
  • Продажи без НДС – та же сумма без НДС. 
  • Продажи по брони – сумма услуг запланированных к оказанию по брони. 
  • ... остальные ресурсы аналогично колонкам рассчитанным по фактически оказанным услугам, но согласно условиям брони.
