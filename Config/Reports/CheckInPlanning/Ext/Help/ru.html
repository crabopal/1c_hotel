Отчет "Планирование заездов"

Назначение

Имя отчета в конфигураторе «CheckInPlanning».

Отчет используется для планирования заездов гостей. При указанной продолжительности заездов, например 21 день, отчет покажет в разрезе типов номеров периоды, когда такие заезды возможны, и количества доступных на эти периоды номеров/мест.

Отчет можно формировать по выбранным типам номеров, группам номеров. Вид расчета продолжительности проживания позволяет выбрать схему формирования периода заезда по дате заезда и продолжительности заезда в днях. Если выбран вид расчета "По расчетному часу" или "По ночам", дата заезда 01.04 и продолжительность 21 день, то датой окончания периода заезда будет 22.04. Если выбран вид "По дням", то датой окончания периода заезда будет 21.04.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По номеру – задает отбор по номеру.
  • По набору услуг.
  • По типу номера - если поле оставить пустым, то отчет выведет данные по всем типам номеров.
  • По виду расчета продолжительности проживания - от выбранного типа зависит дата планируемого выезда гостя.
  • По сроку проживания.

Группировок в отчете не предусмотрено.

Колонки

  • Доступно мест - общее количество мест за вычетом мест в блокировке.
  • Свободно мест - количество мест, готовых для продажи.
  • Дата заезда - дата планируемого заезда гостя.
  • Дата выезда - дата планируемого выезда гостя.
  • Продолжительность - длительность проживания.
  • Гостиница – название гостиницы. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Доступно номеров - общее количество номеров за вычетом номеров в блокировке.
  • Свободно номеров - количество номеров, готовых для продажи.
  • Тип номера – ссылка на справочник «Типы номеров».
