Отчет "Задание на уборку"

Назначение

Имя отчета в конфигураторе «CleaningTask».

Отчет предназначен для планирования работ горничных. В отчет выводятся все номера из номерного фонда. Напротив каждого номера указывается код работы, которую нужно выполнить в номере и информация о проживающих гостях. Отчет формируется на дату, время не учитывается. При расчете работ учитываются текущие проживающие гости и все выезды до конца дня. Также учитываются статусы номеров.

Для правильной работы необходимо заполнить реквизиты отчета:

  • Статус после выселения – необходимо указать значение статуса номера после выселения, обычно это «Грязный». Данное значение подставляется автоматически в отчет, если заполнен параметр в настройках гостиницы (форма карточки гостиницы, закладка «Константы 2»).
  • Набор регл. работ – ссылка на справочник регламентных работ, которые нужно выполнить в номере, например это может быть смена белья. Свойства, состав и периодичность работ задаются в справочнике «Регламентные работы».
  • Номер – используется для задания отбора по номеру комнаты или по группе номеров. Чаще всего используется для отбора по этажам (для этого номера в справочнике «Номерной фонд» должны быть сгруппированы по этажам).
  • Уборка по выезду – указывает вид работ, который нужно выполнять в номере после выезда гостя.
  • Регулярная уборка – указывается вид работы, которая выполняется на каждый день проживания гостя («Текущая уборка»).
  • Уборка после ремонта – указывается вид работ, который нужно выполнить после окончания ремонта в номере. В день окончания ремонта в номере программа автоматически подставит этот вид уборки для номера.
  • Уборка в свободных номерах – указывается вид работы, которую нужно выполнить, если в номере никто не живет второй день и номер простаивает свободным.

Алгоритм формирования отчета следующий:

  • В отчет выводятся все номера номерного фонда.
  • По каждому номеру выводится текущий статус номера.
  • Если в номере на дату отчета запланирован выезд, то добавляется код уборки по выезду, если в номере проживают, то добавляется код регулярной уборки.
  • Дополнительно выполняется проверка на статус номера – если статус «Грязный» (т.е. после выезда), то номеру назначается код выездной уборки, т.к. если номер до сих пор грязный, несмотря на то, что выезд был вчера или ранее, его все равно нужно убирать.
  • Проверяется необходимость проведения регламентной работы, например, смены белья, и, если подошел срок, то к номеру добавляется регламентная работа. Регулярность проведения таких регламентных работ задается в настройках справочника «Регламентные работы».

В отчете удобно пользоваться условным форматированием, например, разные виды работ подсвечивать разными цветами. (см. настройку отчета «230 – Задание на уборку» в группе «Эксплуатация» в демо-базе).

Для планирования работ горничных по нормативам и распределения работы между горничными согласно их трудового графика необходимо использовать документ «План работ».

Ниже приведено описание всех колонок, которые могут быть выедены в отчет. Жирным выделены те колонки, которые используются чаще всего.

Группировки

  • Размещение выезжающего гостя – ссылка на документ «Размещение» выезжающего гостя. Может использоваться для открытия документа непосредственно из отчета по расшифровке.
  • Выездная уборка – наименование работы для выездной уборки. Может быть использовано вместо кода.
  • Выезжающий гость – ссылка на гостя, у которого дата выезда совпадает с датой отчета. Данная колонка предназначена для того чтобы выезжающих гостей выводить в отдельной колонке и выделять их таким образом в общем списке.
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Размещение проживающего гостя - ссылка на документ «Размещение» проживающего гостя. Может использоваться для открытия документа непосредственно из отчета по расшифровке.
  • Проживающий гость – ссылка на гостя проживающего в номере, т.е. дата выезда у которого позже даты отчета.
  • Работа – ссылка на справочник работ, может использоваться для вывода названия работы.
  • Текущая уборка в занятом номере.
  • Регулярная работа – наименование регулярной работы, может быть использовано вместо кода.
  • Номер – номер комнаты. Выводится всегда, если в номере не нужно проводить никаких работ, то поля с кодами работ остаются пустые.
  • Тип блокировки – ссылка на справочник «Типы блокировки», содержит значение установленное документов блокировки.
  • Статус номера – текущий статус номера. Внимание в отчет выводится статус, который установлен у номера на дату и время формирования отчета. Например статус может быть «Занят», в то время как у номера указана выездная уборка – это означает что в номере на дату отчета запланирован выезд, но гости еще не выехали.
  • Документ установки блокировки – ссылка на документ, установивший блокировку. Может быть использован для открытия документа непосредственно из отчета по расшифровке. Также может быть использован для вывода любых реквизитов документа «Блокировка», например, автора.

Колонки

  • Дата заезда – дата заезда гостя в номер.
  • Дата заезда выезжающего гостя – дата заезда гостя, который выделен в колонку «выезжающий».
  • Дата выезда выезжающего гостя – дата выезда гостя, который выделен в колонку «выезжающий».
  • Код выездной уборки – краткий буквенный код для выездной уборки.
  • Гражданство гостя – ссылка на справочник стран, содержит страну гражданства гостя.
  • Тип клиента - значение типа клиента. Ссылка на справочник «Типы клиентов».
  • Контрагент - ссылка на справочник «Контрагенты», от имени которого приехал гость. От имени этого контрагента обычно и было оформлено бронирование.
  • Имя гостя – строка, содержащая имя гостя из справочника клиентов.
  • Гость – ссылка на справочник клиентов.
  • Дата выезда – дата выезда гостя из номера. Если гость еще не выехал, то показывается планируемая дата выезда.
  • Есть заезд по брони - принимает значение «Да», если на номер есть бронь на формируемую дату отчета.
  • Гостей - количество гостей, проживающих в номере.
  • Код работы – код из справочника работ, обычно содержит буквенный краткий код работы. Используется, чтобы уменьшить ширину выводимых в отчет колонок.
  • Код сортировки работы – реквизит справочника работ, используется для сортировки в отчете.
  • Код текущей уборки в занятых номерах – краткий буквенный код текущей уборки в занятом номере.
  • Код регулярной работы – краткий буквенный код периодической регламентной работы, например, смены белья.
  • Код уборки в номерах после ремонта – краткий буквенный код уборки, которую нужно выполнить в номере в день окончания ремонта.
  • Дата окончания ремонта – дата окончания ремонта в номере, показывается по номерам, у которых установлена блокировка.
  • Примечания к ремонту – строка, содержащая примечания к документу блокировки номера.
  • Дата начала ремонта – дата начала блокировки номера.
  • Автор последнего изменения статуса номера.
  • Время последнего изменения статуса номера.
  • Тип номера – характеристика номера, может быть использована для планирования работ.
  • Отчество гостя – строка, содержащая отчество гостя из справочника клиентов.
  • Код уборки в свободных номерах – краткий буквенный код уборки номеров, которые простаивают свободными. Если в гостинице не принято убирать свободные номера, то колонку можно исключить из отчета.
