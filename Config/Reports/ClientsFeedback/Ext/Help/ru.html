Отчет "Отзывы клиентов"

Назначение

Имя отчета в конфигураторе «ClientsFeedback».

Отчет формируется по сохраненным в программе отзывам клиентов. По вопросам из отзывов рассчитывается количество ответов, среднее значение для числовых ответов, процент ответов по каждому значению.

Отборы на форме отчета

  • Период отчета – задает период отбора отзывов.
  • Тип номера – задает отбор по типу номера в котором проживали гости оставившие отзыв.
  • Опрос - задает отбор по виду опросника
  • Вопрос - задает отбор по вопросу
  • Ответ - задает отбор по ответу 
  • Гостиница – задет отбор по гостинице. Можно указывать папку гостиниц или оставить пустой.

Группировки

  • Клиент
  • Контрагент
  • Договор 
  • Опрос
  • Вопрос
  • Ответ 
  • Фирма - Юридическое лицо отеля, по которому прошла продажа сертификата.
  • Номер - номер комнаты, где проживал клиент - покупатель сертификата.
  • Тип номера - категория комнаты, где проживал клиент - покупатель сертификата.
  • Документ основание - размещение/бронь/бронь ресурса клиента

Колонки

  • Кол-во ответов
  • Среднее значение по всем ответам на определенный вопрос
  • Процент ответов этого вида в общем количестве ответов на вопрос данного вида
