Отчет "Реестр договоров"

Назначение

Имя отчета в конфигураторе «ContractsRegister».

Отчет распечатывает реестр договоров за период по контрагенту, типу договора, сотруднику 

Отборы на форме отчета

  • По периоду. Если даты оставить пустыми, то отчет будет сформирован по всей истории договоров.
  • По типу договора. Отчет выведет только договоры с выбранным типом.
  • По контрагенту. Отчет выведет договоры с указанным контрагентом или договоры контрагентов из указанной группы контрагентов.
  • По типу контрагента. Отчет выведет только договоры контрагентов с выбранным типом.
  • По сотруднику. Отчет выведет договоры созданные указанным сотрудником или группой сотрудников.

Группировки

  • Тип договора – Справочник "Типы договоров".
  • Тип контрагента – Справочник "Типы контрагентов".
  • Контрагент - Справочник "Контрагенты".
  • Сотрудник - Справочник "Сотрудники".
  • Отдел – Справочник "Отделы сотрудников".

Колонки

  • Номер договора.
  • Дата договора.
  • Дата регистрации договора в системе
  • Автор договора
  • Контрагент
  • Тип контрагента
  • Тип договора
  • Период действия договора
  • Примечания по договору
  • Планируемый способ оплаты по договору
