Отчет "Текущая реализация услуг"

Назначение

Имя отчета в конфигураторе «CurrentAccountsReceivable».

В отчет попадают только те начисления, по которым не было сформировано актов. Основное назначение отчета – проверка закрытия периода. Если закрытие периода настроено правильно, то сумма актов за закрытый месяц будет равняться сумме всех начислений за месяц. Если появляются расхождения, т.е. сумма отчета по актам («Бухгалтерская реализация услуг») не совпадает с суммой отчета по начислениям («Сводка по оказанным услугам»), то разницу можно будет выявить с помощью данного отчета – «Текущая реализация услуг». В этом отчете вы увидите итоги по группам, по которым есть расхождения между начислениями и актами.

Отчет имеет смысл формировать за прошедший (закрытый) месяц.

Отборы на форме отчета

  • Период отчета – отбирает за какой период с формировать отчет.
  • Фирма – если указано, то в отчет будут выведены только данные указанной фирмы. Если реквизит пустой, то будут выведены данные по всем фирмам.
  • Гостиница – задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • Контрагент – задает отбор по контрагенту или группе контрагентов, если не выбран, то данные будут выведены по всем контрагентам.
  • Договор – задает отбор по договору контрагента.
  • Группа – отбор по группе гостей.
  • Набор услуг – если поле заполнено, то в отчет попадут только данные по услугам входящим в выбранный набор.

Группировки

  • Начисление – ссылка на документ «Начисление», которым проведено начисление услуги по счету.
  • Фирма – ссылка на элемент справочника «Фирмы», по которой проведено начисление. Используется при многофирменном учете.
  • Договор – договор из фолио, по которому проведено начисление.
  • Контрагент – контрагент из фолио, по которому проведено начисление.
  • Лицевой счет – ссылка на фолио (лицевой счет), по которому проведено начисление.
  • Клиент – ссылка на справочник клиентов, содержит гостя, которому услуга была начислена.
  • Валюта – валюта начисления.
  • Номер – номер комнаты, в которой проживал гость.
  • Группа – объединяет несколько гостей, но может также состоять и из одного гостя. Каждый гость обязательно принадлежит какой – либо группе. Номер группы – это номер брони. В разрезе групп ведется учет взаиморасчетов с контрагентами. Если группа не указано, то это означает что начисление сделано по счету клиента не проживающего в гостинице.
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета..
  • Документ основание – ссылка на документ основание по которому прошло начисление, обычно это «Размещение» или «Бронь ресурсов».
  • Услуга – ссылка на начисленную услугу.
  • Ставка НДС – значение ставки, по которой прошло начисление.

Колонки

  • Баланс количества на конец периода – количество на конец периода отчета.
  • Количество в актах – количество по услуге, оформленное в актах.
  • Баланс количества на начало периода – количество на начало периода отчета.
  • Количество оказания – количество по услуге начисленное.
  • Количество – оборот по количеству. Начисление увеличивает количество, проведение акта уменьшает.
  • Баланс на конец периода – сумма на конец периода отчета, складывается из суммы начисленных услуг минус сумма актов.
  • Сумма в актах – сумма, в валюте начисления, которая отражена в актах.
  • Баланс на начало периода – сумма на начало периода отчета, складывается из суммы начисленных услуг минус сумма услуг в актах.
  • Сумма оказания – сама в валюте начисления, которая была начислена.
  • Сумма – оборот по сумме услуг. Начисление услуги увеличивает сумму, проведение акта уменьшает сумму.
  • Сумма НДС в актах – итого по сумме НДС, проведенной актами.
  • Сумма НДС оказания – сумма НДС начисленная.
  • Сумма НДС – оборот по Сумме НДС. Начисление увеличивает Сумму НДС, проведенные акты уменьшают.
