Отчет "Контакты контрагентов"

Назначение

Имя отчета в конфигураторе «CustomerContacts».

Отчет выводит список всех действующих контактных лиц контрагентов. Дополнительно к контактным лицам выводится контактная информация указанная в карточке контрагента

Отборы на форме отчета

  • По периоду регистрации контрагента в системе
  • По контрагенту - Можно указать папку контрагентов, которые будут распечатаны.
  • По тегам - Можно отметить теги и указать условие применения фильтра по нескольким тегам: будут отображаться контрагенты у которых есть все отмеченные теги или один из отмеченных.

Группировки

  • Контрагент – ссылка на справочник контрагентов, указывает на организацию, юр. лицо.

Колонки

  • Контактное лицо – строка, данные контакта в свободной форме
  • Клиент – ссылка на профайл контактного лица в справочнике "Клиенты".
  • Мобильный телефон
  • Рабочий телефон
  • E-Mail
  • Должность контактного лица
