Отчет "Продажи по подарочным картам и бонусам"

Назначение

Имя отчета в конфигураторе «GiftCertificatesSalesTurnovers». 

Отчет позволяет получить детальную распечатку операций по подарочным картам или накоплению бонусов для клиента/контрагента/карты лояльности. 

Отборы на форме отчета

  • Гостиница - задает отбор по гостинице. 
  • Карта - задает отбор по карте лояльности или подарочной карте
  • Тип скидки - задает отбор по типу программы лояльности
  • Контрагент - задает отбор по организации
  • Клиент - задает отбор по клиенту
  • Автор - задает отбор по автору операции изменения остатка подарочной карты или изменения остатка бонусов
  • Сотрудник - задает отбор по сотруднику, который создал подарочную карту или карту лояльности
  • Отдел - задает отбор по отделу сотрудников, которые создали подарочную карту или карту лояльности
  • Период отбора операций

Группировки

  • Все поля из справочника "Дисконтные карты".
