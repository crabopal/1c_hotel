Отчет "Отгруженные но не проданные путевки"

Назначение

Имя отчета в конфигураторе «HotelProductsIssuedButNotSold».

Отчет позволяет получить список отгруженных путевок (оформленных документами "Отгрузка путевок контрагентам"), по которым не заезжали гости.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По типу путевки - задает отбор по типу путевки или курсовки (группе справочника путевок и курсовок).
  • По основным разрезам учета взаиморасчетов - по контрагенту, по договору.
  • По набору услуг - задает отбор по набору услуг.

Группировки

  • Номер накладной на отгрузку – соответствующий реквизит документа «Накладная на отгрузку путевок».
  • Фирма – юр.лицо гостиницы, от имени которой оформлено размещение гостя.
  • Договор – ссылка на договор контрагента, используется как разделитель учета взаиморасчетов с контрагентом.
  • Валюта – валюта документа «Накладная на отгрузку путевок».
  • Контрагент – юр.лицо, заключившее с гостиницей договор, на основании которого произведено размещение гостя.
  • Гостиница – название гостиницы, в которой планировался к размещению гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Тип путевки – группа справочника «Путевки и курсовки».
  • Регистратор – ссылка на документ «Накладная на отгрузку путевок».

Колонки

  • Дата заезда – дата и время предполагаемого заезда.
  • Дата выезда – дата и время предполагаемого выезда.
  • Количество – указание количества путевок.
  • Продолжительность – длительность заезда (вычисляется как разность дат выезда и заезда).
  • Цена – цена одной путевки.
  • Номер путевки – указание номера путевки.
