Отчет "Служба номерного фонда"

Назначение

Имя отчета в конфигураторе «HousekeepingRooms».

Отчет предназначен для контроля состояния номерного фонда. В отчет выводятся все номера из номерного фонда. Напротив каждого номера указывается его статус, состояние номера: планируется ли заезд, выезд, занят номер или свободен. Выводятся все примечания по этому номеру из планируемого заезда, активных по номеру задач и т.д. Отчет формируется на дату.

Ниже приведено описание всех колонок, которые могут быть выедены в отчет. Жирным выделены те колонки, которые используются чаще всего.

Колонки

  • Гостиница – название гостиницы, которой принадлежит номер.
  • Номер – номер комнаты. Выводится всегда, если в номере не нужно проводить никаких работ, то поля с кодами работ остаются пустые.
  • Статус номера – текущий статус номера. Внимание в отчет выводится статус, который установлен у номера на дату и время формирования отчета.
  • Состояние номера – текущее состояние номера строкой. Примеры состояний: Планируется выезд, Планируется заезд, Занят, Свободен, Планируется переселение и т.д. Состояний может быть несколько, они перечисляются через запятую.
  • Тип блокировки – ссылка на справочник «Типы блокировки», содержит значение установленное у документа блокировки номера. 
  • Документ установки блокировки – ссылка на документ, установивший блокировку. Может быть использован для открытия документа непосредственно из отчета по расшифровке. Также может быть использован для вывода любых реквизитов документа «Блокировка», например, автора.
  • Примечания номера – если номер на планируемом заезде или на планируемом переселении, то в отчет выводятся примечания из поля брони "Примечания для горничных". 

  • Кол-во заезжающих гостей – если номер на планируемом заезде или на планируемом переселении, то в отчет выводятся строкой название шаблона размещения гостей в номере. Если планируемого заезда нет, то выводится шаблон проживающих гостей. 

  • Задачи - выводится текст активных задач номера
