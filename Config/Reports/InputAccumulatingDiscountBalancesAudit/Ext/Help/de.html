Отчет "История звонков"

Назначение

Имя отчета в конфигураторе «SimpleCallsHistory».

Отчет позволяет получить детальную распечатку зарегистрированных в программе через ПО "Простые звонки" входящих/исходящих звонков.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По направлению звонка - входящий, исходящий, пропущенный
  • По номеру телефона с которого был звонок - задает отбор по номеру телефона с которого был звонок. Поиск выполняется по условию "содержит" (LIKE) 
  • По номеру телефона на который был звонок - задает отбор по номеру телефона на который был звонок. Поиск выполняется по условию "содержит" (LIKE) 
  • По номеру - задает отбор по номеру, если поле оставить пустым, то будут выведенные данные по всем номерам гостиницы.

Группировки

  • Сотрудник - имя сотрудника, поднявшего трубку.
  • Дата звонка - дата начала звонка.
  • Час звонка - час начала звонка.
  • Месяц звонка - номер месяца начала звонка.
  • Квартал звонка - номер квартала начала звонка.
  • Неделя звонка - номер недели начала звонка.
  • Год звонка - год начала звонка.
  • Гостиница.
  • Направление звонка – входящий, исходящий, пропущенный.
  • Номер – номер гостиницы, в который/из которого был разговор.
  • Номер телефона откуда был звонок.
  • Номер телефона куда был звонок.
  • Контрагент - Контрагент, от которого был звонок
  • Клиент - Клиент от которого был звонок

Колонки

  • Дата и время начала разговора.
  • Дата и время окончания разговора.
  • Длительность разговора в формате Минуты.Секунды
  • Телефонный номер откуда был звонок (строка).
  • Телефонный номер на который был звонок (строка).
  • Количество – количество звонков.
