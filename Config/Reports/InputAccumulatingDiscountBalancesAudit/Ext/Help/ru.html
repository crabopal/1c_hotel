Отчет "Аудит ввода нач. остатков по нак. скидкам и бонусам"

Назначение

Имя отчета в конфигураторе «InputAccumulatingDiscountBalancesAudit».

Отчет используется для аудита операций по вводу начальных остатков по накопительным скидкам и бонусам.

Отчет формируется по документам.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По дате - задает отбор по дате создания документа  

Группировки

  • Группа – объединяет несколько гостей, но может также состоять и из одного гостя. Каждый гость обязательно принадлежит какой-либо группе. Номер группы – это номер брони. В разрезе групп ведется учет взаиморасчетов с контрагентами.
  • Контрагент – ссылка на справочник контрагентов или клиентов, заполняется из документа «Ввод нач. остатков по нак. скидкам», поле "Измерение скидки".
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Документ - ссылка на документ "Ввод нач. остатков по нак. скидкам".
  • Тип скидки - ссылка на справочник "Типы скидок".
  • Дата - дата документа.

Колонки

  • Ресурс
  • Бонус
  • Оплачено бонусами - документ платеж по группе, в способе оплаты которого включен флаг "Оплата бонусами"
  • Платеж бонусами - ссылка на документ платеж.
