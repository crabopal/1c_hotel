Отчет "Отгруженные путевки"

Назначение

Имя отчета в конфигураторе «IssuedHotelProducts».

Отчет позволяет получить список отгруженных путевок по накладным на отгрузку (документам "Отгрузка путевок"). Период отчета отбирает путевки по дате и времени накладных.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По типу путевки - задает отбор по типу путевки/курсовки (группе справочника путевок/курсовок). Если поле оставить пустым, то будут выведены данные по всем типам путевок.
  • По основным параметрам взаиморасчетов - по контрагенту, по договору, по группе гостей.

Группировки

  • Номер накладной на отгрузку – номер документа.
  • Фирма - юр.лицо гостиницы, от имени которой оформлено размещение гостя.
  • Договор – ссылка на договор контрагента, используется как разделитель учета взаиморасчетов с контрагентом.
  • Валюта - валюта накладной.
  • Контрагент – юр.лицо, заключившее с гостиницей договор, на основании которого произведено размещение гостя.
  • Группа – объединяет несколько гостей, но может также состоять и из одного гостя. Каждый гость обязательно принадлежит какой–либо группе.
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Тип путевки - В справочнике путевок/курсовок задается в качестве родительской папки.
  • Накладная на отгрузку - элемент справочника «Накладные на отгрузку путевок», указывает на документ данной путевки.
  • Дата отгрузки - дата отгрузки путевки без времени.
  • Месяц отгрузки - номер месяца отгрузки.
  • Квартал отгрузки - номер квартала отгрузки.
  • Неделя отгрузки - номер недели.
  • Год отгрузки - год отгрузки.

Колонки

  • Дата заезда – дата заезда согласно путевке.
  • Дата выезда – дата выезда, указанная в путевке.
  • Количество - количество отгруженных путевок. Применяется для вывода итогового значения в отчете.
  • Продолжительность - длительность проживания по путевке.
  • Дата и время отгрузки - дата и время отгрузки путевки.
  • Сумма – сумма, на которую были отгружены путевки.
