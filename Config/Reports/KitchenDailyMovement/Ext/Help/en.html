Отчет "Движение гостей для кухни"

Назначение

Имя отчета в конфигураторе «KitchenDailyMovement».

Отчет выводит на каждую дату из периода отчета количества гостей по видам питания по 3 параметрам: количество проживающих гостей со вчера; количество гостей на выезде; количество гостей на заезде. По каждому виду питания рассчитываются количества взрослых, детей и их сумма

Отборы на форме отчета

  • Период отчета – отбирает за какой период сформировать отчет.
  • Гостиница – задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • Номер – задает отбор по номеру комнаты или по группе номеров.
  • Тип номера – задает отбор по типу номера или по группе типов номеров.

Группировки

  • Учетная дата.
  • Вид гостей: проживающие, выезжающие или заезжающие.
  • Вид питания – ссылка на элементы справочника "Пакеты услуг" с включенной галочкой "Это питание"

Колонки

  • Количество взрослых.
  • Количество детей – все кто младше 18 или младше чем возраст детей указанный в карточке гостиницы.
  • Общее количество
