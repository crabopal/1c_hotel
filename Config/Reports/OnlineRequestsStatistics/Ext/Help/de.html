Отчет "Статистика он-лайн запросов"

Назначение

Имя отчета в конфигураторе «OnlineRequestsStatistics».

Отчет позволяет вывести частоту обращений из модуля он-лайн бронирования отеля к тем или иным датам. Отчет визуализирует данные регистра сведений "Запросы из он-лайн систем" 

Отборы на форме отчета

  • По периоду - задает отбор анализируемого периода дат.
  • По гостинице.
  • По коду внешней системы.
  • По utm_source метке.

Группировки

  • Дата – Дата из периода запроса наличия номеров.
  • Месяц – номер месяца из периода запроса наличия номеров.
  • Квартал – номер квартала из периода запроса наличия номеров.
  • Неделя – номер недели из периода запроса наличия номеров.
  • Год – год из периода запроса наличия номеров.
  • Код внешней системы – имя внешней системы из которой приходили запросы наличия номеров. Для он-лайн модуля сайта отеля обычно 1CBITRIX 
  • Гостиница – название гостиницы, в которую выполнялся запрос наличия номеров.
  • utm_source – UTM метка utm_source.
  • utm_medium – UTM метка utm_medium.
  • utm_campaign – UTM метка utm_campaign. 

Колонки

  • Кол-во запросов – кол-во запросов на дату.
