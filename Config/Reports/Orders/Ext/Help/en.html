Отчет "Заказы"

Назначение

Имя отчета в конфигураторе «Orders».

Отчет позволяет получить детальную распечатку заказов.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По номеру - задает отбор по номеру, если поле оставить пустым, то будут выведенные данные по всем номерам гостиницы.
  • По клиенту - задает отбор по клиенту, если поле оставить пустым, то будут выведенные данные по всем клиентам гостиницы.
  • По группе гостей - задает отбор по группе гостей, если поле оставить пустым, то будут выведенные данные по всем группам гостей гостиницы.
  • По типу заказа - задает отбор по типу заказов, если поле оставить пустым, то будут выведенные данные по всем типам заказов гостиницы.
  • По услуге - задает отбор по услуге, если поле оставить пустым, то будут выведенные данные по всем типам услуг гостиницы.
