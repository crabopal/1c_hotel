Отчет "Телефонные разговоры"

Назначение

Имя отчета в конфигураторе «PhoneCalls». 

Отчет позволяет получить детальную распечатку зарегистрированных в программе телефонных разговоров. 

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам. 
  • По типу разговора - международный, местный, сотовый и т.д. 
  • По номеру телефона - задает отбор по номеру телефона. 
  • По номеру - задает отбор по номеру, если поле оставить пустым, то будут выведенные данные по всем номерам гостиницы. 

Группировки

  • Учетная дата - дата звонка (без времени) по данным программы управления отелем. 
  • Учетный час - час звонка, когда он был загружен в программу. 
  • Учетный месяц - номер месяца звонка. 
  • Учетный квартал - номер квартала. 
  • Учетная неделя - номер недели. 
  • Учетный год - год звонка. 
  • Автор - имя пользователя, выполнившего начисление. 
  • Дата разговора - дата звонка по данной биллинговой системе. 
  • Час разговоров - час разговора по тарификатору. 
  • Месяц разговоров - номер месяца разговора. 
  • Квартал разговоров - номер квартала. 
  • Неделя разговоров - номер недели. 
  • Год разговоров - год разговора. 
  • Фирма – юр.лицо гостиницы (организация) по которой проводили начисление. Используется как разделитель учета при многофирменном учете. 
  • Валюта. 
  • Дата курса. 
  • Фолио – лицевой счет, на который была начислена услуга. 
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета. 
  • Услуга на каждый разговор – элемент справочника «Услуги», начисляемая как разовый сбор на каждый разговор. 
  • Ставка НДС услуги на каждый телефонный разговор. 
  • Цена включает НДС – признак того, что колонка «Цена» включает в себя Сумму НДС. 
  • Регион телефонного разговора – текст, пояснение по поводу региона звонка. 
  • Услуга – услуга за которую начисляется стоимость разговора. 
  • Тип телефонного разговора – внутренний, межгород, международный и пр. 
  • Номер – номер гостиницы, из которого был разговор. 
  • Номер телефона куда был звонок. 
  • Единица измерения – обычно минута. 
  • Ставка НДС – указание ставки НДС. 

Колонки

  • Начисление - ссылка на документ. 
  • Начисление на каждый разговор - флажок, который показывает, что кроме стоимости самого разговора начислен еще и разовый сбор. 
  • Сумма начисления на каждый разговор – сумма разового сбора. 
  • Сумма НДС услуги на каждый телефонный разговор. 
  • Период – дата и время начисления услуги. 
  • Дата и время телефонного разговора - дата и время звонка по данным биллинговой системы. 
  • Телефонный номер – из справочника «Телефонные номера», номер, с которого был звонок. 
  • Цена – цена минуты разговора. 
  • Количество – количество минут разговора. 
  • Регистратор – ссылка на документ «Регистрация телефонного разговора». 
  • Примечания – текстовый комментарий. 
  • Сумма – произведение цены на сумму начислений на каждый разговор. 
  • Сумма НДС – сумма НДС для колонки «Сумма».
