Отчет "Динамика продаж (Pickup)"

Назначение

Имя отчета в конфигураторе «Pickup».

Отчет позволяет получить кросс-таблицу динамики продаж номеров в разрезе дат проживания и дат бронирования. Основное отличие от отчета "Обороты продаж номеров" в том, что в оборотах продаж выводится число проданных номеров на дату, которое является разницей между суммой забронированных номеров и номеров в отмененной брони, а в отчете по динамике продаж число забронированных номеров и число отмененных бронирований номеров показывается в разных колонках, причем отмены бронирований учитываются на дату аннуляции.

Отборы на форме отчета

  • Период проживания - задает период дат проживания, на который выводятся число проданных и аннулированных номеров. 
  • Период бронирования - задает период дат бронирования, на который выводятся число проданных и аннулированных номеров. 
  • По контрагенту – по компании указанной в поле "Заказчик" брони, причем не важно является ли эта компания плательщиком или нет
  • По агенту – по агенту указанному в брони
  • По группе – по группе указанной в брони
  • По типу номера – по типу номера указанному в брони
  • По источнику – по источнику указанному в брони
  • По коду маркетинга – по сегменту указанному в брони
  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.

Группировки

  • Учетная дата – дата из периода проживания
  • Дата бронирования - дата создания/изменения/аннуляции брони
  • Учетный месяц – месяц из периода проживания. 
  • Месяц бронирования - месяц создания/изменения/аннуляции брони
  • Учетный квартал – номер квартала учетной даты из периода проживания
  • Квартал бронирования - номер квартала создания/изменения/аннуляции брони
  • Учетная неделя – номер недели в году, на которую приходится учетная дата из периода проживания
  • Неделя бронирования - номер недели создания/изменения/аннуляции брони
  • Учетный год – числовое значение года учетной даты из периода проживания. Может использоваться для создания отчета сравнивающего динамику продаж за несколько лет
  • Год бронирования – числовое значение года создания/изменения/аннуляции брони. Может использоваться для создания отчета сравнивающего динамику продаж за несколько лет
  • Тип номера – ссылка на справочник типов номеров
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Отчетная валюта

    Колонки

    • Продано номеров/мест/доп. мест/чел. дней – количество проданных номеров/мест/доп. мест/чел. дней = кол-во забронированных номеров/мест/доп. мест/чел. дней - кол-во аннулированных номеров/мест/доп. мест/чел. дней на дату проживания
    • Забронировано номеров/мест/доп. мест/чел. дней – количество забронированных номеров/мест/доп. мест/чел. дней на дату проживания 
    • Аннулировано номеров/мест/доп. мест/чел. дней – количество аннулированных номеров/мест/доп. мест/чел. дней на дату проживания 
    • Незаезд номеров/мест/доп. мест/чел. дней – количество аннулированных номеров/мест/доп. мест/чел. дней на дату проживания по статусам брони с включенной галочкой "Это незаезд"
    • Доходы от продажи номеров
    • Доходы от бронирования номеров
    • Доходы в аннулированной брони
    • Доходы в брони со статусами Незаезд
    • Те же суммы, но за вычетом НДС
