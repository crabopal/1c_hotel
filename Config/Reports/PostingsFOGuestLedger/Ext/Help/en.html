Отчет "Балансы по счету Guest Ledger"

Назначение

Имя отчета в конфигураторе «PostingsFOGuestLedger».

Отчет позволяет получить на дату распечатку открытых балансов по счету Guest Ledger. Итог по отчету дает сумму, которую проживающие гости должны отелю. Балансы в отчете сгруппированы в 4 группы:

  1. Балансы по доп. услугам гостей, за проживание которых оплачивают компании
  2. Балансы частных лиц и гостей проживающих бесплатно
  3. Балансы за которые оплачивают компании
  4. Балансы по финансовым лицевым счетам и лицевым счетам клиентов не проживающий в номерном фонде

Суммы показываются в разбивке:

  1. За проживание
  2. За остальные услуги

Сумма за проживание формируется по счетам, у которых тип счета совпадает с типом указанным в параметрах отчета.

Отборы на форме отчета

  • Дата - дата, на конец которой формируется баланс
  • Гостиница - задает отбор по гостинице
  • Контрагент - задает отбор по организации - плательщику

Группировки

  • Группа данных отчета
  • Контрагент

Колонки

  • Номер комнаты
  • Лицевой счет проживания
  • Лицевой счет доп. услуг
  • Клиент
  • Дата заезда
  • Дата выезда
  • Баланс за проживание
  • Баланс за остальные услуги
