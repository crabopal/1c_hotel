Отчет "Анализ продаж"

Назначение

Имя отчета в конфигураторе «PostingsFOIncomeAnalysis».

Отчет позволяет получить кредитовый оборот по счетам учета доходов за выбранную дату, период с начала месяца, период с начала года.

Отборы на форме отчета

  • Гостиница - задает отбор по гостинице.
  • Счет - задает отбор по счету из плана счетов
  • Тип счета - задает отбор по типу счетов
  • Группа счетов - задает отбор по группе счетов (по умолчанию - это группа счетов доходов)
  • Номенклатурная группа - задает отбор по номенклатурной группе

Группировки

  • Номенклатурная группа
  • Тип счета

Колонки

  • Счет
  • Наименование счета
  • Сумма за дату
  • Сумма за период с начала месяца
  • Сумма за период с начала года
