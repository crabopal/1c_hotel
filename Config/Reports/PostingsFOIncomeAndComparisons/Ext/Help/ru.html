Отчет "Сравнение доходов по данным проводок ФО"

Назначение

Имя отчета в конфигураторе «PostingsFOIncomeAndComparisons».

Отчет формируется по всем счетам бухгалтерского плана счетов. Для каждого счета по данным регистра бухгалтерских проводок рассчитываются 6 сумм: оборот по счету за указанный день, за период с начала месяца, за период с начала года, за указанный день в прошлом году, за период с начала месяца прошлого года, за период с начала года прошлого года. Далее по каждому показателю считается разница между суммами этого и прошлого года и процент изменения по сравнению с данными прошлого года.

Данные в отчете группируются по: знаку счета (кредит/дебит), группе счетов, типу счетов
