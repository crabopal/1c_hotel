Отчет "Оборотно-сальдовая ведомость по данным проводок ФО"

Назначение

Имя отчета в конфигураторе «PostingsFOTurnoverBalanceSheet». 

Отчет формируется по всем счетам бухгалтерского плана счетов. Для каждого счета по данным регистра бухгалтерских проводок рассчитываются следующие суммы: баланс (сальдо) по счету на начало периода отчета, кредитовый оборот по счету за период, дебетовый оборот по счету за период, баланс (сальдо) на конец периода отчета.

Данные в отчете группируются по: знаку счета (кредит/дебит), группе счетов, типу счетов, счету
