Отчет "Аудит аннуляций брони ресурсов"

Назначение

Имя отчета в конфигураторе «ResourceReservationAnnulations».

Отчет используется для аудита аннулированной (отмененной) брони ресурсов. Отчет выводит бронь аннулированную за указанный период. Бронь считается аннулированной, если у нее установлен не действующий статус и бронь не находится в статусе завершена. 

Отборы на форме отчета

  • Период отчета – отбирает брони аннулированные в выбранном периоде (по дате и времени установки не действующего статуса брони).
  • Гостиница – задает отбор по гостинице, если поле оставить пустым, то будут показаны данные по всем гостиницам.
  • Контрагент – задает отбор по организации или по группе организаций.
  • Ресурс – задает отбор по ресурсу.
  • Тип ресурса – задает отбор по типу ресурса или по группе типов ресурсов.
  • Сотрудник – задает отбор по сотруднику или по группе сотрудников, проведшему аннулирование.

    Группировки

    • Статус брони – разделитель учета, задается в документе «Бронь ресурсов», обычно принимает значения «Действует», «Отказ» и т.д. Используется в отчетах и отборах.
    • Агент – ссылка на справочник контрагентов, указывает контрагента, который получает комиссию за гостя. Может также использоваться для аналитики работы агентов или туроператоров.
    • Автор – сотрудник, оформивший гостя (пользователь, создавший документ «Размещение»).
    • Учетная дата аннуляции – дата аннуляции брони. Не содержит времени аннуляции. Используется для отбора и группировки.
    • Учетная дата начала периода – дата планируемого начала периода бронирования ресурса. Не содержит времени. Используется для отбора и группировки.
    • Учетная дата окончания периода – дата планируемого окончания периода бронирования ресурса. Не содержит время. Используется для отбора и группировки.
    • Тип клиента – значение типа клиента. Ссылка на справочник «Типы клиентов».
    • Контактное лицо – ссылка на одноименное текстовое поле в документе «Бронь». Указывает на лицо, бронировавшее данный номер от имени клиента. Обычно указывается при бронировании для контрагентов.
    • Договор – значение договора из «Брони».
    • Контрагент – ссылка на справочник «Контрагенты», от имени которого приехал гость. От имени этого контрагента обычно и было оформлено бронирование.
    • Тип контрагента – значение типа контрагента, указанное в «Брони». Может использоваться для группировки и отбора.
    • Дисконтная карта – ссылка на справочник дисконтных карт. Заполняется при поселении или бронировании, если гость предъявил карту или продиктовал ее номер.
    • Тип скидки – разделитель учета, ссылка на справочник «Тип скидок». Установка соответствия между набором услуг и размером скидки.
    • Клиент – ссылка на справочник «Клиентов», карточка основного клиента брони.
    • Группа – объединяет несколько броней ресурсов и, возможно, номеров, но может также состоять и из одного бронирования. Каждая бронь обязательно принадлежит какой-либо группе. Номер группы – это номер брони. В разрезе групп ведется учет взаиморасчетов с контрагентами.
    • Гостиница – название гостиницы, в которой выполняется бронирование. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
    • Направление маркетинга – ссылка на элемент справочника «Направления маркетинга». Используется для анализа, может быть использован в группировках и отборах.
    • Планируемый способ оплаты – значение планируемого способа оплаты в документе «Бронь». Берется у фолио брони ресурсов. Обычно, если бронь оплачивает контрагент, то значение будет «На расчетный счет».
    • Цена – значение цены за час/минуту аренды ресурса. Строка, включающая знак валюты и тип дня календаря. Значение заполняется автоматически при проведении «Брони».
    • Регистратор – ссылка на документ «Бронь ресурса».
    • Ресурс – забронированный ресурс.
    • Тип ресурса – ссылка на справочник «Типы ресурсов».
    • Источник информации – ссылка на аналитический справочник «Источник информации о гостинице». Используется для анализа рекламных источников. Данное значение может быть обязательным полем для заполнения при бронировании.  

    Колонки

    • Комиссия агента – значение комиссии агента, начисляемой за проживание гостя.
    • Тип комиссии агента – значение типа комиссии, может быть одно из значений перечисления «Виды комиссий агентам». Стандартное значение – «%», процент.
    • Автор аннуляции - сотрудник, проведший аннуляцию брони.
    • Автомобиль – строковое значение поля «Автомобиль» из размещения, которое заполняется вручную при поселении или при бронировании.
    • Дата и время начала периода бронирования.
    • Дата и время окончания периода бронирования.
    • Скидка – значение скидки в процентах.
    • Продолжительность – указывается в часах или минутах в зависимости от выбранного ресурса.
    • Кол-во персон – количество персон на мероприятии.
    • Цена в брони – по какой цене было произведено бронирование.
    • Количество аннулирований - количество аннулированных документов "Бронь ресурса".
    • Примечания – срока, значение из документа «Бронь ресурса».
