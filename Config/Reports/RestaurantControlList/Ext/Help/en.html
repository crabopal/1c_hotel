Отчет "Список гостей на питание"

Назначение

Имя отчета в конфигураторе «RestaurantControlList».

Отчет выводит список номеров и проживающих/заезжающих гостей, которым положено питание. Услуги питания начисленные гостям должны входить в набор услуг указываемый в качестве параметра отчета или должны совпадать/входить в группу услуг, также указываемую в качестве параметров отчета. По каждому номеру отчет выводит фамилию гостя, кол-во гостей в номере по возрастам, тип питания гостя и количество уже зарегистрированных проходов гостя на завтрак, обед и ужин. Регистрация проходов осуществляется в форме "Список гостей на питание" доступной в меню Ресторан.

Отборы на форме отчета

  • По гостинице - задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • По номеру - задает отбор по номеру. Если поле оставить пустым, то будут выведены данные по всем номерам.
  • По типу номера - задает отбор по типу номера. Если поле оставить пустым, то будут выведены данные по всем типам номеров.
  • По контрагенту - задает отбор по организации. Если поле оставить пустым, то будут выведены данные по всем организациям и свободное размещение.

Группировки

  • Номер – обычно группа справочника «Номерной фонд».
  • Тип номера – ссылка на справочник «Типы номеров».  
  • Тип питания – услуга или пакет услуг, который определяет вид питания гостя.
  • Контрагент – юр.лицо, заключившее с гостиницей договор, на основании которого произведено размещение гостя.
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.

Колонки

  • Номер – обычно группа справочника «Номерной фонд».
  • Тип питания – услуга или пакет услуг, который определяет вид питания гостя.
  • Гость – клиент, справочник «Клиенты».
  • Тип клиента – тип гостя, справочник «Типы клиентов».
  • Контрагент – организация от которой проживает гость, справочник «Контрагенты».
  • Дата заезда – дата и время заезда, указанная в брони.
  • Дата выезда – дата и время выезда, указанная брони.
  • Продолжительность проживания брони.
  • Шаблон размещения гостей.
  • Документ основание – ссылка на документ «Бронь» или «Размещение» основного гостя в номере.
  • Кол-во взрослых гостей в номере.
  • Кол-во подростков в номере.
  • Кол-во детей в номере.
  • Кол-во младенцев в номере.
  • Кол-во зарегистрированных завтраков
  • Кол-во зарегистрированных обедов
  • Кол-во зарегистрированных ужинов
