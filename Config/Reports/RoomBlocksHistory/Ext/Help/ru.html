Отчет "История блокировок номеров"

Назначение

Имя отчета в конфигураторе «RoomBlocksHistory».

Отчет выводит список блокировок номеров (ремонтов, аренд и проч.), действующих за указанный период по указанным гостиницам, номерам и типам номеров.

Отборы на форме отчета

  • По виду проверки периода отчета - проверка дат блокировок относительно периода формирования отчета. Проверок существует насколько видов:
    • пересечение - в отчете отобразятся блокировки, период действия которых пересекается с периодом отчета;
    • начинается в периоде - в отчет попадут только те блокировки, дата начала которых попадает в запрашиваемый период;
    • заканчивается в периоде - в отчет попадут только те блокировки, дата окончания которых попадает в запрашиваемый период;
    • начинается или заканчивается в периоде - в отчет попадут только те блокировки, дата начала или окончания которых попадает в запрашиваемый период;
    • дата создания документа попадает в период - в отчете отобразятся блокировки, которые были созданы в периоде отчета.
  • По номеру - задает отбор по номеру.
  • По типу блокировки - задает отбор по услуге, если поле оставить пустым, то будут выведены данные по всем типам блокировки.
  • По типу номера - задает отбор по типу номера, если поле оставить пустым, то будут выведены данные по всем типам номеров гостиницы.

Группировки

  • Автор – пользователь, создавший документ «Установить блокировку номера».
  • Учетная дата начала блокировки – дата начала блокировки (без указания времени).
  • День начала блокировки - день начала.
  • Час начала блокировки - час начала.
  • Месяц начала блокировки - номер месяца начала блокировки.
  • Квартал начала блокировки - номер квартала.
  • Неделя начала блокировки - номер недели начала действия.
  • Год начала блокировки - год начала блокировки.
  • Учетная дата окончания блокировки – дата окончания блокировки (без указания времени).
  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Регистратор – ссылка на документ «Установить блокировку номера».
  • Номер – указывает номер заблокированной комнаты.
  • Тип блокировки – указывает вид блокировки номера (ремонт и пр.).
  • Тип номера – ссылка на справочник «Типы номеров», указывает на тип заблокированного номера.

Колонки

  • Мест – количество мест в заблокированном номере.
  • Начало действия блокировки – дата начала действия блокировки, см. документ «Установить блокировку номера».
  • Окончание действия блокировки – дата и время конца действия блокировки, см.документ «Установить блокировку номера».
  • Продолжительность – разница дат конца и и начала блокировки.
  • Блокировка снята – булев флаг, указывает, снята ли в настоящее время блокировка.
  • Период – дата и время начала действия, время с секундами.
  • Момент времени - дата и время начала действия блокировки до секунд.
  • Примечания – текстовое пояснение причины блокировки.
  • Номеров – количество заблокированных номеров.
