Отчет "Время статуса комнаты"

Назначение

Имя отчета в конфигураторе «RoomStatusTime».

Отчет позволяет распечатать время нахождения номера в текущем статусе на момент времени.

Отборы на форме отчета

  • По статусу номера - задает отбор по статусу номера , если поле оставить пустым, то будут выведенные данные по всем статусам номеров гостиницы.
  • По типу номера - задает отбор по типу номера, если поле оставить пустым, то будут выведенные данные по всем типам номеров гостиницы.
  • По группа номеров - задает отбор по группе номеров, если поле оставить пустым, то будут выведенные данные по всем группам номеров гостиницы.
  • По секции номеров - задает отбор по секции номера, если поле оставить пустым, то будут выведенные данные по всем секциям номеров гостиницы.

Группировки

  • Группа – группа номеров.

Колонки

  • Период - дата и время изменения статуса.
  • Время нахождения в текущем статусе - Прошедшее время с установки текущего статуса на момент времени.
  • Примечания - если статус номера был изменен программой автоматически при заселении или выселении гостя, то примечание будет заполнено. Если примечание пустое, значит, статус был изменен вручную.
