Отчет "Аудит повышений категории номеров"

Назначение

Имя отчета в конфигураторе «RoomUpgradesAudit».

Отчет используется для аудита операций продажи номера по стоимости другого типа номера. Технически отчет показывает кто из сотрудников и когда в указанном периоде времени заполнил в брони или размещении поле "Тип номера цены" и этот тип номера отличается от типа забронированного номера или номера проживания.

Отборы на форме отчета

  • Период отчета – отбирает за какой период сформировать отчет.
  • Гостиница – задает отбор по гостинице, если поле оставить пустым, то будут выведены данные по всем гостиницам.
  • Номер – задает отбор по номеру комнаты или по группе номеров.
  • Тип номера – задает отбор по типу номера или по группе типов номеров.
  • Сотрудник – задает отбор по сотруднику, выполнившему изменение.

Группировки

  • Автор изменений – сотрудник выполнивший повышение категории.
  • Дата действия - номер, куда заехал гость изначально.
  • Гость – ссылка на справочник «Клиенты», ссылка на карточку гостя на момент окончания периода отчета.
  • Номер – номер комнаты, в который поселен/забронирован гость на момент окончания периода отчета.
  • Тип номера – указывает на тип номера, в котором размещен/забронирован гость на момент окончания периода отчета.
  • Тип номера цены – указывает на тип номера по которому рассчитывается стоимость проживания 

Колонки

  • Дата заезда – дата и время заезда гостя.
  • Дата выезда – значение даты и времени выезда.
  • Продолжительность – продолжительность проживания гостя в днях или часах, в зависимости от выбранного тарифа. Если в тарифе цена указана за сутки, то продолжительность рассчитывается в днях. Если цена указывается за час, то продолжительность рассчитывается в часах.
  • Группа – объединяет несколько гостей, но может также состоять и из одного гостя на данный момент. Каждый гость обязательно принадлежит какой – либо группе. Номер группы – это номер брони. В разрезе групп ведется учет взаиморасчетов с контрагентами.
  • Гостиница – название гостиницы, в которой размещен гость на данный момент. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Статус размещения/брони.
  • Вид размещения гостя в брони/размещении.
  • Шаблон размещения
  • Причина изменения цены
  • Примечания СПиР в брони/размещении
  • Тариф.
  • Прочие параметры из карточки брони / размещения
