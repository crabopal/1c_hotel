Отчет "Номерной фонд"

Назначение

Имя отчета в конфигураторе «Rooms».

Отчет используется для контроля правильности ввода номерного фонда и для формирования списка номеров по статусам.

Отборы на форме отчета

  • По типу номера - задает отбор по типу номера или группе типов номеров.
  • По номеру - задает отбор по группе номеров или одному номеру комнаты. Если поле оставить пустым, то будут выведены данные по всем номерам гостиницы.

Группировки

  • Гостиница – название гостиницы, в которой размещен гость. Если в одной базе ведется учет по нескольким гостиницам, используется как разделитель учета.
  • Есть блокировки – признак того, что в текущем номере есть действующие блокировки.
  • Номер – указан номер комнаты.
  • Тип номера – указывает тип номера, ссылка на справочник «Типы номеров».
  • Статус номера – ссылка на справочник «Статусы номеров», указывает статус номера, который обычно меняется при заезде и выселении из номера и обычно принимает значения «Занят», «Свободен», «Грязный», «Чистый».

Колонки

  • Мест – число мест в данном номере.
  • Номеров – число номеров.
  • Примечания – текстовый комментарий.
