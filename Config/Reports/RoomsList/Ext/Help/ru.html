Отчет "Список номеров"

Назначение

Имя отчета в конфигураторе «RoomsList».

Список номеров с группировкой по статусу номера.

Выводимые показатели

  • Статус номера – указание наименования из справочника «Статусы номеров».
  • Номер – указание наименования из справочника «Номерной фонд».
  • Тип номера – указание кода из справочника «Типы номеров».
