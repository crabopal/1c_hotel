Отчет "РОССТАТ – Сведения о количестве иностранных граждан по целям визита – Квартальная"

Назначение

Имя отчета в конфигураторе «RosstatForeignersQuarterly».

Сведения о количестве иностранных граждан и о количестве мест для их размещения (нарастающим итогом с начала года).

Выводимые показатели

  • Код страны – указание кода из справочника «Страны».
  • Страна (гражданство) – ссылка на справочник «Страны».
  • Количество дней пребывания (человеко-дней) – продолжительность заезда, выраженная в человеко-днях.
  • Всего иностранных посетителей (человек) – количество человек с данной целью визита.
  • В том числе – по целям поездки (служебная, туризм, частная, работы по найму).
  • Общее количество номеров – количество номеров, занятых для текущей цели визита.
  • Общее количество мест – количество мест, занятых для текущей цели визита.
