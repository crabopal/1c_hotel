Отчет "Отправленные СМС сообщения"

Назначение

Имя отчета в конфигураторе «SMSBeingSent».

Отчет распечатывает отправленные из программы СМС сообщения сохраненные в регистре "Отправленные СМС сообщения". Отчет позволяет группировать итоги по количеству отправленных СМС сообщений и количеству отправленных сегментов сообщений в разрезе клиентов, сотрудников, статусов доставки и шаблонов. 

Отборы на форме отчета

  • По периоду. Если даты оставить пустыми, то отчет будет сформирован по всей истории отправленных СМС. 
  • По статусу доставки. Отчет выведет только сообщения с выбранным статусом доставки. 
  • По сотруднику. Отчет выведет сообщения отправленные выбранному сотруднику. 
  • По отделу. Отчет выведет сообщения отправленные сотрудникам выбранного отдела. 
  • По шаблону - Отчет выведет только те сообщения, которые были созданы по выбранному шаблону. 

Группировки

  • Номер телефона – номер телефона на который отправлялись СМС. 
  • Статус доставки - статус доставки СМС до получателя. 
  • Шаблон - шаблон по которому было создано СМС. 
  • Отдел – отдел сотрудников получателей сообщений. 
  • Сотрудник – сотрудник получатель сообщения. 
  • Результат - статус доставки СМС сообщения до СМС шлюза. 
  • Отправитель - строка или телефонный номер, которые указывались в СМС в качестве отправителя. 
  • Клиент - клиент отеля которому отправлялись СМС сообщения. 
  • Документ клиента – размещение или бронь клиента. 
  • Статус брони/размещения – статус документа на момент отправки СМС сообщения об изменении статуса брони/размещения. Реквизит позволяет получить итоги по количеству отправленных СМС в разрезе статусов брони/размещения. 
  • Дата, номер недели, номер месяца, номер квартала, год отправки СМС сообщений. Позволяют сгруппировать данные отчета по периодам.

Колонки

  • Количество сообщений - кол-во отправленных логических сообщений. 
  • Количество сегментов сообщений - кол-во сегментов которые на самом деле были отправлены получателям СМС сообщений и которые учитывались при тарификации и изменении остатка количества доступных для отправки СМС. 
  • Стоимость - стоимость отправленного СМС. 
  • Период - дата и время отправки СМС. 
  • ID сообщения – уникальный идентификатор СМС сообщения в шлюзе. 
  • Текст сообщения.
